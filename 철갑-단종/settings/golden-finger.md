# 금수저 설계 템플릿 라이브러리

> **목적**: 체계적인 금수저 설계 프레임워크를 제공하여, 금수저 설정의 합리성, 시각화, 쾌감 출력 능력을 보장한다.

---

## 📋 금수저 설계 핵심 원칙

### 1. 기능성 원칙
- **명확한 포지셔닝**: 금수저에 명확한 핵심 기능 필수 (레벨업 보조/전투 증폭/자원 획득)
- **성장성**: 금수저는 주인공 성장과 함께 업그레이드되어야 하며, "불변" 방지
- **제한성**: 합리적 제한 필수 (쿨타임/자원 소모/사용 조건), "무적 치트" 방지

### 2. 시각화 원칙
- **패널화**: 패널/속성 표시로 독자에게 직관적 데이터 피드백
- **진행바**: 스킬 숙련도, 경험치 등에 진행바 사용
- **즉시 피드백**: 사용 후 즉시 효과 표시 (+10 힘/경계 돌파 알림)

### 3. 쾌감 임베딩 원칙
- **획득 쾌감**: 금수저 최초 획득 시 의식감
- **성장 쾌감**: 금수저 업그레이드/새 기능 해금
- **사용 쾌감**: 핵심 순간 금수저 발휘 (때리기/역전)

| 발동 조건 | 언제 발효 | 특정 장면 / 쿨타임 완료 / 대가 지불 |

## 🧩 대가/제한 라이브러리 (흔한)

- **수명/건강**: 매 사용 시 수명 단축 또는 신체 손상
- **기억/감정**: 중요 기억 상실, 감정 냉각
- **자원 소모**: 영석/골드/공헌포인트/신용포인트
- **관계 대가**: 신뢰 투자, 인간관계 붕괴
- **규칙 반작용**: 월급 시 반작용, 강제 쿨타임
- **정보 대가**: 정보 획득 시 동량 정보 상실

## 🛡️ 반제 방식 라이브러리 (흔한)

- **규칙 차단**: 적대 규칙이 금수저 실효시킴
- **공급 차단**: 자원/시스템 포인트 차단
- **미러 대항**: 반파가 동류 능력 보유
- **오도 이용**: 시스템 힌트가 역이용됨
- **대가 전가**: 반파가 주인공에게 더 많은 대가 부담시킴

---

## ⏱️ 쾌감/피드백 리듬 템플릿

- **소보상**: 매 2-3장 최소 1회 감지 가능한 피드백
- **중보상**: 매 8-10장 1회 명백한 업그레이드
- **대보상**: 매 20-30장 1회 버전 교체
- **대가 이행**: 매 대보상 전후 반드시 대가 이행

### 유형 2: 휴대 공간류

**핵심 메커니즘**: 비밀 저장 공간 + 특수 기능

**표준 공간 속성**:

```markdown
【휴대 공간】

기초 파라미터:
- 공간 크기: 100㎡ (업그레이드 가능)
- 시간 유속: 외부 1일 = 공간 10일
- 재배 가속: 영약 성장 속도 +500%
- 저장 기능: 동류 물품 무한 스택

특수 기능:
1. [시간 정지] - 음식/약품 보관 시 신선도 유지
2. [영기 농후] - 공간 내 수련 속도 +300%
3. [의념 수취] - 물품 접촉 즉시 공간에 수납
4. [생물 수납] - 영수/포로 수납 가능 (영력 소모 필요)
```

**업그레이드 경로**:
```markdown
등급 1 → 100 m² (초기)
등급 2 → 500 m² (축기기 + 영석 1000개 필요)
등급 3 → 1000 m² (금단기 + 영석 10000개 필요)
등급 4 → 소세계 (원영기 + 특수 기연 필요)
```

**쾌감 설계**:
- **비축 쾌감**: 말세/전란 전 미친 듯이 물자 비축
- **재배 쾌감**: 공간에서 영약 재배, 빠르게 자원 획득
- **숨기기 쾌감**: 핵심 순간 공간에서 대살기 꺼내기

### 유형 3: 환생/빙의류

**핵심 메커니즘**: 정보 차 우위

**선견지명 유형**:

```markdown
【환생 우위 목록】

1. 시간 노드 기억:
   - 3개월 후: 천운종 비경 개방
   - 6개월 후: 혈찰문 침입
   - 1년 후: 영맥 대폭발
   - 3년 후: 상고 유적 출세

2. 핵심 인물 정보:
   - 이설: 미래에 단성이 됨, 지금은 아직 외문 제자
   - 왕소: 겉은 천재, 실은 마수, 3년 후 반변
   - 운장로: 숨겨진 신분이 원영 대능

3. 보물/기연 위치:
   - 흑풍산맥 깊은 곳: 천뢰과수 (축기 신과)
   - 청운봉 뒤산: 상고 검총 입구
   - 천운성 경매회: 매월 15일 숨겨진 경매품
```

**엔티티 태그 형식**:
```xml
<entity type="미래사건" name="사건명칭" desc="사건설명" tier="등급" time="발생시간" strategy="대응전략"/>

예시:
<entity type="미래사건" name="비경개방" desc="천운종 뒤산 비경 개방, 내부에 축기단" tier="핵심" time="3개월후" strategy="사전에 통행 토큰 준비"/>
<entity type="미래사건" name="혈찰문침입" desc="사도 습격, 가문 위기" tier="핵심" time="6개월후" strategy="사전에 족인과 재산 이전"/>
```

### 유형 4: 출석류

**핵심 메커니즘**: 지속적 출석으로 보상 획득

**출석 시스템 설계**:

```markdown
【매일 출석 시스템】

출석 규칙:
- 일반 출석: 매일 1회 출석 가능, 기본 보상
- 연속 출석: 연속 출석 일수가 길수록, 보상 풍성
- 특수 장소 출석: 특수 장소에서 출석 시 추가 보상

보상 예시:
┌─────────────────────────────────┐
│ 1일차: 취기단 x3                │
│ 7일차: 축기단 x1                │
│ 30일차: 현품 공법 1권             │
│ 100일차: 천품 법보 1건            │
│ 365일차: 신급 혈맥 각성            │
└─────────────────────────────────┘

특수 출석점:
- [천운종 본전 출석]: 10배 종문 공헌 획득
- [비경 입구 출석]: 랜덤으로 비경 열쇠 획득
- [적대 종문 출석]: "대담한 광도" 업적 + 희귀 아이템 획득
```

**쾌감 리듬**:
- 매일 소쾌: 일반 출석 보상
- 매주 중쾌: 7일 출석 보상
- 매월 대쾌: 30일 출석 보상
- 연간 초쾌: 365일 출석 보상

### 유형 5: 노인 영혼/기령류

**핵심 메커니즘**: 스승 보조 + 지식 전수

**기령 설정 템플릿**:

```markdown
【기령: 검령·고진】

기본 정보:
- 진짜 신분: 상고 검선 잔혼
- 최고 경계: 도겁기
- 특기 분야: 검도, 연기, 진법
- 성격 특징: 츤데레 독설, 겉과 속이 다름

보조 기능:
1. [전공]: 주인공에게 검법/공법 전수 가능
2. [감정]: 보물 품급과 용도 감정 가능
3. [지도]: 전투 중 전략 조언 제공
4. [장서]: 상고 공법 라이브러리 보유

제한 조건:
- 공법 전수는 주인공 경계 도달 필요
- 매 지도 시 주인공 영력 소모
- 기령 회복에 특정 자원 필요 (영석/혈정)
```

**대화 스타일 예시**:
```markdown
❌ 틀림 (기계적):
"적 실력이 금단기로 감지됨, 철퇴 제안."

✅ 맞음 (의인화):
"이놈아, 맞은편 늙은이 기식이 웅후해, 최소 금단 후기야! 넌 지금 겨우 축기기인데, 올라가면 밥이 되는 거야! 빨리 뛰어, 이 늙은이한테 창피 주지 마!"
```

### 유형 6: 혈맥/천부형

**핵심 메커니즘**: 혈맥 각성으로 능력 도약, 성장 제한과 대가 동반.

**템플릿 요점**:
- 혈맥 출처: 원고 유족 / 신수 후예 / 조전 은맥
- 각성 조건: 생사 위기 / 특정 영약 / 감정 폭발
- 능력 제한: 각성 횟수 / 부작용 / 쿨타임

**예시**:
```markdown
【혈맥: 창룡지혈】
- 각성 조건: 빈사 시 발동
- 핵심 능력: 육신 강도 +200%, 속도 +50%
- 부작용: 각성 후 3일 정양 필요
```

---

### 유형 7: 이능 각성형 (도시 이능 전용)

**핵심 메커니즘**: 단일 또는 복합 이능 각성, 대가와 성장 상한 강조.

**템플릿 요점**:
- 이능 출처: 실험 사고 / 천부 유전 / 외래 물질 자극
- 상한과 대가: 체력 소모 / 정신 반작용 / 사용 횟수
- 진화 방향: 단선 강화 / 다분지 성장

**예시**:
```markdown
【이능: 시간 응고 (단시간)】
- 초기 상한: 3초 / 회
- 대가: 매 사용 시 30초 현기증
- 진화 방향: 지속 시간 연장 or 쿨타임 단축
```

---

### 금수저 없음 (순수 성장 노선)

**적용 장면**: 로맨스, 현실 장르, 즈후 단편 또는 반클리셰 장르.

**대체 강화점**:
- 주인공 천부: 특기/천부/극강 의지
- 특수 기회: 사승/자원/인맥
- 성장 노선: 스킬 트리/직업 경로/심리 성장

**주의**: 금수저 없음 ≠ "쾌감 없음", 쾌감을 캐릭터, 선택, 대가와 역전에 전이해야 함.

## 🛠️ 금수저 설계 워크플로

### Step 1: 핵심 포지셔닝 확정

**질문 목록**:
1. 주인공의 가장 큰 약점은? (수련 속도 느림/자원 부족/정보 부족)
2. 금수저가 어떤 문제를 해결하는가?
3. 금수저의 독특한 셀링포인트는?

### Step 2: 획득 방식 설정

**흔한 방식**:
- ✅ 우연한 융합 (고리 주움/벼락 맞음)
- ✅ 전승 활성화 (혈맥 각성/조전 보물)
- ✅ 시스템 강림 (신비한 목소리/광막 팝업)
- ❌ 피할 것: 갑자기 출현, 아무 이유 없이

### Step 3: 패널/인터페이스 설계

Markdown 테이블이나 ASCII 아트로 시각화 패널 설계

### Step 4: 업그레이드 노선 기획

```markdown
등급 1 → 등급 2 → 등급 3 → ... → 최종 형태
(주인공 경계 대응: 연기 → 축기 → 금단 → ...)
```

### Step 5: 쾌감 노드 임베딩

- 최초 획득: 충격감
- 최초 사용: 즉효적 효과
- 버전 업그레이드: 새 기능 해금
- 핵심 순간: 금수저 구명/역전

---

## ✅ 금수저 설계 체크리스트

**필수 요소**:
- [ ] 명확한 핵심 기능
- [ ] 시각화 패널/인터페이스
- [ ] 합리적 제한 조건
- [ ] 명확한 업그레이드 노선
- [ ] 임베딩된 쾌감 노드

**피해야 할 지뢰**:
- ❌ 기능이 너무 복잡, 독자가 기억 못함
- ❌ 아무 제한 없는 무적 치트
- ❌ 획득 방식이 너무 임의적
- ❌ 장기간 업그레이드 안 하여 신선함 상실

## 📝 엔티티 태그 확장 설명

금수저 시스템용으로 다음 XML 태그 유형 사용 가능:

```xml
<entity type="시스템모듈" name="모듈명칭" desc="기능설명" tier="등급" unlock="해금조건"/>
<entity type="시스템화폐" name="화폐명칭" desc="획득방식" tier="등급" initial="초기수량"/>
<entity type="시스템아이템" name="아이템명칭" desc="효과" tier="등급" grade="품급" source="획득경로"/>
<entity type="미래사건" name="사건명칭" desc="사건설명" tier="등급" time="발생시간" strategy="대응전략"/>
```

> **v5.0 도입 (v5.4 유지)**: 이 태그들은 **선택사항**입니다. Data Agent가 순수 본문에서 자동으로 엔티티를 추출할 수 있으며, 태그는 수동 표주 장면에만 사용됩니다.

## 📚 참고 사례

### 사례 1: 《전구고무》- 재부 전환 시스템
- 핵심 기능: 현실 돈 → 수련 자원
- 쾌감: 금수저 신분 + 현질로 강해짐
- 제한: 합법적으로 돈을 벌어야 하며, 강도 불가

### 사례 2: 《아유일좌모험옥》- 휴대폰 APP 시스템
- 핵심 기능: 휴대폰으로 임무 발표, 완수하면 보상
- 쾌감: 임무가 기기묘묘, 풍성한 보상
- 제한: 임무 실패 시 처벌

### 사례 3: 《수진채팅군》- 채팅방 시스템
- 핵심 기능: 선인 채팅방 가입, 수련 자원과 정보 획득
- 쾌감: 대인물과 교류, 세뱃돈 뺏기
- 제한: 채팅방 규칙 엄격, 규칙 위반 시 추방

**최종 알림**: 금수저는 강할수록 좋은 게 아니라, "교묘"할수록 좋다. 최고의 금수저는 주인공이 "노력+치트" 양날로 나아가게 하여, 불로소득처럼 보이지도 않으면서, 통쾌하게 적수를 압도할 수 있게 한다.
