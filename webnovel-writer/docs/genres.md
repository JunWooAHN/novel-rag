# 장르 템플릿 설명

시스템에 37개 이상의 웹소설 장르 템플릿이 내장되어 있으며, 단일 장르와 복합 장르를 지원합니다.

## 현판 수선류（예시）

- 수선(修仙)
- 시스템류
- 고무(高武)
- 서양 판타지
- 무한류
- 포스트아포칼립스
- SF

## 도시 현대류（예시）

- 도시 이능
- 도시 일상
- 도시 기발한 상상
- 현실 소재
- e스포츠
- 방송 소설

## 로맨스류（예시）

- 고대 로맨스
- 궁중/가문 암투
- 청춘 달달 로맨스
- 재벌 총재
- 직장 결혼 연애
- 민국 시대 로맨스
- 판타지 로맨스
- 현대 로맨스 기발한 상상
- 여성향 미스터리
- 전원 생활
- 시대물

## 복합 장르 규칙

- `장르A+장르B` 지원（최대 2개）
- 주/부 비율 7:3 권장
- 메인 스토리는 주 장르 로직을 따르고, 부 장르는 훅/규칙/쾌감 포인트를 제공

예시：

- `도시 기발한 상상+규칙 괴담`
- `수선+시스템류`
