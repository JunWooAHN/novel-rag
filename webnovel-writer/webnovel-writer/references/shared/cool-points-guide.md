## 1. 6가지 쾌감 포인트 실행 패턴

### 1. 허세 응징
```
상대가 경멸 → 주인공이 실력 전시 → 상대가 충격/후회
```
**적용**: 도시, 현환, 직장

### 2. 돼지 행세 호랑이
```
겉보기 약함 → 핵심 순간 폭발 → 모두 놀람
```
**적용**: 환생, 숨겨진 정체, 저자세류

### 3. 월급 역전
```
실력 격차 뚜렷 → 주인공 역전 → 적이 믿을 수 없어 함
```
**적용**: 현환, 무협, 경기

### 4. 권위 응징
```
권위가 의심 → 주인공이 실력으로 증명 → 권위가 인정/곤란
```
**적용**: 직장, 학원, 기술류

### 5. 악역 전복
```
악역이 득의 → 계획 파산 → 악역이 낭패
```
**적용**: 모든 장르

### 6. 달콤 초과 기대
```
평범한 일상 → 뜻밖의 깜짝 → 감정 온도 상승
```
**적용**: 로맨스, 달달물

## 2. 쾌감 포인트 3단 구조 (30/40/30 참고 프레임워크)

### 준비 단계 (Setup, 30% 분량)
- **기대 수립**: 독자가 무엇을 기대해야 하는지
- **반차 조성**: 현재 상태 vs 곧 보여줄 상태
- **정보 격차 설정**: 독자는 무엇을 아는가? 캐릭터는 무엇을 아는가?

### 실현 단계 (Delivery, 40% 분량)
- **트리거 시점**: 어떤 사건이 쾌감 포인트를 촉발하는가
- **전시 방식**: 대화/동작/결과로 전시
- **감정 절정**: 쾌감 포인트의 최고조 순간

### 미세 반전 단계 (Twist, 30% 분량)
- **가짜 종료**: 독자가 쾌감 포인트가 끝났다고 생각
- **한 수 더**: 사실 더 대단한 것이 있음
- **여운**: 미세 반전 후 상태와 암시

## 3. 억압과 해소 비율 제어

### 억압과 해소 비율 기준
| 장르 유형 | 억압-해소 비율 | 설명 |
|---------|---------|------|
| 전통 쾌감문 | 억압3 해소7 | 가벼운 억압, 빠른 해소 |
| 하드코어 정극 | 억압5 해소5 | 균형 서사 |
| 학대물/다크 | 억압7 해소3 | 장기 억압, 폭발이 더 통쾌 |

### 억압과 해소 리듬 제어
```
느린 준비(억압) → 빠른 폭발(해소) → 정지 → 재가속
```

### 문장 리듬
- **짧은 문장**: 빠른 리듬, 동작 밀집
- **긴 문장**: 느린 리듬, 디테일 묘사
- **교차**: 리듬 변화 생성

## 4. 쾌감 포인트 밀도 제안 (롤링 윈도우)

| 주기 | 요구 |
|------|------|
| 매 챕터 | "쾌감 포인트 또는 동등한 실현" 우선 보장, 전환 챕터 저밀도 허용 |
| 매 5챕터 | 조합 쾌감 포인트(2가지 패턴 중첩) 1개 이상 권장 |
| 매 10-15챕터 | 마일스톤 쾌감 포인트(주인공 지위 변화) 1개 이상 권장 |

### 쾌감 포인트 강도 등급
| 등급 | 설명 | 빈도 |
|------|------|------|
| 소형 쾌감 포인트 | 단일 패턴, 일상 응징, 규모 작음 | 높음(대부분 챕터) |
| 조합 쾌감 포인트 | 2가지 이상 패턴 중첩, 중요 전환 | 중간(단계 노드) |
| 마일스톤 쾌감 포인트 | 주인공 지위를 바꾸는 단계적 승리 | 낮음(대형 노드) |

## 5. 정보 격차 설계

### 정보 격차 계층
| 계층 | 설명 |
|------|------|
| 독자 기지 | 독자가 이전 글을 통해 이미 아는 정보 |
| 캐릭터 기지 | 장면 속 캐릭터가 아는 정보 |
| 정보 격차 핵심 | 독자는 알지만 캐릭터는 모르는 핵심 정보 |
| 반전 정보 | 미세 반전 시 공개되는 새 정보 |

### 정보 격차 활용
```
독자는 주인공이 숨겨진 강자임을 안다 + 캐릭터는 모른다 = 기대감
캐릭터가 주인공을 조롱 + 독자는 주인공 실력을 안다 = 쾌감 축적
주인공이 실력 전시 + 캐릭터 충격 = 쾌감 해소
```

---

## 6. 응징 4단계법 (핵심 루틴)

**Step 1 준비**: 1-2챕터 전에 정보 격차 수립(독자는 주인공 밑패를 알고, 악역은 모름)

**Step 2 도발**: 1-3회 도발로 대조군 수립(악역이 추앙받음 vs 주인공이 폄하됨)

**Step 3 밀고 당기기**: 2-3라운드 교전, 주인공 약한 척 → 악역 득의 → 기대 극대화

**Step 4 폭발**: 물리적 압도 + 정신적 타격 + 관중 반응 + 실질적 수확

## 7. 미세 반전 유형

### 더 강한 것이 남아있다
한 수 보여줬는데, 사실 더 대단한 것이 있음
```
"이게 내 전력이라고 생각했나?"
```

### 뜻밖의 수확
원래 목표 달성만 하려 했는데, 뜻밖의 부가 이익까지
```
상대 격파 → 보물 획득 → 보물이 기대보다 더 귀중
```

### 상대가 더 비참
상대는 작은 실패라고 생각했는데, 사실 대참사
```
시합에서 짐 → 내기가 폭로 → 신세 망침
```

### 감정 온도 상승
달콤한 줄만 알았는데, 사실 더 달콤
```
평범한 선물인 줄 알았는데 → 정성 준비한 것 발견 → 감동의 눈물
```

### 진실 공개
겉은 A인데, 사실은 B이고, B가 더 대단
```
평범한 옥패인 줄 → 사실 상고 신기 → 주인까지 인정
```

## 8. 쾌감 포인트 업그레이드 경로

### 차원1: 규모 업그레이드
```
소소한 불량배 응징 → 세가 도련님 응징 → 종문 장로 응징 → 제국 하나 멸망
```

### 차원2: 방식 업그레이드
```
폭력 압도 → 지모 압도 → 규칙 장악 → 인과 말살
```

### 차원3: 관중 업그레이드
```
이웃을 놀라게 → 전 도시를 놀라게 → 전국을 놀라게 → 온 천지 신마를 전율시킴
```

## 9. 장르 적합

### 도시 쾌감문
- 허세 응징 중시
- 재력/인맥/신분 반전 활용
- 사회적 지위 압도

### 현환 레벨업
- 전투력 반전 중시
- 실력 압도/등급 격차 돌파 활용
- 월급 전투

### 서스펜스 본격
- 진실 반전 중시
- 증거/추리로 응징 활용
- 지능 압도

### 달달 로맨스
- 감정 깜짝 중시
- 뜻밖의 로맨스/진심 고백 활용
- 달콤함 초과

---

## 10. AI 실행 지침

창작 시 반드시 준수:

1. **반전 설계 시**: **정보 격차 핵심**(누가 무엇을 아는지, 누가 무엇을 모르는지)을 명확히
2. **쾌감 검수 시**: 쾌감이 부족하면 **준비 분량(30%)**이 너무 적어 에너지 부족인지 확인
3. **리듬 점검 시**: 30/40/30을 진단 참고로 사용, 경직된 배분이 아님

## 11. 복선 3단계

| 단계 | 회수 주기 | 예시 |
|------|----------|------|
| 핵심 | 50-300챕터 | 주인공 출생의 비밀/최종 적/골든핑거 내력 |
| 서브라인 | 30-100챕터 | 조연 동기/수수께끼 아이템/사문 비밀 |
| 장식 | 10-30챕터 | 장면 디테일/작은 습관/행인 언급 |
