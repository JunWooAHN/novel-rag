# 현실 소재 스토리 논리

> 현실 소재에서 가장 두려운 것은 "비합리적"이다. 본 문서는 치밀한 스토리 논리를 구축하는 방법을 제공한다.

---

## 1. 논리 체인 구축

### 인과 체인 원칙
```
모든 사건에는 다음이 필요:
- 원인 (왜 발생했는가)
- 과정 (어떻게 발생했는가)
- 결과 (발생 후 어떻게 되었는가)
- 영향 (후속에 대한 영향)
```

### 예시
```
사건: 그녀가 퇴사했다

잘못된 쓰기:
그녀가 갑자기 퇴사했다. (원인 없음)

올바른 쓰기:
원인: 3개월 연속 야근, 어머니 또 입원
과정: 한밤중 사무실에서 병원 전화 받고, 다음 날 사직서 제출
결과: 수입원을 잃었지만, 어머니를 돌볼 수 있음
영향: 경제적 압박 증가, 이후 갈등의 복선
```

---

## 2. 동기 합리성

### 동기 3요소
```
1. 욕망: 무엇을 원하는가
2. 장애물: 무엇이 방해하는가
3. 행동: 어떻게 극복하는가
```

### 동기 강도 검증
```
스스로에게 물어보기: 이 동기가 인물이 이런 행동을 할 만큼 충분한가?

약한 동기:
"지루해서 바람피웠다" ❌

강한 동기:
"결혼이 유명무실한 지 5년, 가장 취약할 때 자신을 이해해주는 사람을 만남" ✓
```

### 흔한 동기
```
생존류: 돈, 건강, 안전
감정류: 사랑, 사랑받기, 소속
존엄류: 존중, 인정, 지위
자아류: 성장, 자유, 의미
```

## 3. 우연 처리

### 우연 사용 원칙
```
1. 우연은 곤경을 만들 수 있지만, 곤경을 해결할 수는 없다
2. 하나의 이야기에 최대 1-2개의 우연
3. 우연에는 복선이 필요
```

### 잘못된 예시
```
"진퇴양난일 때, 갑자기 복권에 당첨됐다." ❌
(우연이 곤경을 해결)
```

### 올바른 예시
```
"카페에서 전 남자친구를 우연히 만남, 마침 현재 남자친구 팔을 끼고 있었다."
(우연이 곤경을 만듦)
```

### 우연 복선 기법
```
우연을 덜 우연하게 보이게:
- 미리 가능성을 암시
- 합리적 시공간 조건 제시
- 인물 반응으로 진실감 강화
```

## 4. 시간선 관리

### 시간선 점검
```
- 사건 발생 순서가 합리적인가?
- 시간 간격이 충분한가?
- 시간 충돌이 없는가?
```

### 흔한 시간 문제
```
문제1: 시간 부족
"1주일 만에 프로그래밍을 처음부터 배웠다" ❌

문제2: 시간 충돌
"오전에 서울에서 회의, 오후에 부산에서 고객 만남" ❌
(합리적 교통 수단이 없다면)

문제3: 부자연스러운 시간 건너뛰기
"3년 후"가 갑자기 나타나, 어떤 전환도 없음 ❌
```

### 시간선 도구
```
시간축 만들기 추천:
- 모든 중요 사건 나열
- 구체적 시간 표기
- 논리 충돌 점검
```

## 5. 인물 행동 논리

### 행동 일관성
```
인물의 행동은 다음에 맞아야:
- 성격 설정
- 과거 경험
- 현재 상황
- 인지 수준
```

### 행동 전환
```
인물 행동에 중대한 변화가 있다면, 필요한 것:
- 충분한 촉발 사건
- 점진적 심리 변화
- 합리적 전환 과정
```

### 예시
```
잘못:
"평소 소심하던 그녀가 갑자기 강해졌다."

올바름:
"3년간 괴롭힘을 당한 후, 딸도 같은 대우를 받는 것을 보자,
처음으로 일어서서 맞섰다."
(촉발 사건이 있고, 합리적 동기가 있음)
```

## 6. 정보 전달 논리

### 정보 출처
```
인물이 아는 정보에는 반드시 출처가 있어야:
- 직접 목격
- 직접 들음
- 타인의 전달
- 추리로 얻음
```

### 흔한 문제
```
문제: 인물이 알면 안 되는 것을 앎
"그녀는 그에게 밖에 다른 여자가 있는 걸 알았다."
(어떻게 알았는가? 설명 필요)

해결:
"그의 셔츠에서 낯선 향수 냄새가 났다."
```

### 정보 격차 설계
```
정보 격차를 이용해 극적 효과 조성:
- 독자는 알고, 인물은 모름 (서스펜스)
- 인물은 알고, 독자는 모름 (반전)
- A는 알고, B는 모름 (오해)
```

## 7. 사회 규칙 논리

### 법률 상식
```
법률 관련 문제는 정확해야:
- 이혼 절차
- 재산 분할
- 양육권
- 노동법
- 형사 책임
```

### 직장 규칙
```
- 승진 절차
- 사직 절차
- 경업금지
- 야근 규정
```

### 의료 상식
```
- 질병 증상
- 치료 과정
- 병원 규칙
- 의료보험
```

## 8. 논리 허점 점검 리스트

### 인과 점검
- [ ] 모든 중요 사건에 원인이 있는가?
- [ ] 원인이 충분히 타당한가?
- [ ] 결과가 논리에 맞는가?

### 동기 점검
- [ ] 인물의 행동에 충분한 동기가 있는가?
- [ ] 동기가 인물 성격에 맞는가?
- [ ] 독자가 이 동기를 이해할 수 있는가?

### 시간 점검
- [ ] 시간선이 명확한가?
- [ ] 시간 충돌이 없는가?
- [ ] 시간 간격이 합리적인가?

### 정보 점검
- [ ] 인물의 정보 출처가 명확한가?
- [ ] "전지적" 문제가 없는가?
- [ ] 정보 전달이 합리적인가?

### 상식 점검
- [ ] 법률 상식에 어긋남이 없는가?
- [ ] 직업 상식에 어긋남이 없는가?
- [ ] 생활 상식에 어긋남이 없는가?

## 9. 논리 허점 수정

### 방법1: 복선 보충
```
허점 발견: 그녀가 비밀번호를 어떻게 알았지?
수정: 앞에 한 줄 추가 "그녀가 우연히 그가 비밀번호를 입력하는 것을 봤다"
```

### 방법2: 설정 조정
```
허점 발견: 시간이 부족
수정: "1주"를 "3개월"로 변경
```

### 방법3: 설명 추가
```
허점 발견: 행동이 비합리적
수정: 심리 묘사 추가, 동기 설명
```

### 방법4: 줄거리 삭제
```
허점 발견: 앞뒤가 안 맞음
수정: 이 줄거리를 삭제하고, 다른 방식으로 대체
```
