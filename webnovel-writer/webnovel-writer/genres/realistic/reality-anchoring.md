# 현실 소재 진실감 고정

> 현실 소재의 핵심은 "진실감"이다. 본 문서는 독자가 이야기를 믿게 만드는 기법을 제공한다.

---

## 1. 진실감 3층 구조

| 층위 | 내용 | 역할 |
|------|------|------|
| 표층 | 디테일의 진실 | 독자가 장면을 "보게" 함 |
| 중층 | 논리의 진실 | 독자가 줄거리를 "믿게" 함 |
| 심층 | 감정의 진실 | 독자가 인물에 "공감"하게 함 |

---

## 2. 디테일의 진실 기법

### 1. 직업 디테일
```
잘못: 그녀는 의사로, 매일 인명을 구한다.
올바름: 그녀는 응급실 전공의로, 36시간 당직을 마치고,
      휴게실 야전침대에서 4시간 자다가,
      간호사에게 깨어났을 때, 입에는 아직 못 먹은 빵이 물려 있었다.
```

### 2. 생활 디테일
```
잘못: 그는 매우 가난하다.
올바름: 월말까지 3일 남았는데, 은행 잔고가 47,600원이었다.
      배달앱의 "할인"을 30분간 살펴보다가,
      결국 9,900원짜리 닭볶음탕을 주문했다.
```

### 3. 환경 디테일
```
잘못: 오래된 아파트다.
올바름: 복도의 센서등이 3개월째 고장나 아무도 고치지 않았고,
      그녀는 매일 어둠 속에서 6층을 올라갔다.
      계단 난간의 페인트는 이미 벗겨져 있었다.
```

### 4. 시대 디테일
```
2024년 특징:
- 모바일 결제, 배달, 카풀
- 야근, 경쟁, 워라밸
- 숏폼, 라이브 커머스
- 주택대출, 자동차 할부, 소비자 대출
```

## 3. 논리의 진실 기법

### 1. 인과 체인 완성
```
잘못: 그녀가 갑자기 퇴사했다.
올바름: 3개월 연속 야근 후, 새벽 2시 사무실에서
      어머니 입원 소식을 전해 받았다.
      다음 날, 사직서를 제출했다.
```

### 2. 동기 합리성
```
잘못: 그는 사랑을 위해 모든 것을 포기했다.
올바름: 그는 3개월간 고민했다.
      마지막으로 그가 결심하게 한 것은,
      공항에서 그녀가 배웅하며 한 "기다릴게"라는 말이었다.
```

### 3. 결과의 현실성
```
잘못: 그녀의 사업이 성공했다.
올바름: 그녀의 회사가 드디어 이익을 냈지만,
      3년의 청춘,
      한 번의 결혼, 그리고 가장 친한 친구를 잃었다.
```

## 4. 감정의 진실 기법

### 1. 복잡한 감정
```
단일 감정(거짓): 그녀는 그를 미워한다.
복잡한 감정(진짜): 그녀는 그를 미워하지만, 아직 사랑하는 자신이 더 미워한다.
                매번 그의 SNS를 보면,
                먼저 들어가서 보고, 다시 자기를 욕한다.
```

### 2. 모순된 심리
```
인물 내면의 진짜 모순:
- 사직하고 싶지만 다음 직장 못 찾을까 두려움
- 이혼하고 싶지만 아이가 아까움
- 고백하고 싶지만 거절당할까 두려움
- 집에 가고 싶지만 부모의 결혼 재촉이 두려움
```

### 3. 감정의 점진적 변화
```
잘못: 그녀가 갑자기 무너져 울었다.
올바름: 그녀는 계속 참았고, 집에 돌아와서,
      문을 닫는 순간,
      눈물이 마침내 흘러내렸다.
      그녀는 현관에 쪼그려 앉아, 꼬박 10분을 울었다.
```

## 5. 자주 쓰이는 직업 진실감 포인트

### 의사
```
- 당직 제도 (24시간/36시간)
- 의료 분쟁 긴장
- 논문, 직급 압박
- 수술 전 긴장, 수술 후 피로
- 죽음 앞의 무력감
```

### 변호사
```
- 야근이 일상
- 사건 수임 압박
- 법 조문의 지루함
- 당사자의 몰이해
- 승소의 성취감 vs 패소의 좌절
```

### 프로그래머
```
- 야근/과로
- 요구사항 변경의 붕괴
- 끝나지 않는 버그
- 35세 위기
- 머리카락과 건강 문제
```

### 교사
```
- 수업 준비, 숙제 채점
- 학부모 단톡방 압박
- 학생의 반항기
- 직급 평가
- 방학의 "숨겨진 야근"
```

### 영업
```
- 실적 압박
- 고객의 까다로움
- 접대 문화
- 수수료 제도
- 월말 실적 맞추기
```

## 6. 사회 현실 고정점

### 경제적 압박
```
- 주택대출: 월 상환금이 수입의 몇 퍼센트
- 자동차 대출: 차량 유지비
- 교육: 학원비, 학군 아파트
- 의료: 큰 병 한 번의 비용
- 노후: 부모의 의료와 노후
```

### 직장 현실
```
- 경쟁: 야근 문화
- 해고: 35세 위기
- 승진: 사내 정치
- 성별: 직장 차별
- 학력: 학벌 차별
```

### 가정 현실
```
- 결혼 재촉: 부모의 압박
- 시댁: 가정 갈등
- 육아: 교육 불안
- 노후: 외동 세대의 압박
- 이혼: 재산 분할, 자녀 양육
```

## 7. 진실감 상실 방지 점검 리스트

### 디테일 점검
- [ ] 직업 묘사가 실제에 맞는가?
- [ ] 수입 수준이 합리적인가?
- [ ] 생활 장면이 진실한가?
- [ ] 시대 특징이 정확한가?

### 논리 점검
- [ ] 인물 동기가 충분한가?
- [ ] 줄거리 전개가 합리적인가?
- [ ] 결과가 현실에 맞는가?
- [ ] 시간선이 가능한가?

### 감정 점검
- [ ] 감정 반응이 진실한가?
- [ ] 심리 변화가 점진적인가?
- [ ] 모순과 복잡성이 있는가?
- [ ] 독자가 공감할 수 있는가?

## 8. 진실감 vs 극적 효과의 균형

### 원칙
```
진실감은 기초이고, 극적 효과는 양념이다
너무 진실하면 = 일상 기록
너무 극적이면 = 뻥치기
```

### 균형 기법
```
1. 진실한 디테일로 극적인 줄거리를 포장
2. 합리적 논리로 우연의 발생을 뒷받침
3. 복잡한 감정으로 극단적 갈등을 부드럽게
4. 일상 장면으로 하이라이트 순간을 부각
```
