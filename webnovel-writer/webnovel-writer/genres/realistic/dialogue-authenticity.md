# 현실 소재 대화 진실감

> 대화는 현실 소재의 리트머스 시험지다. 본 문서는 진실한 대화를 쓰는 기법을 제공한다.

---

## 1. 진실한 대화의 특징

### 1. 불완전성
```
문어체: 이 일은 이렇게 처리해야 한다고 생각합니다.
구어체: 이 일은 말이야... 내 생각엔... 됐어, 네가 알아서 해.
```

### 2. 반복과 망설임
```
문어체: 당신의 관점에 동의하지 않습니다.
구어체: 아니... 내 말은 그게 아니고... 그러니까... 이해해?
```

### 3. 생략과 건너뛰기
```
문어체: 오늘 퇴근 후에 어디 갈 거야?
구어체: 오늘 밤?
```

### 4. 입버릇과 감탄사
```
- 음, 아, 오, 어
- 그러니까, 그게, 어쨌든
- 진짜?, 설마, 대박
```

## 2. 신분별 말투

### 나이별
```
00년대생:
- "미쳤어" "레전드" "이게 뭐야"
- 말이 빠르고, 인터넷 용어 많음
- 밈 스타일 표현

80년대생:
- 비교적 정식
- 가끔 인터넷 용어 쓰지만 능숙하지 않음
- "그러니까... 뭐라 해야 하나"

60년대생:
- 더 정식, 인터넷 용어 적음
- 속담이나 사자성어를 좋아함
- "내가 하는 말 들어봐..."
```

### 직업별
```
의사:
- 전문 용어가 자연스레 나옴
- 말이 간결하고 직접적
- "상황이 좋지 않습니다"

변호사:
- 논리가 치밀
- "첫째, 둘째, 마지막으로" 사용을 좋아함
- "법적 관점에서 보면..."

프로그래머:
- 기술 어휘
- 직접적, 돌려 말 안 함
- "이 요구사항은 비합리적입니다"
```

### 성격별
```
내향:
- 말이 적고, "응" "어"를 자주 씀
- 수동적 반응이 많음
- 긴 문장 적음

외향:
- 말이 많고, 주도적으로 화제 시작
- 감탄사 풍부
- 반문을 좋아함

강세:
- 서술문이 많고, 의문문이 적음
- 남의 말 끊기
- "내 말 들어"

약세:
- 의문문 많음
- "아마" "혹시"를 자주 씀
- "어떻게 생각해?"
```

## 3. 대화 기능

### 1. 스토리 추진
```
잘못: 대화로 배경 설명
"알고 있지, 우리 회사가 2010년에 설립되어서, 주요 업무는..."

올바름: 대화로 갈등 만들기
"사직서 당신 책상에 놨어요."
"미쳤어?"
```

### 2. 인물 보여주기
```
"그녀는 강한 사람이다"라고 말하지 말고
대화를 쓰기:
"이 일은 이렇게 결정됐어."
"그런데..."
"그런데 없어."
```

### 3. 정보 전달
```
잘못: 직접 알려주기
"그가 바람피웠어, 상대는 네 친한 친구야."

올바름: 암시+반응
"어젯밤에 그의 차를 봤어... 아파트 앞에 세워져 있더라."
"어느 아파트?"
"...네 친한 친구네."
```

### 4. 긴장감 조성
```
속뜻이 직접 말하는 것보다 더 강력:
"너 요즘... 괜찮아?"
"잘 지내."
"그러면 다행이고."
(둘 다 괜찮지 않다는 걸 알지만, 둘 다 깨지 않음)
```

## 4. 대화 리듬

### 빠른 리듬 (갈등/긴장)
```
"무슨 뜻이야?"
"말 그대로야."
"너..."
"내가 뭐?"
"이혼하자."
```

### 느린 리듬 (감정/무거움)
```
그녀는 한참을 침묵했다.
"너... 진심이야?"
그는 대답하지 않았다.
창밖의 비가 점점 세차게 내렸다.
"3년을 기다렸어." 그녀가 마침내 입을 열었다, "3년."
```

### 리듬 변화
```
먼저 빠르고 나중에 느림: 다툼 후의 침묵
먼저 느리고 나중에 빠름: 쌓인 후의 폭발
```

## 5. 속뜻 기법

### 1. A를 말하며 B를 의미
```
겉: "날씨가 좋네."
속뜻: "이 주제로 말하고 싶지 않아."
```

### 2. 동문서답
```
"날 사랑해?"
"밥 다 됐어."
```

### 3. 침묵
```
"설명 좀 해줄 수 있어?"
그는 말하지 않았다.
"물어보는 거야."
여전히 침묵.
```

### 4. 화제 전환
```
"어젯밤에 어디 갔어?"
"참, 네 엄마 전화 왔었어."
```

## 6. 자주 쓰이는 대화 장면 템플릿

### 말다툼
```
특징:
- 상대 말 끊기
- 지난 일 들추기
- 인신공격
- 침묵 또는 문 세게 닫기

예시:
"넌 매번 이래!"
"내가 뭘—"
"닥쳐!"
"좋아, 닥칠게, 나가면 되지?"
```

### 이별
```
특징:
- 긴 침묵
- 회상
- 마지막 발버둥
- 품위 있게 또는 붕괴

예시:
"우리... 그만하자."
"...왜?"
"왜는 없어."
"그녀 때문이야?"
"...생각이 많아."
```

### 고백
```
특징:
- 긴장
- 탐색
- 망설임
- 반응 기다리기

예시:
"저기... 할 말이 있는데."
"응?"
"그게... 됐다, 아무것도 아니야."
"말해봐."
"나... 좋아해."
```

### 대면
```
특징:
- 직접적
- 증거
- 추궁
- 설명 기다리기

예시:
"이게 뭐야?"
"...내 핸드폰 뒤졌어?"
"이게 뭐냐고."
"설명할 수 있어..."
"그러면 설명해."
```

## 7. 대화 점검 리스트

### 진실성 점검
- [ ] 이 말을 정말 사람이 이렇게 하겠는가?
- [ ] 인물의 나이/직업/성격에 맞는가?
- [ ] 너무 문어체적이지 않은가?
- [ ] 적절한 구어체 특징이 있는가?

### 기능성 점검
- [ ] 이 대화가 스토리를 추진하는가?
- [ ] 인물 성격을 보여주는가?
- [ ] 삭제해도 되는 잡담이 있는가?
- [ ] 속뜻이 충분한가?

### 리듬 점검
- [ ] 대화 길이가 적절한가?
- [ ] 빠르고 느린 리듬에 변화가 있는가?
- [ ] 침묵과 멈춤이 잘 쓰였는가?
