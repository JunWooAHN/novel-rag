# 현실 소재 인물 깊이 있는 형상화

> 현실 소재의 인물은 반드시 "실제 사람 같아야" 한다. 본 문서는 입체적 인물을 형상화하는 방법을 제공한다.

---

## 1. 입체적 인물의 3차원

| 차원 | 내용 | 역할 |
|------|------|------|
| 사회적 차원 | 직업, 계층, 가정 배경 | 인물의 외적 상황 정의 |
| 심리적 차원 | 성격, 욕망, 두려움, 트라우마 | 인물의 내적 동기 정의 |
| 도덕적 차원 | 가치관, 선, 회색 지대 | 인물의 선택 논리 정의 |

---

## 2. 사회적 차원 구축

### 1. 직업 정체성
```
단순히 "그녀는 의사다"가 아닌
구체적으로:
- 어떤 과? (응급실/외과/소아과)
- 어떤 직급? (인턴/전공의/과장)
- 몇 년 근무? (신입/중견/고참)
- 직업적 어려움? (승진/의료분쟁/워라밸)
```

### 2. 경제 상황
```
구체적으로:
- 월수입이 얼마?
- 주택대출/자동차 할부가 있나?
- 저축이 얼마?
- 소비 습관은 어떤가?
```

### 3. 가정 배경
```
원가정:
- 부모의 직업과 성격
- 가정 분위기 (따뜻/냉담/통제적)
- 어린 시절 경험 (트라우마/행복)
- 부모와의 현재 관계
```

### 4. 사회적 관계
```
- 친구 범위 (많은지/소수 정예인지)
- 동료 관계 (원만/긴장)
- 이웃 관계 (친밀/낯선)
- 사교 습관 (내향/외향)
```

---

## 3. 심리적 차원 구축

### 1. 핵심 욕망
```
모든 사람에게는 하나의 핵심 욕망이 있다:
- 사랑받기/인정받기/존중받기
- 안정감/통제감/자유
- 성공/돈/권력
- 소속감/존재감/의미감
```

### 2. 깊은 두려움
```
욕망에 대응하는 두려움:
- 사랑받고 싶음 → 버림받는 것이 두려움
- 성공하고 싶음 → 실패가 두려움
- 자유를 원함 → 속박이 두려움
- 안정을 원함 → 통제 불능이 두려움
```

### 3. 심리적 트라우마
```
과거의 상처가 현재 행동에 영향:
- 어린 시절 방치 → 성인 후 비위 맞추기형 인격
- 배신당한 경험 → 타인을 믿기 어려움
- 가난을 경험 → 돈에 극도로 예민
- 소중한 사람을 잃음 → 친밀한 관계가 두려움
```

### 4. 방어 기제
```
인물이 자신을 보호하는 방법:
- 회피: 문제를 직면하지 않음
- 공격: 선제공격
- 비위 맞추기: 자기 희생
- 차단: 감정을 끊음
- 합리화: 자기 변명 찾기
```

---

## 4. 도덕적 차원 구축

### 1. 가치 순서
```
가치가 충돌할 때, 인물은 무엇을 선택할 것인가?
- 가정 vs 사업
- 사랑 vs 생계
- 원칙 vs 이익
- 자신 vs 타인
```

### 2. 도덕적 선
```
인물이 절대 하지 않을 것:
- 어떤 사람의 선은 거짓말하지 않는 것
- 어떤 사람의 선은 가족을 해치지 않는 것
- 어떤 사람의 선은 법을 어기지 않는 것
- 어떤 사람에게는 선이 없음
```

### 3. 회색 지대
```
인물이 고민할 선택:
- 아이를 위해, 나쁜 결혼을 참아야 하는가?
- 승진을 위해, 양심에 어긋나는 일을 해야 하는가?
- 생존을 위해, 원칙을 포기해야 하는가?
```

---

## 5. 인물 성장 곡선 설계

### 1. 긍정적 성장
```
결함에서 성장으로:
- 자격지심 → 자신감
- 회피 → 직면
- 의존 → 독립
- 폐쇄 → 개방
```

### 2. 부정적 변화
```
정상에서 타락으로:
- 착함 → 냉담
- 신뢰 → 의심
- 열정 → 무감각
- 고집 → 타협
```

### 3. 평행 곡선
```
자신을 지키며, 세상을 변화시킴:
- 인물이 시종일관 어떤 신념을 지킴
- 행동으로 주위 사람에게 영향
- 어떤 가치관의 힘을 증명
```

---

## 6. 인물 관계 네트워크

### 1. 핵심 관계
```
인물에게 가장 깊은 영향을 주는 관계:
- 원가정 (부모/형제자매)
- 친밀한 관계 (배우자/전 연인)
- 중요한 타인 (멘토/절친/라이벌)
```

### 2. 관계 역동
```
관계는 정적이 아님:
- 낯선 사이에서 친밀하게
- 신뢰에서 배신으로
- 의존에서 독립으로
- 대립에서 화해로
```

### 3. 관계 기능
```
모든 관계에는 기능이 있음:
- 거울: 인물의 진실을 비춤
- 촉매: 인물의 변화를 추진
- 대조군: 인물 특성을 부각
- 시험: 인물의 선을 시험
```

## 7. 인물 디테일 리스트

### 외적 디테일
```
- 외모 특징 (완벽할 필요 없음)
- 옷차림 습관 (성격/경제 상태 반영)
- 작은 동작 (긴장할 때/생각할 때)
- 말투 (버릇어/말 속도/단어 선택)
```

### 생활 디테일
```
- 생활 패턴
- 음식 선호
- 여가 방식
- 소비 습관
```

### 내적 디테일
```
- 가장 자랑스러운 일
- 가장 후회하는 일
- 가장 두려운 것
- 가장 원하는 것
```

---

## 8. 인물 점검 리스트

### 입체도 점검
- [ ] 인물에게 명확한 욕망과 두려움이 있는가?
- [ ] 인물에게 과거의 트라우마나 경험이 있는가?
- [ ] 인물에게 도덕적 회색 지대가 있는가?
- [ ] 인물이 독자로 하여금 사랑과 미움을 동시에 느끼게 하는가?

### 진실성 점검
- [ ] 인물의 행동이 배경에 맞는가?
- [ ] 인물의 선택에 충분한 동기가 있는가?
- [ ] 인물의 감정 반응이 진실한가?
- [ ] 인물에게 성장이나 변화가 있는가?

### 독특성 점검
- [ ] 이 인물이 다른 사람으로 대체될 수 있는가?
- [ ] 인물에게 독특한 말투가 있는가?
- [ ] 인물에게 상징적 특징이 있는가?
- [ ] 인물이 사람의 기억에 남는가?
