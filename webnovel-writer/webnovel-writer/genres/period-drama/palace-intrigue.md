# 고전 궁중 권모술수 설계

> 궁중 다툼은 고전 소설의 클래식 소재다. 본 문서는 정밀한 궁중 다툼을 설계하는 방법을 제공한다.

---

## 1. 궁중 다툼 핵심 요소

| 요소 | 내용 | 역할 |
|------|------|------|
| 목표 | 총애 다툼/지위 쟁탈/복수/생존 | 스토리 추진 |
| 자원 | 황제 총애/가문/인맥/정보 | 다툼의 카드 |
| 수단 | 음모/양모/타인 이용/동맹 | 목표 달성 |
| 대가 | 총애 잃음/강등/목숨/가족 | 긴장감 증가 |

---

## 2. 궁중 세력 구도

### 후궁 세력 구분
```
1등급 (최고 위협):
- 황후 (정궁의 주인)
- 총애 비빈 (황제 총애가 한창)
- 태후 (막후 대보스)

2등급 (잠재적 상대):
- 자녀가 있는 비빈
- 가문이 있는 비빈
- 수단이 있는 비빈

3등급 (포섭 가능):
- 총애 잃은 오래된 사람
- 의지할 곳 없는 신인
- 불만을 품은 궁인
```

### 조정 세력 연관
```
후궁 ←→ 조정 대응 관계:
- 황후 ←→ 황후 모족 (외척)
- 총애 비빈 ←→ 비빈 부형 (신귀)
- 태후 ←→ 태후 모족 (오래된 세력)
- 황자 ←→ 황자 당파 (왕위 쟁탈 세력)
```

## 3. 궁중 다툼 수단 분류

### 1. 음모류
```
모함:
- 누명 씌우기 (상대 궁에 금지품 놓기)
- 스캔들 조작 (사통/불경 날조)
- 타인의 칼 빌리기 (남을 부추겨 실행)

암해:
- 독살 (만성 독/불임약/발광약)
- 사고 위장 (미끄러짐/물에 빠짐/화재)
- 매수 (상대 측근 매수)
```

### 2. 양모류
```
총애 다툼:
- 황제 취향 파악
- 기회 만들기 (우연한 만남/재능 과시)
- 밀당 (은근히)

공 세우기:
- 음모 적발 (호가/밀고)
- 문제 해결 (황제 근심 나누기)
- 자녀 출산 (최대 공)
```

### 3. 동맹류
```
결맹:
- 이익 교환 (서로 돕기)
- 공동의 적 (적의 적은 친구)
- 주종 관계 (강자에 의탁)

분열:
- 이간질 (갈등 조장)
- 이익 유혹 (상대편 사람 포섭)
- 진실 폭로 (동맹의 배신 밝히기)
```

## 4. 궁중 다툼 리듬 설계

### 레벨업 모드
```
입궁 → 자리 잡기 → 약간의 지위 → 위기 봉착 → 절체절명의 반격 → 정상/결말

각 단계의 상대 레벨 점진적 상승:
1. 같은 급 비빈의 소소한 다툼
2. 고위 비빈의 압박
3. 황후/총애 비빈과 정면 충돌
4. 태후/조정과의 궁극 대결
```

### 공수 리듬
```
수동 방어기:
- 막 입궁, 규칙을 모름
- 표적이 됨, 자기 보호를 배움
- 자원과 인맥 축적

주동 공격기:
- 일정한 지위 확보
- 반격 시작
- 점진적 세력 확대

공수겸비기:
- 주요 세력이 됨
- 방어와 공격을 동시에
- 다전선 작전
```

## 5. 클래식 궁중 다툼 장면

### 1. 입궁
```
- 고위 비빈에게 위세 당함
- 냉궁/편전에 배치됨
- 처음 황제를 만남 (놀라움/실례/특별함)
- 첫 동맹/적을 만남
```

### 2. 총애 다툼
```
- 황제와 우연히 만남 (정밀하게 설계한 우연)
- 재능 과시 (금기서화/요리/의술)
- 남다름 (다투지 않아 오히려 관심을 끎)
- 호가/해결 (위기에서의 표현)
```

### 3. 모함당함
```
- 누명 (궁에서 금지품 발견)
- 무고 (날조된 증인 증언)
- 함정 (덫에 빠짐)
- 오해 (황제가 직접 본 가상의 모습)
```

### 4. 반격
```
- 진실 폭로 (진짜 증거 발견)
- 장계취장 (상대의 음모 이용)
- 타인의 힘 빌리기 (상대가 서로 싸우게 만듦)
- 사지에서 역전 (죽음 직전의 반격)
```

### 5. 클라이맥스 대결
```
- 공개 대질 (대전/연회에서의 대결)
- 증거 체인 (하나씩 밝히기)
- 최종 심판 (황제/태후의 판결)
- 적의 결말 (죽음/폐위/강등/발광)
```

## 6. 궁중 다툼 지능선

### 똑똑함의 표현
```
✓ 미리 포석, 후수를 남겨둠
✓ 진짜 의도를 쉽게 드러내지 않음
✓ 규칙과 사람의 마음을 잘 이용
✓ 언제 참아야 하는지 앎
✓ 상대의 음모를 꿰뚫어 봄
```

### 지능 하락 피하기
```
✗ 뻔한 함정에 뛰어듦
✗ 적의 말을 쉽게 믿음
✗ 말하면 안 될 때 말함
✗ 알면 안 되는 사람에게 계획을 말함
✗ 상대의 지능을 과소평가
```

### 합리적인 실수
```
실수할 수 있지만, 합리적이어야:
- 정보 비대칭으로 인한 오판
- 감정에 치우친 충동
- 더 뛰어난 상대에게 당함
- 돌발 요소의 방해
```

## 7. 궁중 다툼 감정선

### 황제와 비빈 감정
```
유형:
- 진심 사랑형: 황제가 진심으로 여주를 사랑
- 이용형: 서로 이용, 시간이 지나며 사랑
- 학대형: 사랑하지만 얻지 못함, 오해 중첩
- 구원형: 여주가 황제를 변화시킴
```

### 감정과 권모의 균형
```
순수 궁중극: 감정은 도구, 권모가 핵심
궁중 로맨스: 권모는 배경, 감정이 핵심
균형형: 권모와 감정 병행

주의:
- 감정선이 궁중극 리듬을 늦추지 않게
- 궁중극이 감정 발전을 희석시키지 않게
- 결정적 순간에 취사선택이 있어야
```

## 8. 궁중 다툼 결말 유형

### HE 결말
```
- 후위에 올라, 제왕과 해로
- 황자를 후원하여 즉위, 태후가 됨
- 궁궐을 떠나, 진정한 사랑과 멀리 감
- 권세를 장악, 성공 후 은퇴
```

### BE 결말
```
- 모든 사람을 이겼지만, 사랑을 잃음
- 높은 지위에 올랐지만, 모든 것이 공허
- 복수를 위해, 모든 것을 바침
- 결국 권력 게임에서 죽음
```

### 열린 결말
```
- 그녀는 그 의자를 바라보며, 웃었다
- 새로운 비빈이 입궁했고, 이야기가 다시 시작됨
- 그녀는 마침내 그 궁문을 걸어 나갔다
```

## 9. 궁중 다툼 점검 리스트

### 논리 점검
- [ ] 세력 구도가 명확한가?
- [ ] 각 음모에 합리적인 실행 방식이 있는가?
- [ ] 여주의 반격에 충분한 전개가 있는가?
- [ ] 지능선이 유지되는가?

### 리듬 점검
- [ ] 긴장과 이완이 있는가?
- [ ] 상대 레벨이 점진적인가?
- [ ] 클라이맥스가 충분히 흥미진진한가?

### 감정 점검
- [ ] 감정선이 궁중극 라인과 조화되는가?
- [ ] 독자가 여주를 위해 긴장하는가?
- [ ] 결말에 감정적 만족이 있는가?
