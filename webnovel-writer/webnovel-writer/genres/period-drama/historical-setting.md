# 고전 소재 역사 배경 설정

> 고전 소설의 매력은 "고대"에 있다. 본 문서는 신뢰할 수 있는 역사 배경을 구축하는 방법을 제공한다.

---

## 1. 시대 선택

### 자주 쓰이는 시대 특징

| 시대 | 특징 | 적합 소재 |
|------|------|---------|
| 가공 | 자유도 높음 | 궁중극, 권모, 달콤글 |
| 당 | 개방적, 번화 | 태평성대, 여성 소재 |
| 송 | 문아하고, 서민적 | 사업전, 일상, 탐정물 |
| 명 | 예교, 금의위 | 권모, 미스터리 |
| 청 | 궁중, 만한 | 궁중극, 왕위 쟁탈 |

### 가공 시대 설정
```
장점:
- 역사에 구애받지 않음
- 규칙을 자유로이 설정 가능
- 역사 고증 논쟁 회피

주의:
- 내적 일관성이 있어야
- 실제 시대를 참조하되 그대로 베끼지 않기
- 자체 세계관 구축
```

---

## 2. 사회 구조

### 계층 구분
```
황실: 황제, 황후, 비빈, 황자, 공주
종실: 친왕, 군왕, 패륵, 패자
훈귀: 공후백자남, 명문 대족
관료: 문관, 무장, 지방관
평민: 상인, 농민, 장인
천민: 노비, 악호, 죄인
```

### 여성 지위
```
정실: 안살림 주인, 내정 관리
첩실: 정실보다 지위 낮음
통방: 시녀 승격
비녀: 주인 시중

주의:
- 적서 구분이 매우 중요
- 정실은 첩실을 관리할 권한 있음
- 첩실 소생은 서출
```

### 가족 구조
```
대가족:
- 족장 (보통 적장방)
- 각 방 (큰방, 둘째방...)
- 적출, 서출
- 방계, 먼 친척

소가정:
- 부모
- 형제자매
- 처첩 자녀
```

## 3. 일상생활

### 호칭 체계
```
황제에게: 폐하, 성상
황후에게: 황후 마마, 모후
비빈에게: X비 마마, 마마
왕자에게: 왕야, 전하
관료에게: 대인, 나리
부인에게: 부인, 마님
자칭: 신, 신첩, 노비, 소녀
```

### 복식
```
남자:
- 평복: 장포, 직령
- 관복: 보복, 조복
- 장신구: 옥패, 부채

여자:
- 평복: 유군, 배자
- 예복: 봉관하피
- 장신구: 보요, 비녀
```

### 음식
```
주식: 쌀밥, 면류, 죽
찬: 지역과 계층에 따라 다름
음료: 차, 술
간식: 떡, 과일

주의:
- 감자, 옥수수, 고추는 명나라 이후에야 있음
- 계층별 음식 차이가 큼
```

### 이동
```
여자: 가마, 마차 (얼굴을 내밀면 안 됨)
남자: 말 타기, 가마, 마차
평민: 도보, 당나귀 수레
```

## 4. 예법 규범

### 만남 예법
```
큰절: 황제, 어른에게
읍: 동년배 남자
만복: 여자 인사
문안: 일상 인사
```

### 혼례
```
육례:
1. 납채 (청혼)
2. 문명 (궁합 보기)
3. 납길 (약혼)
4. 납징 (폐백 보내기)
5. 청기 (날짜 정하기)
6. 친영 (신부 맞이)
```

### 상례
```
- 3년 상 (실제 27개월)
- 정우 (관료가 상을 치르면 관직 사직)
- 상중에는 혼례 불가
```

### 금기
```
- 여자가 외부 남자를 함부로 만나면 안 됨
- 과부 재혼은 차별받음
- 어른에게 결례는 큰 불경
- 후궁이 정치에 간섭하면 안 됨
```

## 5. 궁중 설정

### 후궁 등급 (청나라 기준)
```
황후 (1명)
황귀비 (1명)
귀비 (2명)
비 (4명)
빈 (6명)
귀인 (정원 없음)
상재 (정원 없음)
답응 (정원 없음)
```

### 궁중 건축
```
전조: 정무 처리
후궁: 비빈 거주
동궁: 태자 거처
각 궁: 궁 이름으로 명명 (곤녕궁, 장춘궁 등)
```

### 궁중 인원
```
내시: 시종, 공공
궁녀: 비빈 시중
유모: 연장자 여관
호위: 안전 보호
```

## 6. 과거제와 관로

### 과거 과정
```
동시 → 수재
향시 → 거인
회시 → 공사
전시 → 진사 (장원, 방안, 탐화)
```

### 관직 체계
```
중앙:
- 내각 (대학사)
- 육부 (상서, 시랑)
- 도찰원 (어사)

지방:
- 총독, 순무
- 지부, 지현
```

### 관로 발전
```
- 한림원 (청귀)
- 육부 (실권)
- 외방 (지방관)
- 경관 (중앙)
```

## 7. 흔한 설정 오류

### 호칭 오류
```
❌ 황후가 자칭 "본궁" (상황에 따라 "본궁" 또는 "신첩")
❌ 황제에게 "폐하 당신"이라 함 ("당신" 사용 불가)
❌ 비빈끼리 "언니"라 부름 (위계에 따른 호칭이어야)
```

### 예법 오류
```
❌ 여자가 마음대로 외출하여 쇼핑
❌ 미혼 남녀가 단둘이 있음
❌ 첩실과 정실이 동등한 지위
```

### 상식 오류
```
❌ 고대에 유리창이 있음 (종이창이나 비단창이어야)
❌ 함부로 고추를 먹음 (명나라 이전에는 없음)
❌ 여자가 글을 읽고 쓰는 것이 보편적 (실제로는 소수)
```

## 8. 역사감 조성

### 언어 스타일
```
현대 어휘 피하기:
❌ "OK" "문제없어" "해결"
✓ "좋소" "가능하오" "마쳤소"

고풍 어휘 사용:
- "돈" 대신 "은자"
- "밥 먹기" 대신 "수라 들기"
- "쉬기" 대신 "안식하기"
```

### 세부 묘사
```
고대 물건 사용:
- 기름등, 촛불 (전등이 아님)
- 붓, 벼루 (만년필이 아님)
- 동경 (유리 거울이 아님)
```

### 사고방식
```
고대인의 가치관:
- 가문 명예를 중시
- 문당호대를 따짐
- 예교 규범 준수
- 운명 천의를 믿음
```
