# 고전 소설 스토리 패턴

> 고전 소설에는 그만의 클래식 스토리 패턴이 있다. 본 문서는 자주 쓰이는 스토리 프레임워크와 장면을 제공한다.

---

## 1. 클래식 스토리 프레임워크

### 1. 궁중 다툼 프레임워크
```
입궁 → 자리 잡기 → 총애 다툼 → 위기 → 정상에 오름/퇴장

상세:
1. 입궁 (선발/사혼/가문 배치)
2. 처음 후궁 들어감 (괴롭힘/뒷배 찾기)
3. 총애 획득 (재능/성격/인연)
4. 적 만들기 (황후/총애 비빈의 압박)
5. 단계적 승진 (품계 오름/자녀 출산)
6. 중대 위기 (모함/총애 잃음)
7. 절체절명 반격 (진실 밝히기/역전)
8. 최종 결말 (후위 등극/퇴궁/황제와 화목)
```

### 2. 가문 내 다툼 프레임워크
```
시집감 → 자리 잡기 → 안살림 장악 → 위기 → 안살림 주인

상세:
1. 시집감 (상류 혼인/하류 혼인/충희)
2. 시어머니와 대결 (규칙 세우기/괴롭힘 당함)
3. 동서 다툼 (자원 쟁탈/총애 다툼)
4. 남편 관계 (냉담/점점 따뜻/오해)
5. 안살림 권한 쟁탈
6. 가문 위기 (가산 몰수/몰락)
7. 사태 수습
8. 안살림 주인이 됨
```

### 3. 권모 프레임워크
```
말려듦 → 편 서기 → 대결 → 결전 → 새 국면

상세:
1. 정치 소용돌이에 말려듦
2. 진영 선택/강제로 편 서기
3. 모략에 참여
4. 다자간 대결
5. 핵심 정보/전환점
6. 최종 결전
7. 새로운 국면
```

### 4. 달콤 사랑 프레임워크
```
만남 → 알아감 → 사랑 → 작은 아픔 → HE

상세:
1. 특별한 만남
2. 일상 함께하기
3. 설렘의 순간
4. 관계 확정
5. 작은 파란 (오해/장애물)
6. 문제 해결
7. 달콤한 결말
```

## 2. 클래식 장면 모음

### 만남 장면
```
1. 생명의 은혜
   - 그녀가 그를 구함 (신분 모름)
   - 그가 그녀를 구함 (영웅 구출)

2. 결례/실례
   - 실수로 귀인과 부딪침
   - 신분 모르고 무례한 말

3. 대신 시집감/충희
   - 자매 대신 시집감
   - "곧 죽을 사람"에게 충희

4. 태중 약혼
   - 부모 세대의 약속
   - 수년 후 만남

5. 우연히 함께 있게 됨
   - 한곳에 갇힘
   - 우연히 같은 침대
```

### 아픈 장면
```
1. 오해
   - 직접 "바람" 목격
   - 이간질 당함

2. 강제 이별
   - 가문 반대
   - 정치적 이유
   - 생사 이별

3. 대역/백월광
   - 자신이 대역임을 알게 됨
   - 백월광 귀환

4. 유산/자녀 잃음
   - 해를 당해 유산
   - 아이 요절

5. 냉폭력
   - 차갑게 대함을 당함
   - 무시당함
```

### 달콤 장면
```
1. 질투
   - 그녀가 남과 말하는 것을 봄
   - 누가 그녀를 추구한다고 들음

2. 몰래 관심
   - 그녀가 모르는 줄 알고
   - 사실 그녀는 다 알고 있음

3. 공개적으로 편 보호
   - 누가 그녀를 괴롭히면
   - 그가 당당하게 아내 보호

4. 일상 애지중지
   - 취향에 맞추기
   - 모든 것을 맞춰줌

5. 의식감
   - 대혼/책봉
   - 생일/명절
```

### 얼굴 때리기 장면
```
1. 정체 반전
   - 가난한 친척인 줄 알았는데, 실은 귀녀
   - 버림받은 비인 줄 알았는데, 실은 진정한 사랑

2. 실력 과시
   - 조롱당한 후 재능 드러냄
   - 결정적 순간 사태 수습

3. 진실 폭로
   - 모함한 사람이 폭로됨
   - 백월광 본 모습 드러남

4. 얼굴 때리기 현장
   - 예전에 무시하던 사람이 도움을 구하러 옴
   - 예전에 조롱하던 말이 현실이 됨
```

## 3. 스토리 리듬

### 궁중 다툼 리듬
```
1권 (입궁): 20%
- 캐릭터 설정 구축
- 규칙 이해
- 첫 작은 승리

2권 (총애 다툼): 30%
- 총애 획득
- 적 만들기
- 단계적 승진

3권 (위기): 30%
- 중대 위기
- 밑바닥으로 떨어짐
- 절체절명 반격

4권 (결말): 20%
- 최종 대결
- 정상에 오름/퇴장
- 마무리
```

### 달콤 사랑 리듬
```
만남기: 15%
썸기: 25%
열애기: 30%
작은 아픔기: 15%
HE기: 15%
```

## 4. 스토리 설계 기법

### 1. 복선 설치
```
전반에 깔아놓은 단서:
- 눈에 띄지 않는 인물
- 무심코 한 말
- 작은 물건

후반에 밝혀짐:
- 알고 보니 그 사람이 핵심
- 그 말이 진실을 암시
- 그 물건이 증거
```

### 2. 반전 설계
```
유형1: 정체 반전
- A인 줄 알았는데, 실은 B

유형2: 관계 반전
- 적인 줄 알았는데, 실은 동맹

유형3: 진실 반전
- 이렇다고 생각했는데, 실은 저렇다

유형4: 결말 반전
- HE인 줄 알았는데, 실은 BE (또는 반대)
```

### 3. 클라이맥스 설계
```
궁중 다툼 클라이맥스:
- 공개 대질
- 증거 체인 폭로
- 최종 심판

가문 내 다툼 클라이맥스:
- 분가
- 이혼/합의 이혼
- 진실 대공개

권모 클라이맥스:
- 정변
- 결전
- 즉위
```

## 5. 피해야 할 문제

### 스토리 문제
```
❌ 금수저 너무 많음 (운이 너무 좋음)
❌ 악역이 너무 멍청 (지능이 부족)
❌ 리듬이 느림 (의미 없는 일상)
❌ 이유 없이 아프게 함 (아프게 하기 위한 아프게 하기)
❌ 결말이 급함 (대충 마무리)
```

### 논리 문제
```
❌ 시간선 혼란
❌ 인물 행동이 신분에 맞지 않음
❌ 역사 상식 오류
❌ 권력 운용이 비합리적
```
