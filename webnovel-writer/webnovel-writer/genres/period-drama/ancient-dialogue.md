# 고전 대화와 문체

> 고전 소설의 매력은 언어에 있다. 본 문서는 고풍스러운 느낌의 대화를 쓰는 방법을 제공한다.

---

## 1. 고풍 언어 기초

### 현대어 → 고풍어 변환표

| 현대어 | 고풍어 | 사용 장면 |
|--------|--------|---------|
| 나 | 나/소인/본궁/신첩/노비 | 신분에 따라 선택 |
| 너 | 너/그대/경/각하/공자 | 관계에 따라 선택 |
| 맞다 | 그러하다/정시/확실히 | 긍정 대답 |
| 아니다 | 아니옵니다/그렇지 않습니다 | 부정 대답 |
| 왜 | 어찌하여/무슨 연유로 | 의문 |
| 어쩌지 | 어찌하면 좋겠사옵니까 | 문의 |
| 알다 | 알고 있사옵니다/알겠나이다 | 정보 파악 |
| 모르다 | 모르옵니다/들은 바 없사옵니다 | 모름 |
| 감사 | 감사하옵니다/감사 드리옵니다 | 감사 |
| 미안 | 죄를 용서하소서/불경을 용서하소서 | 사과 |
| 괜찮다 | 괜찮사옵니다/염려 마소서 | 용서 |
| 좋다 | 좋소/허락하노라 | 동의 |
| 잠깐 | 잠시만/잠깐 멈추시오 | 일시 정지 |
| 빨리 | 속히/어서 | 재촉 |
| 가자 | 가시지요/출발하시지요 | 떠남 |

## 2. 신분별 말투

### 황제
```
자칭: 짐, 과인
특징: 위엄 있고, 간결하며, 반박 불가
예시:
- "허락하노라."
- "짐은 피곤하도다."
- "이 일은, 짐이 직접 결정하겠노라."
- "네 죄를 알겠느냐?"
```

### 황후/태후
```
자칭: 본궁, 애가(태후)
특징: 단정하고, 위엄 있으며, 노하지 않아도 위세가 있음
예시:
- "본궁이 알겠다, 물러가거라."
- "방자하도다! 누가 그대에게 그런 담력을 주었느냐?"
- "이 후궁은, 아직 네가 지시할 차례가 아니다."
```

### 비빈
```
자칭: 신첩, 첩신, 본궁(고위)
특징: 성격과 지위에 따라 변화
예시:
- 온화형: "신첩은 감히..."
- 교만형: "본궁의 말을, 네가 감히 듣지 않겠다?"
- 계략형: "언니 말씀이 옳습니다, 동생이 가르침을 받겠습니다."
```

### 궁녀/내시
```
자칭: 노비, 소인
특징: 공손하고, 조심스러우며, 눈치를 봄
예시:
- "노비 명을 받들겠나이다."
- "마마께 아뢰옵니다, 이러이러합니다..."
- "노비는 감히 함부로 말하지 못하겠나이다."
```

### 관료
```
자칭: 신, 미신, 하관
특징: 정식적이고, 조심스러우며, 분수를 앎
예시:
- "신이 아뢸 것이 있나이다."
- "미신은 황공하옵니다."
- "이 일에 대해, 신은 생각하기를..."
```

### 명문가 공자/소저
```
자칭: 소생, 소녀
특징: 교양 있고, 학식이 있음
예시:
- "소생 인사드립니다."
- "소녀 재주가 없어, 부끄럽습니다."
- "공자께서 과찬하십니다."
```

## 3. 고풍 대화 기법

### 1. 주어 생략
```
현대: 나는 알겠어.
고풍: 알겠소이다.

현대: 너 먼저 물러가.
고풍: 물러가거라.
```

### 2. 도치 문형
```
현대: 어떻게 왔어?
고풍: 어찌 오셨소?

현대: 이게 무슨 뜻이야?
고풍: 이 말씀은 무슨 뜻이옵니까?
```

### 3. 문언 허사
```
자주 쓰는 허사:
- 그뿐이다: 그만이다, 그것뿐이다
- 바로: 곧, 다름 아닌
- 그러하다: 뜻밖에도
- 원래: 본래, 처음부터
- 오히려: 도리어
```

### 4. 사자성어/관용구
```
네 글자 표현을 자주 씀:
- 말씀하실 것 없습니다
- 그러실 필요 없습니다
- 과찬이십니다
- 칭찬에 감사드립니다
- 그 명을 따르기 어렵습니다
- 공경이 복종보다 나은 법이옵니다
```

## 4. 감정 표현

### 분노
```
가벼움: "방자하도다!"
중간: "너 이놈 대담하구나!"
심함: "여봐라! 끌어내라!"
극도: "짐이 네 구족을 멸하리라!"
```

### 슬픔
```
절제: "그만이다..."
완곡: "마음이... 좀 편치 않소이다."
직접: "왜... 나에게 이러시는 겁니까?"
붕괴: "하늘이 어찌 이리 불공평하단 말입니까!"
```

### 기쁨
```
절제: "좋도다."
명확: "정녕? 좋구나!"
흥분: "하늘이 우리 대X를 돕는도다!"
```

### 풍자
```
가벼움: "동생 수단이 대단하시네."
중간: "언니 정말 대단한 계략이시네."
심함: "X가 딸답게, 과연... 남다르시네."
```

## 5. 클래식 대화 템플릿

### 처음 만남
```
A: "감히 아가씨 성함을 여쭈어도 되겠습니까?"
B: "소녀 성은 X이고, 이름은 X자 한 글자입니다."
A: "X 아가씨이셨군요, 반갑습니다."
B: "공자께서 예의 바르시네요."
```

### 문안 인사
```
"폐하/마마께 문안 드립니다."
"일어나거라."
"폐하/마마 감사드립니다."
```

### 요청 거절
```
완곡: "이 일은... 아마 적절하지 않을 것 같습니다."
직접: "그 명을 따르기 어렵습니다."
강경: "다시는 말씀하지 마시오!"
```

### 위협 경고
```
절제: "언니 스스로 잘 하시길."
명확: "만약 다음에도 그러시면, 본궁이 가만있지 않겠소."
직접: "본궁이 꼬투리를 잡지 않기를 기도하시오."
```

### 고백/암시
```
절제: "공자는 저에게, 다른 분과는 다릅니다."
명확: "그대를 흠모합니다."
직접: "이 생에서, 나는 오직 그대 한 사람만 인정하오."
```

## 6. 문체 조절

### 가벼운 고풍 (초보자 추천)
```
특징:
- 기본적으로 현대어
- 핵심 단어만 고풍어로 대체
- 대화는 고풍 느낌, 서술은 현대적

예시:
그녀는 그를 바라보며, 마음이 복잡했다.
"왜 이런 짓을 하시는 겁니까?"
"왜냐면..." 그가 잠시 멈추더니, "그대가 다치는 것을 원치 않아서."
```

### 중간 고풍 (주류)
```
특징:
- 대화는 전부 고풍화
- 서술은 반문반백
- 일정한 문언 문형 사용

예시:
그녀는 그를 응시하며, 마음에 온갖 감정이 교차했다.
"왜 이러시는 겁니까?"
그가 한동안 침묵하다가, 비로소 입을 열었다: "그저... 그대가 다치는 것을 차마 볼 수 없어서이오."
```

### 깊은 고풍 (실력 필요)
```
특징:
- 전체 문언화
- 전고를 많이 사용
- 문형이 정제됨

예시:
그녀가 눈을 들어 그를 바라보니, 마음에 온갖 맛이 뒤섞였다.
"군은 어찌하여 이 지경에 이르셨습니까?"
그가 오랫동안 묵묵히 있다가, 비로소 입을 열어 말했다: "그저... 경이 반 푼의 서글픔도 받는 것을 차마 못 보겠기에."
```

## 7. 흔한 실수

### 호칭 오류
```
❌ 황후가 자칭 "애가" (애가는 태후가 쓰는 것)
❌ 황제에게 "당신"이라 함 (고대에 "당신" 없음)
❌ 비빈끼리 "자기야"라 부름 (너무 현대적)
```

### 용어 오류
```
❌ "OK", "문제없어" (현대어)
❌ "내 생각에는" (너무 구어체)
❌ "알지?" (너무 현대적)
```

### 어조 오류
```
❌ 궁녀가 주인에게 "싫어요"라 함 (너무 강경)
❌ 황제가 "부탁해"라 함 (너무 비굴)
❌ 대신이 "아무거나"라 함 (너무 대충)
```
