# 고전 소설 인물 설계

> 고전 소설의 인물은 "고대"의 기질이 필요하다. 본 문서는 시대에 맞는 인물을 설계하는 방법을 제공한다.

---

## 1. 여주 유형

### 1. 가문 내 다툼형 여주
```
특징:
- 총명하고, 인내심 있으며, 수단이 있음
- 눈치가 빠름
- 남의 힘을 빌려 대응할 줄 앎

성장 라인:
괴롭힘 당함 → 반격을 배움 → 안살림 장악 → 안살림 주인이 됨

대표: 《알고 있지만(知否)》 성명란
```

### 2. 궁중 다툼형 여주
```
특징:
- 마음이 치밀
- 숨기는 것을 잘함
- 결정적 순간에 과감

성장 라인:
입궁 → 자리 잡기 → 단계적 승진 → 정상에 오름/무사 퇴장

대표: 《견환전(甄嬛传)》 견환
```

### 3. 권모술수형 여주
```
특징:
- 정치적 두뇌가 있음
- 큰 그림을 봄
- 안살림에 얽매이지 않음

성장 라인:
말려들어감 → 재능을 드러냄 → 큰일에 참여 → 조정 국면에 영향

대표: 《낭야방(琅琊榜)》 예홍군주
```

### 4. 달콤 사랑형 여주
```
특징:
- 성격이 매력적
- 약간의 재치
- 운이 좋음

성장 라인:
만남 → 사랑받음 → 작은 파란 → 행복한 결말

적합: 가벼운 달콤글
```

## 2. 남주 유형

### 1. 제왕형
```
특징:
- 위엄 있고, 깊음
- 의심 많지만 깊은 사랑
- 권력과 사랑의 모순

매력 포인트:
- 만인 위에 서서 그녀에게만 다정
- 그녀를 위해 규칙을 깨뜨림
- 강압적 소유
```

### 2. 왕자형
```
특징:
- 고귀하지만 최고 지위는 아님
- 더 자유로울 수 있음
- 자체 세력 보유

매력 포인트:
- 황위를 다투지 않고 그녀만 원함
- 그녀를 데리고 멀리 갈 수 있음
- 정의와 사악함 사이
```

### 3. 명문가 공자형
```
특징:
- 온화하고 빛나는 옥 같음
- 가문이 현저
- 교양 있음

매력 포인트:
- 군자의 풍도
- 묵묵히 지킴
- 다정하면서 굳건
```

### 4. 장군형
```
특징:
- 강철 같은 터프가이
- 전장의 영웅
- 말주변이 없음

매력 포인트:
- 겉은 차갑고 속은 따뜻
- 행동으로 사랑을 표현
- 보호 본능 강함
```

## 3. 조연 설계

### 악역 여조연
```
유형1: 적녀/정실
- 출신이 고귀, 여주를 무시
- 수단이 잔인
- 최종 비참한 결말

유형2: 백월광
- 겉으로는 청순
- 실제로는 계략적
- 남주와 과거 인연

유형3: 악시어머니/악시누이
- 여주를 괴롭힘
- 다른 사람을 편애
- 최종 얼굴 때리기 당함
```

### 조력 조연
```
유형1: 충성스러운 시녀
- 어릴 때부터 여주를 따름
- 충성스러움
- 결정적 순간에 도움

유형2: 좋은 자매
- 같은 비빈/시누이
- 서로 돕고 의지
- 진심으로 대함

유형3: 암위/호위
- 여주 보호
- 몰래 여주를 좋아할 수 있음
- 결정적 순간에 목숨 구함
```

## 4. 인물 관계 설계

### 궁중 관계
```
핵심 삼각: 황제 - 여주 - 황후/총애 비빈
보조 관계: 태후, 기타 비빈, 황자 공주
외곽 관계: 조정 세력, 모족 세력
```

### 가문 내 관계
```
핵심 삼각: 여주 - 남편 - 시어머니/첩실
보조 관계: 시누이, 동서, 하인
외곽 관계: 친정, 인척
```

### 권모 관계
```
핵심 삼각: 여주 - 남주 - 정적
보조 관계: 동맹, 부하, 가문
외곽 관계: 조정 각 파벌, 변방 세력
```

## 5. 인물 성장 곡선

### 여주 성장 곡선
```
단계1: 순수/약함
- 규칙을 모름
- 괴롭힘 당함
- 누군가 보호해줌

단계2: 각성/학습
- 반격 시작
- 수단을 배움
- 세력 구축

단계3: 강함/장악
- 고수가 됨
- 타인을 보호
- 목표 달성
```

### 남주 변화 곡선
```
유형1: 차가움에서 따뜻으로
- 초기 냉담
- 점점 마음이 끌림
- 최종 깊은 사랑

유형2: 오해에서 이해로
- 초기 오해
- 진실 발견
- 후회하며 보상

유형3: 성장형
- 초기 미성숙
- 시련 겪음
- 합격된 남편/제왕이 됨
```

## 6. 인물 디테일

### 외모 묘사
```
여주:
- 꼭 경국지색일 필요 없음
- 특징이 있으면 됨 (눈/기질)
- 시대 미학에 맞아야

남주:
- 잘생기되 여성스럽지 않게
- 기세가 있어야
- 신분에 맞아야
```

### 기술 설정
```
여주가 가질 수 있는 기술:
- 의술 (흔함)
- 요리 (매력적)
- 금기서화 (재녀)
- 경영 두뇌 (독립적)
- 무술 (특별)

주의: 기술에 출처가 있어야, 갑자기 나타나면 안 됨
```

### 성격 결함
```
인물을 더 사실적으로:
- 여주가 속좁거나, 원한을 품을 수 있음
- 남주가 남성우월주의나 의심이 많을 수 있음
- 결함은 수용 가능한 범위 내여야
```
