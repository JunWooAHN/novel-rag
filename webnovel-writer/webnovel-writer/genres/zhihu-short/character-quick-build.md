# 지후 단편 빠른 캐릭터 구축

> 단편은 캐릭터를 천천히 형상화할 시간이 없다. 본 문서는 선명한 캐릭터를 빠르게 구축하는 방법을 제공한다.

---

## 1. 핵심 원칙

### 단편 캐릭터 3요소
| 요소 | 역할 | 구축 방법 |
|------|------|---------|
| 태그 | 빠른 식별 | 한 문장 정의 |
| 반전 | 기억 포인트 | 겉과 속이 다름 |
| 욕망 | 스토리 추진 | 명확한 목표 |

### 캐릭터 경제학
```
장편: 10만 자로 복잡한 인물 형상화 가능
단편: 500자로 독자가 이 사람을 기억하게 해야
```

---

## 2. 한 문장 캐릭터 템플릿

### 기본 공식
```
[신분] + [반전 특성] + [핵심 욕망]
```

### 예시
| 유형 | 한 문장 캐릭터 |
|------|-----------|
| 여주 | 재벌가 딸이 가난한 친척으로 위장, 자신을 버린 친모에게 복수하기 위해 |
| 남주 | 냉면 총수가 모든 사람에게 냉담한데, 유독 전 아내에게만 겸손 |
| 악역 | 다정하고 현모양처인 백월광, 뒤에서는 가장 깊은 계략의 녹차 |
| 조연 | 가십 좋아하는 것처럼 보이는 친구, 결정적 순간에 항상 여주 편 |

---

## 3. 빠른 캐릭터 도구함

### 1. 신분 태그 라이브러리
```
여주: 진짜 천금/가짜 천금/몰락 천금/사생아, 여총수/평직원/디자이너/의사/변호사, 고아/환생자/전생자/대역
남주: 재벌/태자/사생자/몰락 도련님, CEO/의사/변호사/군인/경찰, 병적/금욕/강아지/늑대
```

### 2. 반전 특성 라이브러리
```
겉은 차갑고 속은 따뜻, 겉은 따뜻하고 속은 차가움, 강자가 약한 척, 약자가 강한 척, 흑화 반전, 세탁 반전
```

### 3. 핵심 욕망 라이브러리
```
복수, 증명, 수호, 탈출, 획득(사랑/권력/돈), 구원
```

## 4. 캐릭터 스케치 기법

### 1. 행동 정의법
```
"그녀가 강하다"라고 말하지 말고
"건물에서 떨어지는 순간, 그녀는 난간을 잡았다"라고 쓰기
```

### 2. 대화 정의법
```
"그녀는 독설가다"라고 말하지 말고
대화를 쓰기: "네가 뭔데?" "네 미래의 형수."
```

### 3. 디테일 정의법
```
"그는 부자다"라고 말하지 말고
"그가 무심코 준 팁이, 내 한 달 월급이었다"라고 쓰기
```

---

## 5. 자주 쓰이는 캐릭터 템플릿

### 여주: 참음→각성형, 돼지 코스프레형, 냉정 독립형
### 남주: 아내 되찾기 화장장형, 숨겨진 깊은 사랑형, 병적 소유형

---

## 6. 조연 스케치

**악역**: 녹차 백월광, 악독한 여조연, 나쁜 남자 전 연인, 악시어머니
**조력**: 독설 친구, 흑막 비서, 따뜻한 비석, 각성 가족

---

## 7. 캐릭터 점검 리스트

- [ ] 한 문장으로 이 인물을 요약할 수 있는가?
- [ ] 인물에게 명확한 욕망/목표가 있는가?
- [ ] 인물에게 기억 포인트(반전/특성)가 있는가?
- [ ] 인물 행동이 설정에 맞는가?
- [ ] 독자가 다른 인물을 빠르게 구분할 수 있는가?
