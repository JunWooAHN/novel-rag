# 지후 단편 리듬 조절

> 단편의 리듬은 생명선이다. 본 문서는 지후 단편(3000-15000자)의 리듬 조절 방법을 제공한다.

---

## 1. 리듬 기초 이론

### 단편 vs 장편 리듬 차이
| 차원 | 장편 | 단편 |
|------|------|------|
| 전개 | 천천히 가능 | 반드시 빠르게 |
| 전환점 | 여러 번 작은 전환 | 1-3번 큰 전환 |
| 감정 | 물결치듯 오르내림 | 직선으로 정상을 향해 |
| 여백 | 많은 여백 | 정확한 여백 |

### 황금 리듬 공식
```
단편 리듬 = 훅(10%) + 온도 상승(30%) + 클라이맥스(40%) + 마무리(20%)
```

---

## 2. 글자수별 배분 템플릿

### 3000자 단편
| 단계 | 글자수 | 내용 |
|------|------|------|
| 훅 | 300 | 서스펜스 조성, 상황 구축 |
| 온도 상승 | 900 | 갈등 심화, 감정 축적 |
| 클라이맥스 | 1200 | 폭발점, 핵심 갈등 |
| 마무리 | 600 | 반전 또는 승화 |

### 8000자 중편
| 단계 | 글자수 | 내용 |
|------|------|------|
| 훅 | 500 | 서스펜스+인물+상황 |
| 1막 | 2000 | 갈등 구축, 첫 전환 |
| 2막 | 3000 | 갈등 격화, 감정 클라이맥스 |
| 3막 | 2500 | 대반전+결말 |

### 15000자 장단편
| 단계 | 글자수 | 내용 |
|------|------|------|
| 오프닝 | 1000 | 훅+배경+인물 |
| 전개 | 4000 | 갈등 구축, 관계 변화 |
| 전환 | 3000 | 첫 대반전 |
| 클라이맥스 | 4000 | 핵심 갈등 폭발 |
| 결말 | 3000 | 최종 반전+마무리 |

---

## 3. 리듬 조절 기법

### 1. 장면 전환법
```
빠른 리듬: 장면 건너뛰기, 전환 생략
"3일 후, 법원." "한 달 후, 그의 회사가 파산했다."

느린 리듬: 디테일 묘사, 감정 렌더링
핵심 장면에 사용: 대면, 고백, 죽음
```

### 2. 문형 조절법
```
가속: 단문, 끊는 문장, 대화
감속: 긴 문장, 묘사, 내면
```

### 3. 정보 밀도법
```
고밀도(빠름): 매 문장에 새 정보
저밀도(느림): 감정 렌더링, 분위기 조성
```

---

## 4. 감정 곡선 설계

학대물: 전개→아픔 정점→반전(HE/BE)
통쾌글: 참음→얼굴 때리기→대통쾌
달콤글: 오해→밀당→HE

---

## 5. 전환점 설계

- 단일 전환(3000자): 전개→【전환】→결말
- 이중 전환(8000자): 전개→【전환1】→발전→【전환2】→결말
- 삼중 전환(15000자): 전개→【전환1】→발전→【전환2】→클라이맥스→【전환3】→결말

---

## 6. 리듬 응급 가이드

- 오프닝 너무 느림 → 배경 삭제, 갈등에 바로 진입
- 중간 늘어짐 → 무관 장면 삭제, 시간 건너뛰기
- 클라이맥스 약함 → 전개의 "참음" 강화, 장면 연장
- 결말 급함 → 반전에 충분한 분량, 감정 마무리 추가

---
