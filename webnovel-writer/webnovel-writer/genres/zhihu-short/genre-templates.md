# 지후 단편 장르별 템플릿

> 본 문서는 지후 인기 단편 장르의 완전한 템플릿을 제공하며, 바로 적용할 수 있다.

---

## 1. 아내 되찾기 화장장 (8000자 템플릿)

### 구조
```
오프닝(500자): 남주 아내 되찾기 진행 중, 여주 냉담
플래시백(2500자): 당초 어떻게 학대했는가
현재(2500자): 그녀의 변화, 그의 겸손
전환점(1500자): 진실/계기
결말(1000자): 깨진 거울 복원/완전히 내려놓기
```

---

## 2. 환생 복수 (5000자 템플릿)

### 구조
```
오프닝(500자): 전생 비참한 죽음/환생 순간
포석(1500자): 핵심 시점 변경
대결(2000자): 원수와 직면
결말(1000자): 복수 성공+새 삶
```

---

## 3. 재벌가 진짜 가짜 천금 (10000자 템플릿)

### 구조
```
오프닝(800자): 정체 폭로/재벌가 복귀
적응(2500자): 배척/비교당함
반격(3500자): 실력 과시/얼굴 때리기
진실(2200자): 당년의 진실/막후 흑수
결말(1000자): 모든 것 되찾기
```

---

## 4. 연예계 마갑 (8000자 템플릿)

### 구조
```
오프닝(500자): 조롱/무시당함
전개(2000자): 각종 마갑(숨겨진 정체) 암시
마갑 벗기기(3500자): 하나씩 정체 공개
마무리(2000자): 전 인터넷 충격+설탕 뿌리기
```

---

## 5. 계약 결혼 (6000자 템플릿)

### 구조
```
오프닝(500자): 계약 이유/규칙 정하기
함께하기(2000자): 낯선 사이에서 익숙하게
설렘(2000자): 자각 못 하는 관심
대면(1500자): 계약 만료/진심 고백
```

---

## 6. 병적 집착 (5000자 템플릿)

### 구조
```
오프닝(500자): 병적 행동 전시
회상(1500자): 왜 이렇게 되었는가
현재(2000자): 소유와 갈등
결말(1000자): 구원/침몰
```

---

## 7. 먼저 결혼 후 사랑 (8000자 템플릿)

### 구조
```
오프닝(600자): 정략결혼 이유/결혼식
적응(2400자): 동거 일상/서로 탐색
썸(2500자): 설렘 순간/질투
확인(2500자): 고백/위기/HE
```

---

## 8. 템플릿 사용 가이드

1. 핵심 감정 결정 (통쾌/아픔/달콤)
2. 글자수 범위 결정
3. 맞는 템플릿 선택
4. 캐릭터 적용, 핵심 장면 설계, 명대사 작성

### 템플릿 조합 기법

| 조합 | 효과 | 예시 |
|------|------|------|
| 환생+아내 되찾기 | 아픔+통쾌 | 환생 후 그의 아내 되찾기 구경 |
| 재벌가+연예계 | 통쾌+달콤 | 재벌가 딸이 연예계 진입 |
| 계약+먼저 결혼 후 사랑 | 순수 달콤 | 계약 결혼으로 시간이 지나며 사랑 |
| 병적+환생 | 아픔+구원 | 환생 후 병적 치유 |
