# 지후 단편 스토리 압축 기법

> 단편의 예술은 삭제의 예술이다. 본 문서는 장편 스토리를 단편으로 압축하는 실용 기법을 제공한다.

---

## 1. 압축 핵심 원칙

### 뺄셈 사고
```
장편 사고: 이 줄거리를 추가할 수 있다
단편 사고: 이 줄거리를 꼭 삭제해야 하나?
```

### 압축 공식
```
단편 = 핵심 갈등 + 핵심 전환 + 감정 클라이맥스
삭제 = 서브 라인 + 전환 + 반복 + 설명
```

---

## 2. 5대 압축 기법

### 1. 시간 건너뛰기법
```
원문(500자): 여주가 남편 외도를 발견하고, 미행 취재하고, 내면 갈등하는 상세 묘사...
압축(50자): "3개월간의 미행 취재, 한 더미의 사진과 이혼 합의서로 바뀌었다."
```

### 2. 결과 앞세우기법
```
원문: 원인을 먼저 전개하고, 결과를 나중에
압축: 결과를 먼저 주고, 플래시백으로 원인 보충
```

### 3. 대화가 서술을 대체
```
원문(200자): 시어머니가 계속 무시한다는 긴 서술...
압축(50자): "내 아들이 뭔데, 네가 뭔데?" 시어머니의 말, 3년간 들었다.
```

### 4. 디테일이 묘사를 대체
```
원문(300자): 얼마나 가난한지, 집이 얼마나 허름한지, 뭘 먹는지 상세 묘사...
압축(30자): 냉장고에 배추 반 포기만 남았고, 이미 1주일째.
```

### 5. 여백 암시법
```
원문: 사정을 자세히 설명
압축: 핵심 정보만 주고, 독자가 스스로 추론
```

---

## 3. 삭제 우선순위

### 반드시 보존
1. 핵심 갈등 (이야기 존재 이유)
2. 주요 전환점 (줄거리 추진 핵심)
3. 감정 클라이맥스 (독자 쾌감/아픔 포인트)
4. 결말 반전 (이야기의 착지점)

### 우선 삭제
1. 부차 인물의 서브 라인
2. 반복 강조 정보
3. 전환 장면
4. 배경 설명
5. 심리 활동의 반복

---

## 4. 흔한 스토리 압축 예시

### 아내 되찾기 화장장 압축
장편(50만 자) → 단편(8000자): 이미 이별 상태에서 시작, 플래시백으로 학대 보여주기

### 환생 복수 압축
장편(80만 자) → 단편(5000자): 핵심 원수 하나만 잡고, 직접 대결

### 재벌가 은원 압축
장편 → 단편(10000자): 핵심 갈등 하나(진짜 가짜 천금/유산 쟁탈)에 집중, 인물 2-3명만

---

## 5. 정보 전달 기법

### 1. 삽입식 배경
```
잘못: 먼저 500자로 배경 소개
올바름: 대화/행동 속에서 자연스럽게
"3년이 됐는데, 아직도 이 허름한 원룸에 살아?" (한 문장으로: 시간+경제 상태+인간관계)
```

### 2. 빙산식 글쓰기
```
빙산 위만 쓰고, 수면 아래는 독자가 상상
"그녀는 핸드폰을 봤다, 47번째 부재중 전화였다." (누가, 왜 안 받았는지 안 설명)
```

### 3. 상징 표현
```
하나의 상징으로 긴 묘사 대체: 반지=결혼 상태, 임신테스트기=임신, 진단서=중병, 친자확인=출생의 비밀
```

## 6. 압축 점검 리스트

### 삭제 점검
- [ ] 삭제할 수 있는 부차 인물이 있는가?
- [ ] 반복 표현된 정보가 있는가?
- [ ] 건너뛸 수 있는 전환 장면이 있는가?
- [ ] 과다한 심리 묘사가 있는가?

### 효율 점검
- [ ] 매 장면이 스토리를 추진하는가?
- [ ] 매 대화에 정보량이 있는가?
- [ ] 최소 글자수로 정보를 전달했는가?

### 완성도 점검
- [ ] 핵심 갈등이 명확한가?
- [ ] 전환점이 충분히 강력한가?
- [ ] 결말에 여운이 있는가?
