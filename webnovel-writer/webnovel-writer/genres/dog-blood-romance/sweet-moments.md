# 달콤 장면 설계 (Sweet Moments Design)

> **핵심 원칙**: 달콤 장면은 로맨스 소설의 "설탕"으로, "아픔"을 균형 맞추는 데 사용된다. 달콤도는 적당해야 하며, 너무 달면 느끼하고, 너무 싱거우면 맛이 없다. 독자가 글을 쫓는 동력 = 아픔 후의 달콤 + 다음 달콤에 대한 기대.

---

## 1. 달콤 장면의 5대 유형

### 유형 1: 애지중지 일상 (Pet Daily Life)

**핵심 공식**:
```
남주 강압적 애지중지 + 여주 애교/건방 = 달콤 폭격
```

**클래식 장면**:
| 장면 | 남주 행동 | 여주 반응 | 달콤 등급 |
|------|---------|---------|---------|
| **밥 먹여주기** | "입 벌려." (직접 먹여줌) | "나 애기 아닌데..." | ⭐⭐⭐ |
| **옷 입히기** | 여주 단추/신발끈 매주기 | 얼굴 빨개짐, 밀치며: "나 혼자 할 수 있어!" | ⭐⭐⭐ |
| **안아주기** | 뒤에서 안으며, 턱을 어깨에 올림 | "또 이러고..." | ⭐⭐⭐⭐ |
| **머리 쓰다듬기** | 머리를 쓰다듬며: "착하지." | 입 삐죽: "머리 만지지 마, 키 안 커!" | ⭐⭐⭐ |
| **벽치기** | 벽 구석에 가두기 | 긴장, 심장 두근두근 | ⭐⭐⭐⭐⭐ |

**예시**:
```
【밥 먹여주기 달콤】
"입 벌려." 린무한이 생선살을 집어 그녀 입가에 대었다.
"나 애기 아닌데..." 쑤녠이 투덜거렸지만, 얌전히 입을 벌렸다.
"응, 착하네." 그가 웃었고, 눈에 애지중지가 가득했다.

【벽치기 달콤】
린무한이 갑자기 다가와, 양손으로 그녀 양옆을 짚으며, 벽 구석에 가두었다.
"너... 뭐 하는 거야..." 쑤녠이 긴장하며 그를 바라보았다.
"어떤 것 같아?" 그가 고개를 숙이며, 숨결이 그녀 얼굴에 닿았다.
쑤녠의 심장이 튀어나올 것 같이 빨리 뛰었다.
```

### 유형 2: 신체 접촉 (Physical Contact)

**핵심 공식**:
```
우연한 접촉 → 심장 두근두근 → 애매모호한 분위기 → 독자 비명
```

**접촉 진행 단계** (점진적):
```
1단계: 손잡기 (첫 접촉, 심장 두근)
2단계: 허리 안기/어깨 감싸기 (친밀 업그레이드)
3단계: 포옹 (안정감 가득)
4단계: 이마 맞대기/코 닿기 (초근접 거리)
5단계: 키스 (감정 폭발)
6단계: 베드신 암시 (점까지만, 세부 묘사 안 함)
```

**각 단계 예시**:

#### 1단계: 손잡기
```
【우연한 손잡기】
사람이 붐비는 가운데, 린무한이 그녀의 손을 잡았다.
"길 잃지 마." 그가 담담하게 말했다.
쑤녠의 얼굴이 순식간에 빨개졌다.
(그가... 그가 내 손을 잡았어!)

【자발적 손잡기】
"손 내밀어."
"왜?"
"네가 도망갈까 봐." 린무한이 강하게 그녀의 손을 잡으며, 열손가락을 꼭 맞잡았다.
```

#### 3단계: 포옹
```
【보호하는 포옹】
"걱정 마, 내가 있잖아."
린무한이 그녀를 꽉 안았다.
쑤녠은 그에게서 은은한 향수 냄새를 맡았고, 심장이 북처럼 뛰었다.

【뒤에서 포옹】
린무한이 뒤에서 그녀의 허리를 감쌌다.
"너... 이러지 마..." 쑤녠이 발버둥쳤다.
"잠깐만 안고 있을게, 움직이지 마." 그의 목소리가 낮고 부드러웠다.
```

#### 5단계: 키스
```
【첫 키스】
린무한이 몸을 숙여, 그녀의 입술에 키스했다.
쑤녠은 눈을 크게 떴고, 머리가 새하얘졌다.
(그가... 그가 나한테 키스했어!)

【강압적 키스】
"넌 내 거야, 다른 남자 더 이상 쳐다보지 마."
말이 끝나기도 전에, 그가 그녀의 얼굴을 감싸며 세게 키스했다.
```

---

### 유형 3: 고백 (Confession)

**핵심 공식**:
```
감정 전개 → 남주 고백 → 여주 충격/감동 → 관계 확인
```

**클래식 고백 유형**:

#### A형: 강압적 고백
```
"쑤녠, 좋아해."
"뭐...?"
"널 처음 본 날부터, 좋아하게 됐어."
린무한이 그녀를 품에 안았다.
"그러니까, 넌 오직 내 것이어야 해."
```

#### B형: 깊은 감정 고백
```
"쑤녠, 알아?"
"뭐?"
"나 이 생에서, 딱 한 사람만 사랑했어."
그가 그녀의 눈을 바라보며, 눈에 깊은 사랑이 가득했다.
"기회를... 줄 수 있어?"
```

#### C형: 행동으로 고백 (말로 사랑한다고 안 하고, 행동으로 증명)
```
"왜 나한테 이렇게 잘해줘?" 쑤녠이 물었다.
린무한은 대답하지 않고, 그녀의 머리만 쓰다듬었다.
"바보."
(왜냐면 널 사랑하니까...)
```

---

### 유형 4: 질투와 애교 (Jealousy & Acting Cute)

**핵심 공식**:
```
남주 질투 → 소유욕 폭발 → 강압적 주인 선언 → 달콤
```

**남주 질투 장면**:
```
【질투 1.0】
"아까 왜 저 남자한테 말 걸었어?"
"그 사람이 길을 물어봤을 뿐인데..."
"앞으로 다른 남자한테 말 걸지 마."
"이건 좀 너무 독단적이잖아!"
"나는 원래 독단적이야." 그가 그녀의 허리를 감싸며, "넌 오직 내 것이어야 해."

【질투 2.0 (질투왕 등판)】
"누가 허락했어 이렇게 달콤하게 웃으라고?"
"응?" 쑤녠이 어리둥절했다.
"다른 남자한테, 웃지 마."
"...그게 무슨 논리야?"
"내 논리야." 린무한이 강압적으로 그녀에게 키스했다.
```

**여주 애교 장면**:
```
【애교로 안아달라기】
"린무한..." 쑤녠이 그의 소매를 잡았다.
"응?"
"안아줘..." 그녀가 작은 소리로 말하며, 얼굴이 사과처럼 빨개졌다.
린무한의 마음이 녹았고, 그녀를 품에 안았다.
"왜 이렇게 귀여워..."

【애교로 용서 구하기】
"잘못했어요..." 쑤녠이 그의 팔을 안으며, 큰 눈을 깜빡였다.
"..." 린무한이 고개를 돌렸다, "애교 부린다고 소용있는 줄 알아."
"그러면 아직 화났어?"
"...안 화나." 그가 항복했다.
```

---

### 유형 5: 영웅 구출 (Hero Saves Beauty)

**핵심 공식**:
```
여주 위험 → 남주 당당하게 등장 → 여주 보호 → 여주 마음이 움직임
```

**클래식 장면**:

#### 장면A: 구조 (사교 자리)
```
"쑤 씨, 저와 한 잔 하시죠?" 끈적한 남자가 귀찮게 굴었다.
"죄송해요, 남자친구가 기다리고 있어서요." 쑤녠이 사양했다.
"남자친구가 누군데?"
그때, 린무한이 다가와 쑤녠의 허리를 감쌌다.
"내가 그녀의 남자친구야. 문제 있어?"
그의 눈빛이 차갑자, 끈적한 남자는 겁먹고 연거푸 물러났다.
```

#### 장면B: 목숨 구하기 (위험 상황)
```
【납치 구출】
"놔줘!" 린무한이 문을 걷어차며, 눈에 살기가 가득했다.
"린... 린무한..." 쑤녠이 울며 그를 불렀다.
"걱정 마, 내가 왔어."
그가 단숨에 납치범들을 제압하고, 그녀를 꽉 안았다.
"미안해, 고생시켜서..."
```

## 2. 달콤 장면의 단계별 배치

### 초기 (썸 시기): 작은 달콤 과자

**특징**: 탐색, 얼굴 빨개짐, 심장 두근, 아슬아슬

**달콤 방식**:
- 우연한 신체 접촉 (부딪힘, 손잡기)
- 눈 마주침 (3초 마주보다가, 얼굴 빨개지며 시선 돌림)
- 작은 계략 (일부러 가까이, 우연 만들기)
- 보호 (비 막아주기, 위험 막아주기)

**예시**:
```
【우연한 접촉】
지하철이 갑자기 급정거하자, 쑤녠이 비틀거리며 린무한의 품에 부딪혔다.
"죄... 죄송합니다..." 그녀가 황급히 물러나며, 얼굴이 익은 새우처럼 빨개졌다.
"조심해." 그가 그녀를 잡아주며, 입꼬리가 살짝 올라갔다.

【눈빛 킬】
쑤녠이 고개를 들자, 마침 린무한의 눈과 마주쳤다.
두 사람이 3초간 바라보았다.
그녀는 황급히 시선을 돌렸고, 심장이 북처럼 뛰었다.
(그의 눈... 정말 예쁘다...)
```

---

### 중기 (연애 시기): 일상 달콤

**특징**: 관계 확인, 공개 사랑 과시, 애지중지 상호작용

**달콤 방식**:
- 일상 상호작용 (밥 먹여주기, 머리 쓰다듬기, 안아주기)
- 작은 서프라이즈 (꽃, 선물, 깜짝 이벤트)
- 질투 애교 (소유욕, 질투 다툼)
- 친밀한 접촉 (키스, 포옹, 손잡기)

**예시**:
```
【모닝 키스】
쑤녠이 막 잠에서 깨, 멍한 상태로 눈을 떴다.
린무한이 몸을 숙여, 그녀의 이마에 키스했다.
"좋은 아침, 내 보물."
"으..." 그녀가 얼굴을 붉히며, 이불 속에 머리를 파묻었다.

【약 먹이기 달콤】
"입 벌려." 린무한이 약을 들고 있었다.
"너무 써..."
"착하지, 먹으면 사탕 줄게."
"나 애기 아닌데..."
"그러면 먹을 거야 말 거야?"
"...먹을게." 쑤녠이 타협했다.
약을 먹고, 린무한이 사탕 하나를 건넸다.
"착하네." 그가 그녀의 머리를 쓰다듬었다.
```

---

### 후기 (결혼 후/안정기): 잔잔한 흐름

**특징**: 생활화된 달콤, 부부의 온정

**달콤 방식**:
- 생활 상호작용 (요리, 설거지, TV 보기)
- 작은 재미 (갑작스런 키스, 포옹, 달콤한 말)
- 기념일 (결혼기념일, 첫 만남 기념일)
- 아이 (아이가 생긴 후의 가정 온정)

**예시**:
```
【요리 달콤】
"자기야, 간 좀 봐줘."
린무한이 다가와, 한 입 맛봤다.
"응, 딱 좋아."
"다행이다~" 쑤녠이 웃었다.
린무한이 갑자기 뒤에서 그녀를 안았다.
"근데, 너가 더 달콤해."

【잠자기 전 달콤】
"졸려?" 린무한이 물었다.
"응..." 쑤녠이 그의 품에 웅크렸다.
"자, 잘 자." 그가 그녀의 이마에 키스했다.
"잘 자..."
```

## 3. 달콤 대화 템플릿

### 템플릿 1: 달콤한 말 공격

**남주 달콤한 말**:
```
"네 가장 큰 단점이 뭔지 알아?"
"뭐?"
"너무 귀여운 거."

"내가 뭘 먹고 싶은 것 같아?"
"뭐?"
"멍하니 너를 바라보기."

"넌 나의 뭐야?"
"...여자친구?"
"아니, 넌 내 목숨이야."
```

**여주 부끄러운 반응**:
```
"너... 입 닥쳐!" (얼굴 빨개짐)
"입만 살았네..." (입꼬리 올라감)
"싫어..." (작은 소리)
```

---

### 템플릿 2: 애지중지 대화

```
【애지중지 1】
여주: "아이스크림 먹고 싶어."
남주: "안 돼, 감기 걸렸잖아."
여주 (애교): "한 입만..."
남주 (항복): "...한 입만."
여주 (기쁨): "좋아!"

【애지중지 2】
여주: "왜 나한테 이렇게 잘해줘?"
남주: "넌 내 여자니까."
여주 (얼굴 빨개짐): "..."
남주 (머리 쓰다듬으며): "바보."
```

---

### 템플릿 3: 소유욕 대화

```
【소유욕 1】
남주: "넌 누구 거야?"
여주: "...네 거."
남주: "더 크게."
여주 (얼굴 빨개짐): "나는 네 거야!"
남주 (만족): "응, 착하네."

【소유욕 2】
남주: "기억해, 넌 오직 내 것이어야 해."
여주: "알았어..."
남주: "다른 남자, 쳐다보는 것도 안 돼."
여주: "이건 좀 너무 독단적이잖아?"
남주: "나는 원래 독단적이야."
```

## 4. 신체 접촉 진행 설계

### 진행 조절 원칙

**금기**: 너무 빠르고 세게 (1화에서 바로 베드신)
**올바름**: 점진적, 단계적

**표준 진행표**:
```
1-10화: 우연한 접촉 (부딪힘, 손잡기)
11-20화: 자발적 접촉 (허리 안기, 어깨 감싸기, 머리 쓰다듬기)
21-30화: 친밀한 접촉 (포옹, 이마 맞대기)
31-40화: 감정 폭발 (키스)
41화+: 더 나아가기 (암시만, 세부 안 씀)
```

**매 접촉 후의 반응**:
```
【처음 손잡기】
쑤녠의 심장이 튀어나올 것 같았다.
(그가... 그가 내 손을 잡았어!)
그녀가 몰래 그를 봤지만, 그는 표정 변화가 없었다.

【처음 키스】
쑤녠의 머리가 새하얘지고, 온몸이 경직되었다.
린무한이 그녀를 놓으며, 이마를 그녀의 이마에 맞댔다.
"긴장하지 마..." 그가 낮게 말했다.
```

## 5. 달콤 장면의 리듬 조절

### 황금 비율

**달콤:아픔 비율**: 6:4 또는 7:3 (달콤 많고 아픔 적지만, 아픔은 있어야)

**챕터 배치**:
```
연속 달콤: 3-5화 (5화 넘기지 말 것, 느끼해짐)
연속 아픔: 2-3화 (3화 넘기지 말 것, 글 포기)
```

**예시 리듬**:
```
1-5화: 달콤 (관계 확인, 일상 애지중지)
6-8화: 아픔 (오해, 냉전)
9-12화: 달콤 (화해, 더 달콤)
13-15화: 아픔 (제3자 등장)
16-25화: 달콤 (입장 표명, 아픔 후 배로 달콤)
```

---

### 달콤 강도 점진적 증가

**원칙**: 뒤의 달콤이 앞보다 더 달아야

```
초기 달콤: ⭐⭐⭐ (손잡기, 얼굴 빨개짐)
중기 달콤: ⭐⭐⭐⭐ (포옹, 키스)
후기 달콤: ⭐⭐⭐⭐⭐ (고백, 관계 확인, 공개)
클라이맥스 달콤: ⭐⭐⭐⭐⭐⭐ (프러포즈, 결혼, 출산)
```

## 6. 과도한 달콤 느끼함 피하기

### 반면교사 (너무 달고 느끼함)

```
【과도한 달콤 느끼함】
1-50화:
- 남주가 매일 여주를 각종 방법으로 애지중지
- 어떤 갈등도 없음
- 매일 설탕 뿌리기
- 독자: 지루해, 글 포기

【올바른 방법】
달콤 속에 아픔, 아픔 후 더 달콤.
```

---

### 달콤 장면의 "여백"

**뭐든 다 쓰지 말 것**:
```
❌ 잘못: 아침 기상부터 밤 잠자리까지 모든 세부를 묘사
✅ 올바름: 핵심 달콤 순간만 쓰고, 나머지는 건너뛰기
```

**예시**:
```
【여백 예시】
두 사람은 오후 내내 쇼핑하며, 많은 것을 샀다.
【쇼핑 세부 건너뛰고, 바로 저녁 식사로】
저녁 식사 때, 린무한이 그녀에게 반찬을 집어주었다.
"많이 먹어, 너무 말랐어."
"나 안 말랐는데..." 쑤녠이 투덜거렸다.
"내 눈에는 마른 거야." 그가 고집했다.
```

## 7. 특별 달콤 장면

### 장면 A: 아플 때 돌봐주기

```
【여주 아플 때】
쑤녠이 고열을 앓으며, 멍한 상태로 잠들었다.
린무한은 밤새 잠을 자지 않고, 침대 옆을 지켰다.
날이 밝았을 때, 그녀가 눈을 뜨자 보인 것은 그의 부은 눈이었다.
"너... 밤새 안 잤어?"
"응." 그가 그녀의 손을 잡으며, "놀래 죽는 줄 알았어..."

【남주 아플 때 (반전 매력)】
"나... 너무 힘들어..." 린무한이 침대에 엎드려, 어린아이처럼.
쑤녠이 웃으면서도 안쓰러웠다: "감기일 뿐인데..."
"나 돌봐줘..." 그가 그녀의 손을 잡았다.
"알았어 알았어, 돌봐줄게." 그녀가 어쩔 수 없다는 듯이.
(평소에는 이렇게 독단적인데, 아프면 어린아이가 되네...)
```

---

### 장면 B: 기념일 서프라이즈

```
【생일 서프라이즈】
"생일 축하해!"
린무한이 불을 켜자, 방 안에 장미꽃이 가득했다.
쑤녠이 입을 가리며, 눈물이 멈추지 않았다.
"너... 언제 준비한 거야..."
"진작부터 준비했어." 그가 다가와, 그녀를 품에 안았다.
"마음에 들어?"
"마음에 들어... 너무 좋아..."

【프러포즈 장면】
"쑤녠, 나와 결혼해줘."
린무한이 한쪽 무릎을 꿇고, 손에 반지를 들었다.
주위 사람들이 떠들었다: "결혼해! 결혼해!"
쑤녠이 울면서 고개를 끄덕였다: "그럴게..."
```

---

### 장면 C: 여주 보호 (당당한 편 보호)

```
【편 보호 1.0】
"그녀는 내 여자야, 누가 감히 건드려?"
린무한이 쑤녠 앞을 막으며, 눈에 살기가 가득했다.

【편 보호 2.0】
"그녀를 괴롭히는 건, 나를 괴롭히는 거야."
린무한이 차갑게 상대를 바라보았다.
"알아서 할 거면, 지금 사과해."

【편 보호 3.0 (극한)】
"그녀 머리카락 한 올이라도 건드리면, 전부 쓸어버릴 거야."
전체 장소가 조용해졌다.
아무도 감히 움직이지 못했다.
```

## 8. 달콤 장면 자가 점검 리스트

- [ ] **전개가 있는가**: 달콤 장면에 감정 전개가 있는가? (갑작스럽면 안 됨)
- [ ] **캐릭터에 맞는가**: 남주/여주의 반응이 그 성격에 맞는가?
- [ ] **리듬이 합리적인가**: 달콤 강도가 점진적으로 증가하는가? 달콤과 아픔이 교차하는가?
- [ ] **충분히 섬세한가**: 심리 활동과 신체 반응을 묘사했는가? (얼굴 빨개짐, 심장 두근)
- [ ] **과하지 않은가**: 연속 5화 이상 순수 달콤을 피했는가?
- [ ] **새로운가**: 이번 달콤과 지난번 달콤이 어떻게 다른가?

| 달콤 유형 | 달콤도 | 적합 단계 | 핵심 요소 | 예시 |
|---------|------|---------|---------|------|
| **일상 애지중지** | ⭐⭐⭐ | 전체 단계 | 밥 먹여주기, 머리 쓰다듬기, 안아주기 | "입 벌려." |
| **신체 접촉** | ⭐⭐⭐⭐ | 썸 시기+ | 손잡기, 포옹, 키스 | 열손가락 맞잡기 |
| **고백** | ⭐⭐⭐⭐⭐ | 핵심 노드 | 깊은 눈빛, 달콤한 말 | "좋아해." |
| **질투 애교** | ⭐⭐⭐⭐ | 연애기 | 소유욕, 강압적 선언 | "넌 내 거야!" |
| **영웅 구출** | ⭐⭐⭐⭐⭐ | 위기 순간 | 보호, 당당한 등장 | "누가 감히 건드려?" |
| **기념일 서프라이즈** | ⭐⭐⭐⭐⭐⭐ | 클라이맥스 | 서프라이즈, 감동의 눈물 | 프러포즈, 생일 |

## 달콤 장면의 궁극 공식

```
감정 전개 (심리 활동)
    ↓
달콤 상호작용 (대화+동작)
    ↓
신체 반응 (얼굴 빨개짐, 심장 두근)
    ↓
여백 (갑자기 멈춤, 서스펜스)
```

**예시**:
```
【전개】
쑤녠은 좀 긴장되어, 감히 그를 보지 못했다.
(그가 혹시...)

【상호작용】
린무한이 갑자기 그녀의 손을 잡았다.
"나와 함께해줄래?"

【반응】
쑤녠의 심장이 튀어나올 것 같았다.
그녀가 작은 소리로 말했다: "...좋아."

【여백】
린무한이 웃으며, 그녀를 품에 안았다.
석양의 빛이 두 사람에게 내리쬐었다...
(뒷이야기는 독자 상상에 맡김)
```
