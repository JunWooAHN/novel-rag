# 막장 로맨스 클래식 클리셰 모음 (Romance Tropes)

> **핵심 원칙**: 클리셰는 문제가 아니다, 클리셰를 잘 쓰는 것이 핵심이다. 독자가 좋아하는 건 "새로운 것"이 아니라 "통쾌한 것"이다. 클래식 클리셰가 클래식인 이유는 독자의 감정 포인트를 정확히 자극하기 때문이다.

---

## 1. 10대 클래식 클리셰

### 클리셰 1: 재벌 총수 (Dominant CEO)

**핵심 공식**:
```
재벌 총수 + 신데렐라 여주 = 권력차+신분차 → 충돌 → 정복 → 달콤
```

**필수 요소**:
- **남주 설정**: 젊고 유능(28-35세), 재산 억대, 겉은 차갑고 속은 따뜻, 결벽증/강박증
- **여주 설정**: 평범한 소녀, 착하고 강인, 경제적 어려움, 자존심 있음
- **핵심 줄거리**:
  1. 우연한 만남(차 사고/구조/오해)
  2. 계약/합의(가짜 여친/대리모/거래)
  3. 강압적 추구(기다리기/벽치기/강제 키스)
  4. 학대적 사랑(오해/이별/질병)
  5. 달콤한 결말(고백/결혼/출산)

**예시 장면**:
```markdown
【재벌 선언】
"여자, 너는 성공적으로 내 관심을 끌었어."
육 총수가 위험한 눈빛으로 그녀를 응시했다.

【벽치기 장면】
그가 한 손으로 벽을 짚으며, 그녀를 품 안에 가두었다.
"도망치려고? 늦었어."
```

**클래식 변형**:
- **냉면 총수** × 순진 청순 비서
- **흑막 총수** × 차가운 여강인
- **병적 총수** × 치유형 여주

### 클리셰 2: 대역문 (Substitute)

**핵심 공식**:
```
여주는 백월광의 대역 → 남주가 여주를 학대 → 여주 떠남 → 남주 아내 되찾기 화장장
```

**필수 요소**:
- **백월광**: 남주 마음속 완벽한 여신(보통 죽었거나/실종)
- **여주**: 백월광과 닮은 외모, 대역으로 취급받음
- **아픔 설계**:
  1. 남주가 여주를 통해 백월광에 대한 그리움 해소
  2. 남주가 여주 앞에서 백월광 언급
  3. 남주가 여주에게 백월광의 옷을 입게 함
  4. 백월광 귀환, 여주 버림받음

**클래식 장면**:
```markdown
【아픈 대화】
"네가 내가 널 사랑해서 결혼한 줄 알아? 아니, 넌 그녀의 그림자일 뿐이야."
그가 차갑게 말하며, 손에는 백월광의 사진을 쥐고 있었다.

【아내 되찾기 화장장】
"내가 잘못했어, 제발 돌아와줘..."
그가 빗속에 무릎 꿇었지만, 그녀는 고개도 돌리지 않고 걸어갔다.
"미안해요, 당신이 사랑하는 사람은 내가 아니야, 나도 더 이상 당신을 사랑하지 않아."
```

**반전 기법**:
- **여주 흑화**: 참는 것에서 복수로
- **진실 폭로**: 백월광이 사실은 녹차/나쁜 여자
- **정체 반전**: 여주가 진짜 백월광

### 클리셰 3: 재벌가 은원 (Wealthy Family Drama)

**핵심 공식**:
```
재벌 가문 투쟁 + 남녀주 사랑 = 권력 게임 + 감정 얽힘
```

**필수 요소**:
- **가문 배경**: 백년 명문/상업 제국
- **권력 투쟁**: 상속권/지분 쟁탈
- **감정 장애물**: 신분 불일치/가문 반대/가문 원수
- **악역**: 악독한 어른/백련화 연적/흑막 형제

**클래식 줄거리**:
```markdown
【가문 반대】
"그녀는 우리 육 가에 어울리지 않아! 내 시체를 밟고 넘어가야 할 거야!"
육 할머니가 탁자를 치며 소리쳤다.

【원수 화해】
"너를 위해, 나는 육씨 그룹 전체를 포기할 수 있어."
그가 공개적으로 선언했고, 전체 장소가 소란스러워졌다.
```

**하위 클리셰**:
- **정략결혼**: 가문 연합 → 가짜가 진짜가 됨 → 진정한 사랑
- **복수**: 여주가 복수를 위해 남주에게 접근 → 시간이 지나며 사랑
- **권력 쟁탈**: 남주 권력 쟁탈 + 여주 보조 → 함께 권력 장악

### 클리셰 4: 먼저 결혼 후 사랑 (Marriage First, Love Later)

**핵심 공식**:
```
급속 결혼(계약/합의) → 일상 함께하기 → 시간이 지나며 사랑 → 아픔 포인트 → 진정한 사랑
```

**필수 요소**:
- **급속 결혼 이유**:
  - 가문 강제 결혼
  - 서로 이용 (유산 상속/프로젝트 수주)
  - 전 연인에 대한 복수
  - 예상치 못한 임신
- **함께하기 모드**: 동거하지만 따로 자기 → 점점 친밀 → 선 넘기
- **감정 전환점**: 관심 없는 척 → 질투 → 소유욕 폭발

**클래식 장면**:
```markdown
【계약 조항】
"제1조: 거리를 유지하고, 따로 잔다."
"제2조: 1년 후 이혼, 서로 간섭하지 않는다."
"제3조..."
6개월 후—
"여보, 제1조 폐기해도 되지?"
그가 그녀를 놓지 않고 안았다.

【질투 장면】
그녀가 다른 남자와 말하는 것을 보고, 그는 얼굴을 찌푸리며 다가왔다.
"부인, 우리 집에 갈 시간이야."
위험한 말투.
```

### 클리셰 5: 학대적 깊은 사랑 (Tortured Love)

**핵심 공식**:
```
사랑 → 오해/배신 → 아픈 이별 → 진실 밝혀짐 → HE/BE
```

**필수 요소**:
- **아픔 원천**:
  - 오해(제3자 이간/우연)
  - 배신(겉으로는 배신이지만 실은 보호)
  - 상처(유산/이혼/감금)
  - 질병(암/기억상실/장애)
- **학대 강도**:
  - 가벼운 학대: 오해 → 설명 → 화해
  - 중간 학대: 이별 → 각자 고통 → 재회
  - 심한 학대: 생사의 이별 → 후회막급

**클래식 장면**:
```markdown
【오해 아픔】
"네가 직접 우리 아이를 죽였어..."
그녀는 눈물범벅에, 눈빛에는 생기가 없었다.
그는 설명하려 했지만, 모든 증거가 자신을 가리키고 있었다.

【진실 밝혀짐】
"미안해, 다 내 잘못이야..."
그가 그녀의 병상 앞에 무릎 꿇며, 눈물을 비 오듯 흘렸다.
하지만 그녀는 이미 의식이 없었다.
```

**BE vs HE**:
- **BE(비극 결말)**: 여주 사망/기억상실/떠남, 남주 평생 후회
- **HE(해피 결말)**: 오해 해소, 재결합, 결혼 출산

### 클리셰 6: 환생 복수 (Rebirth Revenge)

**핵심 공식**:
```
전생 비참한 죽음 → 과거로 환생 → 나쁜 남자/녹차 복수 → 진정한 사랑 만남 → 역전
```

**필수 요소**:
- **전생 경험**: 나쁜 남자에게 배신/친구에게 모함/재벌가 학대/비참한 죽음
- **환생 이점**: 미래를 앎/전생 기억/선견지명
- **복수 대상**: 나쁜 전남편/백련화 자매/악독한 시어머니
- **진정한 반려자**: 전생에 무시했던 좋은 남자/새로 등장한 재벌

**클래식 장면**:
```markdown
【환생 각성】
눈을 떠보니, 10년 전으로 돌아와 있었다.
"이번 생에서, 나는 절대 같은 실수를 되풀이하지 않을 거야!"

【복수 얼굴 때리기】
"또 나를 속이려고? 그 수법은 너무 많이 봤어."
그녀는 차갑게 웃으며 증거를 꺼냈고, 나쁜 남자의 얼굴이 창백해졌다.

【진정한 사랑 만남】
전생에 그는 묵묵히 그녀를 지켰지만, 그녀는 못 본 척했다.
이번 생에서, 그녀는 먼저 그에게 다가갔다: "우리 다시 시작하자, 좋아?"
```

### 클리셰 7: 연예계 (Entertainment Industry)

**핵심 공식**:
```
무명 여주 + 최고배우/금주 남주 = 성상납 스캔들 → 공개 → 안티 얼굴 때리기
```

**필수 요소**:
- **여주 설정**: 18선 작은 배우/신인/대역
- **남주 설정**: 최고배우/감독/엔터 회사 대표
- **줄거리 설계**:
  1. 여주가 성상납/악재에 시달림
  2. 남주가 당당하게 아내 보호
  3. 여주가 실력으로 역전
  4. 연애 공개, 전 인터넷 축복

**클래식 장면**:
```markdown
【성상납 스캔들】
#모 18선 여배우 잠자리로 상승#
실시간 검색어 폭발.

【당당한 아내 보호】
최고배우가 직접 나섬:
"그녀는 내 아내야, 불만 있어?"
첨부 사진: 결혼증명서.
전 인터넷 폭발.

【실력으로 얼굴 때리기】
여주가 연기력으로 대상 수상, 안티 입 닫음.
"연기력이야말로 진짜 실력이지."
```

### 클리셰 8: 달콤 무학대 (Pure Fluff)

**핵심 공식**:
```
남주가 여주 애지중지 + 여주가 사랑받음 = 전체 달콤 + 아픔 제로
```

**필수 요소**:
- **남주 속성**: 아내 보호광/아내 노예/딸바보
- **여주 속성**: 귀여움/부드러움/치유형
- **달콤 설계**:
  - 매일 다른 방식의 애지중지
  - 남주가 여주를 위해 바보같은 짓
  - 사랑 과시로 솔로들 괴롭히기
  - 생활 일상 달콤

**클래식 장면**:
```markdown
【애지중지 일상】
"여보 말이 다 맞아."
"여보가 원하는 거, 다 줄게."
"여보가 행복한 게 제일 중요해."

【사랑 과시】
기자: "육 대표님, 성공의 비결은 무엇인가요?"
육 대표: "아내 말 잘 듣는 거요."
전체 장소: "......"
```

**달콤 유형**:
- **애지중지형**: 남주가 무조건적으로 여주 애지중지
- **애교형**: 재벌이 여주 앞에서 애교
- **반전 매력**: 겉은 차갑고 속은 따뜻, 여주에게만 다정

### 클리셰 9: 연하/누나 연하 연애 (Younger Man Romance)

**핵심 공식**:
```
성숙한 여주 + 젊은 남주 = 누나 연하 → 아내 되찾기 → 세상 편견 깨기
```

**필수 요소**:
- **나이차**: 3-10세
- **여주 설정**: 성숙하고 독립적/사업 성공/이혼/사별
- **남주 설정**: 밝음/집요함/누나 보호광
- **장애물**: 세간의 시선/여주 자격지심/가족 반대

**클래식 장면**:
```markdown
【추구】
"누나, 좋아해요."
젊은 남자가 진지하게 말했다.
"넌 아직 어려..."
"나 이미 성인이에요, 게다가 나이는 문제가 아니에요."

【편견 깨기】
"내가 사랑하는 건 이 사람이에요, 나이가 아니라."
그가 공개적으로 선언했고, 세상의 시선을 개의치 않았다.
```

### 클리셰 10: 비밀 결혼 (Secret Marriage)

**핵심 공식**:
```
결혼했지만 정체 숨김 → 각종 우연으로 거의 들킬 뻔 → 공개 → 전 인터넷 충격
```

**필수 요소**:
- **비밀 결혼 이유**:
  - 가문 반대
  - 사업 고려 (연예인)
  - 저조하게 (부자)
- **거의 들킬 뻔**:
  - 같은 프레임에 찍힘
  - 결혼반지 발각
  - 아이가 엄마라고 부름
- **공개 방식**:
  - 우연히 노출
  - 자발적 공개
  - 어쩔 수 없이

**클래식 장면**:
```markdown
【거의 들킬 뻔】
기자: "린 씨, 당신 손의 결혼반지는..."
여주: "아, 이건... 소품이에요!"

【공개 충격】
최고배우가 SNS에 올림:
"소개할게, 내 아내 @린 씨"
첨부 사진: 결혼증명서+가족 사진
실시간 검색어 폭발.
```

**대표작**: 《환생 재벌가의 총애》 류

## 3. 클리셰 혁신 기법

### 기법 1: 성격 반전
**전통**: 재벌 총수 × 순진 청순
**혁신**: 엉뚱 총수 × 차가운 여주

**예시**:
```markdown
【전통 재벌】
"여자, 넌 성공적으로 내 관심을 끌었어."

【엉뚱 총수】
"언니, 카톡 교환하자~"
그가 순진한 큰 눈을 깜빡였다.
```

---

### 기법 2: 정체 교체
**전통**: 재벌 남 × 신데렐라 여
**혁신**: 재벌 여 × 강아지 남

---

### 기법 3: 배경 혁신
**전통**: 현대 도시
**혁신**:
- 민국 배경 + 재벌 클리셰
- 종말 배경 + 달콤 사랑
- 고대 가공 + 먼저 결혼 후 사랑

---

### 기법 4: 다중 클리셰 겹치기
**예시**: 대역 + 환생 + 아내 되찾기 + 진짜 가짜 천금
```markdown
여주 전생은 대역, 학대당해 죽음 → 환생하니 자신이 진짜 천금 →
가짜 천금 복수 → 재벌 아내 되찾기 → 진실 밝혀짐 → HE
```

---

## 4. 클리셰 자가 점검 리스트

글을 쓴 후, 항목별 체크:
- [ ] **핵심 공식이 명확한가**: 독자가 한눈에 어떤 클리셰인지 알 수 있는가?
- [ ] **필수 요소가 갖춰졌는가**: 해당 클리셰의 핵심 요소가 다 있는가?
- [ ] **감정 리듬이 합리적인가**: 달콤과 아픔 비율이 적절한가? (달콤글 7:3, 학대물 3:7)
- [ ] **혁신점이 있는가**: 클래식 기반에 새로움이 있는가?
- [ ] **쾌감 포인트가 충분한가**: 5000자마다 최소 1개의 달콤/얼굴 때리기/역전 포인트
- [ ] **뻔한 것을 피했는가**: 독자가 가장 싫어하는 막장 포인트를 피했는가?

## 클리셰 빠른 참조표

| 클리셰 유형 | 핵심 요소 | 주요 쾌감 | 적합 독자 | 학대 비율 |
|---------|---------|---------|---------|---------|
| **재벌 총수** | 권력차+강압 추구 | 총애+벽치기 | 소녀향 | 3:7(달콤 많음) |
| **대역문** | 백월광+학대 사랑 | 아내 되찾기 화장장 | 학대물 팬 | 7:3(학대 많음) |
| **재벌가 은원** | 가문 투쟁+사랑 | 권모+아내 보호 | 통쾌글 팬 | 5:5(균형) |
| **먼저 결혼 후 사랑** | 계약→진정한 사랑 | 시간이 지나며 사랑 | 일상향 | 2:8(달콤 많음) |
| **학대적 깊은 사랑** | 오해+상처 | 아픔+BE/HE | 학대물 팬 | 8:2(학대 위주) |
| **환생 복수** | 선견지명+역전 | 나쁜 남자 얼굴 때리기 | 통쾌글 팬 | 2:8(통쾌 많음) |
| **연예계** | 스타+가십 | 공개+얼굴 때리기 | 아이돌 팬 | 3:7(달콤 많음) |
| **달콤 무학대** | 전체 애지중지 | 달콤+설탕 뿌리기 | 달콤글 팬 | 0:10(순수 달콤) |
| **누나 연하** | 나이차+아내 되찾기 | 늑대 강아지+누나 보호 | 성숙 여성향 | 2:8(달콤 많음) |
| **비밀 결혼** | 비밀+공개 | 정체 반전 | 가십향 | 1:9(달콤 많음) |

## 부록: 반면교사

### 실수 1: 클리셰 쌓기, 논리 혼란
```markdown
여주가 재벌이면서, 대역이면서, 환생까지 하고, 동시에 진짜 천금까지...
```
**문제**: 클리셰가 너무 많아 독자가 혼란.

**개선**: 1-2개 메인 클리셰에 집중, 나머지는 보조로.

---

### 실수 2: 클리셰가 식상, 새로움 전무
```markdown
또 재벌 벽치기, 또 "여자, 넌 성공적으로 내 관심을 끌었어"...
```
**문제**: 2025년인데, 이런 밈은 이미 식상.

**개선**: 클래식 기반에 새 요소 추가 (엉뚱함, 반클리셰).

---

### 실수 3: 클리셰를 위한 클리셰
```markdown
분명 설명하면 해결될 오해를, 꼭 10화 끌기.
분명 직접 고백하면 되는데, 꼭 계약 만들기.
```
**문제**: 억지스럽고, 글자수 채우기 위한 클리셰.

**개선**: 클리셰는 스토리에 봉사해야 하며, 스토리가 클리셰에 봉사하는 게 아니다.

## 클래식 사례 분석

### 사례 1: 《하이상소묵》
**클리셰**: 학대적 깊은 사랑 + 집요한 기다림
**성공 포인트**:
- "만약 그때..."의 아쉬움
- 남주의 집요한 7년 기다림
- 오해에 깊이가 있고, 막장적이지 않음

---

### 사례 2: 《삼삼래흘》
**클리셰**: 재벌 총수 + 달콤 무학대
**성공 포인트**:
- 남주 설정이 매력적 (건방+애지중지)
- 여주가 순진 청순이 아님, 주견이 있음
- 일상 디테일 달콤

---

### 사례 3: 《미미일소흔경성》
**클리셰**: 학원 + 게임 + 달콤
**성공 포인트**:
- 두 사람 다 학교 천재 설정
- 게임 요소 참신
- 전체 초달콤, 막장 제로

---

## 총결

클리셰는 폄하하는 말이 아니라, "독자가 기대하는 줄거리 패턴"이다. 클리셰를 잘 쓰는 핵심:
1. **클래식을 숙지**: 독자가 무엇을 좋아하는지 알기
2. **적절한 혁신**: 클래식 기반에 새로움 추가
3. **스토리에 봉사**: 클리셰가 스토리에 봉사, 반대가 아님
4. **리듬 조절**: 달콤과 아픔 비율 합리적으로
5. **억지 피하기**: 클리셰가 자연스러워야, 쓰기 위해 쓰면 안 됨
