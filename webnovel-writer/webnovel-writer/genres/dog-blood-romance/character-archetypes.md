# 로맨스 캐릭터 설정 보감 (Romance Character Archetypes)

> **핵심 원칙**: 좋은 로맨스 소설은 캐릭터 설정이 70%, 스토리가 30%이다. 독자가 따라가는 건 이야기가 아니라 "이 커플 무조건 밀어야 해"라는 마음이다.

---

## 1. 남주 캐릭터 설정（12가지 클래식 유형）

### 유형 1: 재벌 총수형

**핵심 특성**:
```
외면: 젊고 유능(28-35세) + 재산 억대 이상 + 극상 외모
내면: 겉으로는 차갑고 속은 따뜻 + 소유욕 강함 + 여주에게만 다정
필수 스펙: 결벽증/강박증 + 여자에게 무관심 + 어린 시절 트라우마
```

**성격 설정**:
- **외부**: 냉혹무정, 신속과감, 한마디로 결정
- **여주에게**: 애지중지, 강압적이지만 다정, 전전긍긍
- **약점**: 여주가 떠날까 봐, 여주가 다칠까 봐, 여주가 울까 봐 두려움

**클래식 대사 템플릿**:
```
"넌 내 거야, 아무도 빼앗을 수 없어."
"널 위해 온 세상을 줄 수 있어, 하지만 넌 날 떠날 수 없어."
"너 말고는 어떤 여자에게도 관심 없어." (여주에게)
"꺼져." (다른 여자에게)
```

**직업 선택**:
- **가장 흔한**: CEO, 그룹 회장, 투자회사 대표
- **가능**: 의사(외과 과장), 변호사(파트너), 군인(대령 이상)
- **금기**: 평범한 직원, 영업사원(재벌 총수 설정 파괴)

---

### 유형 2: 차갑고 금욕적인 유형

**핵심 특성**:
```
외면: 차갑고 고고함 + 웃지 않음 + 정장 깔끔
내면: 자기절제 + 이성 최우선 + 감정에 둔감
반전 매력: 한번 빠지면 → 미친 듯한 소유 + 통제 불능 집착
```

**성격 변화 곡선**:
```
전반(1-30화): 냉담하고 거리를 둠, 여주를 못 본 척
중반(30-80화): 여주를 의식하기 시작, 내면 갈등
후반(80화+): 완전히 빠져듦, 미친 듯이 추구
```

**무너지는 순간**:
```
【첫 번째 균열】
그는 여주의 뒷모습을 응시하며, 처음으로 "잡아두고 싶다"는 생각이 들었다.
(내면 독백: 이상하다, 왜 그녀가 떠날 때 불안하지?)

【완전히 빠지는 순간】
"나는 아무도 사랑하지 않을 줄 알았어."
그는 그녀의 얼굴을 두 손으로 감싸며, 눈에 깊은 사랑이 가득했다.
"너를 만나고서야, 나도 통제 불능이 될 수 있다는 걸 알았어."
```

**대표작**: 《하이상소묵(何以笙箫默)》 허이천, 《미미일소흔경성(微微一笑很倾城)》 샤오나이

---

### 유형 3: 흑막 요괴형

**핵심 특성**:
```
외면: 요사스러운 미남 + 사악한 미소 + 자유분방한 행동
내면: 깊은 계략 + 빈틈없는 계산 + 자기 편 강력 보호
특징: 겉으로는 세상을 가볍게 여기지만, 실제로는 한 사람에게 깊이 빠짐
```

**성격 태그**:
- 웃는 호랑이(웃음이 부드러울수록, 수단이 더 잔인)
- 여우(유혹의 달인)
- 아내 보호광(감히 여주를 괴롭히면 전부 쓸어버림)

**클래식 장면**:
```
【흑막 함정】
"도망칠 수 있을 것 같아?"
그는 입꼬리를 올리며 미소 지었다, 이미 천라지망을 쳐놓았다.

【아내 보호광】
"그녀는 내 마음 속 보물이야, 누구든 건드리면 죽는다."
그는 부드럽게 웃었지만, 눈 속에는 살기가 가득했다.
```

---

### 유형 4: 충견 강아지형

**핵심 특성**:
```
외면: 밝고 잘생김 + 깨끗하고 상쾌 + 소년미
내면: 충성스럽고 한결같음 + 달라붙고 애교 + 여주를 목숨처럼 여김
나이차: 여주보다 3-8세 어림 (누나 연하 커플)
```

**성장 곡선**:
```
전반: 아기 강아지(애교 부리며 안아달라고 함)
중반: 성장기(묵묵히 여주를 지킴)
후반: 늑대 강아지(소유욕 폭발, 강력한 아내 보호)
```

**클래식 대사**:
```
"누나, 나 다 컸어, 결혼해줄 수 있어?"
"계속 기다릴게, 네가 나를 받아줄 때까지."
"걱정 마, 내가 있잖아." (성장 후)
```

**대표작**: 《치아문단순적소미호(致我们单纯的小美好)》 장첸

---

### 유형 5: 병적 집착형 (고위험 설정)

**핵심 특성**:
```
외면: 병적 아름다움 + 음울한 기질 + 기이한 미소
내면: 편집적 소유 + 왜곡된 편애 + 미친 듯 위험
위험 지수: ★★★★★
```

**설정 리스크 안내**:
- ⚠️ **주의**: 변태로 쓰기 쉬움, 독자 이탈 위험
- ✅ **균형**: 병적 + 깊은 사랑 = 위험한 한결같음
- ❌ **금기**: 병적 + 폭력 = 공포영화

**수용 가능한 병적 표현**:
```
【소유욕】
"넌 나만 봐야 해, 나만 생각해야 해, 나만의 것이어야 해."
(여주를 잡아두고, 시야에서 벗어나게 하지 않음)

【미친 듯한 수호】
"누가 널 울렸어?"
그의 눈빛이 차갑고, 손에 든 칼에서 피가 떨어졌다.
"말해, 내가 그를 죽여줄게."
```

**수용 불가능한 병적 표현** (금기):
```
❌ 여주 감금, 학대, 강제
❌ 여주 주변 가족 및 친구 해치기 (악인이 아닌 이상)
❌ 사랑이라는 이름의 통제와 상처
```

---

### 유형 6: 다정한 젠틀맨형

**핵심 특성**:
```
외면: 우아하고 세련됨 + 온화하고 빛나는 옥 같음 + 단정한 행동
내면: 다정하고 세심 + 여성 존중 + 꼼꼼
반전: 부드러운 외면 아래 강한 내면
```

**적용 시나리오**:
- **초반 조연 → 후반 진정한 사랑** (여주가 먼저 나쁜 남자를 좋아하다가, 나중에 좋은 사람을 만남)
- **소꿉친구** (어릴 때부터 함께, 묵묵히 지킴)
- **치유형** (여주가 상처받은 후 만나는 따뜻함)

**클래식 장면**:
```
【묵묵히 지킴】
"여기서 계속 기다릴게, 네가 돌아볼 때까지."

【다정한 치유】
그는 부드럽게 그녀의 눈물을 닦았다: "울지 마, 내가 있잖아."
```

---

### 유형 7: 금기 계열 (사제/삼촌-조카/상사-부하)

**핵심 특성**:
```
신분차: 선생 vs 학생 / 삼촌 vs 조카 / 상사 vs 부하
나이차: 8-15세
금기감: 도덕적 압박 + 세상의 시선 + 윤리적 금기
```

**감정선 설계**:
```
단계 1: 억누르며 절제 (안 되는 줄 알지만, 감정을 주체 못 함)
단계 2: 갈등과 모순 (이성과 감정의 격렬한 충돌)
단계 3: 금기 돌파 (사랑을 위해, 모든 것을 불사)
```

**클래식 대사**:
```
"널 사랑하면 안 되는데, 나 자신을 억제할 수가 없어."
"전 세계가 반대해도, 난 너와 함께할 거야."
```

**주의사항**:
- ✅ 여주 반드시 성인 (18세+)
- ✅ 감정 발전이 자연스러워야 하며, 갑작스러우면 안 됨
- ❌ 미성년 연애 금지
- ❌ 실제 혈연관계 금지 (양부녀는 가능)

|------|---------|---------|---------|---------|
| **군인 터프가이** | 강철 같은 부드러움+나라 수호 | 특수부대/군인 | "내 목숨은 필요 없어도, 넌 반드시 살아야 해" | 군대 로맨스 |

## 2. 여주 캐릭터 설정（10가지 클래식 유형）

### 유형 1: 순진 청순형 (초보자에게 가장 쉬움)

**핵심 특성**:
```
외면: 청순하고 귀여움 + 부드럽고 무해 + 보호 본능 자극
내면: 착하고 순수 + 밝고 낙천적 + 계산 없음
지능: 바보는 아니지만, 감정에는 둔감
```

**성격 태그**:
- 길치, 먹보, 어둠 무서워함, 귀신 무서워함
- 쉽게 속고, 쉽게 사람을 믿음
- 괴롭힘 당하면 울지만, 원한을 품지 않음

**클래식 장면**:
```
【괴롭힘 당함】
그녀는 억울해서 입술을 깨물며, 눈물이 눈에 글썽였다.
"미안해요... 일부러 그런 게 아니에요..."

【보호받음】
남주가 그녀를 한 팔로 끌어안았다: "걱정 마, 내가 있잖아."
그녀는 결국 참지 못하고 울음을 터뜨렸다: "흑흑흑..."
```

**적합 소재**: 학원 달콤글, 재벌 총수 애정글, 치유 계열

---

### 유형 2: 부드러운 토끼형 (가장 인기)

**핵심 특성**:
```
외면: 부드럽고 연약 + 불쌍해 보임 + 보호 본능 자극
내면: 강하고 참을성 있음 + 착하고 부드러움 + 남에게 폐 끼치지 않음
특징: 다쳐도 말하지 않고, 묵묵히 참음
```

**남주를 끄는 포인트**:
- **연약하지만 강함**: 울면서도 미소 짓기
- **부드럽지만 선이 있음**: 괴롭힐 순 있어도, 존엄을 짓밟으면 안 됨
- **의존하지만 독립적**: 보호가 필요하지만, 쓸모없지는 않음

**클래식 장면**:
```
【참음】
그녀는 구석에 숨어, 몰래 눈물을 닦았다.
"괜찮아, 나 할 수 있어..."

【발각됨】
남주가 그녀 손의 상처를 보고, 마음이 아파 미칠 것 같았다.
"왜 나한테 말 안 했어?!"
```

---

### 유형 3: 쿨한 여강인 (통쾌한 글 필수)

**핵심 특성**:
```
외면: 언니 분위기 + 강한 아우라 + 유능하고 결단력 있음
내면: 사업에 진심 + 독립적이고 자주적 + 남자에게 의존하지 않음
반전: 밖에서는 여강인, 남주 앞에서는 여자
```

**직업 선택**:
- 여성 CEO, 변호사, 의사, 특수요원, 디자이너

**감정선 설계**:
```
전반: 사업이 우선, 남주를 무시
중반: 점점 마음이 끌리지만, 인정하기를 거부
후반: 완전히 빠져들어, 여자로 변함
```

**클래식 장면**:
```
【쿨한 언니 분위기】
그녀는 차가운 눈으로 모두를 훑었다: "불복? 그러면 한번 해보시지."

【반전 매력】
그녀는 그의 품에 안겨 애교를 부렸다: "자기야, 나 그거 먹고 싶어~"
남주 (충격): "너... 너 방금 나한테 뭐라 했어?"
```

---

### 유형 4: 흑막 꼬마 요정

**핵심 특성**:
```
외면: 요염하고 매혹적 + 교활한 미소 + 유혹의 달인
내면: 똑똑하고 재치 있음 + 손해 안 봄 + 자기 편 강력 보호
특징: 유연하게 대처, 부드러움과 강함을 겸비
```

**성격 곡선**:
- **적에게**: 웃는 호랑이, 미소가 달콤할수록 덫이 깊음
- **남주에게**: 달콤하면서도 야릇, 유혹하고 도망감
- **가족에게**: 자기 편 보호, 건드리면 죽음

**클래식 장면**:
```
【남주 유혹하기】
그녀는 입꼬리를 올리며, 그의 귀에 대고 속삭였다: "보고 싶었어?"
남주 (귀 빨개짐): "...장난치지 마."
그녀는 웃으며 뒤로 물러났다: "체, 재미없네."

【편 보호】
"감히 내 사람을 괴롭혀?"
그녀는 사람 좋은 미소를 지었지만, 눈에는 살기가 가득했다.
```

---

### 유형 5: 환생 복수녀 (학대물 필수)

**핵심 특성**:
```
전생: 나쁜 남자와 악녀에게 죽음당함
환생 후: 복수가 주, 사랑은 부
성격 변화: 유약함 → 강하고 과감
```

**복수 3단계**:
```
단계 1: 진실을 깨달음 (전생의 연인이 원수)
단계 2: 치밀한 계획 (환생의 이점을 활용해 복수)
단계 3: 대복수 달성 (나쁜 남녀 응징)
```

**남주와의 관계**:
- **전생 남주**: 배신자 → 후에 후회막급 (아내 되찾기 화장장)
- **이번 생 남주**: 새로운 캐릭터 → 여주의 복수를 도움 → 서로 사랑

**클래식 대사**:
```
"이번 생에서, 나는 더 이상 널 사랑하지 않을 거야." (전생 남주에게)
"네가 빚진 것, 열 배로 돌려받을 거야!" (원수에게)
```

|------|---------|---------|---------|---------|

## 3. 캐릭터 조합 공식 (황금 커플 조합)

### 공식 1: 강한 남주 + 약한 여주 (가장 클래식)

```
재벌 총수 + 순진 청순 = 보호 본능 폭발 + 애지중지
```

**장점**: 독자 몰입감 강함, 보호하고 보호받는 욕구 충족
**단점**: 식상하기 쉬움
**혁신**: 여주에게 숨겨진 실력 부여 (겉으로는 순하지만, 실제로는 대단한 사람)

---

### 공식 2: 강한 여주 + 더 강한 남주 (대등한 관계)

```
여강인 + 차갑고 금욕적인 남주 = 좋은 상대 + 서로 정복
```

**장점**: 커플감 강함, 평등한 연애
**단점**: 달콤함이 부족
**혁신**: "먼저 마음을 주는 사람이 지는" 내기 추가

---

### 공식 3: 흑막 + 흑막 (지략 대결)

```
흑막 남주 + 흑막 여주 = 속고 속이기 + 깊은 학대 연애
```

**장점**: 스토리가 흥미진진, 학대 연애 자극적
**단점**: 집필 난이도 높음
**적합**: 궁중극, 권모술수, 사업 대결 소재

---

### 공식 4: 연하 + 성숙한 여주 (누나 연하 연애)

```
충견 강아지 + 쿨한 언니/부드러운 여주 = 반전 매력 + 애지중지
```

**장점**: 신선함, 누나팬의 환상 충족
**단점**: 상대적으로 비주류
**혁신**: 아기 강아지에서 늑대 강아지로 성장

---

### 공식 5: 병적 + 치유형 (고위험 조합)

```
병적 집착 남주 + 다정한 치유 여주 = 위험한 구원
```

**장점**: 자극적, 다크 계열 독자가 가장 좋아함
**단점**: 잘못되기 쉬움, 공포영화가 될 수 있음
**균형**: 병적 행동은 여주에게만 다정, 다른 사람에게는 냉혹

---

## 4. 캐릭터 설정 금기 (절대 범하면 안 됨)

### 금기 1: 성녀 여주

**증상**:
```
❌ 괴롭힘 당하고도 원수 편들기: "그에게도 사정이 있을 거야..."
❌ 나쁜 남자에게 버려지고도 용서: "그가 나를 사랑하는 걸 믿어..."
❌ 해를 당하고도 복수 안 함: "됐어, 지난 일은 지난 일이야..."
```

**독자 반응**: "이 여주 미쳤어?! 너무 답답해!"

**올바른 방법**: 착할 수 있지만, **반드시 선이 있어야** 한다.

---

### 금기 2: 나쁜 남주 (세탁 불가)

**증상**:
```
❌ 바람 피우고 변명: "그냥 잠깐 혼란스러웠어..."
❌ 여주 학대하고 사과 안 함: "네가 당해야 했어..."
❌ 여주를 상처 주고 후회 안 함: "떠나면 떠나는 거지, 상관없어..."
```

**독자 반응**: "이 남주는 평생 혼자여야 해!"

**올바른 방법**:
- **학대는 가능하지만, 반드시 아내 되찾기 화장장**
- **상처를 준 후 반드시 미친 듯이 후회**
- **마지막에 반드시 무릎 꿇고 용서 빌기**

---

### 금기 3: 바보 조연 (도구인간)

**증상**:
```
❌ 악역 지능이 마이너스, 주인공에게 쉽게 깔림
❌ 조연은 "너 정말 대단하다!"만 외침
❌ 모든 사람이 주인공 중심으로만 돌아감
```

**독자 반응**: "조연들 다 바보야?"

**올바른 방법**: **조연도 지능, 동기, 입체감을 가져야 한다**

---

## 5. 캐릭터 설정 혁신 기법

### 기법 1: 클래식 설정 뒤집기

```
재벌 총수 → 사실은 연기, 진짜 성격은 집순이
순진 청순 → 사실은 가장, 진짜 정체는 특수요원
차가운 남주 → 사실은 사회공포증, 사람과 대화를 못 함
```

---

### 기법 2: 다중 정체성 겹치기

```
여주 = 학교 천재 + 해커 + 격투 고수 + 숨겨진 부잣집 딸
남주 = 재벌 + 킬러 + 재벌가 후계자 + 전직 특수부대
```

**주의**: 너무 많이 쌓지 말 것, 3-4개 정체면 충분

---

### 기법 3: 클래식 설정에 결함 추가

```
재벌 총수 + 사회공포증 (여주에게만 사회공포 없음)
순진 청순 + 길치 (심각할 정도로)
차가운 남주 + 결벽증 (여주만 만지게 함)
```

**효과**: 반전 매력 증가, 더 사실적

## 6. 캐릭터 설정 자가 점검 리스트

캐릭터 설정 시, 항목별 체크:

- [ ] **매력 있는가**: 독자가 이 캐릭터를 좋아할까?
- [ ] **반전이 있는가**: 성격에 다면성이 있는가?
- [ ] **성장이 있는가**: 캐릭터가 스토리와 함께 성장하는가?
- [ ] **선이 있는가**: 착하지만 성녀는 아닌지, 흑막이지만 변태는 아닌지?
- [ ] **논리적인가**: 성격, 행동, 직업이 일치하는가?
- [ ] **충분히 독특한가**: 다른 소설의 캐릭터와 차별점이 있는가?
