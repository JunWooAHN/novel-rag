# 힘의 체계 설계 (Power Systems Design)

> **핵심 원칙**: 힘의 체계는 현판 소설의 뼈대다. 좋은 힘의 체계 = 명확한 등급 구분 + 합리적 성장 경로 + 충분한 상상 공간.

---

## 1. 힘의 체계 4대 기초 요소

### 요소1: 에너지 본질
| 유형 | 에너지 명칭 | 대표작 | 특징 |
|------|---------|---------|------|
| **영기 수련** | 영기/진기/원력 | 《범인수선전》 | 천지 영기 흡수 연화 |
| **마법 원소** | 마력/원소의 힘 | 《투라대륙》 | 화/수/풍/토 원소 |
| **무도 의지** | 기혈/무도진의 | 《무동건곤》 | 육체 힘+의지 |
| **이능 유전자** | 유전자 에너지 | 《탄식성공》 | 유전자 진화, SF |
| **신앙 신력** | 신앙의 힘/신력 | 《반룡》 | 신도 신앙 응집 |
| **혼합 체계** | 다종 에너지 공존 | 《완미세계》 | 영기+법칙+혈맥 |

### 요소2: 경지 등급 (9단계 체계)
- 수선: 연기 → 축기 → 금단 → 원영 → 화신 → 연허 → 합체 → 대승 → 도겁
- 마법: 견습 → 마법사 → 대마법사 → 마도사 → 성마도 → 전설 → 반신 → 진신
- 무도: 무도 → 무자 → 무사 → 종사 → 대종사 → 무성 → 무제 → 무신 → 지존

### 요소3: 능력 표현
각 경지의 이동 능력, 공격 범위, 파괴력, 수명, 특수 능력을 구체적으로.
- 매 경지마다 "질적 변화"가 있어야 (단순히 "더 강함"이 아닌)
- 능력이 시각화 가능해야 (독자가 상상 가능)
- 너무 일찍 "폭발"하지 않게 (3경지에서 벌써 천지 파괴하면 안 됨)

### 요소4: 돌파 조건
자원 축적형, 깨달음형, 시련형, 전승형, 혼합형.

---

## 2. 3대 심화 설계

### 심화1: 소경지 구분
각 대경지를 초기 → 중기 → 후기 → 대원만으로 나눔.

### 심화2: 전투력 배가 시스템
공법 품급, 무기 품급, 법보 신병, 혈맥 천부, 비법 폭발, 진법 가성 등 배가 요소.

### 심화3: 숨겨진 경지/특수 노선
알고 있는 최고 경지 위에 "진짜 최고 경지"가 있음, 주인공이 다른 길을 걸음 등.

---

## 3. 세계관 융합

- **지도와 경지 대응**: 다른 경지에 다른 지도 (저급/중급/고급 대륙 + 신역)
- **세력과 경지 문턱**: 세력 가입에 특정 경지 필요
- **수명과 시간 범위**: 경지가 높을수록 수명이 길어, 이야기 시간 범위 확대

---

## 4. 흔한 문제와 해결

1. **체계 붕괴**: 전반 금단기가 "도시 파괴" → 후반 원영기가 "돌 깨기" → 설정 수첩 유지
2. **경지 인플레이션**: 너무 빨리 승급 → 최소 20-30만 자마다 대경지 돌파
3. **주인공 무적 증후군**: 항상 적보다 강함 → 숨겨진 고수, 특수 제한, 팀 전투

- [ ] 돌파 조건이 명확한가?
- [ ] 소경지 구분이 있는가?
- [ ] 전투력 배가 시스템이 있는가?
- [ ] 세계관과 융합되었는가?
- [ ] 앞뒤 일관성이 있는가?

## 힘의 체계 빠른 참조표

| 체계 유형 | 에너지 본질 | 경지 수 | 승급 방식 | 적합 소재 |
|---------|---------|---------|---------|---------|
| **수선 체계** | 영기 | 9-12단계 | 자원+깨달음+천겁 | 선협/수진 |
| **마법 체계** | 마력/원소 | 7-9단계 | 명상+시전 연습 | 서양 판타지 |
| **무도 체계** | 기혈/진기 | 7-10단계 | 육체 단련+무기 | 무협/동양 현판 |
| **이능 체계** | 유전자/이능 | 6-8단계 | 유전자 진화+각성 | SF/종말 |
| **신앙 체계** | 신력/신앙 | 8-10단계 | 신도 모집+신화 점화 | 신화/서사시 |
