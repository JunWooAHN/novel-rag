# 현판 소설 클래식 클리셰 설계 (Xuanhuan Plot Patterns)

> **핵심 원칙**: 현판 소설의 클리셰는 "익숙함+신선함"의 결합이다. 독자는 익숙한 클리셰를 좋아하고 (몰입감), 새로움도 필요하다 (심미 피로 방지).

---

## 1. 10대 클래식 오프닝

1. **폐물 유형** (가장 클래식): 천재→폐물→퇴혼→골든 핑거→역전. 대표: 《투파창궁》
2. **전생 유형** (가장 자유): 현대인 이세계 전생→현대 지식/시스템→역천개명. 대표: 《투라대륙》
3. **환생 유형** (가장 통쾌): 강자가 전생→배신/추락→환생→수선의 길 재도전. 대표: 《수라무신》
4. **퇴혼 유형** (쾌감 집중): 퇴혼→즉시 맹세→3/5년 후 얼굴 때리기→전 약혼녀 후회
5. **시스템 유형** (가장 만능): 시스템 바인딩→임무 완료→보상→빠른 강해짐 (출석/상점/임무/뽑기/흡수)
6. **탈사 유형** (다크): 강자가 임종에 타인 몸 빼앗기→전생 기억으로 굴기
7. **천선지자 유형** (가장 강력): 태어날 때부터 천재→최고 혈맥/체질→동세대 압도
8. **보물 줍기 유형** (가장 가벼움): 우연히 신기/비급 획득→빠르게 강해짐
9. **모함당함 유형** (아픔 오프닝): 모함→종문/가문에서 쫓겨남→복수 굴기
10. **쌍수 유형** (성인향): 특수 공법 수련→쌍수 필요→미녀 모으기

---

## 2. 5대 메인 라인 템플릿

- **복수선** (가장 열혈): 가문 파멸→은인자중 수련→원수 하나씩 격파→최종 보스
- **쟁패선** (가장 웅대): 세력 건설→영토 확장→대륙 통일→비승
- **보물 찾기선** (가장 자유): 비경 탐험→기연 획득→실력 향상→다음 비경
- **수호선** (가장 따뜻): 가족/연인 지키기→강적 대항→약자 보호→수호신이 됨
- **성신선** (가장 웅대): 범인→수선자→선인→신령→지고신

---

## 3. 6대 서브 라인 클리셰

1. **미녀선 (후궁)**: 미녀 만남→오해→화해→함께 전투→감정 싹틈→후궁에 합류
2. **형제선 (의리)**: 형제 만남→고난 함께→생사 함께→형제 피해→주인공 복수
3. **사제선 (전승)**: 사부 만남→절학 전수→사부 피해→주인공 복수/유지 계승
4. **세력선 (왕조 건설)**: 세력 건설→인재 모집→영토 확장→일방 패자가 됨
5. **보물선 (기연)**: 비경 발견→관문 통과→보물/전승 획득→실력 급상승
6. **펫선 (영수)**: 요수 수복→키움→요수 진화→전력이 됨

---

## 4. 줄거리 리듬 조절

### 리듬 템플릿 (100만 자 기준)
```
앞 10만 자 (오프닝): 세계관 구축, 주인공 굴기
10-30만 자 (1권): 첫 대충돌, 초기 복수
30-50만 자 (2권): 더 높은 세계로 진입
50-70만 자 (3권): 메인 라인 추진, 후궁 모으기
70-90만 자 (4권): 최종 보스 전 시련
90-100만 자 (대결말): 최종 결전, 비승/성신
```

### 쾌감 밀도
- 매 5000자마다 최소 1개 소쾌감
- 매 2만 자마다 최소 1개 중쾌감
- 매 10만 자마다 최소 1개 대쾌감

---

## 5. 흔한 클리셰 조합 (히트 공식)

1. 폐물 + 퇴혼 + 시스템
2. 전생 + 환생 + 선지
3. 천재 + 모함 + 복수
4. 보물 줍기 + 할아버지 + 쌍수
5. 시스템 + 출석 + 후궁

---

## 6. 클리셰 식상함 피하기

1. **반전**: 전통: 퇴혼당함→역전 / 혁신: 주인공이 먼저 퇴혼→전 약혼녀 후회
2. **융합 혁신**: 단일 시스템 → 이중 시스템(수선+과학기술)
3. **캐릭터 혁신**: 열혈 주인공 → 신중한 주인공(극도로 조심, 모험 안 함)
4. **세계관 혁신**: 단일 수선 세계 → 다원 우주(수선+과학기술+마법)

---

## 7. 자가 점검 리스트

- [ ] 오프닝이 매력적인가? 앞 3화가 독자를 잡는가?
- [ ] 메인 라인이 명확한가? 주인공의 최종 목표는?
- [ ] 쾌감이 밀집한가? 매 5000자마다 소쾌감?
- [ ] 클리셰에 새로움이 있는가?
- [ ] 서브 라인이 풍부한가? 후궁/형제/사제 등?
- [ ] 리듬이 합리적인가? 완급이 있고 늘어지지 않는가?
