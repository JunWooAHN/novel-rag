# 현판 소설 쾌감 포인트 설계 (Xuanhuan Cool Points Design)

> **핵심 원칙**: 현판 쾌감 = 힘의 압도 + 얼굴 때리기 반전 + 간지 전시. 독자가 원하는 건 "주인공이 대단해"라는 쾌감이다.

---

## 1. 현판 쾌감의 5대 유형

### 유형1: 전투력 압도 (가장 직접적)
주인공 실력이 적보다 훨씬 위, 일격 필살

### 유형2: 간지+얼굴 때리기 (가장 클래식)
적이 허세 → 주인공이 얼굴 때리기

### 유형3: 월급 도전 (가장 열혈)
낮은 경지가 높은 경지를 격파

### 유형4: 전장 충격 (가장 간지)
주인공이 놀라운 일을 하여, 모두를 충격시킴

### 유형5: 반전 역전 (가장 열혈)
주인공이 압도당함 → 갑자기 폭발 → 역살

---

## 2. 10대 클래식 쾌감 장면

1. **경매회 얼굴 때리기**: 상대가 돈 자랑 → 주인공 더 비싸게 → 전장 충격
2. **비무 대회 우승**: 모두 무시 → 주인공 연승 압도 → 우승 → 충격
3. **연단/연기 전장 충격**: 모두 조롱 → 주인공 극품 단약 연성 → 얼굴 때리기
4. **비경 보물 탈취**: 여럿이 쟁탈 → 주인공 어부지리 → 보물 획득
5. **퇴혼 얼굴 때리기**: 퇴혼당함 → 주인공 굴기 → 전 약혼녀 후회 → 주인공 무시
6. **일격필살**: 적 허세 → 주인공 일격 → 전장 침묵
7. **군체 압도**: 여럿이 포위 → 주인공 전체 섬멸 → 아무도 움직이지 못 함
8. **일격파진**: 아무도 진법 못 깨 → 주인공 일격 파괴 → 충격
9. **미녀 구하기**: 미녀 위험 → 주인공 영웅 등장 → 미녀 마음이 움직임
10. **악역 때리기**: 악역 허세 → 주인공 압도 → 악역 구걸 → 주인공 무시

---

## 3. 쾌감 강도 등급

| 등급 | 발동 조건 | 빈도 |
|------|---------|------|
| **S급** | 보스 처치/경지 대돌파/적대 세력 섬멸 | 10만 자당 1번 |
| **A급** | 월급 도전 성공/신기 획득/강적 얼굴 때리기 | 2만 자당 1번 |
| **B급** | 잡몹 섬멸/연단 성공/소 돌파 | 5000자당 1번 |
| **C급** | 간지 한 마디/소 보물 획득/행인 충격 | 2000자당 1번 |

---

## 4. 쾌감 콤보 (연속 타격)

- 간지 → 얼굴 때리기 → 일격필살
- 압도당함 → 반전 → 압도
- 조롱 → 충격 → 무릎 꿇기
- 도발 → 수락 → 압도 → 충격

---

## 5. 현판 특색 쾌감

- **천겁 도전**: 천겁을 맨몸으로 버팀, 무상처 → "천겁을 맨몸으로?!"
- **연단 쾌감**: 극품 단약 연성 → 전장 충격
- **요수 수복**: 상고 흉수를 수복 → 전장 멍
- **금제 파괴**: 상고 금제를 일격으로 → 충격
- **신맥 개방**: 구조 신맥 동시 각성 → "만고 이래 없는 일!"

---

## 6. 쾌감 밀도 조절

- 매 2000자: 최소 1개 C급 쾌감
- 매 5000자: 최소 1개 B급 쾌감
- 매 2만 자: 최소 1개 A급 쾌감
- 매 10만 자: 최소 1개 S급 쾌감

### 검증 공식
```
쾌감 총수 = 챕터 글자수 ÷ 2000
```

---

## 7. 쾌감 피로 방지

문제: 매번 잡몹 일격필살 반복 → 독자 "또 일격필살? 신선함 없어!"

해결: 쾌감 다양화 (전투력 압도/기술 전시/지혜/감정선/열혈 전투 번갈아)

---

## 8. 쾌감과 아픔의 배합

- 쾌감: 70%, 아픔: 20%, 평범: 10%
- 아픔이 깊을수록, 쾌감이 더 통쾌

---

## 9. 자가 점검 리스트

- [ ] 빈도가 충분한가? 매 2000자마다 쾌감?
- [ ] 강도가 충분한가? S/A/B/C 각급 쾌감 분포?
- [ ] 다양한가? 쾌감 반복을 피했는가?
- [ ] 캐릭터에 맞는가? 주인공 성격에 맞는 쾌감?
- [ ] 스토리를 추진하는가?

| **반전** | 열세→우세 | S급 | 10만 자/회 | 봉인 해제 |

## 쾌감 설계 심화 기법

1. **쾌감 점진**: 연기기 일격→축기기 일격→금단기 일격 (점점 더 통쾌)
2. **쾌감 중첩**: 일격필살 + 충격 + 미녀 구하기 = 초강력 쾌감
3. **쾌감 반전**: 이전 화 아픔 → 이번 화 역살
4. **쾌감 서스펜스**: "3년 후에 보자" → 50화 후 주인공 귀환 압도
