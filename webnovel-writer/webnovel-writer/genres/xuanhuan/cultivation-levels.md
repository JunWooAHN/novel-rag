# 수련 경지 설정 (Cultivation Levels Design)

> **핵심 원칙**: 수련 경지는 현판 소설의 진행 막대다. 좋은 경지 설정 = 명확한 층위감 + 합리적 돌파 난이도 + 충분한 서스펜스 공간.

---

## 1. 경지 설정의 5대 핵심 요소

### 요소1: 경지 명칭
- **점진식**: 연체 → 응기 → 축기 → 금단 → 원영 → 화신 → 연허 → 합체 → 대승 → 도겁
- **숫자 등급식**: 1성 무자 → 2성 무자 → ... → 9성 무자
- **칭호식**: 무도 → 무자 → 무사 → 무종 → 무존 → 무성 → 무제 → 무신
- **경지식**: 범경 → 영경 → 왕경 → 황경 → 제경 → 성경 → 신경
- **혼합식**: 전반(구체) → 중반(칭호) → 후반(경지)

### 요소2: 경지 수량
| 소설 길이 | 대경지 수 | 소경지 수 | 총 층급 |
|---------|-----------|-----------|--------|
| **단편(30만 자)** | 5-7개 | 각 3-4층 | 15-28층 |
| **중편(50-100만 자)** | 7-9개 | 각 3-5층 | 21-45층 |
| **장편(100-300만 자)** | 9-12개 | 각 4-9층 | 36-108층 |
| **초장편(300만 자+)** | 12-15개 | 다중 대세계 분할 | 제한 없음 |

### 요소3: 경지 묘사
각 경지의 핵심, 수련 과정, 능력 향상, 상징적 능력을 구체적으로 묘사.

### 요소4: 돌파 난이도
```
저급: 성공률 50-80%
중급: 성공률 30-50%
고급: 성공률 10-30%
신급: 성공률 1-10%
```
실패 결과: 경지 하락, 금단 파쇄(폐인), 주화입마, 천겁에 사망

### 요소5: 자원 수요
단약, 영석, 공법, 천재지보, 전승 등. 각 경지 돌파에 필요한 자원 명확히.

---

## 2. 경지와 전투력의 관계

- 대경지마다 기초 전투력 5-10배 상승
- 소경지마다 전투력 20-50% 상승
- 월급 도전 공식: 실제 전투력 = 경지 기초 × 공법배수 × 무기배수 × 법보배수 × 혈맥배수

---

## 3. 경지 돌파 스토리 설계

### 일반 돌파 (5000자 표준)
준비 → 충격 → 천겁 → 성공의 4단계 묘사

### 특수 돌파
- 전투 중 돌파 (절체절명 반격)
- 기연 돌파 (상고 동부에서 전승 획득)
- 억압 후 폭발 돌파 (봉인 해제 후 연속 돌파)
- 단체 돌파 (특수 기연으로 팀 전원 돌파)

---

## 4. 경지와 세계관의 융합

- **지도 분층**: 저급/중급/고급 대륙 + 신역, 각 경지에 대응하는 지도
- **수명과 시간선**: 경지가 높을수록 수명이 길어, 이야기 시간 범위 확대
- **세력 등급 문턱**: 세력 가입에 특정 경지 필요

---

## 5. 흔한 문제와 해결

1. 이름 너무 복잡 → 간단히, 통일된 접두사
2. 경지 너무 많아 후반 붕괴 → 횡적 발전 (전기/법보/혈맥 향상)
3. 돌파 너무 쉬움 → 실패 설정, 대가 높이기
4. 경지 묘사 지루 → 구체적 묘사, 능력 전시

---

## 6. 자가 점검 리스트

- [ ] 이름이 기억하기 쉬운가?
- [ ] 수량이 예상 글자수에 맞는가?
- [ ] 각 경지 특성이 명확한가?
- [ ] 돌파 난이도가 점진적으로 높아지는가?
- [ ] 자원 수요가 명확한가?
- [ ] 경지 상승 후 전투력에 질적 변화가 있는가?
- [ ] 지도/세력/수명과 대응하는가?
- [ ] 앞뒤 설정에 모순이 없는가?
