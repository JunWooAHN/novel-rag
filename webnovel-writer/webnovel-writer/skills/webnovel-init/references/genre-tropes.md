## 선협 장르 공식

### 클래식 금수저(치트키)

| 유형 | 핵심 메커니즘 | 전형적 쾌감 포인트 |
|------|---------|---------|
| 흡수 시스템 | 적을 흡수하여 능력 획득 | 월경급 처치 → 실력 폭발적 상승 |
| 출석 시스템 | 매일 출석하여 보상 획득 | 신급 아이템 획득 → 동급 즉사 |
| 반지 속 노인 | 강자의 영혼이 지도 | 절학 전수 → 천재 굴욕 |
| 회귀물 | 전생 기억을 가지고 돌아감 | 미래 예지 → 기연 선점 |
| 특수 체질 | 타고난 수련 속도 가속 | 3일 만에 돌파 → 모두를 경악시킴 |

### 전형적 스토리 공식

**파혼물**: 파혼 → 주인공 부상 → 체면 구기기 → 상대 후회
**행인 굴욕물**: 조롱 → 실력 과시 → 경악/무릎 꿇기
**비경 보물 쟁탈물**: 진입 → 위험 조우 → 쟁탈 → 보물 획득 → 실력 폭발적 상승
**종문 대비물**: 참가 신청 시 조롱 → 연승 → 결승전 역전 → 전체 경악

## 도시 장르 공식

### 클래식 금수저(치트키)

| 유형 | 핵심 메커니즘 | 전형적 쾌감 포인트 |
|------|---------|---------|
| 투시안 | 물건/인체를 꿰뚫어 봄 | 원석 도박으로 벼락부자 |
| 의술 시스템 | 난치병 치유 | 권력자 치료 → 자원 획득 |
| 무도 전승 | 고대 무가 전승 | 외국 고수 격파 |
| 초능력 | 염력/번개/화염 | 허세 + 체면 구기기 |

### 전형적 스토리 공식

**허세 체면 구기기물**: 무시당함 → 신분 공개 → 경악과 후회
**돼지 흉내내며 호랑이 잡기물**: 신분 은폐 → 결정적 순간 폭로 → 모두 무릎 꿇음

## 대역 장르 공식

### 핵심 감정선

| 단계 | 여주 심리 | 남주 심리 | 전형적 쾌감 포인트 |
|------|---------|---------|---------|
| 미인지 시기 | 사랑받는 것에 몰입 | 여주를 백월광 대역으로 취급 | 달콤한 일상 |
| 인지 시기 | 의심, 내면 동요 | 혼란, 여주에 대한 진짜 감정 발생 | 감정 밀당 |
| 확인 시기 | 감정 붕괴, 가치관 붕괴 | 사랑한 것이 여주 본인임을 확인 | 학대극 절정 |
| 결별 시기 | 떠나기로 결심, 자아 회복 | 후회, 보상하고 싶어함 | 여주 각성 |
| 내려놓기 시기 | 진정한 초연함, 자기 성장 | 아내 쫓기 화장장물 | 반전 쾌감 |

### 전형적 스토리 공식

**대역 발견물**: 단서 발견 → 대역 신분 확인 → 감정 붕괴 → 떠남
**아내 쫓기 화장장물**: 남주 후회 → 비천한 만류 → 여주 거절 → 반복 밀당 → 화해/비극엔딩
**신분 반전물**: 여주가 진짜 백월광 → 진실 폭로 → 충격적 반전

### 금수저(치트키) 제안
- 시공간 이동(진실 발견의 계기)
- 기억 각성(숨겨진 신분 공개)
- 시스템 보조(자기 성장 가속)

## 다자다복 장르 공식

### 핵심 시스템 메커니즘

| 메커니즘 | 기능 | 전형적 쾌감 포인트 |
|------|------|---------|
| 자녀 시스템 | 출산, 품질, 능력 계승 | 고품질 자녀 탄생 |
| 하렘 시스템 | 호감도, 수집, 전용 스킬 | 여주 공략, 하렘 다툼 |
| 레벨업 시스템 | 경험치, 레벨, 능력치 배분 | 자녀 수 폭증으로 레벨업 |
| 보상 시스템 | 가챠, 업적, 마일스톤 | 신급 보상 획득 |

### 전형적 스토리 공식

**하렘 수집물**: 만남 → 호감도 상승 → 공략 성공 → 하렘 입성
**자녀 성장물**: 자녀 탄생 → 성장 양육 → 능력 각성 → 아버지를 빛냄
**시스템 레벨업물**: 임무 완료 → 경험치 폭증 → 레벨업 → 새 기능 해금

### 금수저(치트키) 제안
- 다자다복 시스템(핵심)
- 호감도 패널(공략 보조)
- 자녀 재능 시스템(성장 시각화)

## 다크 장르 공식

### 핵심 매력

| 유형 | 메커니즘 | 전형적 쾌감 포인트 |
|------|------|---------|
| 지배 쾌감 | 타인 절대 통제 | 적 복종, 공포 |
| 정복 쾌감 | 영토 정복, 세력 확장 | 세력 흡수, 제국 건설 |
| 흡수 쾌감 | 능력/유전자 약탈 | 흡수 진화, 실력 폭발적 상승 |
| 압도 쾌감 | 실력 격차 전시 | 한 수에 즉사, 절망과 공포 |

### 전형적 스토리 공식

**어둠 각성물**: 세계에 버림받음 → 어둠의 힘 각성 → 복수/정복
**세력 구축물**: 첫 부하 수하 → 기지 설립 → 세력 확장 → 새 질서 수립
**흡수 진화물**: 하급 흡수 → 소화 변환 → 진화 돌파 → 더 강한 대상 흡수

### 금수저(치트키) 제안
- 유전자 흡수 시스템(생물형)
- 그림자 지배 시스템(제어형)
- 파괴 환생 시스템(파괴형)
- 기생 침투 시스템(잠복형)

## 악역 유형 라이브러리

| 유형 | 특징 | 체면 구기기 방식 | 적용 단계 |
|------|------|---------|----------|
| 한량 도련님 | 오만방자 | 공개 격파 | 전기 |
| 위선자 장로 | 겉으로는 정파 | 공개 폭로 | 중기 |
| 같은 문하 사형 | 재능 질투 | 역살 | 전기 |
| 적대 종문 | 종문 간 원한 | 소대 전멸 | 중후기 |

## 공식 사용 제안

**70% 공식 + 30% 혁신**:
- 70% 공식: 독자 기대 충족, 쾌감 제공
- 30% 혁신: 놀라움 창출, 지루함 방지

**과도한 사용 금지**:
- 같은 공식 연속 3회 이상 사용 금지
- 악역 대사를 완전히 동일하게 하지 않기
- 예상치 못한 요소 삽입(악역 항복/주인공 실패)
