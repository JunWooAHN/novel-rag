# 분류별 제약 템플릿 라이브러리(플랫폼 분류 기준)

> **포지셔닝**: 플랫폼 주요 분류에 따라 "제약 팩"을 제공하여, 차별화된 창의 패키지를 빠르게 생성합니다.
> **사용법**: 분류 선택 → 1-2개 제약 팩 선택 → 3축 믹스매치법과 병합 → 창의 패키지 생성.

## 목차
- 사용 규칙
- 남성향 분류 제약 팩
- 여성향 분류 제약 팩
- 범용 풍미 추가 팩

---

## 사용 규칙

1. **장르 기반** = 선정된 분류
2. 제약 팩에서 최소 **2항목** 계승(규칙 제한 + 캐릭터 갈등 또는 규칙 제한 + 훅/쾌감)
3. **3축 믹스매치**: 최소 2/3 축이 비기본 옵션
4. 반공식 규칙 우선 적용:
   - 범용 반공식(AT-001~010)
   - 선협/현환(XH-001~020)
   - 도시/역사(UR-001~020)
   - 게임/SF(GM-001~020)
   - 규칙 괴담(RM-001~020)
