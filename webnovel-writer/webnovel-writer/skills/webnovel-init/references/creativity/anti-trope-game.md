# 게임/SF 반공식 라이브러리 (Game & Sci-Fi Anti-Tropes)

> **포지셔닝**: 게임문, SF 장르의 비관행 제한과 비공식 쾌감 포인트로, 2026년 인기 순위 실증 분석 데이터 기반, 창의 차별화를 구동합니다.

## 목차
- 1. 흔한 공식(회피 또는 반전 필요)
- 2. 비관행 제한(프로젝트당 최소 1개 선택)
- 3. 비공식 쾌감(전통 체면 구기기 대체)
- 4. 조합 예시
- 5. 사용 가이드

## 1. 흔한 공식(회피 또는 반전 필요)

| 공식 | 문제 | 출현 빈도 |
|------|------|---------|
| 시스템물 동질화(무제한 치트키) | 시장 포화, 차별화 부족 | 극히 높음 |
| 수치 무상한(기대감 상실) | 독자 추격 동력 상실 | 극히 높음 |
| 2장까지 치트키 획득 중(리듬 지연) | 전기 리듬 과도 느림, 이탈률 높음 | 높음 |
| 3장에 명확한 대적 미등장 | 갈등 부족, 독자 이탈 | 높음 |
| 처음 5장 세계관 과도 설명 | 치명적 침체, 독자 건너뜀 | 높음 |
| 주인공에 명확한 단기 목표 없음 | 독자가 왜 추격하는지 모름 | 보통 |
| IP 융합에 새 논리 없음(순수 이식) | 창의 부족, 독자 놀라움 없음 | 보통 |

## 2. 비관행 제한(프로젝트당 최소 1개 선택)

### 2.1 시스템/치트키 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| GM-001 | 치트키에 명확한 상한(시간/횟수/에너지 소모) | 자원 관리가 핵심 전략 | 체험 카드 매번 5분, 사용 후 24시간 대기 |
| GM-002 | 치트키 발동에 조건 필요(비상시 사용 불가) | 조건 조성이 스토리 핵심 | 극도 위험 시에만 시스템 활성화 |
| GM-003 | 치트키에 랜덤 부정적 효과 | 위험과 수익 공존 | 시스템 사용 시 20% 확률로 랜덤 처벌 발동 |
| GM-004 | 치트키가 타인에게 발각되면 게임 규칙 변경 | 은폐와 보호가 핵심 긴장 | 시스템 발각 후 모든 플레이어가 주인공 표적으로 |
| GM-005 | 치트키와 게임/세계 규칙 간 충돌 | 규칙 충돌이 지속적 긴장 조성 | 시스템이 준 스킬이 게임 물리법칙 위반 |

### 2.2 성장 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| GM-006 | 수치 성장에 천장(돌파 메커니즘 필요) | 돌파 메커니즘이 단계별 클라이맥스 | 레벨 상한 100, 돌파에 특수 임무 완료 필요 |
| GM-007 | 레벨업에 실질적 대가 필요(몹 사냥만이 아님) | 매번 성장에 무게감 | 레벨업 시 기존 스킬 하나 포기 필요 |
| GM-008 | 강력한 능력에 부작용 | 능력 강할수록 대가 큼 | 최강 스킬 사용 후 3일 혼수 |
| GM-009 | 자원 부족(무한 획득 불가) | 자원 쟁탈이 핵심 갈등 | 전 서버에 희귀 재료 리젠 포인트 10개뿐 |
| GM-010 | 높은 레벨이 더 큰 위협(비선형 안전감) | 강해지는 것 ≠ 더 안전 | S급 돌파 후 S급 몬스터가 능동적으로 추적 |

### 2.3 전투/경쟁 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| GM-011 | 무제한 월경 도전 불가 | 전략적 돌파구 찾기 필수 | 월경 도전 시 시스템 처벌 메커니즘 발동 |
| GM-012 | 승리에 대가(소모/노출/부채) | 승리는 무료가 아님 | 시합 이겼으나 핵심 전술 노출 |
| GM-013 | 규칙이 상대에게도 활용됨 | 규칙은 양날의 검 | 주인공이 발견한 허점을 상대가 역으로 활용 |
| GM-014 | 전임자의 적 계승 | 성장이 새 문제 초래 | 강자 격파 후 그 모든 원수가 주인공에게 이전 |
| GM-015 | 특정 규칙 위반 불가(게임 메커니즘/물리법칙) | 제약 경계가 현실감 조성 | 아무리 강해도 게임 기본 물리 위반 불가 |

### 2.4 세계/정보 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| GM-016 | 주인공이 완전한 규칙 모름(정보 비대등) | 규칙 탐색이 지속적 동력 | 매뉴얼 절반만 있고 나머지는 직접 발견 필요 |
| GM-017 | 규칙이 시간에 따라 진화 | 주인공이 지속적으로 적응 | 매주 게임 규칙 업데이트, 이전 전략 실효 |
| GM-018 | 플레이어/세력마다 규칙 해석이 다름 | 정보 차이가 전략 대결 조성 | 주인공이 타인이 모르는 규칙 해석 발견 |
| GM-019 | 망각 메커니즘(무한 정보 축적 불가) | 정보 관리가 핵심 | 사망 시마다 기억 일부 망각 |
| GM-020 | 능력 공개/전시하면 규칙 변경 | 은폐가 생존 전략 | 특정 스킬 공개 사용 후 시스템이 해당 스킬 약화 |

## 3. 비공식 쾌감(전통 체면 구기기 대체)

### 3.1 전략형 쾌감

| ID | 쾌감 패턴 | 설명 | 예시 |
|----|---------|------|------|
| GM-S01 | 규칙 역제 | 규칙 허점으로 상대 역제 | 게임 판정 메커니즘 이용해 상대 자폭 유도 |
| GM-S02 | 행동 예측 | AI/NPC/상대 행동 패턴 예측 | 상대 행동 규칙 분석, 3수 앞 포석 |
| GM-S03 | 크로스 시스템 이전 | 크로스 시스템/크로스 게임 지식 이전 | 현실 물리 지식으로 게임 내 퍼즐 해결 |
| GM-S04 | 약자가 강자 이김 | 약세 자원으로 강세 자원 격파 | 최저급 재료로 최고급 장비 합성 |
| GM-S05 | 숨겨진 메커니즘 | 숨겨진 메커니즘 발견 및 활용 | 아무도 모르는 게임 내 히든 던전 발견 |

| ID | 쾌감 패턴 | 설명 | 예시 |
|----|---------|------|------|

| GM-S07 | 부작용 무기화 | 능력 부작용을 무기로 사용 | 스킬 부정적 효과로 상대에게 반사 데미지 |

| GM-S10 | 이이제이 | 적의 규칙으로 적 격파 | 상대가 설계한 함정으로 상대를 역으로 제압 |

| GM-S12 | 실패가 최적해 | 실패로 보이는 선택이 최적해임이 밝혀짐 | 주인공이 최악의 직업을 선택했으나 숨겨진 장점 발견 |

## 4. 조합 예시

### 예시1: 게임문-IP 융합물

```
반공식 규칙: GM-005(치트키와 게임 규칙 충돌) + GM-016(완전한 규칙 모름)
비공식 쾌감: GM-S01(규칙 역제) + GM-S12(실패가 최적해)

핵심 갈등: IP 세계로 이세계했으나, 원작 스토리가 이미 궤도 이탈, 주인공의 "스포일러"가 점점 부정확
창의 구동: 끊임없이 변하는 스토리에서 어떻게 새 생존 전략을 찾을 것인가?
차별화: "스토리를 알아서 무적"이 아니라 "내가 아는 스토리가 점점 맞지 않음"
```

### 예시2: 종말 생존-건조물

```
반공식 규칙: GM-009(자원 부족) + GM-010(높은 레벨에 더 큰 위협)
비공식 쾌감: GM-S04(약자가 강자 이김) + GM-S09(단기 희생)

핵심 갈등: 합성/건조 시스템과 다른 생존자의 자원 쟁탈, 강해지면 더 강한 위협 유인
창의 구동: 자원 부족한 종말에서 어떻게 지속 가능한 생존 체계를 구축할 것인가?
차별화: "시스템이 있어서 무적"이 아니라 "내 시스템이 나를 모든 이의 표적으로 만듦"
```

### 예시3: SF-크툴루 하드코어물

```
반공식 규칙: GM-016(완전한 규칙 모름) + GM-017(규칙이 진화)
비공식 쾌감: GM-S05(숨겨진 메커니즘) + GM-S15(진실 공개)

핵심 갈등: 이성적 주인공이 비이성적 세계에서 규칙성 탐색, 그러나 규칙성 자체가 끊임없이 변화
창의 구동: 규칙이 끊임없이 진화하는 세계에서 어떻게 이성을 유지할 것인가?
차별화: "규칙성을 찾아서 무적"이 아니라 "규칙성 자체가 함정"
```

## 5. 사용 가이드

### 5.1 선택 프로세스

1. "비관행 제한"에서 1-2개 선택
2. "비공식 쾌감"에서 2-3종을 주요 쾌감 패턴으로 선택
3. 조합이 "화학 반응"을 일으키는지 점검
4. 제약 기반의 독특한 줄거리 해결책 2-3개 설계

### 5.2 게임/SF 장르 특별 팁

- ✅ **1장에 반드시 치트키 등장**: 2장까지 미루면 안됨
- ✅ **3장에 반드시 명확한 대적 등장**: 환경/규칙/구체적 악역 중 선택
- ✅ **수치 피드백 시각화 필요**: 전후 비교(전투력 50→전투력 180)
- ✅ **치트키에 반드시 상한**: 체험 카드에 시간, 능력에 소모
- ✅ **매장 최소 1개 소쾌감**: 쾌감이 1장 넘게 빠지면 안됨
- ❌ 시스템 대사 1000자 초과(독자가 건너뜀)
- ❌ 처음 5장 세계관 과도 설명
- ❌ 주인공 능력에 상한/대가 없음

### 5.3 함정 회피

- ❌ 제약 선택 후 치트키로 우회
- ❌ 제약이 전기에만 유효하고 후기에 사라짐
- ❌ 제약과 쾌감 패턴 충돌
- ✅ 제약이 전문 관통
- ✅ 제약이 스토리 발전을 구동
- ✅ 제약과 쾌감이 상호보완
