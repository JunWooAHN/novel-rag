# 도시/역사 반공식 라이브러리 (Urban & History Anti-Tropes)

> **포지셔닝**: 도시 이능, 역사 이세계 장르의 비관행 제한과 비공식 쾌감 포인트로, 2026년 인기 순위 실증 분석 데이터 기반, 창의 차별화를 구동합니다.

## 목차
- 1. 흔한 공식(회피 또는 반전 필요)
- 2. 비관행 제한(프로젝트당 최소 1개 선택)
- 3. 비공식 쾌감(전통 체면 구기기 대체)
- 4. 조합 예시
- 5. 사용 가이드

---

## 1. 흔한 공식(회피 또는 반전 필요)

| 공식 | 문제 | 출현 빈도 |
|------|------|---------|
| 연예계 포화 공식(이세계→즉시 스타 됨) | 장르 심각한 과잉, 동질화 극히 높음 | 극히 높음 |
| 치트키 무대가(시스템 무소모/무상한) | 긴장감 부족, 독자 기대감 상실 | 극히 높음 |
| 악역 순수 악, 동기 없음 | 인물 단편적, 갈등 설득력 부족 | 높음 |
| 이세계→즉시 무술 연습으로 고수 됨 | 과시 공식, 지식류의 신선함 부족 | 높음 |
| 1장 순수 대화, 환경 묘사 없음 | 독자가 몰입감 구축 불가 | 높음 |
| 감정선 종이인형 여성 캐릭터 | 평판 붕괴 위험 | 보통 |
| 지식 압도 무저항(아무도 의문 제기 않음) | 갈등 부족, 쾌감 저렴 | 보통 |

## 2. 비관행 제한(프로젝트당 최소 1개 선택)

### 2.1 치트키 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| UR-001 | 치트키에 소모 메커니즘(매 사용 시 자원/시간/건강 소모) | 매번 사용이 자원 관리 결정 | 미래 예지 시마다 수명 1년 소모 |
| UR-002 | 치트키 발동에 특정 조건 충족 필요(비상시 사용 불가) | 조건 조성이 스토리 핵심 | 절체절명 상황에서만 시스템 활성화 |
| UR-003 | 치트키에 정보 차이 상한(미래/역사의 일부만 앎) | 불완전 정보가 지속적 서스펜스 조성 | 3일 이내 사건만 볼 수 있음 |
| UR-004 | 치트키가 타인에게 발견되면 치명적 위험 | 은폐와 보호가 핵심 긴장 | 시스템 발견 시 국가기관 추적 |
| UR-005 | 치트키가 주인공 핵심 결함과 결합(많이 쓸수록 결함 심화) | 능력과 대가 깊이 결합 | 예지 능력 강할수록 현재를 느끼지 못함 |

### 2.2 주인공 능력 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| UR-006 | 지식 우위에 유효기간(역사가 예상에서 벗어남) | 주인공이 지속적으로 변화에 적응 | 하나를 바꾸면 후속 역사 전부 궤도 이탈 |
| UR-007 | 전문 지식 전환에 시간 필요(즉시 현금화 불가) | 축적 과정이 스토리 메인라인 | 배합을 알아도 설비와 자금 없음 |
| UR-008 | 주인공의 역사/산업 변경이 연쇄 반응 유발 | 비선형 결과가 예상치 못한 갈등 조성 | 한 사람을 구하면 다른 재난 유발 |
| UR-009 | 주인공에 명확한 도덕적 마지노선(무한 정보 차이 활용 불가) | 도덕 선택이 핵심 긴장 | 주가 등락을 알지만 내부거래 불원 |
| UR-010 | 주인공의 현대 사고가 고대/특정 환경에서 오해 유발 | 문화 충돌이 코미디와 위기 조성 | 현대 평등 관념이 고대에서 대역부도 취급 |

### 2.3 인간관계 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| UR-011 | 동맹이 자체 이익 소구(무조건 지지 아님) | 동맹 관계 지속 유지 필요 | 파트너가 언제든 이익 때문에 전향 가능 |
| UR-012 | 악역에 합리적 동기(이익 충돌, 인품 문제 아님) | 대립면이 더 설득력 | 악역은 기득권을 수호하는 산업 거두 |
| UR-013 | 감정선에 실질적 장애물(일견종정 무장애 아님) | 감정 발전에 실질적 포석 필요 | 상대에게 자체 사업과 원칙 존재 |
| UR-014 | 권위자가 쉽게 설득되지 않음(여러 번 증명 필요) | 인정 과정이 쾌감 축적 | 전문가가 3번 성공을 봐야 주인공을 믿음 |
| UR-015 | 주인공의 성공이 질투와 정치적 저항 유발 | 성공 자체가 새 위기 조성 | 개혁 성공 후 이익 집단 연합 탄압 |

### 2.4 세계 규칙 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| UR-016 | 역사/산업에 관성(변화에 시간과 대가 필요) | 변혁 과정이 메인라인 | 신기술 보급에 10년 소요 |
| UR-017 | 자원 유한(무한 획득 불가) | 자원 관리가 핵심 전략 | 시동 자금 기회 1번뿐 |
| UR-018 | 시대 한계성이 실제 존재(주인공도 제한) | 주인공이 전지전능하지 않음 | 고대에 현대 의료 없어, 병인 알아도 치료 불가 |
| UR-019 | 성공이 더 큰 새 압력 초래 | 무한 게임 구조 | 회사 커지면 더 강한 경쟁자 직면 |
| UR-020 | 특정 규칙 위반 불가(법률/도덕/물리) | 제약 경계가 현실감 조성 | 아무리 똑똑해도 물리법칙 위반 불가 |

## 3. 비공식 쾌감(전통 체면 구기기 대체)

### 3.1 지식 압도형 쾌감

| ID | 쾌감 패턴 | 설명 | 예시 |
|----|---------|------|------|
| UR-S01 | 지식으로 문제 해결 | 현대 지식으로 고대/산업 난제 해결(구체적 과정) | 화학 지식으로 고대 야금 난제 해결, 전 과정 추론 전시 |
| UR-S02 | 예측 포석 | 타인 행동 예측하고 미리 포석 | 3장 전에 심은 기물이 핵심 시점에 효과 발휘 |
| UR-S03 | 규칙 허점 | 규칙 허점 발견하고 합법적 활용 | 고대 법률 조문 허점으로 상대 역제 |
| UR-S04 | 크로스 분야 이전 | 크로스 영역 지식 이전(A분야 지식으로 B분야 문제 해결) | 현대 경영학으로 고대 군대 문제 해결 |
| UR-S05 | 정보 차이 역전 | 주인공이 상대 모르는 핵심 정보를 앎 | 상대 패를 알면서 모르는 척 |

### 3.2 대가형 쾌감

| ID | 쾌감 패턴 | 설명 | 예시 |
|----|---------|------|------|
| UR-S06 | 대가형 승리 | 진짜 대가를 치른 후의 승리(더 무게감) | 감정 하나를 포기하고 핵심 동맹 교환 |
| UR-S07 | 취사선택 | 한 가지를 포기하고 더 중요한 것 교환 | 비밀 하나를 자발적 폭로하고 상대 신뢰 교환 |
| UR-S08 | 약점 무기화 | 자신의 약점을 무기로 사용 | 상대의 자기 경시를 이용해 함정 설치 |
| UR-S09 | 규칙 내 돌파 | 규칙 제약 내에서 돌파구 찾기 | 고대 예법 프레임 내에서 여성 경상의 합법 경로 찾기 |
| UR-S10 | 축적 폭발 | 천부가 아닌 장기 축적으로 성공 | 10장 포석 후 한번에 모든 배치 이행 |

### 3.3 반전형 쾌감

| ID | 쾌감 패턴 | 설명 | 예시 |
|----|---------|------|------|
| UR-S11 | 과소평가 반격 | 과소평가된 자의 정확한 반격 | 모두 주인공 실패할 줄 알았는데, 주인공이 데이터로 모든 이가 틀렸음을 증명 |
| UR-S12 | 실패 포석 | 패배로 보이는 것이 실은 포석 | 협상 하나를 자발적으로 지고 더 큰 칩 교환 |
| UR-S13 | 인지 전복 | 상대가 자기가 틀렸음을 인식하는 순간 | 악역이 자기가 줄곧 주인공에게 유도당하고 있었음을 인식 |
| UR-S14 | 다선 영향 | 다방면 세력이 동시에 주인공의 영향 받음 | 하나의 결정이 동시에 세 세력의 방향을 바꿈 |
| UR-S15 | 역사 공개 | 역사/산업이 조용히 바뀐 것의 공개 | 독자가 주인공이 이미 전체 시대 방향을 바꿨음을 인식 |

## 4. 조합 예시

### 예시1: 역사 이세계-지식 개혁물

```
반공식 규칙: UR-006(지식에 유효기간) + UR-008(역사 변경 시 연쇄 반응)
비공식 쾌감: UR-S01(지식으로 문제 해결) + UR-S14(다선 영향)

핵심 갈등: 주인공이 역사 흐름을 알지만 매번 개입이 역사를 궤도 이탈시킴
창의 구동: 끊임없이 변하는 역사 속에서 어떻게 최적해를 찾을 것인가?
차별화: "내가 미래를 알아서 무적"이 아니라 "내가 아는 미래가 점점 부정확해짐"
```

### 예시2: 도시-산업 개혁물

```
반공식 규칙: UR-007(지식 전환에 시간 필요) + UR-015(성공이 정치적 저항 유발)
비공식 쾌감: UR-S10(축적 폭발) + UR-S03(규칙 허점)

핵심 갈등: 주인공에게 산업 변혁 지식이 있으나 매 단계마다 기득권자 공격 직면
창의 구동: 체제 내에서 어떻게 합법적 돌파 경로를 찾을 것인가?
차별화: "시스템이 있어서 무적"이 아니라 "규칙으로 규칙을 이김"
```

### 예시3: 역사 이세계-여주 내정물

```
반공식 규칙: UR-009(도덕적 마지노선) + UR-016(역사에 관성)
비공식 쾌감: UR-S09(규칙 내 돌파) + UR-S11(과소평가 반격)

핵심 갈등: 여주에게 현대 지식이 있으나 고대 여성 신분에 제한, 직접 행동 불가
창의 구동: 예법 제약 내에서 어떻게 여성 경제 독립 경로를 찾을 것인가?
차별화: "이세계해서 모든 규칙 타파"가 아니라 "규칙 내에서 틈새를 찾음"
```

## 5. 사용 가이드

### 5.1 선택 프로세스

1. "비관행 제한"에서 1-2개 선택
2. "비공식 쾌감"에서 2-3종을 주요 쾌감 패턴으로 선택
3. 조합이 "화학 반응"을 일으키는지 점검
4. 제약 기반의 독특한 줄거리 해결책 2-3개 설계

### 5.2 도시/역사 장르 특별 팁

- ✅ **지식 우위에 과정이 있어야**: "주인공이 답을 말함"이 아니라 "주인공이 추론 과정을 전시"
- ✅ **악역에 합리적 동기**: 이익 충돌 > 인품 문제
- ✅ **감정선에 실질적 장애물**: 상대에게 자체 원칙과 사업 존재
- ✅ **3장 1피크 리듬**: 1장 곤경, 2장 능력 초전시, 3장 소승+새 장애물
- ❌ 치트키 무대가(시스템 무소모)
- ❌ 지식 압도 무저항(모든 사람이 즉시 주인공을 믿음)
- ❌ 악역 순수 악, 동기 없음

### 5.3 함정 회피

- ❌ 제약 선택 후 치트키로 우회
- ❌ 제약이 전기에만 유효하고 후기에 사라짐
- ❌ 제약과 쾌감 패턴 충돌
- ✅ 제약이 전문 관통
- ✅ 제약이 스토리 발전을 구동
- ✅ 제약과 쾌감이 상호보완
