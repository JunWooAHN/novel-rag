# 규칙 괴담 반공식 라이브러리 (Rules Mystery Anti-Tropes)

> **포지셔닝**: 규칙 괴담 장르의 비관행 제한과 비공식 쾌감 포인트로, 창의 차별화를 구동합니다.

## 목차
- 1. 흔한 공식(회피 또는 반전 필요)
- 2. 비관행 제한(프로젝트당 최소 1개 선택)
- 3. 비공식 쾌감(전통 탈출 대체)
- 4. 조합 예시
- 5. 규칙 설계 템플릿
- 6. 사용 가이드

---

## 1. 흔한 공식(회피 또는 반전 필요)

| 공식 | 문제 | 출현 빈도 |
|------|------|---------|
| 주인공에 특수 능력으로 규칙 꿰뚫어 봄 | 추리 난이도 저하 | 극히 높음 |
| 규칙이 항상 해독 가능 | 진짜 위협감 부족 | 높음 |
| 동료가 하나씩 죽어감 | 패턴화된 사망 | 높음 |
| 최후에 탈출 성공 | 결말 예측 가능 | 높음 |
| 규칙 출처가 사신/저주 | 설명 단일 | 보통 |
| 주인공만 유일한 생존자 | 변화 부족 | 보통 |

## 2. 비관행 제한(프로젝트당 최소 1개 선택)

### 2.1 주인공 능력 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| RM-001 | 주인공이 완전한 규칙을 볼 수 없음 | 시행착오/추리로 해결 필수 | 규칙 매뉴얼에 빠진 페이지 |
| RM-002 | 주인공 특수 능력에 심각한 부작용 | 능력 사용에 저울질 필요 | 규칙 꿰뚫기 시 기억 한 단락 상실 |
| RM-003 | 주인공 능력이 규칙에 의해 "학습"됨 | 같은 수는 한 번만 사용 가능 | 규칙이 주인공 해독 방식에 적응 |
| RM-004 | 주인공이 규칙의 일부 | 주인공 행동이 규칙 자체에 영향 | 주인공 사망 시 새 규칙 발동 |
| RM-005 | 주인공에 어떤 특수 능력도 없음 | 순수 지혜와 관찰에 의존 | 보통 사람 시점 |

### 2.2 규칙 자체 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| RM-006 | 규칙 해독 불가, 적응만 가능 | 생존이지 승리가 아님 | 규칙은 세계 법칙, 변경 불가 |
| RM-007 | 규칙이 진화/변이 | 동적 위협 | 누군가 사망할 때마다 규칙 업데이트 |
| RM-008 | 규칙 간 충돌 | 규칙으로 규칙에 대항 | A 규칙 준수 시 반드시 B 규칙 위반 |
| RM-009 | 규칙 처벌이 지연됨 | 언제 발동될지 모름 | 위반 후 랜덤 시간에 처벌 발동 |
| RM-010 | 규칙의 진짜 의미가 문자와 다름 | 문자 게임 | "말하지 마라"가 실제로는 "거짓말하지 마라" |

### 2.3 환경/팀 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| RM-011 | 팀에 내부자 존재 | 신뢰 위기 | 누군가 의도적으로 규칙 발동 |
| RM-012 | 탈출이 끝이 아님 | 규칙이 따라옴 | 탈출 후 현실 세계에서 규칙 유효 |
| RM-013 | 시간 루프 | 반복 시도하나 대가 있음 | 사망 후 시작점 복귀, 그러나 기억 불완전 |
| RM-014 | 규칙 공간이 확장 중 | 긴박감 | 매 시간 규칙 영역이 2배로 확대 |
| RM-015 | 규칙 준수에도 대가 | 안전한 선택지 없음 | 규칙 준수하면 천천히 인간성 상실 |

### 2.4 정보 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| RM-016 | 주인공이 자신이 규칙 공간에 있음을 모름 | 진실 발견이 첫 단계 | 정상 세계로 생각 |
| RM-017 | 규칙 매뉴얼이 가짜/불완전 | 정보를 완전히 신뢰할 수 없음 | 매뉴얼이 함정 |
| RM-018 | 사람마다 보는 규칙이 다름 | 정보 비대칭 | 각자 규칙 일부만 볼 수 있음 |
| RM-019 | 규칙이 잊혀짐 | 기억 관리 | 규칙을 알게 된 후 점차 망각 |
| RM-020 | 규칙을 말하면 규칙 실효 | 침묵의 대결 | 타인에게 규칙을 알려주면 규칙 변화 |

## 3. 비공식 쾌감(전통 탈출 대체)

### 3.1 추리형 쾌감

| ID | 쾌감 패턴 | 설명 | 예시 |
|----|---------|------|------|
| RM-S01 | 규칙 역추론 | 결과에서 규칙 추론 | 사망 패턴에서 규칙 내용 추론 |
| RM-S02 | 규칙 조합 | 여러 규칙의 조합 효과 활용 | A규칙+B규칙=안전구역 |
| RM-S03 | 규칙 경계 테스트 | 규칙의 정확한 경계 찾기 | "말하면 안된다"의 경계는? |
| RM-S04 | 규칙 출처 추리 | 규칙이 왜 존재하는지 추론 | 규칙은 누군가의 집착 |
| RM-S05 | 가짜 규칙 식별 | 진짜 규칙과 가짜 규칙 구분 | 매뉴얼에 가짜 규칙 섞여 있음 |

## 4. 조합 예시

### 예시1: 정보 비대칭 괴담

```
반공식 규칙: RM-018(사람마다 다른 규칙을 봄) + RM-020(규칙을 말하면 실효)
비공식 쾌감: RM-S09(정보 대결) + RM-S07(인성 대결)

핵심 갈등: 각자 규칙 일부만 알고, 공유 불가
창의 구동: 직접 소통 불가 상황에서 어떻게 협력할 것인가?
차별화: 사교 추리형 괴담, 사람과 사람의 대결에 중점
```

### 예시2: 규칙 진화 괴담

```
반공식 규칙: RM-007(규칙이 진화) + RM-003(규칙이 주인공을 학습)
비공식 쾌감: RM-S03(경계 테스트) + RM-S06(규칙으로 규칙에 대항)

핵심 갈등: 매번 해독하면 규칙이 더 어려워짐
창의 구동: 규칙이 끊임없이 진화하는 상황에서 어떻게 생존할 것인가?
차별화: 동적 위협, 매번 루프가 다름
```

### 예시3: 대가형 괴담

```
반공식 규칙: RM-015(규칙 준수에도 대가) + RM-006(규칙 해독 불가)
비공식 쾌감: RM-S17(부분 준수) + RM-S20(공동 부담)

핵심 갈등: 준수와 위반 모두 대가가 있으며, 어떤 것을 감수할지만 선택 가능
창의 구동: 대가를 어떻게 최소화할 것인가?
차별화: 안전한 선택지 없음, 모든 선택에 무게감
```

### 예시4: 신분형 괴담

```
반공식 규칙: RM-004(주인공이 규칙의 일부) + RM-016(주인공이 자신이 규칙 공간에 있음을 모름)
비공식 쾌감: RM-S12(신분 반전) + RM-S15(현실 반전)

핵심 갈등: 주인공이 자신이 규칙의 핵심임을 발견
창의 구동: 주인공이 자신이 "괴물"이라는 진실에 어떻게 직면할 것인가?
차별화: 주인공 시점 전복, 피해자에서 가해자로
```

## 5. 규칙 설계 템플릿

### 5.1 기본 규칙 템플릿

```markdown
【규칙 명칭】
발동 조건: {어떤 상황에서 규칙 유효}
규칙 내용: {규칙의 구체적 요구}
위반 처벌: {규칙 위반 결과}
숨겨진 의미: {규칙의 진짜 목적/심층 의미}
활용 가능점: {주인공이 활용할 수 있는 허점/경계}
```

### 5.2 규칙 설계 원칙

1. **내재 논리**: 규칙에 존재 이유가 있어야
2. **추리 가능성**: 독자가 규칙을 추론할 수 있어야
3. **경계 명확**: 규칙 경계가 테스트 가능해야
4. **대가 명확**: 위반 처벌이 구체적이어야
5. **활용 가능성**: 규칙에 활용 가능한 공간이 있어야

### 5.3 규칙 복잡도 통제

| 분량 | 핵심 규칙 수 | 숨겨진 규칙 수 | 가짜 규칙 수 |
|------|-----------|-----------|---------|
| 단편(5만자 이하) | 3-5 | 1-2 | 0-1 |
| 중편(5-20만자) | 5-8 | 2-3 | 1-2 |
| 장편(20만자 이상) | 8-12 | 3-5 | 2-3 |

## 6. 사용 가이드

### 6.1 선택 프로세스

1. "비관행 제한"에서 1-2개 선택
2. "비공식 쾌감"에서 2-3종을 주요 쾌감 패턴으로 선택
3. 핵심 규칙 3-5개 설계
4. 각 규칙에 "활용 가능점" 설계
5. 규칙 간 흥미로운 상호작용이 있는지 점검

### 6.2 함정 회피

- ❌ 규칙이 너무 쉽게 해독됨
- ❌ 규칙 처벌이 충분히 무섭지 않음
- ❌ 주인공 능력이 너무 강해 규칙이 무의미
- ❌ 규칙 간 연관 없음
- ✅ 규칙에 진정한 위협감
- ✅ 해독에 대가 필요
- ✅ 규칙 간 흥미로운 상호작용
- ✅ 주인공의 승리가 능력이 아닌 지혜에서 옴
