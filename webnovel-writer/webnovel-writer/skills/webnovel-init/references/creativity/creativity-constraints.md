# 창의 제약 시스템 (Creativity Constraints)

> **포지셔닝**: 창의 생성의 구조화된 제약을 정의하여, 비공식적 창의 산출을 구동합니다.
> **원칙**: 제약은 제한이 아니라 창의의 촉매제입니다; 구조화된 제약은 참신성과 차별화를 높이는 데 도움이 됩니다.

## 목차
- 1. 창의 패키지 Schema (Idea Package)
- 2. 3축 믹스매치법 (Three-Axis Mashup)
- 3. 반공식 트리거 (Anti-Trope Triggers)
- 4. 미러 대립 설계 (Antagonist Mirror)
- 5. 오프닝 훅 우선법 (Hook-First Design)
- 6. 하드 제약 구동 창의 (Hard Constraints)
- 7. 3문 스크리닝법 (Three-Question Filter)
- 8. 평가 시스템 (Scoring System)
- 9. 출력 형식

## 2. 3축 믹스매치법 (Three-Axis Mashup)

### 2.1 3축 정의

| 축 | 설명 | 예시 |
|---|------|------|
| **장르 기반** | 스토리의 세계관 유형 | 선협, 도시, 규칙 괴담 |
| **규칙 제한** | 세계/능력/행동의 하드 제약 | 자원 부족, 치트키에 대가 존재, 직접 전투 금지 |
| **캐릭터 갈등** | 주인공 내적 갈등 또는 세계와의 충돌 | 반쾌감(압도 추구 안함), 도덕적 딜레마, 정체성 인식 |

### 2.2 믹스매치 규칙

**최소 2/3 축이 "해당 장르 기본 옵션이 아닌 것"이어야 함**

| 장르 | 기본 옵션 | 비기본 옵션(권장) |
|------|---------|------------------|
| 선협 | 자원 충분, 치트키 무대가, 압도 추구 | 자원 부족, 치트키에 대가 존재, 반쾌감/은둔 수행 |
| 도시 | 현대 기술, 신분 은폐, 허세 체면 구기기 | 규칙 침입, 신분 공개, 지략 대결 |
| 로맨스 | 남강여약, 오해 구동, 해피엔딩 | 대등한 실력, 정보 투명, 오픈엔딩 |
| 규칙 괴담 | 규칙 해독 가능, 주인공 특수 능력, 탈출 생존 | 규칙 불가역, 주인공 무특수 능력, 대가형 생존 |

### 2.3 믹스매치 예시

```
✅ 좋은 믹스매치:
선협(장르) + 자원 극도 부족(규칙) + 주인공 반쾌감(캐릭터)
→ 3/3 축 비기본, 창의 공간 큼

⚠️ 보통 믹스매치:
선협(장르) + 치트키에 대가(규칙) + 압도 추구(캐릭터)
→ 2/3 축 비기본, 수용 가능

❌ 공식적 믹스매치:
선협(장르) + 자원 충분(규칙) + 압도 추구(캐릭터)
→ 0/3 축 비기본, 거부
```

## 3. 반공식 트리거 (Anti-Trope Triggers)

### 3.1 필수 선택 규칙

**모든 프로젝트는 최소 1개의 비관행 규칙을 선택해야 함**

### 3.2 범용 반공식 라이브러리

| ID | 반공식 규칙 | 적용 장르 | 창의 구동 |
|----|-----------|---------|---------|
| AT-001 | 치트키에 대가가 있고 불가역 | 전체 장르 | 매번 사용이 선택의 기로 |
| AT-002 | 주인공이 직접 체면 구기기 불가, 규칙/시스템을 통해서만 반격 | 쾌감물/선협 | 지략 대결이 무력 대결을 대체 |
| AT-003 | 주인공의 장점이 동시에 치명적 약점 | 전체 장르 | 양날의 검 설계 |
| AT-004 | 악역과 주인공이 같은 치트키/능력 공유 | 전체 장르 | 미러 대립 |
| AT-005 | 주인공의 목표가 독자 예상과 반대 | 전체 장르 | 반예상 서사 |
| AT-006 | 세계 규칙이 주인공에게 불리(주인공 특권 없음) | 규칙 괴담/선협 | 공정한 대결 |
| AT-007 | 주인공의 성장 대가로 무언가를 잃음 | 전체 장르 | 성장의 무게 |
| AT-008 | 정보 대칭(주인공이 독자보다 더 아는 것 없음) | 서스펜스/규칙 괴담 | 공동 추리 |
| AT-009 | 주인공의 "올바른 선택"이 부정적 결과 초래 | 전체 장르 | 도덕적 회색 지대 |
| AT-010 | 치트키 사용 횟수/쿨타임 제한 | 시스템물 | 자원 관리 |

### 3.3 장르별 반공식

상세 참조:
- `anti-trope-xianxia.md` - 선협/현환 반공식
- `anti-trope-urban.md` - 도시/역사 반공식
- `anti-trope-game.md` - 게임/SF 반공식
- `anti-trope-rules-mystery.md` - 규칙 괴담 반공식

## 4. 미러 대립 설계 (Antagonist Mirror)

### 4.1 핵심 원칙

**악역과 주인공은 같은 "욕망/결함"을 공유하지만, 반대 경로를 선택한다**

### 4.2 미러 템플릿

| 공유 특질 | 주인공 경로 | 악역 경로 |
|---------|---------|---------|
| 힘에 대한 갈망 | 노력/희생을 통해 획득 | 약탈/배신을 통해 획득 |
| 상실에 대한 두려움 | 놓아주기/수용 배움 | 모든 것을 통제/소유 |
| 인정 추구 | 자신의 가치 증명 | 타인에게 인정 강요 |
| 과거 회피 | 직면하고 화해 | 모든 증거 파괴 |
| 사랑하는 이 보호 | 사랑하는 이의 성장 지원 | 사랑하는 이를 감금/통제 |

### 4.3 미러 예시

```
주인공: 임천, 가족 보호를 위해 힘을 갈망
악역: 모용전, 모든 것을 지배하기 위해 힘을 갈망

공유 특질: 힘에 대한 갈망
주인공 경로: 수련과 희생을 통해 힘 획득
악역 경로: 타인 흡수를 통해 힘 획득

미러 충돌: 둘의 대결은 실력 대결뿐 아니라 "힘을 얻는 방식"의 싸움
```

## 5. 오프닝 훅 우선법 (Hook-First Design)

### 5.1 핵심 원칙

**먼저 훅을 만들고, 그 다음에 개요를 정한다**

완전한 개요를 확정하기 전에 반드시 먼저 설계해야 할 것:
1. 한 줄 훅(10자 이내)
2. 오프닝 장면(50자 이내)
3. 1장 말미 서스펜스(30자 이내)

### 5.2 훅 템플릿

| 훅 유형 | 템플릿 | 예시 |
|---------|------|------|
| 반전 훅 | [신분A]인데 [행동B] | 폐물 도련님이 종주를 무릎 꿇림 |
| 서스펜스 훅 | [이상 현상], [의문] | 그는 세 번 죽었고, 매번 기억한다 |
| 대가 훅 | [X 획득], 대가는 [Y] | 신급 시스템 획득, 대가는 수명 |
| 선택 훅 | [딜레마], 그는 [의외의 것]을 선택 | 아내를 구할 것인가 세계를 구할 것인가, 그는 세 번째 길을 선택 |
| 반전 훅 | [예상A], 실제로는 [B] | 모두가 그가 죽었다고 생각했다, 그 자신 포함 |

### 5.3 오프닝 장면 템플릿

| 장면 유형 | 특징 | 적용 장르 |
|---------|------|---------|
| 위기 오프닝 | 주인공이 생사의 갈림길에 | 규칙 괴담, 선협 |
| 반전 오프닝 | 주인공 신분/능력과 표현 간 반전 | 돼지 흉내물, 도시 |
| 서스펜스 오프닝 | 미해결 수수께끼 제시 | 서스펜스, 규칙 괴담 |
| 충돌 오프닝 | 주인공과 타인의 직접 충돌 | 쾌감물, 로맨스 |
| 일상 파괴 | 평온한 일상이 깨짐 | 전체 장르 |

## 6. 하드 제약 구동 창의 (Hard Constraints)

### 6.1 핵심 원칙

**2-3개의 하드 제약을 정의하여 독특한 스토리 해결책을 이끌어낸다**

### 6.2 하드 제약 유형

| 유형 | 설명 | 예시 |
|------|------|------|
| 세계관 제약 | 세계 운영의 불가침 규칙 | "수련자는 범인을 죽일 수 없다" |
| 능력 제약 | 주인공 능력의 엄격한 제한 | "치트키는 하루에 한 번만 사용 가능" |
| 행동 제약 | 주인공 행동의 금지구역 | "주인공은 능동적 공격 불가" |
| 정보 제약 | 주인공이 알고/모르는 경계 | "주인공은 자신이 이세계인임을 모름" |
| 자원 제약 | 희소 자원의 엄격한 제한 | "전 세계에 영석이 100개뿐" |

### 6.3 제약 조합 예시

```
프로젝트: 《규칙 감옥》

하드 제약1(세계관): 규칙은 한번 발동되면 취소 불가
하드 제약2(능력): 주인공은 규칙을 "볼" 수만 있고 "바꿀" 수는 없음
하드 제약3(행동): 주인공이 타인에게 규칙을 알릴 때마다 자신의 기억 한 단락을 잃음

창의 구동:
- 규칙을 바꿀 수 없는 상황에서 주인공이 어떻게 타인을 도울 것인가?
- 기억 상실 대가 속에서 주인공이 어떻게 선택할 것인가?
- 규칙 취소 불가가 어떻게 긴장감을 만들 것인가?
```

## 7. 3문 스크리닝법 (Three-Question Filter)

### 7.1 스크리닝 질문

| # | 질문 | 통과 기준 |
|---|------|---------|
| Q1 | 이 장르를 왜 "이렇게만 써야" 하는가? | 최소 1개의 독특한 이유를 제시할 수 있음 |
| Q2 | 이 주인공을 일반 캐릭터로 바꾸면 무너지는가? | 예(주인공 설계가 스토리와 깊이 결합됨을 의미) |
| Q3 | 이 셀링 포인트를 한 마디로 설명할 수 있고 기존 공식과 겹치지 않는가? | 예(셀링 포인트가 명확하고 차별화됨을 의미) |

### 7.2 스크리닝 프로세스

```
3-5개 창의 생성
    ↓
3문 스크리닝
    ↓
3/3 통과 → 평가 진입
2/3 통과 → 수정 후 재스크리닝
1/3 또는 0/3 통과 → 탈락
```

## 8. 평가 시스템 (Scoring System)

### 8.1 5차원 평가

| 차원 | 가중치 | 1점 | 3점 | 5점 |
|------|------|-----|-----|-----|
| 참신도 | 25% | 진부함 | 미세 혁신 | 새 카테고리 개척 |
| 시장성 | 20% | 소수 비인기 | 중간 규모 독자층 | 대중 인기 |
| 작성 가능성 | 20% | 극도로 어려움 | 보통 난이도 | 쉽게 구현 가능 |
| 쾌감 밀도 | 20% | 쾌감 희소 | 중간 밀도 | 고밀도 |
| 장기 잠재력 | 15% | 연재 어려움 | 연재 가능 | 무한 확장 |

### 8.2 계산 공식

```
총점 = 참신도×2.5 + 시장성×2 + 작성 가능성×2 + 쾌감 밀도×2 + 장기 잠재력×1.5
만점 = 50점
합격선 = 30점
추천선 = 40점
```

```markdown
- 결함: {flaw}

- 공유 특질: {shared_trait}
- 반대 경로: {opposite_path}

**오프닝 훅**:
- 훅: {hook_sentence}
- 오프닝: {opening_scene}
- 서스펜스: {chapter_end_suspense}

**하드 제약**:
1. {constraint_1}
2. {constraint_2}

**3문 스크리닝**:
- Q1: {answer_1}
- Q2: {answer_2}
- Q3: {answer_3}

**평가**: {total}/50
- 참신도: {novelty}/5
- 시장성: {market_fit}/5
- 작성 가능성: {writability}/5
- 쾌감 밀도: {cool_point_density}/5
- 장기 잠재력: {long_term_potential}/5
```
