## 핵심 포지셔닝

작품의 핵심 매력을 정확히 식별하고 정의하여, 모든 창작 요소(주인공, 치트키, 세계관, 줄거리)가 이 셀링 포인트를 중심으로 전개되도록 하고, 독자에게 독특하고 일관된 읽기 체험을 제공합니다.

## 1. 핵심 셀링 포인트 이론 기초

### 1.1 핵심 셀링 포인트의 정의

**핵심 셀링 포인트 = 독자가 이 책을 선택하는 유일한 이유**

> 독자가 당신의 소설을 이해하는 데 10초밖에 없다면, 어떤 한 마디로 끌 것인가?

**3층 구조**:
- **표층(장르 태그)**: 도시, 현환, SF 등 → 독자가 클릭할지 결정
- **중층(핵심 셀링 포인트)**: 회귀 복수, 규칙 괴담, 악역 세탁 등 → 독자가 계속 볼지 결정
- **심층(감정 체험)**: 쾌감, 학대, 열혈, 달달, 서스펜스 등 → 독자가 유료 구독할지 결정

### 1.2 핵심 셀링 포인트 vs 기타 개념

| 개념 | 정의 | 차이 |
|------|------|------|
| **핵심 셀링 포인트** | 작품의 가장 핵심적 매력 | 유일, 전문 관통, 대체 불가 |
| **장르** | 스토리 배경 유형 | 현환/도시/SF, 범위 광범위 |
| **치트키** | 주인공 특수 우위 | 셀링 포인트에 봉사하는 도구 |
| **쾌감** | 독자 쾌감 원천 | 셀링 포인트의 구체적 표현 형식 |
| **캐릭터** | 인물 설정 | 셀링 포인트의 인격화 담체 |

**예시**:
```
❌ 오류: "내 소설은 도시 회귀문이다"(이것은 장르이지 셀링 포인트가 아님)
✅ 정확: "악역으로 회귀하여, 전생 기억으로 세탁 역전"(이것이 핵심 셀링 포인트)
```

### 1.3 핵심 셀링 포인트 황금 공식

**공식1: 한 줄 셀링 포인트**
```
[주인공 신분/우위] + [핵심 행동] + [독특한 목표] = 핵심 셀링 포인트
```

**예시**:
- 회귀 비즈니스 거물(신분) + 수능 전으로 돌아감(행동) + 인생 정점 다시 쓰기(목표)
- 출석 시스템 숙주(우위) + 매일 랜덤 보상 획득(행동) + 최강자 달성(목표)
- 규칙 허점을 꿰뚫어 봄(우위) + 규칙 괴담에서 생존(행동) + 세계 진실 해독(목표)

**공식2: 핵심 셀링 포인트 조합**
```
핵심 셀링 포인트 = 대리 충족 약속 + 감정 만족 + 독특한 가치
```

**설명**:
- **대리 충족 약속**: 독자가 현실에서 얻을 수 없지만, 스토리에서 체험할 수 있는 궁극 쾌감(예: 차원 격하 공격, 말하면 법이 됨)
- **감정 만족**: 쾌감, 달콤함, 긴장, 치유의 구체적 감정 착지점
- **독특한 가치**: 동장르 작품과의 1% 미세 혁신

**공식2: 차별화 셀링 포인트**
```
동류 작품 흔한 설정 + 미세 혁신/반전 = 차별화 셀링 포인트
```

**예시**:
- 일반 회귀문: 주인공 모든 것 압도 → **미세 혁신**: 회귀 후 미래가 이미 바뀌었음을 발견
- 일반 시스템문: 무한 보상 → **반전**: 시스템이 매번 보상마다 치명적 대가
- 일반 선협문: 주인공 천부적 재능 → **미세 혁신**: 주인공 수련 불가, "외부 치트"로 보완

## 2. 시장 핫이슈 및 혁신 기회 식별

### 2.1 인기 셀링 포인트 생명주기 분석(2025 샘플)

| 셀링 포인트 유형 | 생명주기 단계 | 시장 포화도 | 혁신 기회 | 제안 전략 |
|---------|------------|-----------|---------|---------|
| **도시 회귀** | 성숙기 | 높음(레드오션) | 미세 혁신(악역 시점, 여성향 시점) | 반드시 차별화 필요 |
| **시스템 출석** | 성숙기 | 높음(레드오션) | 다른 요소 결합(서스펜스, 추리) | 순수 출석물 피하기 |
| **규칙 괴담** | 성장기 | 보통 | 크로스 장르 융합(도시, 현환) | 골든 진입 시기 |
| **악역 세탁** | 성장기 | 보통 | 시점 혁신(여성향, 달달물) | 잠재력 큼 |
| **무한류** | 성숙기 | 높음(레드오션) | 여성향 무한류 | 세분화 심화 필요 |
| **퀵 이세계** | 쇠퇴기 | 극히 높음 | 심층 혁신 또는 전환 | 신인 비추천 |

### 2.2 시장 공백점 식별 체크리스트

**다음 조합이 충분히 개발되었는지 확인**:

- [ ] 장르A + 인기 셀링 포인트B = 이미 히트작이 있는가?
- [ ] 전통 셀링 포인트 + 새 시점(여성향/악역/조연) = 누군가 시도했는가?
- [ ] 인기 셀링 포인트 + 반공식 설정 = 충분히 참신한가?
- [ ] 크로스 장르 융합(예: 도시+규칙 괴담) = 성공 사례가 있는가?

**시장 공백 예시**(2025년 잠재 방향 샘플):
- 규칙 괴담 + 도시 배경(현대 도시 속 규칙 세계)
- 회귀 + 조연 시점(원작 조연으로 회귀, 스토리 변경)
- 시스템 + 군상극 다주인공(여러 명이 시스템 보유, 서로 대결)
- 악역 세탁 + 여성향 달달물(악역 대물이 세탁 후 아내 쫓기)

### 2.3 독자층 이동 트렌드(2025 샘플)

**"순수 쾌감"에서 "쾌감+두뇌 대결"로**:
- 독자들이 점점 지능 있는 주인공을 기대
- 단순 치트키 압도만으로는 유료 구독 유치 불충분
- 서스펜스, 추리, 반전 요소 인기

**"단일 주인공"에서 "군상극 다시점"으로**:
- 다주인공, 다시점 서사가 유행하기 시작
- 조연도 완전한 성장선이 필요
- 악역이 더 이상 도구인이 아니며, 합리적 동기 필요

**"남성향 독점"에서 "성별 균형"으로**:
- 여성향 시장 빠르게 성장
- 남성향 작품이 여성 시점 시도 시작
- 성별 반전, 성별 평등 주제 주목

## 3. 셀링 포인트와 요소의 체계적 매칭

### 3.1 주인공 신분과 셀링 포인트 매칭

**매칭 원칙**: 주인공 신분이 핵심 셀링 포인트를 **최대한 전시**해야 함

**예시 분석**:

| 핵심 셀링 포인트 | 최적 주인공 신분 | 왜 매칭되는가 | 매칭되지 않는 신분 |
|---------|------------|-----------|-------------|
| 회귀 복수 | 전생 피해자 | 복수 동기+정보 차이 우위 | 원한 없는 행인 |
| 규칙 해독 | 논리 능력 강한 추리자 | 규칙 허점 발견 가능 | 무뇌 무인 |
| 악역 세탁 | 전생 악역 대물 | 세탁 동기+반전 매력 | 처음부터 좋은 사람 |
| 시스템 출석 | 빠른 성장이 필요한 약자 | 출석이 약점 보완 | 원래부터 천재 |
| 비즈니스 전쟁 권모 | 비즈니스 천재/회귀자 | 비즈니스 지식+정보 우위 | 비즈니스를 전혀 모름 |

**주인공 성격과 셀링 포인트 매칭**:

```
셀링 포인트: 회귀 복수
✅ 매칭 성격: 냉정, 심모원려, 인내심 있게 포석
❌ 불매칭: 충동적, 성녀, 쉽게 용서

셀링 포인트: 규칙 괴담
✅ 매칭 성격: 신중, 이성적, 관찰력 강함
❌ 불매칭: 무모, 부주의, 생각 없음

셀링 포인트: 달달물
✅ 매칭 성격: 온화, 세심, 유혹할 줄 앎
❌ 불매칭: 둔감, 돌직구, 감성지능 낮음
```

### 3.2 치트키와 셀링 포인트 매칭

**매칭 원칙**: 치트키가 핵심 셀링 포인트에 **전문적으로 봉사**해야 하며, 범용 만능이 아님

**치트키 설계 3문**:
1. 이 치트키가 셀링 포인트를 더 부각하는가?
2. 이 치트키 없이는 셀링 포인트가 성립 불가능한가?
3. 치트키가 셀링 포인트의 존재감을 빼앗지 않는가?

**매칭 예시**:

| 핵심 셀링 포인트 | 매칭되는 치트키 | 매칭되지 않는 치트키 |
|---------|------------|---------------|
| **회귀 복수** | 전생 기억+핵심 정보 | 무적 전투력(복수와 무관) |
| **규칙 해독** | 규칙 허점을 꿰뚫는 능력 | 규칙 직접 무시(셀링 포인트 파괴) |
| **시스템 출석** | 매일 출석 보상 획득 | 한 번에 무적 장비 획득 |
| **악역 세탁** | 독심술(타인 생각 파악) | 시간 되돌리기(너무 만능) |
| **비즈니스 전쟁 권모** | 미래 비즈니스 기회 예지 | 무력 폭발(주제 이탈) |

**치트키 업그레이드 논리와 셀링 포인트 연관**:
```
셀링 포인트: 규칙 괴담 해독
치트키 업그레이드 경로:
Lv1: 기본 규칙을 볼 수 있음
Lv2: 규칙 허점을 발견할 수 있음
Lv3: 규칙 변화를 예측할 수 있음
Lv4: 새 규칙을 창조할 수 있음

매번 업그레이드가 "규칙 해독"이라는 핵심 셀링 포인트를 강화
```

### 3.3 세계관과 셀링 포인트 매칭

**매칭 원칙**: 세계관 규칙이 셀링 포인트의 가치를 **증폭**해야 함

**예시 분석**:

```
셀링 포인트: 회귀가 가져다준 정보 차이 우위

✅ 매칭되는 세계관:
- 주식/비즈니스 전쟁 배경(정보 차이=부)
- 선협 세계(기연 위치를 미리 앎)
- 연예계(어떤 노래가 히트할지 앎)

❌ 매칭되지 않는 세계관:
- 완전히 정적인 세계(미래가 변하지 않아 회귀 무의미)
- 랜덤성 극히 높은 세계(정보 차이 무용)
```

```
셀링 포인트: 규칙 해독

✅ 매칭되는 세계관:
- 엄격한 규칙 제약의 괴담 세계
- 명확한 규칙의 게임 세계
- 등급이 엄격한 선협 체계

❌ 매칭되지 않는 세계관:
- 규칙 없는 혼란한 세계
- 규칙이 수시로 바뀌는 세계
```

## 4. 메인 스토리 구조와 셀링 포인트 관철

### 4.1 "큰 목표+소순환" 발전 모델

**큰 목표**: 셀링 포인트를 중심으로 설정한 궁극 목표

**소순환**: 각 단계에서 셀링 포인트를 반복 강화하는 줄거리 패턴

**메인 스토리 관철 메커니즘**:
- **큰 목표 + 소순환**: 각 줄거리 포인트가 반드시 핵심 셀링 포인트를 강화
- **독자 기대 관리**: 약속한 쾌감이 반드시 골든 3장 내 첫 구현, 이후 고정 빈도로 이행

**예시(회귀 복수문)**:

```
큰 목표: 원수를 완전히 쓰러뜨려 전생 억울함 씻기

소순환(매 10-15장 1회):
1. 원수의 약점 하나 발견(정보 차이 우위)
2. 맞춤형 계획 수립(지략 대결)
3. 계획 실행 및 체면 구기기(복수 쾌감)
4. 원수 반격(새 갈등 조성)
5. 주인공 한 단계 더 나아감(성장+복수 진행)

각 순환이 "회귀 복수"라는 핵심 셀링 포인트를 강화
```

### 4.2 단계별 셀링 포인트 구현

**3막 구조와 셀링 포인트 관철**:

| 단계 | 글자 수 범위 | 셀링 포인트 구현 방식 | 예시(규칙 괴담) |
|------|---------|------------|-----------------|
| **1막(개시)** | 0-10만자 | 셀링 포인트 수립, 독특성 전시 | 주인공이 규칙 세계 진입, 해독 능력 전시 |
| **2막(전개)** | 10-50만자 | 셀링 포인트 심화, 업그레이드 변화 | 규칙이 점점 복잡, 해독 난이도 상승 |
| **3막(클라이맥스)** | 50만자+ | 셀링 포인트의 궁극 구현 | 세계 궁극 규칙 해독, 진실 밝힘 |

**각 단계의 셀링 포인트 강화 점검**:

- [ ] 1막: 독자가 처음 3장에서 핵심 셀링 포인트를 이해했는가?
- [ ] 2막: 셀링 포인트가 각 소클라이맥스에서 구현되었는가?
- [ ] 3막: 궁극 클라이맥스가 셀링 포인트의 가장 강한 표현인가?

### 4.3 줄거리가 셀링 포인트를 관철하는 4가지 방식

**방식1: 직접 전시**
```
셀링 포인트: 회귀가 가져다준 미리 알기
구현: 주인공이 직접 예언하고, 그 후 적중
```

**방식2: 대비 반전**
```
셀링 포인트: 악역 세탁
구현: 전생 악행 vs 금생 선행, 강한 대비 형성
```

**방식3: 갈등 증폭**
```
셀링 포인트: 규칙 해독
구현: 규칙이 점점 엄격해지고, 해독 난이도 점점 상승
```

**방식4: 캐릭터 상호작용**
```
셀링 포인트: 시스템 출석
구현: 다른 캐릭터가 주인공 성장 속도에 놀라며, 시스템 우위 부각
```

## 5. 차별화 전략과 혁신 방향

### 5.1 동류 작품 대비 분석법

**단계1**: 같은 셀링 포인트의 성공 작품 3-5부 찾기

**단계2**: 공통점과 차이점 분석

| 작품 | 핵심 셀링 포인트 | 주인공 설정 | 치트키 | 차별화 포인트 |
|------|---------|---------|--------|-----------|
| 작품A | 회귀 복수 | 비즈니스 거물 | 전생 기억 | 비즈니스 전쟁 권모 |
| 작품B | 회귀 복수 | 연예 스타 | 전생 기억 | 연예계 체면 구기기 |
| 작품C | 회귀 복수 | 학생 일등 | 전생 기억 | 수능으로 운명 변경 |

**단계3**: 시장 공백 또는 미세 혁신점 찾기

```
기존 조합: 회귀 복수 + 비즈니스/연예/학업
시장 공백: 회귀 복수 + 과학연구/스포츠/정계
미세 혁신: 회귀 복수 + 악역 시점(악역으로 회귀하여 세탁)
```

### 5.2 6가지 차별화 전략

**전략1: 시점 혁신**
```
일반: 남성 주인공 → 혁신: 여성 주인공
일반: 정파 주인공 → 혁신: 악역 주인공
일반: 단일 시점 → 혁신: 다시점 군상극
```

**전략2: 캐릭터 반전**
```
일반: 천재 주인공 → 혁신: 폐물 주인공 역전
일반: 냉혹 주인공 → 혁신: 소프트 주인공(반전 매력)
일반: 만능 주인공 → 혁신: 명확한 단점이 있는 주인공
```

**전략3: 치트키 혁신**
```
일반: 무한 보상 시스템 → 혁신: 대가가 있는 시스템
일반: 전지전능 → 혁신: 특정 분야에서만 강함
일반: 영구 치트키 → 혁신: 시간제한 또는 횟수 제한
```

**전략4: 세계관 융합**
```
일반: 순수 도시 → 혁신: 도시+현환 요소
일반: 순수 선협 → 혁신: 선협+과학기술 요소
일반: 순수 역사 → 혁신: 역사+이세계 요소
```

**전략5: 리듬 혁신**
```
일반: 느린 워밍업 → 혁신: 오프닝부터 클라이맥스
일반: 선형 서사 → 혁신: 다선 교차+반전
일반: 단일 쾌감 → 혁신: 다유형 쾌감 결합
```

**전략6: 감정 혁신**
```
일반: 순수 쾌감문 → 혁신: 쾌감+학대+열혈 결합
일반: 감정선 없음 → 혁신: 감정선과 메인 스토리 깊이 융합
일반: 달달물 → 혁신: 학대 후 달달함(학대연애)
```

## 6. 일관성 메커니즘과 독자 기대 관리

### 6.1 셀링 포인트 관철의 5대 일관성 원칙

**원칙1: 오프닝 약속 = 전문 이행**
```
오프닝 약속: "회귀 복수"
전문 이행: 각 단계마다 복수 진행 추진
위반 예시: 전기 복수, 후기 농사문으로 변화
```

**원칙2: 치트키 강도 균형 유지**
```
✅ 올바름: 치트키가 주인공 성장에 따라 단계적 업그레이드
❌ 오류: 오프닝 무적 → 중기 무력하게 당함 → 후기 다시 무적
```

**원칙3: 주인공 성격 OOC 금지**
```
✅ 올바름: 냉정한 주인공이 시종 이성적 결정
❌ 오류: 전기 냉정, 후기 갑자기 충동적으로 사지에 뛰어듦
```

**원칙4: 세계관 규칙 자기모순 금지**
```
✅ 올바름: 선협 체계 전후 일관
❌ 오류: 전기 "경계 월경 불가"라 했는데, 후기 주인공 월경이 밥 먹듯
```

**원칙5: 쾌감 빈도 안정**
```
✅ 올바름: 3-5장마다 소쾌감, 10-15장마다 대쾌감
❌ 오류: 전기 쾌감 밀집, 후기 10장에 쾌감 하나도 없음
```

### 6.2 독자 기대 관리 전략

**전략1: 약속 명확, 즉시 이행**
```
1장: "주인공이 복수할 것"을 약속
3장: 첫 소복수(약속 이행)
10장: 첫 대복수(약속 강화)
```

**전략2: 소목표 설정, 지속적 만족**
```
큰 목표: 최강자 달성
소목표:
- 1단계: 반 1등
- 2단계: 학교 1등
- 3단계: 시 전체 1등
각 소목표 달성 시 독자에게 성취감
```

**전략3: 적절한 여백, 서스펜스 조성**
```
명확히 알림: 주인공에게 회귀 우위 있음
여백: 그러나 미래가 주인공에 의해 변할 수 있는가?
서스펜스 조성: 주인공이 정말 운명을 다시 쓸 수 있을까?
```

**전략4: 정기적 새로고침, 심미적 피로 방지**
```
1-10장: 회귀 복수(비즈니스 전쟁)
10-20장: 새 적 등장(권모)
20-30장: 더 큰 음모 발견(서스펜스)
핵심 셀링 포인트 유지, 그러나 장면/상대 교체
```

### 6.3 셀링 포인트 이탈 경보 메커니즘

**이탈 신호 식별**:

- ⚠️ 독자 댓글: "왠지 XX문으로 바뀐 것 같은데?"
- ⚠️ 구독 데이터 하락
- ⚠️ 핵심 셀링 포인트 3장 연속 미등장
- ⚠️ 새로 도입한 요소가 셀링 포인트 존재감 빼앗음

**교정 방법**:

1. **빠른 복귀**: 다음 장에서 즉시 핵심 셀링 포인트 강화
2. **리듬 조정**: 셀링 포인트와 무관한 줄거리 삭감
3. **재집중**: 캐릭터 대화를 통해 독자에게 핵심 셀링 포인트 상기
4. **독자 소통**: 작가의 말에서 핵심 셀링 포인트 재확인

## 8. 자주 묻는 질문과 해결 방안

### Q1: 셀링 포인트가 너무 많아서 어떤 걸 핵심으로 할지 모르겠다면?

**A**: "삭제법" 사용
- 각 셀링 포인트를 순서대로 삭제하여, 삭제하면 스토리 전체가 성립하지 않는 것을 찾기
- 삭제 불가능한 셀링 포인트가 핵심 셀링 포인트
- 나머지는 보조 셀링 포인트 또는 쾌감 설계로 활용

**예시**:
```
후보 셀링 포인트: 회귀 + 시스템 + 비즈니스 전쟁
회귀 삭제 → 시스템+비즈니스 전쟁 여전히 성립
시스템 삭제 → 회귀+비즈니스 전쟁 여전히 성립
비즈니스 전쟁 삭제 → 회귀+시스템은 막연한 레벨업문이 됨
결론: 비즈니스 전쟁이 핵심 셀링 포인트, 회귀와 시스템은 보조
```

### Q2: 셀링 포인트가 좋은데 30만자+ 지속 방법을 모르겠다면?

**A**: "계단식 업그레이드" 사용
- 셀링 포인트를 여러 단계로 분해
- 각 단계 난이도 상승, 그러나 핵심은 불변
- 장면, 상대, 규칙 교체, 그러나 셀링 포인트는 불변

**예시(규칙 괴담)**:
```
1단계: 기본 규칙 해독(쉬움)
2단계: 복합 규칙 해독(보통)
3단계: 동적 규칙 해독(어려움)
4단계: 궁극 규칙 해독(지옥)
셀링 포인트 불변: 규칙 해독
그러나 난이도와 깊이 단계적 상승
```

### Q3: 셀링 포인트 동질화가 심하면 어떻게 차별화할 것인가?

**A**: "조합 혁신법" 사용(`creative-combination.md` 참조)
- A셀링 포인트 + B시점 = 새 셀링 포인트
- A셀링 포인트 + C캐릭터 = 새 셀링 포인트
- A셀링 포인트 + D세계관 = 새 셀링 포인트

**예시**:
```
일반: 회귀 복수(남주)
혁신: 회귀 복수(여주)
혁신: 회귀 복수(악역 시점)
혁신: 회귀 복수(조연 시점)
```

### Q4: 셀링 포인트가 오프닝에서 매력적인데 중후기에 동력이 떨어지면?

**A**: "셀링 포인트 업그레이드 경로" 수립
- 오프닝: 셀링 포인트 기본 형태 전시
- 중기: 셀링 포인트가 도전에 직면, 강제 업그레이드
- 후기: 셀링 포인트의 궁극 형태

**예시(시스템 출석)**:
```
오프닝: 매일 출석으로 소보상 획득
중기: 숨겨진 출석 장소 발견, 보상 더 좋음
후기: 출석 시스템 진화, 자기 맞춤 보상 가능
셀링 포인트는 항상 "출석", 그러나 플레이 방식이 업그레이드
```

### Q5: 독자가 "셀링 포인트가 이탈했다"고 하면 어떻게 교정할 것인가?

**A**: 3단계 교정법
1. **즉시 복귀**: 다음 장에서 핵심 셀링 포인트 강화
2. **무관 줄거리 삭감**: 셀링 포인트와 무관한 서브 스토리 삭제
3. **독자 소통**: 작가의 말에서 핵심 셀링 포인트 재확인

**예시**:
```
이탈 상황: 회귀 복수문이 농사문으로 변함
교정 단계:
1. 다음 장에서 즉시 복수 줄거리 배치
2. 농사 세부 묘사 삭감
3. 작가의 말: "앞으로 복수 리듬을 가속하겠습니다"
```

## 9. 핵심 셀링 포인트 정의 템플릿

```markdown
## 핵심 셀링 포인트 정의

회귀 비즈니스 거물(신분) + 수능 전으로 돌아감(행동) + 인생 정점 다시 쓰기(목표)

독자가 이 셀링 포인트에서 얻는 것은?(쾌감/학대/열혈/달달/서스펜스 등)

이 셀링 포인트가 독자의 어떤 감정적 필요를 자극?(복수/성장/역전/치유 등)

독자에게 약속하는 핵심 읽기 체험은?
```

### 9.2 요소 매칭 설계표

```markdown
## 핵심 요소 매칭

### 주인공 설정

- **성격**: [반드시 셀링 포인트와 매칭]
- **동기**: [반드시 셀링 포인트와 일치]

### 치트키 설계
- **유형**: [셀링 포인트에 전문 봉사]
- **핵심 기능**: [셀링 포인트의 독특성 강화]
- **업그레이드 논리**: [셀링 포인트와 깊이 결합]
```
