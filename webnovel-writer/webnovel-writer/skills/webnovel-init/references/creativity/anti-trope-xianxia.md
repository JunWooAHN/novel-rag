# 선협/현환 반공식 라이브러리 (Xianxia Anti-Tropes)

> **포지셔닝**: 선협/현환 장르의 비관행 제한과 비공식 쾌감 포인트로, 창의 차별화를 구동합니다.

## 목차
- 1. 흔한 공식(회피 또는 반전 필요)
- 2. 비관행 제한(프로젝트당 최소 1개 선택)
- 3. 비공식 쾌감(전통 체면 구기기 대체)
- 4. 조합 예시
- 5. 사용 가이드

## 2. 비관행 제한(프로젝트당 최소 1개 선택)

### 2.1 치트키 제한류

| ID | 반공식 규칙 | 창의 구동 | 예시 |
|----|-----------|---------|------|
| XH-001 | 치트키 사용 시마다 수명 소모 | 매번 사용이 생사의 기로 | 1년 수명으로 1회 돌파 교환 |
| XH-002 | 치트키가 특정 조건에서만 활성화 | 조건 조성이 스토리 핵심 | 빈사 상태에서만 사용 가능 |
| XH-003 | 치트키 보상에 랜덤 부정적 효과 | 위험과 수익 공존 | 공법 획득하나 감각 하나 랜덤 봉인 |
| XH-004 | 치트키를 여러 명이 공유(경쟁 관계) | 제로섬 대결 | 전 세계에 시스템 숙주 10명뿐 |
| XH-005 | 치트키가 타인에게 탈취당할 수 있음 | 은폐와 보호가 핵심 | 죽으면 치트키가 이전됨 |

| XH-007 | 수련 속도가 도덕과 연동 | 선악 선택이 실력에 영향 | 살인하면 수위 하락 |

| XH-S04 | 규칙 허점 | 규칙 허점 발견 및 활용 | 금제의 사각지대 발견 |

## 4. 조합 예시

### 예시1: 은둔 수행 선협

```
반공식 규칙: XH-010(경계 높을수록 수명 짧아짐) + XH-009(자원 극도 부족)
비공식 쾌감: XH-S05(장기 포석) + XH-S06(희생으로 승리 교환)

핵심 갈등: 주인공이 장생을 추구하나, 수련하면 수명이 줄어듦
창의 구동: "수련=감수"인 세계에서 어떻게 가장 오래 살 것인가?
차별화: 최강을 추구하지 않고, 가장 오래 사는 것을 추구
```

### 예시2: 규칙 선협

```
반공식 규칙: XH-013(전투가 규칙으로 판정) + XH-018(고계가 저계에 개입 불가)
비공식 쾌감: XH-S01(규칙 활용) + XH-S04(규칙 허점)

핵심 갈등: 실력이 결정 요인이 아니며, 규칙이 핵심
창의 구동: 규칙 프레임 내에서 어떻게 최대 우위를 얻을 것인가?
차별화: 지략이 무력을 대체, 변호사형 주인공
```

### 예시3: 대가 선협

```
반공식 규칙: XH-001(치트키가 수명 소모) + XH-012(월경에 반드시 대가)
비공식 쾌감: XH-S06(희생으로 승리 교환) + XH-S10(지연 대가)

핵심 갈등: 매번 강해질 때마다 미래를 투자
창의 구동: "대가 부채"를 어떻게 관리할 것인가?
차별화: 자원 관리형 선협, 매번 선택에 무게감
```

## 5. 사용 가이드

### 5.1 선택 프로세스

1. "비관행 제한"에서 1-2개 선택
2. "비공식 쾌감"에서 2-3종을 주요 쾌감 패턴으로 선택
3. 조합이 "화학 반응"을 일으키는지 점검
4. 제약 기반의 독특한 줄거리 해결책 2-3개 설계

### 5.2 함정 회피

- ❌ 제약 선택 후 치트키로 우회
- ❌ 제약이 전기에만 유효하고 후기에 사라짐
- ❌ 제약과 쾌감 패턴 충돌
- ✅ 제약이 전문 관통
- ✅ 제약이 스토리 발전을 구동
- ✅ 제약과 쾌감이 상호보완
