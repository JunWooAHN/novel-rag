# 영감 수집 정리 참고 가이드

## 핵심 포지셔닝

산발적 아이디어를 실행 가능한 창작 방향으로 전환하며, 체계적 방법을 통해 영감을 정제, 태깅 및 조합합니다.

---

## 1. 영감 분류 체계

### 1.1 영감 유형 식별

| 유형 | 특징 | 예시 |
|------|------|------|
| **장르 영감** | 스토리 배경과 세계 유형 | 도시 회귀, 성간 쟁패, 고대 궁투 |
| **캐릭터 영감** | 인물 특질과 신분 | 냉혹한 킬러, 순수 학생 일등, 복흑 총재 |
| **세계관 영감** | 설정 규칙과 체계 | 선협 체계, 미래 기술, 평행 세계 |
| **줄거리 훅** | 독자를 끄는 스토리 포인트 | 신분 교환, 시간 루프, 진실 반전 |
| **치트키 영감** | 주인공 특수 우위 | 시스템 출석, 회귀 기억, 이능 각성 |
| **감정 체험 영감** | 전달하고 싶은 감정 | 열혈 열정, 달콤한 치유, 긴장 스릴 |

### 1.2 창의 성숙도 등급

- **기초층**: 개념만 있고 구체적 설정 부족
- **발전층**: 초보적 캐릭터 또는 세계관 프레임 존재
- **성숙층**: 완전한 스토리 구조와 메인 스토리 설계 구비

## 2. 단일 영감 심층 발굴

### 2.1 핵심 컨셉 추출

**공식**: "만약 [설정/사건]이면, 어떻게 될까?"

예시:
- "만약 주인공이 타인의 죽음 카운트다운을 볼 수 있다면, 어떻게 될까?"
- "만약 모든 사람이 어제의 기억을 잃어버렸다면, 어떻게 될까?"

### 2.2 5차원 잠재력 평가(1-5점 척도)

| 차원 | 평가 포인트 | 1점 | 5점 |
|------|---------|-----|-----|
| **독창성** | 시장 동질화 정도 | 진부한 공식 | 유일무이 |
| **시장 잠재력** | 독자층 규모 | 소수 비인기 | 대중 인기 |
| **확장성** | 장편(30만자+) 지탱 가능 여부 | 전개 어려움 | 스토리 공간 큼 |
| **창작 난이도** | 설정/줄거리 복잡도 | 극도로 어려움 | 쉽게 구현 |
| **개인 적합도** | 지식 축적/흥미/자원 | 완전히 낯설음 | 자유자재 |

**총점 참고**:
- 20-25점: 높은 잠재력, 우선 개발
- 15-19점: 보통 잠재력, 다듬기 필요
- <15점: 임시 보류 또는 재조합

### 2.3 리스크 식별 목록

흔한 창작 리스크:
- ❌ 설정이 너무 복잡하여 붕괴 가능
- ❌ 리듬 조절 어려움(너무 빠름/느림)
- ❌ 동질화 경쟁 치열
- ❌ 전문 지식이 필요하나 축적 부족
- ❌ 쾌감 설계 단일, 후기 동력 부족

## 3. 영감 태깅 시스템

### 3.1 태그 명명 규범

**형식**: `[주분류]-[하위분류]` 또는 `[핵심 요소]-[변형]`

예시:
```
도시-회귀
시스템-출석물
악역-세탁
군상극-다시점
서스펜스-규칙 괴담
현환-선협
SF-성간
```

### 3.2 태그 조합 전략

**단일 태그**: 장르 포지셔닝 명확
```
현환
```

**이중 태그**: 장르 + 셀링 포인트
```
도시-회귀
현환-시스템
```

**삼중 태그+**: 장르 + 셀링 포인트 + 특색
```
도시-회귀-복수
현환-시스템-군상극
SF-성간-권모
```

## 4. 창의 조합 혁신법

### 4.1 A+B 이중 요소 조합

**공식**: 서로 다른 영감의 핵심 요소 중첩

예시:
- `도시 회귀 + 시스템 출석` → 회귀 도시 출석물
- `서스펜스 추리 + 규칙 괴담` → 규칙 해독물
- `고대 궁투 + 현대 기억` → 이세계 궁투문

**평가 기준**:
- ✅ 화학 반응: 두 요소 결합 후 새로운 매력 발생
- ✅ 실현 가능성: 조합 후 설정 논리 일관
- ❌ 충돌: 요소 상호 모순, 융합 어려움

### 4.2 A+B+C 삼중 요소 조합

**공식**: 장르 + 셀링 포인트 + 캐릭터 특색

예시:
```
도시 + 회귀 + 악역 세탁
= 악역으로 회귀한 도시문, 세탁으로 역전 실현

현환 + 시스템 + 군상극 다시점
= 여러 주인공이 시스템을 보유하고, 서로 대결하는 현환문

SF + 시간 루프 + 추리 해독
= 시간 루프에 갇혀 진실을 해독하는 SF 서스펜스
```

**경고**: 요소가 너무 많으면 메인 스토리 혼란, 리듬 실패를 방지하세요.

### 4.3 미세 혁신과 변형

**방법**: 기존 영감에 "X 교체" 작업

- **시점 교체**: 악역 시점, 조연 시점, 다시점
- **매체 교체**: 책이 게임으로, 꿈이 현실로
- **시대 교체**: 현대 배경이 고대로, 미래가 과거로
- **능력 교체**: 주인공 약화, 적 강화, 규칙 변경

## 5. 창의 맵 시각화

### 5.1 4차원 분류법

**장르별 분류**:
```
현환류:
  - INSP-001: 선협 체계 혁신
  - INSP-005: 이세계 대륙 쟁패

도시류:
  - INSP-002: 회귀 복수
  - INSP-008: 비즈니스 전쟁 권모
```

**혁신도별 분류**:
```
전통형(안정적이나 경쟁 큼):
  - INSP-001: 클래식 선협 레벨업

미세 혁신(위험 적당):
  - INSP-003: 선협 + 현대 기술

전복형(고위험 고수익):
  - INSP-007: 수련 없는 선협 세계
```

**성숙도별 분류**:
```
컨셉급(아이디어만):
  - INSP-004: 시간이 거꾸로 흐르는 세계

초안급(초보적 설정):
  - INSP-006: 주인공이 타인 능력 복제 가능

완성급(완전한 스토리 프레임):
  - INSP-002: 회귀 복수문, 3권 개요 완성
```

**우선순위별 분류**:
```
높은 잠재력(즉시 개발):
  - INSP-002: 시장 잠재력 5점, 개인 적합도 5점

보통 잠재력(다듬기 필요):
  - INSP-005: 독창성 높으나 난이도 큼

낮은 우선순위(임시 보류):
  - INSP-009: 시장이 너무 소수
```

### 5.2 갭 분석

- [ ] 설정만 있고 갈등이 없는가?

**제안**: 갭 발견 후 「창의 조합」 또는 「미세 혁신」으로 보완합니다.

## 6. Top 추천 스크리닝법

### 6.1 스크리닝 기준

종합 평가 공식:
```
총점 = 독창성×2 + 시장 잠재력×3 + 확장성×2 + 개인 적합도×2 - 창작 난이도×1
```

**가중치 설명**:
- 시장 잠재력 가장 중요(×3)
- 독창성, 확장성, 개인 적합도 동등 중요(×2)
- 창작 난이도는 부정적 요인(-×1)

### 6.2 추천 이유 템플릿

```
【추천 #1】INSP-002 - 도시 회귀 복수
우선순위: 1(최고)
이유: 시장 잠재력 높음(대중 장르) + 혁신도 적당(악역 세탁 참신) +
     창작 난이도 통제 가능(도시 배경 다루기 쉬움) + 개인 적합도 높음(도시 생활에 익숙)
다음 단계: 「시장 포지셔닝 분석」 단계 진입, 대상 독자와 플랫폼 전략 명확화
```

## 7. 실전 워크플로

### 단계1: 영감 포착(1-3일)

1. **광범위 수집**: 모든 아이디어 기록, 평가하지 않음
2. **초보 분류**: 영감 유형별 정리
3. **빠른 태깅**: 각 영감에 초보 태그 부착

### 단계2: 심층 발굴(3-5일)

1. **건별 평가**: 5차원 평가법으로 점수 부여
2. **리스크 식별**: 잠재적 창작 난점 목록화
3. **정보 보충**: 영감의 배경과 디테일 보강

### 단계3: 조합 혁신(2-3일)

1. **A+B 조합 시도**: 화학 반응 탐색
2. **A+B+C 탐색**: 차별화 우위 구축
3. **미세 혁신 변형**: 다양한 각도로 영감 재창조

### 단계4: 시각화 정리(1-2일)

1. **창의 맵 구축**: 4차원 분류법으로 정리
2. **갭 분석**: 약점 식별 및 보강
3. **Top 스크리닝**: 개발할 가치가 가장 높은 3-5개 창의 선발

## 8. 자주 묻는 질문과 해결 방안

### Q1: 영감이 너무 많아서 어떤 걸 선택해야 할지 모르겠다면?

**A**: 「종합 평가 공식」으로 정량 평가하고, 고점수 항목을 우선 개발합니다.

### Q2: 영감이 좋은 것 같은데 확장이 안 된다면?

**A**: 「확장성」 차원을 점검하고, A+B 조합으로 새 요소를 도입해 봅니다.

### Q3: 동질화가 심하면 어떻게 혁신할 것인가?

**A**: 「미세 혁신법」(시점 교체/매체 교체/시대 교체)을 사용하여, 익숙한 프레임에서 변형합니다.

### Q4: 영감이 개념만 있고 구체적 설정이 없다면?

**A**: 다음 단계인 「시장 포지셔닝 분석」 또는 「핵심 셀링 포인트 정의」로 진입하여, 대상 독자를 역산하여 설정 수요를 도출합니다.
