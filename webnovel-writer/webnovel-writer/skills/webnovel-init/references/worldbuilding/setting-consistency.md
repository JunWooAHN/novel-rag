# 설정 일관성 점검 가이드 (Setting Consistency Check)

> **핵심 원칙**: 설정은 천마행공할 수 있으나, 논리는 반드시 일관되어야 합니다. 독자는 "마법이 존재한다"는 것은 수용할 수 있지만, "이 세계의 마법이 때되면 되고 안되면 안된다"는 것은 수용할 수 없습니다.

---

## 1. 일관성의 3대 지주

### 물리 법칙 일관성 (Physics Consistency)
세계의 기본 규칙이 확립되면, 임의로 깨뜨릴 수 없습니다.

#### 긍정 사례 ✅
```
설정: 수련자의 비행에는 영력 소모 필요
→ 제100장: 주인공 영력 고갈, 공중에서 추락
→ 논리 일관, 독자 인정
```

#### 부정 사례 ❌
```
설정: 범인은 수련 불가, 영근 각성 필요
→ 제50장: 주인공은 범인인데, 각고의 노력으로 수련 성공
→ 전후 모순, 독자 의문: "그럼 영근이 왜 필요해?"

수정 방안:
방안A: 주인공이 사실은 은성 영근(후기 각성)
방안B: 주인공이 외부 치트 도구 획득(예: 탈영주, 타인 영근 탈취 가능)
```

### 힘 체계 일관성 (Power System Consistency)
등급 압제, 전력 비교가 전후 일관되어야 합니다.

#### 흔한 문제
| 문제 유형 | 사례 | 수정 방안 |
|---------|------|---------|
| **전력 붕괴** | 제10장 "금단 강자 일장으로 성 파괴",<br/>제100장 금단이 집 하나만 부숨 | 새 차원 도입(성에 호성 대진 있음) 또는 전기 과장이었다고 인정(회상 수정) |
| **무한 월경** | 주인공 연기에서 금단 월경, 나중에 연기 10층이 축기도 못이김 | 월경 조건 설정(신병/진법/기습 필요, 상시 불가) |
| **경계 실효** | 경계 높을수록 수명 길다고 설정했는데, 어떤 대물이 만년 살았는데 원영 | 특수 체질/탈사/시간 유속 차이로 설명 |

### 사회 생태 일관성 (Social Ecology Consistency)
세계의 경제, 정치, 문화가 기본 논리에 부합해야 합니다.

#### 일관성 점검 목록
- [ ] **화폐 체계**: 영석/골드의 구매력이 안정적인가?(제10장 단약 1알 1000영석인데, 제50장 같은 단약 10영석이면 안됨)
- [ ] **세력 균형**: 왜 정사 양도가 천년간 공존 가능?(견제 요인 필요, 예: 절세 강자 약속, 공동 적, 자원 상호보완)
- [ ] **인구 비율**: 수사와 범인의 수량 비율이 합리적인가?(모두가 수련 가능하면, 누가 농사?)

## 2. 흔한 논리 허점과 수정

### 허점 1: "악역 지능이 갑자기 하락"
**표현**: 전기 심모원려하던 악역이, 주인공 체면 구기기 시점에 갑자기 멍청해짐.

**수정 방안**:
- **함정 미리 설치**: 악역이 어리석어 보이나 실은 낚시질(역이용).
- **정보 차이**: 악역이 주인공의 돌파/신기 획득을 몰라서 경시.
- **내부 분열**: 악역 세력 내 반역자가 의도적으로 정보 유출.

### 허점 2: "설정이 스토리를 위해 왜곡"
**표현**:
- 설정: 금술 사용 시 수명 연소
- 스토리: 주인공 금술 10번 사용, 부작용 전혀 없음
- 독자: "수명 연소한다더니?"

**수정 방안**:
- **복선 미리 매복**: 주인공이 "불사지체"류 치트 획득, 부작용 면역 가능.
- **후기 빚 갚기**: 수명이 암중에 연소되고 있었으나, 후기 갑자기 위기 폭발(새 스토리 촉발).
- **등가교환**: 금술 사용 후마다 주인공이 치른 대가 명확 전시(예: 머리카락 백발화, 경계 하락).

### 허점 3: "시간선 혼란"
**표현**:
- 제30장: "이 비경은 백년에 한 번 혈월의 밤에만 개방, 지난번은 50년 전"
- 제80장: "50년 전 혈월의 밤, 그 선배가 비경 진입 후 실종"
- 독자: "그럼 이번 혈월은 몇 번째야? 시간이 안 맞잖아!"

**수정 방안**:
- **시간축 문서 수립**: 모든 중대 사건의 시간점 기록(하단 템플릿 참조).
- **통일 기년법**: "수진력 XXX년" 또는 "주인공 15세 그해"를 앵커로 사용.

## 3. 설정 일관성 점검 템플릿

### 세계 법칙 자가점검표
```markdown
## 핵심 법칙 (철률, 위반 불가)
1. **죽음 불가역**: 죽은 이는 부활 불가(단...특수 조건 제외)
2. **경계 압제**: 저경계가 고경계에 상해 불가(단...치트/진법 제외)
3. **에너지 보존**: 힘 사용에 반드시 소모(영력/체력/수명)

## 가변 법칙 (전제 조건 충족 시 깨뜨릴 수 있음)
1. **비행 제한**: 축기 이하 비행 불가
   - 예외: 비주 탑승/고수가 데려감
2. **수명 상한**: 금단 수명 500년
   - 예외: 연수단 복용/특수 체질

## 현재 버전 번호
v1.2(설정 수정 시마다 버전 번호 업데이트, 변경 이유 기록)
```

### 힘 체계 자가점검표
```markdown
## 경계 전력 대조표
| 경계 | 대표적 전적 | 수명 | 영력 총량 |
|------|-----------|------|---------|
| 연기 | 맨손으로 돌 부수기 | 100년 | 100 |
| 축기 | 검으로 비행, 1인이 백인 군대 섬멸 | 200년 | 1,000 |
| 금단 | 일장으로 소읍 파괴, 단시간 지형 변경 가능 | 500년 | 10,000 |
| 원영 | 일국 멸망, 강을 뒤집고 바다를 뒤집음 | 1,000년 | 100,000 |

## 월경 규칙
- **최대 폭**: 주인공 대경계 1개 월경 가능(연기가 축기를 처치)
- **필요 조건**: 신병+진법+기습+상대 경시
- **상시화 불가**: 매번 월경마다 반드시 참혹한 대가(중상/비장의 카드 소모)
```

### 시간축 자가점검표
```markdown
## 메인 시간축
| 사건 | 주인공 나이 | 수진력 연도 | 비고 |
|------|---------|-----------|------|
| 출생 | 0세 | 10050년 | - |
| 영근 각성 | 15세 | 10065년 | 쌍영근, 자질 평범 |
| 종문 입문 | 16세 | 10066년 | 천검종 외문 제자 |
| 시스템 획득 | 17세 | 10067년 | 절벽 추락, 기연 |
| 축기 성공 | 20세 | 10070년 | 소요 3년(동기 최고속) |

## 서브 시간축(악역)
| 사건 | 시간 | 영향 |
|------|------|------|
| 혈신교 수립 | 5000년 전 | 정마대전 발발 |
| 전임 혈신교주 실종 | 100년 전 | 현재 교주 즉위(실력 미회복) |
| 혈신교 혈신 부활 음모 | 현재 | 메인 스토리 충돌 원인 |
```

## 4. 동적 유지: 설정집 파일 구조

`/webnovel-init`에서 생성된 프로젝트에 다음 파일이 포함되어야 합니다:

```
设定集/
├── 세계관설정.md        # 물리 법칙, 지리, 역사
├── 힘체계설정.md        # 경계, 공법, 전력 대조표
├── 세력설정.md          # 각 대종문/가문/세력 관계
├── 인물카드/           # 각 중요 캐릭터 별도 파일
│   ├── 주인공-임천.md
│   ├── 악역-엽양신.md
│   └── 사존-운선자.md
├── 시간축.md            # 메인+서브 시간축
└── 설정변경일지.md      # 매번 설정 수정 이유 기록
```

### 설정 변경 일지 템플릿
```markdown
## v1.0 → v1.1 변경 기록
**일자**: 2025-01-01
**변경 내용**:
- 수정: 금단 수명 300년에서 500년으로 변경
- 이유: 제50장 "그 금단 선배가 400년을 살았다"는 서술과 충돌
- 영향 범위: 전 30장 모든 금단 수명 관련 서술 재점검 필요

## v1.1 → v1.2 변경 기록
**일자**: 2025-01-10
**변경 내용**:
- 신규: "법칙 감오" 차원 도입
- 이유: 후기 수치 팽창 방지(영력 총량만으로 승부를 계속 낼 수 없음)
- 영향 범위: 원영기부터 법칙 감오가 새로운 전력 차원이 됨
```

## 5. 실시간 점검 워크플로(집필 중 사용)

### 새 장 집필 전마다
1. **설정집 검토**: 이번 장에 관련된 설정(경계/세력/시간) 확인
2. **이전 장 검색**: 키워드로 이전에 비슷한 설정을 썼는지 검색
3. **모순점 표시**: 전후 모순 발견 시 즉시 `설정변경일지.md`에 기록

### 대형 스토리 완료 후마다
1. **시간축 업데이트**: 스토리 발생 시간점 기록
2. **전력표 업데이트**: 새 경계/새 강자 등장 시 대조표에 보충
3. **부작용 점검**: 주인공이 사용한 금술/치트의 후속 대가 전시 여부

## 🛠️ 일관성 점검 목록

`/webnovel-write`에서 장 생성 후, 반드시 다음 점검 통과:
- [ ] **경계 전력**: 이번 장 전투 장면이 힘 체계 설정에 부합?
- [ ] **시간 논리**: 사건 발생 시간이 이전과 모순 없음?
- [ ] **인물 설정**: 캐릭터 행동이 성격/입장에 부합?
- [ ] **도구 제한**: 신기/단약/법보 사용이 설정 범위 초과하지 않음?
- [ ] **세력 관계**: 이번 장 관련 세력 상호작용이 기존 관계망에 부합?

## 부록: 흔한 독자 의문 사례 라이브러리

### 사례 1: "왜 주인공은 XXX 방법을 안 써?"
- **문제**: 주인공에게 분명 더 간단한 해결 방안이 있는데, 복잡한 경로를 고집.
- **원인**: 작가가 주인공이 이전에 획득한 능력/도구를 잊음.
- **예방**: "주인공 현재 능력 목록"을 유지하고, 매번 집필 전 열람.

### 사례 2: "이 악역이 어떻게 다시 살아났어?"
- **문제**: 분명 죽였던 악역이 합리적 설명 없이 다시 등장.
- **원인**: 악역이 계속 스토리를 추동하길 원했으나 미리 복선 안깔음.
- **수정**: 보충 설명(분신/가사/누군가 구함), 설정집에 "메울 구덩이" 표시.

### 사례 3: "이 세계의 경제가 붕괴했어"
- **문제**: 영석 구매력이 전후로 백배 차이.
- **원인**: 화폐 앵커물 미설정(예: 영미 1근=영석 10개).
- **예방**: "물가 참고표" 설정, 핵심 상품 가격 고정.
