# 힘 체계 설계 가이드 (Power Systems)

> **핵심 원칙**: 힘 체계는 단순한 레벨업 사다리가 아니라, 스토리 리듬을 통제하는 밸브입니다. 좋은 체계는 독자가 "강해짐"을 명확히 느끼게 하면서, 후기 수치 붕괴를 방지합니다.

---

## 1. 3층 구축법

### 기초 규칙층
| 요소 | 설명 |
|------|------|
| 힘 체계 | 출처/등급/제한/대가 |
| 물리 법칙 | 현실과의 차이점 |
| 핵심 갈등 | 세계 운영의 기저 충돌 |
| 자원 분포 | 희소 자원 및 그 영향 |

### 사회 구조층
| 요소 | 설명 |
|------|------|
| 세력 구도 | 주요 세력/관계/충돌 |
| 계층 구분 | 상승 통로/고착 정도 |
| 권력 구조 | 누가 집권/어떻게 운영 |
| 경제 체계 | 화폐/무역/자원 |

### 문화 디테일층
| 요소 | 설명 |
|------|------|

| 풍속 금기 | 절기/의식/금기 |
| 가치 관념 | 무엇을 숭상/무엇을 경멸 |
| 일상 생활 | 의식주행 디테일 |

## 2. 등급 체계 구축 (Leveling)

### 표준 계단 모델
명확한 등급 설정, 각 급 간 뚜렷한 실력 격차.
- **대경계**: 질적 변화(예: 연기 → 축기, 범인 → 수사).
  - **격차 묘사**: "축기 이하는 모두 개미", "금단 강자 공포 여하"
- **소경계**: 양적 변화(예: 초기 → 중기 → 후기 → 원만).
  - **격차 묘사**: "영력이 더욱 심후", "큰 기술 2개 더 발사 가능"

### 명명 규범
- **선협**: 연기, 축기, 금단, 원영, 화신...
- **이능**: F급, E급, D급... S급, SS급, SSS급.
- **현환**: 투자, 투사, 대투사... / 반혈, 동천, 화령...
- **서양 판타지**: 학도, 정식 법사, 대마법사, 마도사, 전설, 반신.

## 2. 전력 균형과 팽창 통제

### 월경 도전 원칙 (The Underdog Rule)
주인공은 반드시 월경 가능하나 무한 월경은 불가.
- **합리적 월경**: 연기 9층이 축기 초기를 격파(대경계 문턱 1개 넘기).
  - **이유**: 극품 공법 + 절세 신병 + 기습 + 상대 경시.
- **비합리적 월경**: 연기 3층이 원영 노괴를 격파.
  - **결과**: 전력 체계 즉시 붕괴, 독자 이탈.

### 수치 팽창 통제 밸브 (Inflation Control)
- **맵 교체 (Map Reset)**: 초보자 마을에서 패자가 된 후, 대맵에 진입하면 자신이 하위임을 발견.
  - *예시*: "천남성에서 나는 제일 천재였는데, 중주 성지에 오니 겨우 내문 제자 수준."
- **새 차원 (New Dimension)**: 새로운 힘의 매개변수 도입.
  - *예시*: 전기는 영력 총량 경쟁, 후기는 법칙 감오/영혼 강도/영역 장악 경쟁.

## 3. 스킬과 공법 체계

### 스킬 트리 설계
- **기본기**: 평타, 쿨타임 짧음, 소모 적음.
- **폭발기**: 궁극기, 쿨타임 긴, 소모 큼, "비장의 카드"이기도 함.
- **패시브**: 상시 버프(예: 회복 속도+100%, 화속성 면역).
- **금술**: 위력 거대하나 심각한 부작용(예: 수명 연소로 10배 전력 교환).

### 공법 등급
- **천지현황 / SABC**: 간단명료, 독자 인지 비용 낮음.
- **유일성**: 주인공은 반드시 전 작품 유일하거나 오래 전 실전된 최고 공법 수련.

## 4. 힘 체계 템플릿 (Reference)

### 템플릿 A: 전통 선협
```
연기 (1-9층): 기를 체내로 이끌어 몸 강화
축기 (초중후): 도기 구축, 수원 200년
금단 (1-9전): 금단 응결, 공중 비행
원영: 단 부수어 영 생성, 육체 손괴 시 탈사 가능
화신: 천지 법칙 영오, 초보적 공간 장악
연허: 태허 유영
합체: 몸이 만천으로 화함
대승: 겁 넘어 비승
```

### 템플릿 B: 고무/이능
```
1품/2품/3품 (무도): 피육골 단련
4품/5품/6품 (무사): 내경/강기 연출
7품 (종사): 정신력 외방, 종사 모욕 불가
8품 (대종사): 금신 응련
9품 (무성): 국운 진압
절정: 인류 수호신
```

### 템플릿 C: 신비/서열 (마약 체계)
```
서열 9 (시작): 미약한 초범 능력 획득
...
서열 5 (질변): 신성 획득
...
서열 0 (진신): 권병 장악
*특징*: 승진에 역할 연기법 + 마약 필요, 실패 리스크 있음.
```

## 7. 시스템류 설계 (System-based Power)

### 시스템 패널 설계
```
능력치 패널 + 스킬 트리 + 임무 시스템 + 상점/가챠
```

### 능력치 설계
| 능력치 | 설명 |
|------|------|
| 기본 능력치 | 힘/민첩/지능 등 |
| 전투 능력치 | 공격/방어/속도 등 |
| 특수 능력치 | 행운/매력/오성 등 |
| 숨겨진 능력치 | 기운/인과 등 |

### 스킬 트리 설계
- **액티브 스킬**: 능동 발동 필요
- **패시브 스킬**: 자동 발효
- **천부 스킬**: 고유 능력
- **상위 스킬**: 상급 해금

### 임무 시스템
| 임무 유형 | 설명 |
|----------|------|
| 메인 임무 | 스토리 추동 |
| 서브 임무 | 콘텐츠 보강 |
| 일일 임무 | 안정 수익 |
| 히든 임무 | 예상치 못한 보너스 |

### 보상 메커니즘
- 경험치/능력치 포인트
- 스킬/장비
- 골드/자원
- 특수 도구
