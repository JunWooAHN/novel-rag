# 세력 체계 설계 가이드 (Faction Systems)

> **핵심 원칙**: 세력은 배경판이 아니라 스토리의 추동기입니다. 좋은 세력 설계는 주인공의 모든 선택을 극적 긴장감으로 가득 채울 수 있습니다.

---

## 1. 세력 계층 구조 (Hierarchy)

### 피라미드 모델
```
최상위 세력 (1-3개)
  ↓ 통제/영향
중간 세력 (5-10개)
  ↓ 의존/대항
하위 세력 (수십 개)
  ↓ 자원 쟁탈
산수/평민 (무수)
```

### 최상위 세력 (Top-Tier)
- **정의**: 세계 규칙의 제정권 장악(예: 수련계의 6대 성지)
- **특징**:
  - 최강 전력 보유(최소 한 명의 정상급 강자 주둔)
  - 핵심 자원 통제(예: 유일한 전송진, 최대 영맥)
  - 역사 유구(천년 이상 전승)
- **주인공과의 관계**: 초기 우러러봄 → 중기 접촉 → 후기 견제/대체

### 중간 세력 (Mid-Tier)
- **정의**: 지역 패주(예: 한 성, 한 나라의 통치자)
- **특징**:
  - 최상위 세력의 틈새에서 생존
  - 내부 파벌 난립, 정치 투쟁 치열
  - 하위 세력에 절대적 발언권
- **주인공과의 관계**: 초기 보호소 → 중기 발판 → 후기 주인공에게 초월됨

### 하위 세력 (Low-Tier)
- **정의**: 가문, 방파, 소종문
- **특징**:
  - 자원 부족, 언제든 멸망 가능
  - 중간 세력에 의존하여 보호 획득
  - 주인공의 초보자 마을
- **주인공과의 관계**: 출발점 → 빠르게 초월 → 귀환 시 압도

## 2. 세력 관계망 (Relationship Network)

### 4대 관계 유형

#### A. 세습적 원한 (Blood Feud)
- **원인**: 역사적 원한(예: 성지 쟁탈, 멸족의 한)
- **특징**: 만나면 반드시 싸움, 죽지 않으면 안됨
- **스토리 역할**: 주인공이 한쪽 가입 시 자동으로 다른 쪽과 적대

#### B. 이익 동맹 (Alliance)
- **원인**: 공동 이익(예: 수파 대항, 비경 개발)
- **특징**: 겉으로는 화목, 뒤에서는 암투
- **스토리 역할**: 협력 임무 중 각 측의 본모습 노출, 새 갈등 발생

#### C. 부용 관계 (Vassal)
- **원인**: 실력 격차 현격, 약자가 강자에 의존
- **특징**: 강자가 보호 제공, 약자가 자원 상납
- **스토리 역할**: 주인공 소속 세력이 억압당해 반항 스토리 촉발

#### D. 중립 경쟁 (Neutral Competition)
- **원인**: 깊은 원한 없으나 같은 자원 쟁탈
- **특징**: 우물물 강물 범하지 않으나 이익 충돌 시 별개
- **스토리 역할**: 무술대회 구혼, 경매 입찰, 비경 보물 쟁탈

## 3. 세력 설계 템플릿 (Templates)

### 템플릿 1: 종문/학원
```markdown
**명칭**: 천검종
**유형**: 검수 종문(최상위 세력)
**핵심 자원**:
  - 조사가 남긴 검총(백 자루 신검 보유)
  - 극품 검영맥 하나 장악
**대표 공법**: 《만검귀종결》
**세력 등급**: S급(6대 성지 중 하나)
**내부 구조**:
  - 종주 일파(실용파)
  - 대장로 일파(수구파)
  - 검각 장로(중립파)
**외교 전략**:
  - 천운종과 대대로 혼인
  - 마도 세력과 불사불휴
  - 중립 상회에 우호 유지
**주인공 포지션**: 외문 제자 → 친전 제자 → 종주 계승
```

### 템플릿 2: 가문/혈맥
```markdown
**명칭**: 엽가
**유형**: 수선 세가(중간 세력)
**핵심 자원**:
  - 조전 혈맥(화속성 천부)
  - 3개 성지의 세수
**대표 공법**: 《분천결》
**세력 등급**: A급(지방 호문)
**내부 구조**:
  - 적계(순혈) vs 방계(잡혈)
  - 장방, 이방, 삼방의 권력 투쟁
**외교 전략**:
  - 천검종에 의존
  - 다른 가문과 연합하여 조정에 대항
**주인공 포지션**: 가문 추방 → 영광스러운 귀환으로 체면 구기기
```

### 템플릿 3: 악역 조직
```markdown
**명칭**: 혈신교
**유형**: 마도 사교(최상위 악역)
**핵심 자원**:
  - 금기의 혈제지법
  - 사령의 땅 하나 장악
**대표 공법**: 《혈신경》
**세력 등급**: S급(마도 3대 세력 중 수장)
**내부 구조**:
  - 교주(반미치광이 상태, 실력 공포)
  - 4대 호법(각자 딴마음)
  - 무수한 광신도
**외교 전략**:
  - 정도 세력과 불사불휴
  - 암중에 꼭두각시 왕조 지원
**주인공 포지션**: 숙적(주인공 가족 전원을 죽인 범인)
```

## 4. 세력 스토리 엔진 (Plot Drivers)

### 내부 갈등(주인공 부상 추동)
1. **권력 투쟁**: 주인공이 파벌 다툼에 휘말려 편 들기 강요.
2. **자원 배분**: 핵심 자원(영맥, 전승 등) 쟁탈.
3. **반역자/내통자**: 세력 내부에 외적과 내통하는 자.

### 외부 충돌(위기 조성)
1. **멸문 위기**: 적대 세력 갑작스러운 공격, 주인공 배수진 강요.
2. **자원 쟁탈**: 비경 개방, 각 대세력 혼전.
3. **동맹 와해**: 원래 동맹이 이익 배분 불균으로 반목.

## 5. 세력 부상 스토리라인 (Rise to Power)

주인공이 제로에서 시작하여 자체 세력 수립(쾌감문 적합).

### 단계 1: 초창기
- **원인**: 주인공이 원래 세력에 배신/추방당하거나, 버려진 종문 유적 발견.
- **초기 멤버**: 3-5인 소대(단짝, 은인, 구한 약자).
- **첫 밑천**: 소형 자원 포인트 쟁취(예: 광맥, 약원).

### 단계 2: 확장기
- **병력 모집**: 산수 수복, 소가문 흡수.
- **명성 구축**: 강적 격파, 약자 구조, 구세력 공개 도전.
- **영토 점령**: 한 성에서 한 지역으로 확장.

### 단계 3: 쟁패기
- **제도 구축**: 공법고, 연단방, 장서각 설립.
- **외교 수단**: 다른 중간 세력과 동맹, 적대 세력 고립.
- **충신 양성**: 심복 발탁, 핵심 서클 형성.

### 단계 4: 패주기
- **최상위 도전**: 원래 6대 성지 격파 또는 수복.
- **새 규칙 제정**: 세계 운영 방식 변경(예: 노예제 폐지, 전승 개방).
