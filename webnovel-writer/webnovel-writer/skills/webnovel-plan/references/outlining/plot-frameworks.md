## 1. 범용 줄거리 프레임워크

### 프레임워크 A: 영웅의 여정 (Hero's Journey)
**적합**: 90%의 웹소설에 적용 가능

#### 12개 단계
```
1. 평범한 세계: 주인공은 평범한 사람/폐물
2. 모험의 부름: 위기 조우 (파혼/친인 살해/세계 멸망)
3. 부름 거부: 주인공이 처음엔 관여하고 싶지 않음 (나는 그냥 조용히 수련하고 싶다)
4. 스승과의 만남: 금수저/사존의 지도 획득
5. 첫 번째 관문 통과: 종문 가입/수선계 진입
6. 시련과 동맹: 절친, 여주를 만나고 소규모 전투 경험
7. 동굴 깊숙이: 위험 지역 진입 (비경/적대 세력)
8. 고난의 시련: 최대 위기 조우 (사존 살해/모함당함)
9. 보상: 신기 획득/깨달음/경지 돌파
10. 귀환의 길: 성과를 가지고 복귀
11. 부활: 불로 다시 태어나 실력 대폭 상승
12. 영약을 가지고 귀환: 전설이 되어 세계를 바꿈
```

#### 웹소설 간소화 버전 (3막 구조)
```
1막 (전반 30%): 세계관 구축, 주인공 위기 조우
2막 (중간 40%): 주인공 성장, 다수 시련, 실력 축적
3막 (후반 30%): 최종 결전, 대보스 격파
```

## 2. 웹소설 전용 프레임워크

### 프레임워크 B: 면박 쾌감문 프레임워크
**공식**: 조롱당함 → 인내 → 폭발 → 면박 → 순환

#### 표준 흐름
```markdown
Step 1: 낙차 설정
- 주인공은 한때 천재/호문 도련님
- 어떤 이유로 추락 (영근 폐지/가문 멸문)

Step 2: 첫 번째 조롱
- 한때의 약혼녀가 파혼
- 대사: "너 같은 폐물이, 나에게 어울리지 않아!"

Step 3: 인내 단계
- 주인공이 겉으로 참고 견딤
- 내면: "삼십년 하동, 삼십년 하서, 소년을 무시하지 마라!"
- 은밀히 노력 (금수저 획득/고수련)

Step 4: 소규모 면박
- 어떤 작은 자리에서 실력 과시 (예: 종문 시험 1등)
- 면박 대상: 한때 그를 조롱했던 단역
- 독자: "통쾌!"

Step 5: 대규모 면박
- 중요한 자리에서 (종문 대비/가문 회의) 적을 압도
- 면박 대상: 한때의 약혼녀/적대 가문 소주
- 독자: "통쾌통쾌!"

Step 6: 다음 순환 진입
- 더 큰 맵으로 이동 (초보 마을에서 주성으로)
- 더 강한 조롱자 등장 (가문 소주에서 종문 천재로)
```

#### 면박 리듬 조절
- **빈도**: 10~20장마다 최소 1회 소면박
- **점증**: 면박의 쾌감이 점점 업그레이드 (구두 면박→실력 면박→압도식 면박)
- **반복 방지**: 항상 "약혼녀 파혼" 하나만 반복하면 안 됨

### 프레임워크 C: 폐물 역전 프레임워크
**공식**: 폐물 → 기연 → 역전 → 패권

```markdown
## 1단계: 폐물기 (1-50장)
- 주인공은 공인된 폐물 (영근 없음/재능 부족/신체 장애)
- 괴롭힘, 조롱, 버림받음
- **핵심**: 반드시 독자가 주인공에게 동정심을 느끼게 해야 함

## 2단계: 기연기 (51-100장)
- 절벽에서 떨어짐/비경 진입/전승 획득
- 금수저 획득 (시스템/신기/공법)
- 역전 시작

## 3단계: 굴기기 (101-500장)
- 초보 마을에서 패권
- 더 큰 무대로 진입 (종문/성지)
- 한때 무시했던 사람들을 계속 면박

## 4단계: 패권기 (501장+)
- 정상급 강자가 됨
- 세계 규칙을 바꿈
- 속편 연결 인터페이스 (비승/더 높은 위면으로)
```

---

### 프레임워크 D: 저자세 반전 프레임워크
**공식**: 강자 → 실력 은폐 → 과소평가당함 → 폭발 → 충격

```markdown
## 설정
- 주인공은 실제로 매우 강함 (환생/탈사/진신 봉인)
- 하지만 저자세를 선택 (구도/말썽 피하려 함)

## 줄거리 추진
1. 주인공이 일부러 평범하게 행동
2. 악역/단역이 그래서 그를 무시
3. 주인공이 어쩔 수 없이 출수
4. 일격필살, 전장 경악
5. 주인공: "나는 그냥 조용히 하고 싶었는데, 왜 나를 밀어붙이는 거야?"

## 독자 쾌감 포인트
- "허세가 벼락 맞음"의 역방향 활용
- 주인공이 분명 강한데 약한 놈 취급당함 (반전 매력)
- 폭발 시의 충격감
```

## 3. 장르별 줄거리 프레임워크

### 수선류 프레임워크
```
연기기 (1-100장): 초보 마을, 기초 설정 구축
축기기 (101-200장): 종문 가입, 자리 잡기
금단기 (201-400장): 비경 보물 쟁탈, 기연 획득
원영기 (401-600장): 종문 위기, 구세주가 됨
화신기 (601-800장): 영역 간 모험, 더 강한 적과 대면
비승 (801장+): 선계로 비승, 속편 시작
```

### 도시 이능류 프레임워크
```
각성기 (1-50장): 이능 획득, 능력 적응
성장기 (51-200장): 이능자 서클에서 두각
쟁패기 (201-500장): 이능자 대전/국제 대회 참여
정상기 (501장+): 최강 이능자가 되어 지구 수호
```

### 게임 경쟁류 프레임워크
```
초보기 (1-100장): 게임 진입, 메커니즘 숙지
레벨업기 (101-300장): 던전 돌기, 장비 파밍, 길드 설립
경쟁기 (301-600장): 리그/세계대회 참가
정상기 (601장+): e스포츠 레전드가 됨/게임과 현실 융합
```

## 4. 줄거리 추진의 만능 엔진

### 엔진 1: 시간 제한
- **3년의 약속**: "3년 후, 내가 직접 찾아가 청혼하겠다!"
- **카운트다운**: "비경이 7일 후 폐쇄"/"혈월이 3일 후 강림"
- **작용**: 긴박감 조성, 줄거리 늘어짐 방지

### 엔진 2: 공간 이동
- **맵 전환**: 초보 마을→주성→성지→선계
- **작용**: 전력 등급 리셋, 팽창 방지; 새로운 캐릭터, 새로운 세력 도입

### 엔진 3: 외부 위협
- **수조 습격**: 정사 양도의 강제 연합
- **이족 침입**: 공동의 적 제공
- **작용**: 대사건 조성, 줄거리 클라이맥스 추진

### 엔진 4: 사람/물건 찾기
- **여동생 구출**: 주인공의 핵심 동기
- **일곱 개의 드래곤볼 모으기**: 수집류 줄거리
- **작용**: 명확한 단계별 목표 제공

## 5. 줄거리 프레임워크 조합

단일 프레임워크는 단조로워지기 쉬우므로 조합하여 사용 가능:

### 조합 사례 1: 폐물 역전 + 면박 쾌감문
```
1-50장: 폐물이 파혼당함 (면박 프레임워크 오프닝)
51-100장: 시스템 획득 (폐물 역전 프레임워크의 기연)
101-200장: 전 약혼녀 면박 (면박 프레임워크의 첫 클라이맥스)
201-500장: 계속 역전하며 더 강한 자를 면박 (조합 순환)
```

### 조합 사례 2: 영웅의 여정 + 저자세 반전
```
1-50장: 주인공이 소년 시절로 환생 (영웅의 여정의 "부름")
51-100장: 일부러 실력 은폐 (저자세 반전)
101-200장: 어쩔 수 없이 출수, 전장 경악 (저자세 반전의 폭발)
201장+: 영웅의 여정의 "시련→시험→귀환"으로 추진
```

## 프레임워크 선택 가이드

### 선택 기준
| 독자층 | 추천 프레임워크 | 이유 |
|---------|---------|------|
| **입문 독자** | 폐물 역전 + 면박 쾌감문 | 쾌감이 직접적이고 몰입감이 강함 |
| **경험 많은 독자** | 영웅의 여정 + 저자세 반전 | 깊이 있고, 반클리셰 |
| **여성 독자** | 궁투/연예계 경쟁 프레임워크 | 독서 습관에 부합 |
| **유료 독자** | 수선/도시 이능 프레임워크 | 장기 연재, 늘리기 용이 |

### 프레임워크 점검 목록
- [ ] **명확한 3막 구조가 있는가?** (시작/중간/결말)
- [ ] **단계별 목표가 있는가?** (독자가 "다음에 뭘 할지" 알 수 있도록)
- [ ] **리듬 변화가 있는가?** (클라이맥스와 전환이 교대, 계속 긴장하거나 계속 평이할 수 없음)
- [ ] **장르 특성에 맞는가?** (수선문은 비승이 있어야, 도시문은 허세 면박이 있어야)

## 부록: 프레임워크 속찰표

### 빠른 적용 템플릿
```markdown
## 나의 소설 프레임워크 선택
**유형**: 수선문
**주 프레임워크**: 폐물 역전 (신규 독자 유치)
**보조 프레임워크**: 면박 쾌감문 (쾌감 강화)
**줄거리 엔진**: 여동생 구출 (핵심 동기) + 3년의 약속 (시간 제한)

## 분권 기획
1권: 폐물기 (파혼당하고 시스템 획득)
2권: 역전기 (종문 대비, 전 약혼녀 면박)
3권: 구출기 (단서 추적, 악역과 첫 대결)
4권: 최종 결전 (혈신교주 격파, 여동생 구출)
5권: 비승 (전설이 되어 선계로 비승)
```

이 템플릿을 사용하면 구조가 완전한 웹소설 프레임워크를 빠르게 구축할 수 있다.
