# 개요 구조 설계 가이드 (Outline Structure)

> 아카이브 설명: 본 파일은 과거 방법론 참고 자료이며, `/webnovel-plan` 주 프로세스에서 자동 로드되지 않습니다.
> 연동이 필요하면, 반드시 `SKILL.md`에 명확한 단계 트리거 조건과 읽기 지시를 추가해야 합니다.

> **핵심 원칙**: 개요는 지도이지, 족쇄가 아니다. 좋은 개요는 방향을 안내하면서도, 영감을 위한 여백을 남겨야 한다.

## 1. 개요의 3층 구조

### 제1층: 골격 개요 (필수, 30%)
**목적**: 이야기에 명확한 기승전결이 있도록 보장.

```markdown
## 골격 개요 예시
**서장 (1-50화)**: 폐물 소년 임천이 파혼당하고, 기연으로 흡수 시스템 획득
**전반부 (51-200화)**: 종문에서 부상, 한때 조롱하던 자들 체면 깎기, 여동생이 납치당한 것을 발견
**중반부 (201-500화)**: 여동생을 구하기 위해 수선계 진출, 각 대세력과 교전, 실력 급상승
**후반부 (501-800화)**: 신세의 비밀 해명, 알고 보니 상고 대능의 환생, 최종 대결 혈신교주
**결말 (801-850화)**: 혈신 격파, 여동생 구출, 선계 비승 (속편 인터페이스 유지)
```

**골격 개요 체크리스트**:
- [ ] **기점 명확**: 주인공의 초기 상태와 핵심 모순은 무엇인가?
- [ ] **전환점**: 최소 3개의 중대한 스토리 전환 (예: 골든핑거 획득, 종문 가입, 사존 살해)
- [ ] **종점 명확**: 이야기의 최종 목표 (마왕 격파/비승/패권)

### 제2층: 분권 개요 (권장, 50%)
**목적**: 장편을 여러 작은 클라이맥스로 분할하여, 독자 피로 방지.

#### 분권 원칙
- **각 권 하나의 소목표**: 예를 들어 제1권 "초보 마을 성장", 제2권 "종문 시련"
- **권 말에 반드시 클라이맥스**: 소보스 격파, 신기 획득, 경지 돌파
- **권과 권 사이 과도**: 갑자기 맵 전환 금지, 복선 필요

#### 분권 개요 템플릿
```markdown
## 제1권: 부상의 길 (1-150화)
**핵심 목표**: 폐물에서 천재로의 역전
**주요 충돌**: 가문 내부 투쟁, 파혼 사건, 종문 선발
**클라이맥스**: 종문 대비 1위 차지, 엽량진 체면 깎기
**복선**: 주인공 신세가 범상치 않음을 암시, 후속 "상고 혈맥" 단서 매설

## 제2권: 종문 풍운 (151-300화)
**핵심 목표**: 천검종에서 자리 잡기
**주요 충돌**: 내문 제자 배척, 장로 파벌 투쟁, 비경 쟁탈
**클라이맥스**: 비경에서 검총 전승 획득, 실력 폭증
**복선**: 여동생이 혈신교에 납치된 단서 발견

## 제3권: 구원의 여정 (301-500화)
**핵심 목표**: 혈신교 추적, 여동생 구출
**주요 충돌**: 혈신교와의 여러 차례 교전, 정사 양도의 오해, 능력 부족의 초조
**클라이맥스**: 단신으로 혈신교 총단 돌입, 교주와 첫 교전 (패배하지만 생존)
**복선**: 여동생이 특수 체질을 지녔으며, 혈신 부활의 핵심임을 알게 됨
```

### 제3층: 챕터 개요 (선택, 20%)
**목적**: 각 챕터의 구체적 내용까지 세분화, 초보자나 막힘 시 활용.

#### 챕터 개요 템플릿
```markdown
## 제1화: 파혼의 치욕
**글자 수**: 3000자
**주선 스토리**:
  - 엽가 소주 엽량진이 방문하여 파혼
  - 임천이 모욕당하고, 온 가문이 수치
  - 임천이 분노하지만 반항할 힘이 없음 (폐물 상태 표현)
**부선 스토리**:
  - 아버지 탄식, 여동생 위로
  - 복선 매설: 임천 손의 옥패가 미세하게 빛남
**쾌감포인트**: 없음 (억압 챕터, 후속 체면 깎기를 위한 축적)
**결말 훅**: "바로 그때, 임천의 뇌리에 갑자기 기계적 목소리가 울렸다: '흡수 시스템 활성화……'"
```

**챕터 개요의 유연성**:
- 핵심 내용만 작성, 구체적 대화와 세부 사항은 집필 시 발휘
- 영감이 폭발하면 개요에서 벗어날 수 있음 (단, 돌아와서 개요 수정 필요)

## 2. 개요의 상세 정도 선택

### 대략적 개요 스타일 (경험자 적합)
- **내용**: 골격 개요 + 분권 개요만 작성
- **장점**: 집필 자유도 높음, 수시로 조정 가능
- **단점**: 방향 이탈이나 막힘 쉬움

### 세밀한 개요 스타일 (초보자 적합)
- **내용**: 골격 + 분권 + 챕터 개요 (최소 앞 50화)
- **장점**: 집필 시 방황 없이, 매일 무엇을 쓸지 파악
- **단점**: 초기 준비 시간이 길음

### 혼합 스타일 (추천)
- **내용**: 골격 개요 (전체) + 분권 개요 (전체) + 챕터 개요 (향후 10-20화)
- **장점**: 방향감도 있고, 유연성도 유지
- **방법**: 한 권 완성할 때마다 다음 권의 챕터 개요 보충

## 3. 개요의 동적 조정

### 언제 개요를 조정해야 하는가?
1. **독자 피드백**: 특정 캐릭터/스토리가 특히 인기 있으면, 비중 증가 가능
2. **영감 폭발**: 갑자기 더 좋은 스토리 방향이 떠오름
3. **데이터 이상**: 특정 챕터의 구독/즐겨찾기가 급락하면, 스토리에 문제가 있다는 뜻

### 개요 조정 방법
```markdown
## 개요 변경 로그
**날짜**: 2025-01-03
**변경 내용**: 원래 제2권에서 여동생 사망 (칼날) 계획이었으나, 독자 피드백으로 여동생 인기가 너무 높음
**새 방안**: "여동생 납치"로 변경, 제3권에서 생사 공개 (서스펜스 연장)
**영향 범위**: 제2권 클라이맥스 재설계 필요, "검총 전승 획득"으로 변경
```

### 개요 조정의 레드라인 (절대 불가)
- **주인공 캐릭터 설정**: 갑자기 선인에서 악인으로 (또는 반대로) 변경 불가, 충분한 복선 없이는
- **능력체계**: 경지 설정을 임의로 변경 불가, 그렇지 않으면 이전 내용의 전투력 비교가 전부 붕괴
- **핵심 주선**: 지선은 조정 가능하지만, "여동생 구출"과 같은 핵심 목표는 쉽게 포기 불가

## 4. 개요 도구 추천

### 도구 A: Markdown + Git
```
outline/
├── master.md
├── volumes/
│   ├── vol_1.md
│   ├── vol_2.md
│   └── vol_3.md
├── chapters/
│   ├── 001-050.md
│   └── 051-100.md
└── changelog.md
```
**장점**: 순수 텍스트, 버전 관리와 검색이 용이

### 도구 B: 마인드맵 (XMind/MindNode)
```
주선: 여동생 구출
├── 제1권: 초보 마을 부상
│   ├── 1-10화: 파혼 사건
│   ├── 11-30화: 시스템 획득
│   └── 31-50화: 종문 선발
├── 제2권: 종문 풍운
│   └── ...
```
**장점**: 시각화 강함, 계층 관계 명확

|------|---------|---------|------|------|------|

**장점**: 데이터화 관리에 적합, 쾌감포인트 밀도 통계에 편리

## 5. 개요와 설정집의 연동

개요는 단독이 아니며, 반드시 설정집과 연계해야 한다:

### 체크리스트
- [ ] **인물 카드**: 모든 중요 캐릭터 등장 전, 설정집에 인물 카드가 만들어져 있는가?
- [ ] **세력 관계**: 세력 충돌 관련 시, 설정집의 세력 관계도에 부합하는가?
- [ ] **능력체계**: 주인공의 경지 상승이 능력체계 설정의 리듬을 따르는가?
- [ ] **타임라인**: 각 권의 시간 범위가 합리적인가? (갑자기 10년 도약 금지)

### 예시: 개요와 설정집의 충돌
```markdown
## 문제
개요: 제50화에서 주인공이 금단기로 돌파
설정집: 주인공 16세, 정상 수련 속도로 20년 걸려야 금단
충돌: 타임라인 불합리

## 해결 방안
방안A: 개요 조정, 축기기로 변경
방안B: 설정집에 "흡수 시스템으로 수련 100배 가속 가능" 보충
방안C: 기연 스토리 추가 (만년 영과 복용)
```

## 개요 자가점검 체크리스트

집필 시작 전, 이 체크리스트로 개요의 적격 여부를 확인:
- [ ] **완전성**: 도입, 중간, 결말이 모두 있는가?
- [ ] **리듬**: 명확한 클라이맥스와 저점의 교차가 있는가? (계속 클라이맥스이거나 계속 평탄하면 안 됨)
- [ ] **논리**: 스토리 진행이 합리적인가? (캐릭터가 갑자기 바보가 되는 것에 의존하면 안 됨)
- [ ] **쾌감포인트**: 매 10-20화마다 최소 1개 쾌감포인트가 있는가?
- [ ] **복선**: 뿌린 떡밥에 회수 계획이 있는가? (몇 화에서 회수하는지 표기)
- [ ] **글자 수**: 예상 총 글자 수가 플랫폼 요구에 부합하는가? (기점 최소 100만 자)

## 부록: 고전 개요 사례 분석

### 사례 1: 《범인수선전》 개요 특징
- **골격**: 평범한 소년 수선 → 선계 대능이 됨 (초장편, 800만 자)
- **분권**: "맵"으로 구분 (인계→영계→선계), 맵 전환 시마다 실력 초기화 재시작
- **리듬**: 각 소경계마다 독립적인 소클라이맥스 (법보 획득/적 격파)

### 사례 2: 《투파창궁》 개요 특징
- **골격**: 천재 소년 몰락 → 부상 복수 → 투제가 됨
- **분권**: "실력 등급"으로 구분 (투자→투왕→투성), 각 대경계 하나의 권
- **리듬**: "3년 약속" 같은 명확한 시간 절점, 긴박감 조성
