# 갈등 설계 가이드 (Conflict Design)

> **핵심 원칙**: 갈등 없이는 이야기가 없다. 갈등은 줄거리의 엔진이며, 쾌감 포인트의 원천이다.

---

## 1. 갈등의 3대 층위

### 층위 1: 외부 갈등 (인물 vs 인물/세력/환경)
**정의**: 주인공과 외부 세계의 대립
**유형**:
- **개인적 원한**: 주인공 vs 엽양신(연적/원수)
- **세력 대결**: 천검종 vs 혈신교
- **환경 도전**: 도겁/수해/천재지변

### 층위 2: 내부 갈등 (인물 vs 자아)
**정의**: 주인공 내면의 갈등
**유형**:
- **도덕적 딜레마**: 여동생을 구하기 위해 도시를 학살해야 하는가?
- **정체성 인식**: 나는 정도의 제자인가, 마도의 전승자인가?
- **욕망 충돌**: 힘의 추구 vs 사랑하는 사람 지키기

### 층위 3: 이념 갈등 (가치관 vs 가치관)
**정의**: 서로 다른 세계관의 충돌
**유형**:
- **정사 간의 다툼**: 정도의 위선 vs 마도의 진실
- **천도 논쟁**: 순천 vs 역천개명
- **약육강식 vs 약자 보호**

## 2. 갈등 강도 등급

### S급 갈등 (생사 결전)
**특징**: 불사불휴, 양측 중 최소 한쪽이 소멸
**발동 조건**:
- 살부지구/탈처지한
- 멸문멸종
- 세계 존망

**예시**:
```markdown
주인공 vs 혈신교주 (최종 BOSS)
- 원한: 혈신교가 주인공 가족을 죽이고 여동생을 납치
- 목표: 혈신교 완전 소멸
- 결과: 반드시 한쪽이 사망
```

### A급 갈등 (중대 이익)
**특징**: 핵심 이익 관련, 타협 가능
**발동 조건**:
- 성지 전승 쟁탈
- 종문 후계자 다툼
- 비경 보물 쟁탈

**예시**:
```markdown
주인공 vs 같은 문파 사형 (친전 제자 자리 쟁탈)
- 갈등: 자리는 하나뿐
- 결과: 비시를 통해 승부를 가릴 수 있으며, 패자가 반드시 죽지는 않음
```

### B급 갈등 (체면/지위)
**특징**: 한 입 기운을 다투는 것, 화해 가능
**발동 조건**:
- 조롱/도발당함
- 연적 갈등
- 순위 경쟁

**예시**:
```markdown
주인공 vs 단역 ("너 따위가?"라고 조롱당함)
- 갈등: 존엄 수호
- 결과: 한번 때려주거나 면박주면 됨, 굳이 죽일 필요 없음
```

### C급 갈등 (일상적 마찰)
**특징**: 소소한 다툼, 분위기 조절
**발동 조건**:
- 자리 다툼
- 말다툼
- 오해

**예시**:
```markdown
주인공 vs 행인 (식당 줄서기 새치기)
- 갈등: 소소한 갈등
- 결과: 몇 마디 말다툼, 또는 실력으로 살짝 위압
```

## 3. 갈등 에스컬레이션 메커니즘

### 에스컬레이션 공식
```
소갈등 → 오해 심화 → 이해관계 얽힘 → 불사불휴
```

### 에스컬레이션 사례
```markdown
1단계(C급): 주인공과 엽양신이 주루에서 말다툼
2단계(B급): 엽양신이 체면 손상으로 자객을 보내 주인공 암살(실패)
3단계(A급): 주인공이 엽가 호위를 반살하고, 엽가에서 장로를 보내 추격
4단계(S급): 주인공이 엽가 분가를 멸하고, 엽가 가주가 직접 출전
```

**역할**: 단계적 에스컬레이션을 통해 갈등을 더 합리적으로 만들고, "한마디에 바로 생사 대전"의 돌발감을 피한다.

## 4. 갈등 설계 템플릿

### 템플릿 A: 대립 갈등 (주인공 vs 단일 적)
```markdown
## 갈등 카드: 주인공 vs 엽양신
**기인**: 엽양신이 파혼하며 주인공을 모욕
**전개**:
  - 10장: 엽양신이 종문에서 주인공을 조롱
  - 30장: 종문 대비, 주인공이 엽양신을 격파
  - 50장: 엽양신이 가문 장로를 불러 보복
**클라이맥스**: 80장, 주인공이 엽가를 혈세
**결말**: 엽양신 사망, 갈등 완전 해결
**잔여**: 엽가 배후의 후원자(성지)가 주인공에게 적의를 품음
```

### 템플릿 B: 삼자 갈등 (주인공 vs 적A + 적B)
```markdown
## 갈등 카드: 정사마 삼파 혼전
**정도**: 천검종 (주인공 소속)
**사도**: 혈신교
**마도**: 만독굴

**도화선**: 비경 개방, 삼파 모두 독점하려 함
**전개**:
  - 100장: 삼파가 비경 입구에서 대치
  - 110장: 비경 진입 후, 정도 내부 분열 (누군가 사도와 연합하려 함)
  - 120장: 마도가 사도를 기습, 주인공이 혼란을 틈타 보물 탈취
**클라이맥스**: 130장, 주인공이 삼파 혼전 속에서 어부지리
**결말**: 삼파 양패구상, 주인공만 이득
```

### 템플릿 C: 내부 갈등 (주인공 vs 소속 세력)
```markdown
## 갈등 카드: 주인공 vs 종문 장로파
**배경**: 종문 내부가 종주파와 장로파로 분열
**기인**: 주인공의 실력이 너무 강해 장로파의 이익을 위협
**전개**:
  - 200장: 장로파가 은밀히 주인공을 탄압
  - 210장: 주인공이 모함당해 종문에서 쫓겨날 뻔함
  - 220장: 주인공이 증거를 찾아 장로파에 반격
**클라이맥스**: 230장, 종문 대회에서 주인공이 장로파의 외적 결탁을 폭로
**결말**: 장로파 청산, 주인공이 종문 핵심 인물이 됨
```

## 5. 갈등의 리듬 조절

### 갈등 밀도
- **최저 기준**: 10장당 최소 1개의 B급 이상 갈등
- **이상적 상태**: 5장마다 1개의 소갈등 + 20장마다 1개의 대갈등
- **금기**: 연속 30장 동안 뚜렷한 갈등이 없음 (줄거리가 늘어지게 느껴짐)

### 갈등과 쾌감 포인트의 배합
```
갈등 구축(억압) → 주인공 반격(통쾌) → 갈등 에스컬레이션(재억압) → 주인공 압도(대통쾌)
```

**예시**:
```markdown
40장: 엽양신이 주인공을 조롱 (억압)
41장: 주인공이 실력을 보여주며 살짝 면박 (소통쾌)
42장: 엽양신이 가문 장로를 불러옴 (억압 심화)
45장: 주인공이 장로를 처치하고 엽가를 혈세 (대통쾌)
```

## 6. 무의미한 갈등 피하기

### 무의미한 갈등의 특징
1. **이유 없음**: 두 사람이 전혀 접점이 없는데 갑자기 싸움
2. **반복 갈등**: 주인공이 이미 엽양신을 세 번이나 면박줬는데, 또 네 번째
3. **결과 없는 갈등**: 싸우고 나서 양쪽 다 손해도 이득도 없음

### 어떻게 갈등을 유의미하게 만드는가?
- **반드시 기인이 있어야 함**: 이해충돌/가치관 충돌/오해/원한
- **반드시 결과가 있어야 함**: 승자는 보상(경험/보물/명성), 패자는 대가(사망/지위 상실)
- **반드시 줄거리를 추진해야 함**: 이번 갈등을 통해 주인공이 강해졌거나/새로운 인물을 만났거나/새로운 단서를 얻었거나

## 7. 다선 갈등 교차

### 왜 다선이 필요한가?
- 단일 갈등선이 단조로워지는 것 방지
- 복잡성을 만들어 가독성 증가
- 조연에게 활약 공간 부여

### 다선 갈등 예시
```markdown
## 1권에서 동시 진행되는 세 갈등선
**주선**: 주인공 vs 엽양신 (개인적 원한)
**부선A**: 천검종 vs 혈신교 (세력 대결, 배경판)
**부선B**: 주인공 vs 종문 시험 (환경 도전)

## 교차점
30장: 종문 대비 (주선 + 부선B)
50장: 혈신교가 종문을 기습, 주인공이 혼란을 틈타 엽양신을 처치 (삼선 합류)
```

## 8. 갈등 해결 방식

### 방식 1: 무력 압도 (70%)
**적합**: 대부분의 웹소설
**흐름**: 주인공 실력이 강함→바로 적을 압도→통쾌
**예시**: "일검참금단! 전장이 경악!"

### 방식 2: 지략 승리 (20%)
**적합**: 주인공이 일시적으로 적을 이길 수 없을 때
**흐름**: 계략/진법/독약으로 적을 약화시킴→그 후 출수
**예시**: "주인공이 미리 비경에 함정을 설치하고, 적을 유인하여 비경 기관으로 적을 제거"

### 방식 3: 화해/타협 (5%)
**적합**: 생사 갈등이 아닌 경우
**흐름**: 양측이 공동 이익점을 찾음→일시적 연합
**예시**: "정사 양도가 대립하지만, 수조가 밀려와 연합하여 적을 막을 수밖에 없음"

### 방식 4: 일시적 보류 (5%)
**적합**: 후속 줄거리에 복선 깔기 위해
**흐름**: 외력 개입(강자 출현/시간 만료/비경 폐쇄)→갈등 중단
**예시**: "두 사람이 생사를 다투는 순간, 종주가 나타남: '그만!'"

## 9. 갈등 설계 자가 점검 목록

갈등을 설계할 때마다 다음 항목을 점검:
- [ ] **기인 명확**: 왜 싸우는가? ("네가 마음에 안 들어" 같은 저급한 이유는 안 됨)
- [ ] **실력 대비**: 적이 주인공보다 강한가? (너무 약하면 긴장감이 없음)
- [ ] **이해관계**: 갈등이 핵심 이익과 관련되는가? (체면보다 보물이 더 매력적)
- [ ] **에스컬레이션 합리성**: 갈등이 단계적으로 에스컬레이션되는 과정이 있는가? (처음부터 생사 대전은 안 됨)
- [ ] **후속 영향**: 갈등 종료 후 잔여 문제가 있는가? (복선 깔기)
- [ ] **캐릭터 설정 부합**: 주인공/악역의 행동이 그 성격에 부합하는가?

## 갈등 라이브러리 (자주 쓰는 템플릿)

### 갈등 유형 속찰표
| 갈등 유형 | 기인 | 강도 | 해결 방식 | 쾌감 포인트 |
|---------|------|------|---------|------|
| 파혼 면박 | 무시당함 | A급 | 무력 압도 | 전 약혼녀 면박 |
| 비경 보물 쟁탈 | 자원 쟁탈 | S급 | 지략+무력 | 신기 획득 |
| 종문 내분 | 권력 투쟁 | A급 | 편들기+숙청 | 지위 상승 |
| 수조 습격 | 환경 위기 | S급 | 연합 방어 | 공훈+돌파 |
| 정사 대전 | 이념 충돌 | S급 | 무력 결전 | 마두 격파 |
| 모함당함 | 오해/소인 | B급 | 증거 찾아 반격 | 진상 폭로 |

이 표를 사용하면 적절한 갈등 유형을 빠르게 선택하고, 각 갈등마다 명확한 해결 방식과 쾌감 포인트를 확보할 수 있다.

## 부록: 갈등 설계 사례 분석

### 사례: 《투파창궁》의 갈등 설계
**핵심 갈등**: 소염 vs 나란연연 (3년의 약속)
**갈등 에스컬레이션**:
1. 파혼 (C급→B급 갈등)
2. 3년의 약속 (A급 갈등)
3. 운란종 개입 (S급으로 에스컬레이션, 소염 vs 운란종)
4. 최종 결전 (운란종 멸문)

**장점**: 갈등 에스컬레이션이 자연스럽고, 개인적 원한에서 세력 대결로 상승하며, 층층이 진행된다.
