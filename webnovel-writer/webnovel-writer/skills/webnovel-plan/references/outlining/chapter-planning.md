# 챕터 기획 기법 (Chapter Planning)

> **핵심 원칙**: 모든 챕터는 하나의 작은 이야기이며, 도입, 전개, 클라이맥스, 결말이 있어야 한다. 독자가 읽고 나서 "시원하다" 또는 "다음 챕터가 보고 싶다"는 느낌을 받아야 한다.

---

## 1. 챕터의 황금 구조

### 표준 챕터 구조 (3000자)
```
도입 (300자): 훅, 독자의 계속 읽기를 유도
전개 (1500자): 스토리 진행, 충돌 조성
클라이맥스 (1000자): 쾌감포인트/반전/체면 깎기
결말 (200자): 서스펜스/훅, 다음 챕터 구독 유도
```

### 도입 훅의 5가지 유형
1. **서스펜스형**: "바로 그때, 검은 그림자가 갑자기 임천의 뒤에 나타났다!"
2. **충돌형**: "엽량진이 냉소했다: '오늘이 네 기일이다!'"
3. **정보 격차형**: "임천이 모르는 것은, 방금 그의 행동이 이미 정체를 드러냈다는 것이다."
4. **역순형**: "3일 후, 천검종은 폐허가 될 것이다. 그리고 이 모든 것은 오늘의 한 가지 결정에서 비롯되었다……"
5. **이어받기형**: "(전 챕터에 이어) 임천은 깊이 숨을 들이쉬고, 비경의 대문을 밀어 열었다."

## 2. 챕터 리듬 설계

### 리듬 유형

#### A. 쾌감포인트 챕터 (70%)
**목적**: 독자에게 통쾌함을 주고, 구독률 향상
**구조**:
```
1. 충돌 설정 (주인공이 도발당함/위험에 처함)
2. 주인공 실력 발휘 (체면 깎기/즉사/허세)
3. 모두 경악 ("이게 어떻게 가능하지!")
4. 주인공 수확 (경험치/보물/명성)
```

**예시**:
```markdown
## 제50화: 일검참금단
- 도입: 금단 장로가 임천을 제 분수도 모른다고 조롱
- 전개: 임천이 검을 뽑아, 검의를 펼침
- 클라이맥스: 일검으로 금단 장로를 참살, 전체가 경악
- 결말: 종주 등장: "흥미롭군, 너를 친전 제자로 받겠다." (다음 챕터 훅 매설)
```

#### B. 과도 챕터 (20%)
**목적**: 앞뒤를 잇고, 복선 매설
**구조**:
```
1. 수확 정리 (전리품 점검/전투 요약)
2. 배경 설명 (세계관 보충/새 세력 도입)
3. 서스펜스 배치 (다음 위기 암시)
```

**예시**:
```markdown
## 제51화: 암류용동
- 도입: 임천이 거처로 돌아와, 비경에서 얻은 보물을 점검
- 전개: 보물의 내력 소개 (설정 보충)
- 전개: 누군가 임천을 몰래 감시 (복선 매설)
- 결말: "혈신교의 밀정이 정보를 전달했다: '목표 확인 완료.'"
```

#### C. 칼날 챕터 (10%)
**목적**: 고통 포인트 조성, 감정 동요 유발
**구조**:
```
1. 주인공이 중대한 타격을 입음 (사존이 살해됨/친인이 납치됨)
2. 주인공 비통에 빠짐
3. 복수의 맹세
```

**예시**:
```markdown
## 제200화: 사존 운명
- 도입: 사존이 임천을 보호하기 위해 일대백으로 싸움
- 전개: 임천이 어쩔 수 없이 도망치며, 사존이 포위당해 죽는 것을 지켜봄
- 클라이맥스: 사존이 임종 전 임천에게 공력을 전수: "기억해라, 복수해라!"
- 결말: 임천이 무릎 꿇고 절규: "맹세한다, 혈신교, 반드시 멸문시키겠다!"
```

## 3. 챕터 글자 수 관리

### 표준 글자 수
- **기점 등 장편 플랫폼**: 3000자/챕터 (가장 쾌적)
- **단편 플랫폼 (지호/위챗)**: 1500-2000자/챕터
- **유료 챕터**: 2000자 이상 (2000자 미만이면 독자가 아깝다고 느낌)

### 글자 수 배분 황금 비율
```
도입 훅: 10% (300자)
스토리 전개: 50% (1500자)
클라이맥스 쾌감포인트: 33% (1000자)
결말 훅: 7% (200자)
```

### 특수 상황
- **대형 클라이맥스 챕터**: 5000-6000자까지 가능 (예: 종문 대비 결승, 대보스 격파)
- **과도 챕터**: 2500자까지 압축 가능 (단, 2000자 이하 금지)

## 4. 챕터 제목 기법

### 제목의 역할
- **클릭 유도**: 목차 페이지에서 눈에 띄게
- **적절한 스포일러**: 독자에게 이번 챕터의 볼거리를 알려주되, 완전 스포는 금지

### 제목 공식

#### 공식 1: 핵심 사건
```
제1화: 파혼의 치욕
제50화: 일검참금단
제100화: 혈세엽가
```
**장점**: 직접적, 독자가 한눈에 내용 파악
**단점**: 서스펜스 부족

#### 공식 2: 서스펜스형
```
제1화: 신비로운 목소리
제50화: 그가, 왔다
제100화: 그 일검의 풍정
```
**장점**: 서스펜스 있음, 클릭 유도
**단점**: 낚시 제목 위험, 내용이 뒷받침해야 함

#### 공식 3: 대화형
```
제1화: "너, 자격 없어!"
제50화: "이건 불가능해!"
제100화: "돌아왔다."
```
**장점**: 몰입감 있음, 감정 강렬
**단점**: 많이 쓰면 심미 피로

#### 공식 4: 조합형 (추천)
```
제50화: 일검참금단! 전장 경악
제100화: 혈세엽가, 복수의 길 개시
제200화: 사존 운명, "반드시 죽이겠다!"
```
**장점**: 핵심 사건과 감정 포인트 모두 포함

## 5. 챕터 간 연결

### 연결 방식

#### A. 직접 이어받기
```
제49화 결말: "임천이 깊이 숨을 들이쉬고, 일검을 내질렀다!"
제50화 도입: "검광이 스치자, 금단 장로의 동공이 급격히 수축되었다……"
```
**적용**: 전투 챕터, 클라이맥스 챕터

#### B. 시간 도약
```
제49화 결말: "임천이 비경에 들어갔다."
제50화 도입: "3일 후, 임천이 비경에서 나오자, 기운이 크게 변해 있었다."
```
**적용**: 과도 챕터, 수련 폐관

#### C. 시점 전환
```
제49화: 주인공 시점 (임천이 비경에서 탐색)
제50화: 악역 시점 ("종주님, 임천이 비경에 들어간 지 3일입니다, 손을 쓸까요?")
```
**적용**: 다중 서사, 복선 매설

## 6. 쾌감포인트 밀도 관리

### 쾌감포인트 등급
| 등급 | 쾌감 강도 | 빈도 | 예시 |
|------|---------|------|------|
| **S급** | 초쾌감 | 매 50-100화 | 대보스 격파, 비승, 적대 세력 멸문 |
| **A급** | 매우 쾌감 | 매 20-30화 | 전 약혼녀 체면 깎기, 종문 대비 1위 차지 |
| **B급** | 쾌감 | 매 10화 | 도발자 즉사, 신기 획득 |
| **C급** | 소쾌감 | 매 3-5화 | 엑스트라 체면 깎기, 영석 벌기 |

### 쾌감포인트 밀도 점검
- **최저 기준**: 매 10화에 최소 1개 B급 이상 쾌감포인트
- **이상적 상태**: 매 5화 1개 C급 + 매 10화 1개 B급 + 매 30화 1개 A급
- **금기**: 연속 20화 쾌감포인트 없음 (독자 이탈)

## 7. 챕터 기획 템플릿

### 템플릿 A: 전투 챕터
```markdown
## 제XX화: [제목]
**글자 수**: 3000
**주선 스토리**: 주인공 vs [적]
**충돌 원인**: [왜 싸우는가?]
**전투 흐름**:
  1. 적이 주인공을 조롱/경시
  2. 주인공이 실력을 숨기고, 먼저 약한 척
  3. 적이 이겼다고 생각하고, 방심
  4. 주인공 폭발, 일격필살
  5. 모두 경악: "이렇게 강했다니!"
**쾌감포인트**: 체면 깎기/즉사/허세
**복선**: [어떤 떡밥을 뿌리는가?]
**결말 훅**: [다음 챕터로 유도]
```

### 템플릿 B: 스토리 챕터
```markdown
## 제XX화: [제목]
**글자 수**: 3000
**주선 스토리**: [어떤 주선을 추진하는가?]
**부선 스토리**: [어떤 지선이 관련되는가?]
**신규 정보**:
  - 세계관 보충: [새 세력/새 맵 소개]
  - 인물 관계: [새로운 연결 구축]
**쾌감포인트**: 없음 (과도 챕터) 또는 소쾌감 (정보/보물 획득)
**복선**: [후속 스토리를 위한 떡밥]
**결말 훅**: [서스펜스 조성]
```

### 템플릿 C: 수련 챕터
```markdown
## 제XX화: 돌파!
**글자 수**: 3000
**주선 스토리**: 주인공이 [새 경지]로 돌파
**수련 과정**:
  1. 현재 경지 병목 회고
  2. 깨달음/단약 복용/에너지 흡수
  3. 돌파 시 이변 묘사 (천지 영기 집결/뇌겁 강림)
  4. 돌파 성공, 실력 대폭 상승
**쾌감포인트**: 경지 상승, 전투력 급상승
**대비**: 돌파 전후 실력 격차 표현 (예: 이전에 이길 수 없던 적을 이제 일격에 처리)
**결말 훅**: "바로 그때, 공포스러운 기운이 임천을 포착했다……"
```

## 8. 챕터 자가점검 체크리스트

매 챕터 완성 후, 이 체크리스트로 점검:
- [ ] **글자 수**: 2000-4000자 범위인가? (유료 챕터는 최소 2000자)
- [ ] **도입**: 처음 300자에 충분한 흡인력이 있는가?
- [ ] **충돌**: 이번 챕터에 명확한 충돌 또는 진행이 있는가?
- [ ] **쾌감포인트**: 이번 챕터에 최소 1개 소쾌감포인트가 있는가? (과도 챕터라면 없을 수 있지만, 연속 3화 없으면 안 됨)
- [ ] **결말**: 독자의 다음 챕터 구독을 유도하는 훅이 있는가?
- [ ] **논리**: 이번 챕터 내용이 설정집과 개요에 부합하는가?
- [ ] **리듬**: 이번 챕터의 리듬은 빠른가 (전투/체면 깎기) 느린가 (과도/수련)? 앞뒤 챕터와 대비가 되는가?

## 9. 흔한 챕터 문제와 해결

### 문제 1: 챕터가 너무 묽어서, 독자가 "물타기"라고 비난
**증상**: 긴 환경 묘사, 내면 독백, 전 챕터 내용 반복
**해결**:
- 불필요한 환경 묘사 삭제 (새 맵 첫 진입이 아닌 한)
- 내면 독백 200자 초과 금지
- 전 챕터 내용 반복 금지 (역순/회상이 아닌 한)

### 문제 2: 챕터가 너무 건조하고, 정보량 과다
**증상**: 한 챕터에 5명의 새 캐릭터, 3개의 새 세력, 10개의 새 설정 도입
**해결**:
- 챕터당 최대 2명의 새 캐릭터
- 새 설정은 여러 챕터에 분산하여 소개
- 나레이션이 아닌 대화로 설정 소개

### 문제 3: 챕터에 클라이맥스가 없고, 평범무기
**증상**: 처음부터 끝까지 "그가 A를 했다, 그다음 B를 했다, 그다음 C를 했다"
**해결**:
- 필수 요구: 챕터당 최소 1개 감정 고조점 (쾌감/웃음/고통/서스펜스)
- "억양법" 사용: 먼저 억누르고, 그다음 폭발
