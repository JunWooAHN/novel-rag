<context>
이 파일은 챕터 품질 빠른 자가 점검에 사용됩니다. Claude는 일반 작문 오류를 이미 알고 있으며, 여기서는 웹소설 창작에 특화된 자주 발생하는 문제만 나열합니다.
</context>

<instructions>

## 빠른 자가 점검 목록

| 점검 항목 | 통과 기준 | 위반 결과 |
|--------|----------|----------|
| 전력 합리성 | 주인공 실력 ≤ state.json | 전력 체계 파괴 |
| 쾌감 포인트 존재 | 최소 1개 쾌감 포인트/장 | 독자 이탈 |
| 엔티티 식별 | 새 엔티티를 Data Agent가 자동 추출 가능 | 설정 혼란 |
| 인물 일관성 | 대화/행동이 캐릭터 설정에 부합 | OOC 이탈감 |
| 리듬 균형 | 연속 5장 이상 같은 Strand 아닌 것 | 심미 피로 |
| 복선 추적 | 복선이 식별 및 기록 가능 | 복선 망각 |

</instructions>

<examples>

<example>
<input>오류: 주인공 축기 3층인데, 금단기 적을 격파</input>
<output>
❌ **전력 붕괴**

✅ 수정: 월급 전투가 반드시 필요하다면:
- 금수저/비법 가호
- 상대가 부상/약화
- 환경 우위/함정 보조
</output>
</example>

<example>
<input>오류: 전체 챕터가 주인공 이동, 갈등도 쾌감 포인트도 없음</input>
<output>
❌ **쾌감 포인트 부재**

✅ 수정: 이동 중 배치:
- 사건 조우 (강도/요수/기연)
- 캐릭터 만남 (동료/적/여주)
- 숨겨진 장소/보물 발견
</output>
</example>

<example>
<input>오류: 갑자기 "자소종"이 등장, 설정집에 이 세력 없음</input>
<output>
❌ **무단 창작**

✅ 수정:
- 새 세력에 명확한 이름과 묘사 확보
- Data Agent가 자동 추출하여 설정집 추가 여부 확인
</output>
</example>

<example>
<input>오류: 주인공 성격 "참을성 있고 침착"인데, 갑자기 폭발 실성</input>
<output>
❌ **인물 OOC**

✅ 수정:
- 캐릭터 카드 성격 참조
- 변화가 필요하면 복선 필요 (역린 건드림/중대 자극)
- 성격 변화 원인 표기
</output>
</example>

<example>
<input>오류: 악역 대사가 전부 "이 미천한 벌레!" "주제도 모르고!"</input>
<output>
❌ **대사 유형화**

✅ 수정:
- C급 악역은 유형화 가능
- B급 이상은 지능과 개성이 있어야
- 조롱도 자연스럽고 정보량이 있어야
</output>
</example>

</examples>

<errors>
❌ 전력 붕괴 (월급 즉살 무사유) → ✅ state.json 확인, 합리적 상대 설정
❌ 쾌감 포인트 부재 (전체 챕터 무갈등) → ✅ 최소 1개 쾌감 포인트, 전환 챕터도 필요
❌ 무단 창작 (새 엔티티 묘사 모호) → ✅ 새 엔티티에 명확한 이름과 묘사 확보
❌ 인물 OOC (성격 돌변 무복선) → ✅ 캐릭터 카드 참조, 변화에는 복선 필요
❌ 리듬 단조 (연속 10장 순전투) → ✅ strand_tracker 확인, Strand 전환
❌ 복선 망각 (100장 초과 미회수) → ✅ 핵심 복선 50장 내 회수
❌ 대사 유형화 (악역이 구호만 외침) → ✅ B급 이상 악역은 지능이 있어야
</errors>
