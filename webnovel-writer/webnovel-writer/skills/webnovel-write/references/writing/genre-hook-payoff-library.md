# 신규 제재 속성 라이브러리: 장말 훅 + 미시 보상 (e스포츠 / 라이브 방송문 / 크툴루)

`webnovel-write` Step 1.5에서 사용: 빠르게 장말 훅 + 미시 보상 하나를 선택하여 동질화를 피합니다.

---

## 사용 규칙

- 매 챕터 추천: `1개 기대 앵커 포인트 (장말 또는 후반) + 1-2개 미시 보상`.
- 같은 훅 유형이 연속 3장 반복되는 것을 피합니다.
- 반복 사용 시, 반드시 차별화 포인트 제시 (대상, 대가, 결과 중 최소 1항 변경).

---

## 1) e스포츠 (esports)

### 장말 훅 라이브러리 (우선)
- **위기 훅**: 다음 경기 상대가 임시로 진용 변경, 핵심 전술이 타겟팅됨.
- **선택 훅**: 주인공이 "보수적 득점"과 "올인 역전" 사이에서 양자택일해야 함.
- **갈망 훅**: 승급까지 한 경기 남았는데, 주력 상태 이상.
- **감정 훅**: 팀원이 인터뷰에서 공개적으로 책임을 지며, 여론 분열 유발.

### 미시 보상 라이브러리 (고빈도)
- 정보 보상: 상대 전술 약점이 식별되고 검증됨.
- 인정 보상: 코치/팀원이 처음으로 주인공의 결정을 공개 인정.
- 관계 보상: 팀 내 핵심 갈등이 본 챕터에서 실질적 완화.
- 자원 보상: 핵심 훈련 자원 또는 전술 권한 획득.

### 빠른 단편
```text
장말 훅: 선택 훅 - 결승전은 안정 운영인가 올인 한타인가?
미시 보상: 인정 보상 - 코치가 마지막 라운드 BP 주도권을 주인공에게 넘김.
```

## 2) 라이브 방송문 (livestream)

### 장말 훅 라이브러리 (우선)
- **위기 훅**: 방송 클립이 악의적으로 편집되어, 부정적 키워드가 실검에 오름.
- **선택 훅**: 즉시 여론에 대응할 것인가, 증거를 잡고 내일 밤 반격할 것인가.
- **갈망 훅**: 플랫폼 메인 추천 자리까지 데이터 한 단계 차이.
- **감정 훅**: 핵심 팬덤이 이탈 의심, 방송 분위기 급변.

### 미시 보상 라이브러리 (고빈도)
- 자원 보상: 브랜드 테스트 건 또는 핵심 협업 기회 확보.
- 인정 보상: 시청자 평판 전환, 탄막이 의심에서 지지로 변환.
- 정보 보상: 폭로 단서 확인, 증거 체인의 한 고리 형성.
- 관계 보상: 팀 업무 재편 후 효율 상승이 즉각 효과 발휘.

### 빠른 단편
```text
장말 훅: 위기 훅 - 내일 아침 10시, 상대방이 "확증" 장문을 공개할 예정.
미시 보상: 정보 보상 - 주인공이 검증 가능한 원본 백엔드 캡처 확보.
```

## 3) 크툴루 (cosmic-horror)

### 장말 훅 라이브러리 (우선)
- **서스펜스 훅**: 이미 해독된 규칙이 새 장면에서 예외가 발생.
- **위기 훅**: 봉인 노드가 조기 실효, 오염이 확산 시작.
- **선택 훅**: 동료를 구할 것인가 먼저 의식을 차단할 것인가, 양립 불가.
- **감정 훅**: 주인공 이성치 임계, 기억에 비가역적 공백 발생.

### 미시 보상 라이브러리 (고빈도)
- 단서 보상: 전문 디테일과 새 증거가 성공적으로 폐합.
- 정보 보상: "실행 가능한 생존 규칙" 하나 확인.
- 감정 보상: 캐릭터가 공포 속에서 한 번의 능동적 결단 완수.
- 관계 보상: 핵심 동료 관계가 의심에서 위험 공담으로 전환.

### 빠른 단편
```text
장말 훅: 서스펜스 훅 - 7번째 규칙이 거울 방에서 역으로 작동.
미시 보상: 단서 보상 - 3장 전의 낡은 지도 표시가 오염원 위치와 대응.
```

## 저반복 체크 (집필 전 30초)

- 본 챕터 훅 유형이 최근 2장과 같은가?
- 본 챕터 미시 보상 유형이 연속 3장 변화 없는가?
- 본 챕터에 "정량화 가능한 변화" (결과/관계/자원/리스크)가 있는가?
