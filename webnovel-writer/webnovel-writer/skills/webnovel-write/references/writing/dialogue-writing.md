## 1. 잠재 대사 5계층 분석

### 1. 감정 잠재 대사
숨겨진 감정과 정서
```
표면: "왔구나."
잠재 대사: 오랫동안 기다림/차갑게 거리 둠/놀라서 불안
```

### 2. 동기 잠재 대사
숨겨진 목적과 동기
```
표면: "요즘 어떻게 지내?"
잠재 대사: 탐색/관심/대화거리 찾기/암시
```

### 3. 관계 잠재 대사
숨겨진 인물 관계
```
표면: "왕 사장님, 안녕하십니까."
잠재 대사: 존경/풍자/거리 둠/인사치레
```

### 4. 줄거리 잠재 대사
숨겨진 줄거리 전개
```
표면: "이 건은, 내가 처리하겠습니다."
잠재 대사: 곧 행동/대충 넘기기/위협/약속
```

### 5. 주제 잠재 대사
숨겨진 주제와 사상
```
표면: "사람마다 운명이 있는 법이지."
잠재 대사: 숙명론/무력감/수용/반어
```

---

## 2. 잠재 대사 유형 라이브러리

| 유형 | 특징 | 예시 | 잠재 대사 |
|------|------|------|--------|
| 탐색형 | 에둘러 캐기 | "최근 이 사장님과 많이 가까워졌다면서?" | 관계 탐색/경고/질투 |
| 은폐형 | 모호한 답변 | "그날 밤? 집에서 쉬고 있었어." | 행적 은폐/거짓말/회피 |
| 암시형 | 말 속에 뜻이 있음 | "어떤 일은, 너무 많이 알면 좋지 않아." | 경고/위협/보호 |
| 회피형 | 화제 전환 | "이건... 다음에 얘기하죠." | 회피/미루기/마주하기 싫음 |

---

## 3. 대화 설계 원칙

### 1. 캐릭터 설정에 부합
- 언어 습관이 신분에 맞아야
- 용어 스타일이 성격에 일관
- 말하는 방식이 배경에 부합

### 2. 줄거리 추진
- 핵심 정보 전달
- 갈등 유발/상승
- 진실 공개/은폐

### 3. 인물 관계 표현
- 호칭 변화가 관계를 암시
- 어조 변화가 태도를 암시
- 화제 선택이 친소를 암시

### 4. 잠재 대사 함축
- 표면 뜻 ≠ 진짜 의도
- 여백으로 독자가 생각하게
- 반응을 통해 잠재 대사 드러냄

---

## 4. 대화 어조 설계

| 어조 | 표현 | 잠재 대사 |
|------|------|--------|
| 온화 | 나직이, 천천히 | 관심/위로/유혹 |
| 냉담 | 짧고, 평이 | 거리 둠/불만/경고 |
| 격앙 | 급촉, 반복 | 분노/초조/흥분 |
| 풍자 | 반어, 과장 | 불만/비웃음/공격 |

**침묵 설계**:
- 침묵의 의미: 사고/거절/경악/인내
- 침묵을 깨는 시점: 핵심 정보/감정 전환점
- 침묵의 묘사: 동작/표정/환경

## 5. 대화 리듬 조절

### 빠른 리듬 (전투/긴장 장면)
```
"죽여라!"
"받아라!"
"깨져라!"
검광이 번쩍이고, 선혈이 비산.
"너...... 어떻게 가능......"
"넌 너무 약해."
```
**특징**: 단문, 동작 빠름, 군더더기 없음

### 느린 리듬 (일상/복선 장면)
```
"사형, 이번 비경 개방이 위험할까?"
임천이 잠시 생각했다: "알 수 없지. 고서에 따르면, 지난 비경 개방은 300년 전이었어, 그때 들어간 100여 명 중, 살아 나온 사람은 열 명도 안 됐어."
"그러면... 우리 가야 해?"
"가야지. 기연과 위험은 공존하는 거야, 수선의 길이 원래 그런 거지."
```
**특징**: 긴 문장, 정보량 많음, 사고 멈춤 있음

## 6. 대화와 동작/심리 결합

### 대화와 동작 결합
```
❌ "안녕하세요." 그가 말했다.
✅ "안녕하세요." 그가 살짝 고개를 끄덕였지만, 시선은 손에 든 문서를 떠나지 않았다.
```

### 대화와 심리 결합
```
"아무것도 아니야." 그녀가 말했다.
하지만 꽉 쥔 주먹이 그녀의 감정을 드러냈다.
```

### 대화와 환경 결합
```
"우리... 헤어지자."
창밖의 비가 점점 세지고, 유리 위의 그림자를 흐리게 했다.
```

---

## 7. 각 단계별 대화 설계

| 단계 | 대화 특징 | 기능 |
|------|----------|------|
| 첫 만남 | 인사/탐색 | 첫인상 구축, 관계 복선 매설 |
| 친숙해짐 | 일상 소통 | 성격 표현, 관계 심화 |
| 갈등 | 언쟁/대치 | 모순 폭로, 전환 추진 |
| 화해 | 설명/사과 | 오해 해소, 관계 업그레이드 |

---

## 8. 대화 황금 비율

- **대화**: 40-50% (웹소설 주류)
- **서술**: 30-40%
- **심리 활동**: 10-20%

**대화 과다 문제**: 물타기, 독자가 "쓸데없는 말 좀 줄여!" 하고 욕함
**대화 과소 문제**: 전부 서술, 화면감 부족

<errors>
❌ 정보 쏟기 ("있잖아, 나는 3년 전 서울에서 왔는데, 그때 아버지가 아파서...") → ✅ 정보 분산 매설
❌ 만인일면 (모든 캐릭터 말투가 동일) → ✅ 언어 개성화
❌ 무효 대화 ("안녕." "안녕." "오늘 날씨 좋다." "그러네.") → ✅ 매 대사마다 기능 있어야
❌ 과도한 설명 ("내가 이렇게 한 이유는..."이라고 직접 동기 말함) → ✅ 잠재 대사로 표현
❌ "said" 병 (그가 말했다, 그녀가 말했다, 그가 또 말했다) → ✅ 동작/표정으로 태그 대체
❌ 무의미한 인사 ("실례하지만 잠깐..." "괜찮습니다, 말씀하세요") → ✅ 바로 본론으로
❌ 자문자답 독각희 → ✅ 간결한 내면 독백으로 압축하거나 행동으로 표현
</errors>
