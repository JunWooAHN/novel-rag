## 1. 심리 묘사 3층위

### 의식 층면
캐릭터가 인식할 수 있는 심리 활동
```
그는 이렇게 생각하면 안 된다는 것을 알면서도, 참을 수가 없었다...
```

### 잠재의식 층면
캐릭터가 어렴풋이 느끼지만 마주하고 싶지 않은 심리
```
그녀는 자신에게 그저 보통 친구일 뿐이라고 말했지만, 자꾸만 무의식적으로 그가 있는 쪽을 바라보았다.
```

### 무의식적 노출
캐릭터 자신도 인식하지 못한 심리 유출
```
"나 괜찮아." 그녀가 말했지만, 꽉 쥔 주먹이 그녀를 배신했다.
```

## 2. 심리 묘사 5기법

### 1. 직접 내면 독백
핵심 장면의 심리 표현
```
"불가능해!" 그의 마음속에 크게 놀랐다, "그가 어떻게 이런 실력이 가능하지?"
```
**사용 원칙**: 핵심 감정 노드에서만 사용, 단락당 3문장 이내

### 2. 간접 심리 묘사
행동, 표정, 대화를 통한 표현
```
그녀의 손가락이 무의식적으로 옷자락을 비틀고 있었고, 시선은 이리저리 피하며, 그와 눈을 마주치지 못했다.
```

### 3. 감각 촉발 심리
시각, 청각, 촉각, 후각 촉발
```
익숙한 향수 냄새가 풍겨왔고, 그의 마음이 갑자기 조여왔다——그녀다.
```

### 4. 꿈으로 비추는 심리
꿈의 상징과 은유
```
그는 또 그 장면을 꿈꿨다, 그녀가 돌아서 떠나고, 그가 미친 듯이 쫓아가도 절대 따라잡을 수 없는.
```

### 5. 자유 연상
사고 도약으로 깊은 심리 표현
```
창밖의 비를 바라보며, 그는 그날을 떠올렸고, 그녀의 눈물을 떠올렸고, 자신의 비겁함을 떠올렸다...
```

## 3. 감정 변화 곡선

### 단일 감정 점진
```
불안 → 걱정 → 공포 → 절망
호감 → 설렘 → 좋아함 → 깊은 사랑
```

### 감정 전환
```
분노 → 경악 → 이해 → 담연
기대 → 실망 → 분노 → 냉담
```

### 감정 모순
```
사랑과 미움의 교차
신뢰와 의심의 공존
갈망과 공포의 동시 존재
```

## 4. 감정 강도 등급

| 등급 | 특징 | 글자 수 | 묘사 방식 |
|------|------|------|----------|
| 1급 | 일상적 가벼운 파동 | 10자 | 한 필로 지나침 |
| 2급 | 뚜렷한 감정 | 30자 | 간단 묘사 |
| 3급 | 강렬한 감정 | 50자 | 외현+내현 결합 |
| 4급 | 감정 폭발 | 100-200자 | 챕터 클라이맥스 |

**1급 예시**: 임천이 약간 무력하게 고개를 저었다.

**2급 예시**: 임천이 미간을 찌푸리며, 마음에 약간 불쾌했다. 이 엽양신도 너무 건방지군.

**3급 예시**:
```
임천이 검 자루를 꽉 쥐었고, 손가락 관절이 하얗게 변했다.
(참아! 반드시 참아! 지금은 때가 아니야!)
그는 깊이 숨을 들이쉬고, 마음속의 분노를 억눌렀다.
```

**4급 예시**:
```
"사존!!!"
임천이 울부짖었고, 목소리가 찢어지듯 고통스러웠다.
그는 피웅덩이 속에 무릎을 꿇고, 두 손이 떨리며 사존의 시신을 들어 안았다.
눈물이 멈추지 않고 흘러내렸다.
왜......
왜 자신은 이렇게 약한 건가?!
왜 사존이 죽는 것을 눈앞에서 보면서도, 아무것도 할 수 없는 건가?!
"맹세코......" 임천이 고개를 들었고, 눈에 핏줄이 가득했다, "혈신교, 반드시 너희를 멸문시키겠다!"
```

## 5. 내면 갈등 설계

| 유형 | 설명 | 예시 |
|------|------|------|
| 욕망 vs 도덕 | 원하는 것과 해야 하는 것의 충돌 | 복수하고 싶지만 옳지 않다는 것을 알고 |
| 이성 vs 감정 | 이성적 판단과 감정적 충동 | 놓아야 한다는 것을 알지만 포기할 수 없고 |
| 자아 vs 타인 | 개인 이익과 타인 이익 | 자신을 구할 것인가 남을 구할 것인가 |
| 과거 vs 현재 | 과거 경험과 현재 선택 | 과거의 상처가 현재에 영향 |

**갈등 표현**: 우유부단 → 반복 갈등 → 자기 설득 → 최종 결정

## 6. 핵심 감정 묘사 템플릿

### 분노 (가장 다용)
**트리거**: 모욕당함, 친인 살해, 배신당함
```
【외현】임천의 안색이 무섭도록 어두워지고, 눈에서 불이 나올 듯했다. 두 주먹을 꽉 쥐고, 몸이 미세하게 떨렸다.
【내현】(죽여버리겠어!)
【행동】"죽어라!" 임천이 폭발하며 출수, 일검이 찔렸다!
```

### 슬픔 (칼 챕터 필수)
**트리거**: 친인 사망, 연인 이별
```
【외현】임천이 바닥에 무릎 꿇고, 어깨가 격렬히 떨렸다. 눈물이 시야를 흐리게 했다.
【내현】(사존...... 미안합니다...... 제가 못나서......)
【전환】그가 고개를 들었고, 눈 속의 슬픔이 서서히 증오로 변했다. "반드시 복수하겠습니다......"
```
**주의**: 슬픔이 너무 오래 지속되면 안 됨, 빠르게 "복수 결심"으로 전환해야 함

### 공포 (압박감 조성)
**트리거**: 자신보다 훨씬 강한 적 조우
```
【외현】임천의 이마에 식은땀이 줄줄, 등이 서늘했다. 이 기운...... 너무 무섭다!
【내현】(안 돼, 정면으로 부딪히면 안 돼! 도망쳐야 해!)
【행동】그는 주저 없이 돌아서 달렸다. 살아남으면, 언젠가 기회가 있을 테니!
```

### 절망 (극한 학대 포인트)
**트리거**: 막다른 골목, 사면초가
```
【외현】임천이 무력하게 주저앉고, 눈빛이 공허했다. 모두가 그를 배신했다......
【내현】(왜...... 왜 이렇게 된 건가......)
【전기】바로 그때, 한 목소리가 울렸다: "소년, 강해지고 싶은가?"
```
**주의**: 절망은 최대 1-2장, 후속 역전을 부각시키기 위한 것

## 7. 감정 점진적 묘사

### 잘못된 예시 (감정 점프)
```
10장: 임천이 기분 좋게 사형과 농담.
11장: 임천이 사존 살해 소식 듣고, 극도로 분노, 복수 맹세!
```
**문제**: 너무 갑작스럽고, 복선 없음

### 올바른 예시 (점진적)
```
10장: 임천이 사존의 최근 행적이 수상하다고 느끼며, 약간 걱정.
11장: 사존이 외출 전 후사를 부탁하고, 임천 마음이 불안.
12장: 임천이 사존의 위험 소식을 듣고, 급히 달려감.
13장: 임천이 도착했을 때, 사존은 이미 사망, 비통+분노 폭발!
```
