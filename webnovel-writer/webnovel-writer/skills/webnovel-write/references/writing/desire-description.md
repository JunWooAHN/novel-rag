<context>
이 파일은 욕망 묘사 참고용입니다. 핵심 원칙: 감각적 진실성 + 감정 층위감 + 문학적 승화 + 건강한 방향. 감각 묘사는 감정 표현을 위해 봉사하며, 암시와 여백이 직설적 묘사보다 낫습니다.
</context>

<instructions>

## 1. 핵심 원칙

```
감각 묘사는 감정 표현을 위해 봉사
줄거리 추진이 감각적 자극보다 우선
문학적 아름다움과 감각적 체험의 균형
암시와 여백이 직설적 묘사보다 나음
```

**척도 조절**:
```
암시 > 묘사
감정 > 감각
아름다움 > 자극
```

## 2. 오감 기초

### 촉각 묘사
| 층위 | 묘사 중점 | 예시 어휘 |
|------|----------|----------|
| 온도 | 냉열 감지 | 뜨거운, 차가운, 온열 |
| 질감 | 거칠고 매끄러움 | 실크 같은, 거친, 부드러운 |
| 압력 | 경중 완급 | 가볍게 쓸다, 꽉 쥐다, 눌리다 |
| 전류감 | 감전 같은 | 저린, 전율, 떨림 |

### 후각 묘사
| 유형 | 감정 연관 | 예시 |
|------|----------|------|
| 체향 | 친밀, 익숙함 | 은은한 향기 |
| 기식 | 존재감 | 온열한 호흡 |
| 환경향 | 분위기 조성 | 단향, 꽃향 |

### 청각 묘사
| 유형 | 효과 | 예시 |
|------|------|------|
| 호흡소리 | 감정 변화 | 급촉, 안정, 떨림 |
| 심장소리 | 내면 상태 | 쿵쿵 뜀, 한 박자 건너뜀 |
| 속삭임 | 친밀감 | 귓가에서 나지막이 |
| 환경음 | 분위기 | 빗소리, 바람소리 |

### 시각 묘사
| 초점 | 묘사 중점 | 기법 |
|------|----------|------|
| 눈빛 | 감정 전달 | 깊은, 몽롱한, 뜨거운 |
| 표정 | 감정 변화 | 살짝 붉어진, 떨리는, 입술 깨무는 |
| 동작 | 상태 표현 | 미세한 떨림, 경직, 이완 |
| 광영 | 분위기 조성 | 어둑한, 몽롱한, 얼룩진 |

### 미각 묘사
| 유형 | 은유 의미 | 예시 |
|------|----------|------|
| 단 | 행복, 만족 | 달콤한 느낌 |
| 쓴 | 씁쓸함, 아쉬움 | 씁쓸한 눈물 |
| 짠 | 눈물, 땀 | 짠 맛 |

## 3. 감각 교직

### 교직 패턴
| 패턴 | 특징 | 적합 장면 |
|------|------|----------|
| 병렬식 | 다감각 동시 표현 | 장면 전면 표현 |
| 점진식 | 감각 강도 점진적 상승 | 감정 발전 |
| 대비식 | 감각이 대비 형성 | 긴장감 조성 |
| 통감식 | 감각 혼합 융합 | 시적 표현 |

### 감각 배합 전략
```
시각 + 촉각 → 현장감
후각 + 청각 → 환경감
미각 + 촉각 → 친밀감
시각 + 청각 → 영화감
후각 + 촉각 → 사적감
```

### 감각 주부 배분
- 주도 감각 확정 (1-2종)
- 보조 감각으로 점경
- 감각 과부하 방지
- 리듬 변화 유지

## 4. 욕망 층위

```
표층 끌림 (외적 매력)
    ↓
중층 갈망 (감정적 필요)
    ↓
심층 욕망 (본능적 추동)
```

### 욕망 표현 방식
| 방식 | 설명 | 효과 |
|------|------|------|
| 신체 반응 | 생리 변화 | 현실감 |
| 심리 활동 | 내면 독백 | 몰입감 |
| 행동 암시 | 동작 디테일 | 함축미 |
| 환경 투영 | 환경 호응 | 분위기감 |

### 욕망 억제 기법
```
가까이 다가가고 싶다 → 하지만 거리를 유지
닿고 싶다 → 하지만 손을 거두다
말하고 싶다 → 하지만 침묵
```

---

## 5. 분위기 조성

### 분위기 요소
| 요소 | 작용 | 기법 |
|------|------|------|
| 조명 | 기조 설정 | 어둑한, 몽롱한, 부드러운 |
| 공간 | 사적감 | 폐쇄적, 좁은, 단독 |
| 시간 | 특수성 | 심야, 황혼, 비 오는 날 |
| 소리 | 환경감 | 적막, 빗소리, 음악 |

### 분위기 점진
```
일상 분위기 → 애매한 분위기 → 긴장 분위기 → 클라이맥스 분위기 → 여운 분위기
```

### 분위기와 감정 대응
| 분위기 | 감정 | 묘사 중점 |
|------|------|----------|
| 온화 | 안심, 의존 | 따뜻함, 부드러움 |
| 애매함 | 설렘, 기대 | 가까우면서 먼 듯 |
| 긴장 | 갈망, 억제 | 호흡, 심장 박동 |
| 뜨거움 | 해방, 탐닉 | 감각 폭발 |

---

## 6. 리듬 조절

### 감정 리듬 곡선
```
평온 → 파동 → 상승 → 클라이맥스 → 여운
```

### 리듬 조절 기법
| 단계 | 리듬 | 묘사 중점 |
|------|------|----------|
| 복선기 | 느림 | 분위기, 암시 |
| 발전기 | 점점 빠르게 | 감각 점진 |
| 절정기 | 빠름 | 감각 폭발 |
| 수렴기 | 느림 | 여운, 회미 |

### 문형 리듬
```
긴 문장 → 완만, 섬세
단문 → 긴장, 급촉
끊어진 문장 → 강조, 폭발
```

## 7. 은유와 여백

### 자주 쓰는 은유
| 본체 | 유체 | 효과 |
|------|------|------|
| 욕망 | 화염 | 뜨거운, 타오르는 |
| 갈망 | 조수 | 밀려오는, 삼키는 |
| 억제 | 얼음 | 냉각, 억압 |
| 해방 | 둑 터짐 | 폭발, 통제 불능 |

### 여백 기법
```
❌ 과정 직접 묘사
✅ 전주 묘사 + 생략부호 + 여운 묘사
```

### 암시 수법
- 동작 암시: 손가락 미세한 떨림, 호흡 급촉
- 환경 암시: 커튼 흔들림, 촛불 흔들림
- 대화 암시: 말하다 멈춤, 말 속에 뜻이 있음
- 시간 암시: 얼마나 지났는지 모르겠다

## 8. 심리 배합

### 심리 묘사 층위
```
표층 의식 (무엇을 생각하는가)
    ↓
감정 파동 (무엇을 느끼는가)
    ↓
본능 반응 (신체 반응)
```

### 심리와 감각 배합
| 감각 | 심리 반응 | 예시 |
|------|----------|------|
| 촉각 | 전율, 긴장 | 닿을 때 심장 박동 가속 |
| 후각 | 도취, 미혹 | 체향에 둘러싸여 |
| 청각 | 민감, 기대 | 호흡소리가 들리면 |
| 시각 | 설렘, 갈망 | 시선이 교차 |

### 내면 독백 기법
```
❌ "그녀는 매우 설레었다"
✅ "심장 소리가 그도 들을 수 있을 만큼 크게 느껴졌다"
```

---

## 9. 장면 적용

### 첫 설렘
```
감각: 시각 위주
심리: 호기심, 긴장
리듬: 느림, 섬세
중점: 눈빛, 작은 동작
```

### 애매한 밀당
```
감각: 촉각+후각
심리: 기대, 억제
리듬: 빠르다 느리다
중점: 가까우면서 먼 듯
```

### 감정 확인
```
감각: 다감각 교직
심리: 확신, 만족
리듬: 점진으로 클라이맥스
중점: 감정 해방
```

### 이별 그리움
```
감각: 후각+촉각 회상
심리: 서운함, 갈망
리듬: 느림, 무거움
중점: 감각 기억
```
