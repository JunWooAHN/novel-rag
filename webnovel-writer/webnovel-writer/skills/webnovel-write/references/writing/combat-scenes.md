## 1. 5단계 구조

| 단계 | 분량 | 내용 | 리듬 |
|------|------|------|------|
| 기수 | 15-20% | 대치 탐색, 환경 분위기, 심리 구도 | 느림 |
| 탐색 | 20-25% | 초기 교전, 실력 탐색, 능력 과시 | 점점 빠르게 |
| 갈등 상승 | 30-40% | 본격 교전, 비장의 카드 공개, 전황 변화 | 빠름 |

## 2. 리듬 변화 조절

**빠른 리듬 (격렬한 교전)**: 단문 + 동작 밀집 + 빠른 전환
```
소염이 움직였다.
한 주먹.
왕호가 세 걸음 물러섰다.
또 한 주먹.
흉골이 부서지는 소리.
```

**느린 리듬 (대치 축적)**: 긴 문장 + 디테일 묘사 + 심리 활동
```
소염이 깊이 숨을 들이쉬고, 체내 투기의 흐름을 느꼈다. 그는 알고 있었다, 다음 이 일격이 모든 것을 결정할 것임을. 맞은편의 왕호도 마찬가지로 축적 중이었고, 공기 중에는 숨 막히는 압박감이 감돌았다.
```

**리듬 변화 곡선**:
```
느림(대치) → 빠름(교전) → 느림(숨고르기) → 빠름(폭발) → 느림(종료)
```

## 3. 화면 전환 기법

| 앵글 | 묘사 중점 | 적합 장면 |
|------|----------|----------|
| 원경 | 전체 전투 화면, 전장 전경, 세력 비교 | 오프닝, 대규모 전투 |
| 근경 | 상세 동작과 표정, 미세 표정, 근육 긴장 | 핵심 동작, 감정 표현 |
| 클로즈업 | 핵심 순간 확대 (주먹 접촉, 무기 충돌) | 결정적 순간 |

**전환 예시**:
```
【원경】두 도영이 산정상에서 대치, 광풍이 울부짖었다.
【근경】소염의 눈에 한 줄기 정광이 스쳤고, 입꼬리가 미세하게 올라갔다.
【클로즈업】그의 주먹이 꽉 쥐어지고, 손가락 관절이 하얗게 변했다.
【원경】다음 순간, 두 도영이 동시에 사라지고, 산정상에 거대한 구덩이가 폭발했다.
```

## 4. 감각 묘사

| 감각 | 묘사 중점 | 예시 |
|------|----------|------|
| 시각 | 동작 궤적, 특수효과 광망, 환경 변화 | 검광이 용처럼, 화염이 치솟고 |
| 청각 | 권풍 울부짖음, 무기 충돌, 뼈 부러짐 | "딱" 하고 날카로운 소리 |
| 촉각 | 주먹 충격, 통증 전달, 기파 충격 | 뼈가 부서지는 진동 |
| 후각 | 혈비린내, 탄내, 땀 냄새 | 공기 중에 혈비린내가 감돌고 |

**종합 예시**:
```
주먹이 왕호의 가슴에 꽂히는 순간, 소염은 뼈가 부서지는 진동을 느꼈다【촉각】.
"딱" 하고 날카로운 소리【청각】, 왕호의 몸이 끊어진 연처럼 날아갔다【시각】.
공기 중에 옅은 혈비린내가 감돌았다【후각】.
```

## 5. 심리 묘사 배합

**전투 심리 변화 곡선**:
```
자신감 → 경계 → 경악 → 공포 → 절망
또는
긴장 → 침착 → 흥분 → 광열 → 만족
```

**내면 독백 시점**:
- 핵심 결정 전
- 상대의 비장의 카드 발견 시
- 비장의 카드 사용 전
- 승패가 갈린 후

**심리 묘사 예시**:
```
"불가능해!" 왕호 마음속에 크게 놀랐다, "그는 분명 투자인데, 어떻게 이런 힘이 가능하지?"
공포가 파도처럼 밀려왔고, 그는 처음으로 이 "폐물"을 건드린 것을 후회했다.
```

## 6. 관중 반응 (필수)

행인 반응을 통해 주인공의 대단함을 부각시키고, 쾌감을 강화:

```
전장이 경악했다.
"이... 이게 어떻게 가능해!"
"그가 설마 일격에..."
모두가 서로 쳐다보며, 눈에 불신이 가득했다.
```

**관중 반응 유형**:
- 경악형: 동공 수축, 턱이 떨어짐
- 공포형: 물러남, 식은땀, 다리 풀림
- 숭배형: 눈이 빛남, 환호
- 질투형: 얼굴이 시퍼레짐, 이를 악뭄

---

## 7. 전투 유형 템플릿

**1v1 결투**: 대치 → 탐색 → 교전 → 비장의 카드 → 결승

**군전 혼전**: 전경 → 주인공 포커스 → 조연 교차 → 핵심 전환점 → 수렴

**월급 도전**: 압도당함 → 발버둥 → 전기 → 폭발 → 역전

**팀 협동**: 분업 → 호흡 → 위기 → 암묵적 이해 → 승리
