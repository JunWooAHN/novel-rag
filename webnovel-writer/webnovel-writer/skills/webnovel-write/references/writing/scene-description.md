## 1. 오감 층위

### 시각 (가장 중요)
- 동작: 궤적, 속도, 힘
- 특수효과: 광망, 색채, 형태
- 환경: 변화, 파괴, 분위기
- 표정: 미세 표정, 눈빛, 자세

### 청각
- 소리: 대화, 호흡, 심장 박동
- 음향: 충돌, 파쇄, 바람소리
- 침묵: 소리 없는 압박감
- 어조: 말투, 리듬, 감정

### 촉각
- 온도: 뜨거움, 차가움, 따뜻함, 서늘함
- 힘: 가벼운, 무거운, 팽팽한, 느슨한
- 질감: 매끄러운, 거친, 부드러운, 딱딱한
- 동태: 정지, 이동, 떨림

### 후각
- 체향: 신분 표시, 매력 전달
- 기식: 호흡, 체온이 실어오는 향
- 환경: 장면 냄새, 분위기 조성
- 변화: 연한 데서 진한 데로 감정 발전 암시

### 미각
- 직접: 음식, 음료
- 은유: 씁쓸한, 달콤한, 신
- 감정: 미각으로 정서 표현

## 2. 감각 교직 방법

### 병렬식
다감각 동시 표현, 풍부함 증대
```
그의 손가락이 그녀의 볼을 스쳤고【촉각】,
은은한 담배 향이 풍겼고【후각】,
그녀는 자기 심장이 빨라지는 소리를 들었다【청각】.
```

### 점진식
감각 강도 점진적 상승, 감정 클라이맥스 추진
```
먼저 있는 듯 없는 듯한 향기【후각 약】,
그다음 손끝의 가벼운 접촉【촉각 중】,
마지막으로 뜨거운 숨결이 귓가에 뿌려졌다【촉각+청각 강】.
```

### 대비식
다른 감각이 대비를 이루어 층위감 증대
```
밖은 뼈를 에는 찬바람【촉각 차】,
그의 품은 봄처럼 따뜻했다【촉각 온】.
```

## 3. 장면 유형별 감각 중점

| 장면 유형 | 주감각 | 중점 |
|----------|--------|------|
| 전투 장면 | 시각+청각+촉각 | 동작 궤적, 충돌음, 충격감 |
| 감정 장면 | 촉각+후각+청각 | 피부 접촉, 체향, 호흡 심장 박동 |
| 환경 장면 | 시각+청각+후각 | 풍경 광영, 환경음, 장면 냄새 |
| 미식 장면 | 미각+후각+시각 | 식감 맛, 향기 열기, 색택 담음 |
| 공포 장면 | 청각+촉각+시각 | 기이한 소리, 음침한 촉감, 어두운 광영 |

## 4. 감각 묘사 기법

### 구체화
```
❌ 그녀는 향기로웠다.
✅ 그녀 몸에서 은은한 치자꽃 향이 났고, 햇살에 말린 듯 따뜻한 기운이 섞여 있었다.
```

### 동태화
```
❌ 그의 손이 따뜻했다.
✅ 그의 손끝이 그녀의 손등을 스쳤고, 한 줄기 온열한 자취를 남겼다.
```

### 감정화
```
❌ 바람이 차다.
✅ 찬바람이 칼처럼 얼굴을 베었고, 그녀가 떠날 때의 눈빛처럼 차가웠다.
```

### 대비화
```
그녀의 입술은 차가웠지만, 입맞춤은 숨이 멎을 만큼 뜨거웠다.
```

## 5. 생리 반응 묘사

| 감정 | 생리 반응 |
|------|----------|
| 설렘 | 심장 한 박자 건너뜀/가속, 호흡 급촉/멈춤, 귀 발열/얼굴 붉어짐, 손바닥 땀 |
| 긴장 | 근육 긴장, 목구멍 건조, 동공 수축, 손가락 떨림 |
| 공포 | 솜털 곤두섬, 등골 서늘, 다리 풀림, 심장 박동 북소리 같음 |
| 분노 | 피가 솟구침, 관자놀이 뜀, 주먹 꽉 쥐어짐, 이를 악뭄 |

## 6. 환경 분위기 조성

### 광영 운용
```
햇빛 → 따뜻함, 희망
그림자 → 억압, 위험
달빛 → 로맨스, 신비
촛불 → 애매함, 온화
```

### 날씨 운용
```
맑은 날 → 명랑, 적극적
비 오는 날 → 우울, 전환점
눈 오는 날 → 순결, 냉혹
안개 → 방황, 신비
```

### 소리 운용
```
적막 → 압박, 긴장
시끌벅적 → 혼란, 활기
자연 소리 → 평온, 치유
기계 소리 → 냉막, 현대
```

## 7. 장면 묘사의 "정도"

| 장면 유형 | 글자 수 권장 | 예시 키워드 |
|----------|----------|------------|
| 새 맵 첫 진입 | 50-150자 | 핵심 특징 3-5문장 |
| 특수 분위기 조성 | 30-80자 | 공포/긴장/온화 |
| 전투 장면 | 거의 묘사 안 함 | 환경이 전투에 영향 주지 않는 한 |
| 전환 장면 | 10-30자 | 간단 설명 |

**장면 유형 속찰표**:

| 유형 | 묘사 중점 | 키워드 |
|------|----------|--------|
| 종문/학원 | 건축, 인원, 분위기 | 산봉우리, 궁전, 제자, 영기 |
| 비경/유적 | 신비, 위험 | 석문, 부문, 금제, 기관 |
| 전장 | 혼란, 피비린내 | 시체, 선혈, 함성 |
| 시장 | 활기, 생활 기운 | 인파, 호객, 상점 |
| 밀실/동굴 | 억압, 폐쇄 | 어둑한, 습한, 음침한 |
| 궁전/호화 저택 | 호화, 권력 | 금벽휘황, 호위, 진보 |

## 8. 동정 결합

### 정적 묘사 (지루)
```
산봉우리가 높고, 나무가 푸르고, 하늘이 파랗다.
```

### 동적 묘사 (생동)
```
산봉우리가 구름을 뚫고 솟아 있고, 산바람이 울부짖으며 불어 온 하늘 낙엽을 날렸다. 수풀 깊은 곳에서 짐승 울음이 전해오고, 영조 몇 마리가 놀라 날아올라, 날개를 퍼덕이는 사이 깃털이 눈처럼 떨어졌다.
```

**기법**: 동사 추가 (울부짖다, 휩쓸다, 전해오다, 날아오르다, 퍼덕이다, 떨어지다)

## 9. 인물과 장면 상호작용

### 잘못된 예시 (분리)
```
【장면】방이 어둡고, 촛불 하나만 있었다.
【인물】임천이 들어왔다.
```

### 올바른 예시 (융합)
```
임천이 문을 밀었고, 방 안은 어둠투성이였으며, 탁자 위의 촛불 하나만 미약한 빛을 흔들고 있었다.
그는 눈을 가늘게 뜨고, 촛불 빛을 빌려 사방을 둘러보았다——낡은 탁자와 의자, 먼지가 잔뜩 쌓인 책장, 모서리의 거미줄……
"오랫동안 사람이 살지 않았군." 그가 미간을 찌푸렸다.
```
