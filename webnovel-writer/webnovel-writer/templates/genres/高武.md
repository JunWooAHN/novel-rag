# 고무 장르 템플릿 (High Martial Arts)

> **핵심 셀링포인트**: 무도 정점 + 열혈 전투 + 실력이 최고. 주먹이 곧 도리이며, 강자가 규칙을 정한다.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack M21
- 범용 중첩: Pack U03

## 1. 핵심 유파 세분화

### 전민 고무류
- **특징**: 영기 부활, 전민 무도, 무도가 주류가 됨
- **핵심 쾌감**: 무도 돌파, 랭킹 상승, 국전 영광
- **대표작**: 《전구고무》《아유일검》《만족지겁》

### 무도 종사류
- **특징**: 전통 무술, 종사 경계, 무학 전승
- **핵심 쾌감**: 무학 돌파, 문파 쟁패, 무림 맹주
- **대표작**: 《용사연의》《국술종사》

### 격투 경기류
- **특징**: 무대 비무, 프로 격투, 열혈 대결
- **핵심 쾌감**: 무대 승리, 기술 향상, 챔피언 영광
- **대표작**: 《권진산하》《전직고수》

### 무도 수진류
- **특징**: 무도와 수진 결합, 무로 도에 입문
- **핵심 쾌감**: 무도 경계, 육신 성성, 무쇄허공
- **대표작**: 《차천》《완미세계》《성허》

## 2. 세계관: 고무 사회학

### 무도 지위
- **은밀기**: 무자가 숨고, 일반인은 모름
- **공개기**: 무도 공개, 직업이 됨
- **주류기**: 무도가 사회 핵심, 무자 지위 숭고

### 사회 구조
| 계층 | 특징 | 권력 |
|------|------|------|
| 무성 | 일국의 힘 | 초연한 지위 |
| 종사 | 진국 전력 | 국사급 |
| 대사 | 일성의 힘 | 고위층 |
| 고수 | 엘리트 전력 | 중간층 |
| 무자 | 기초 전력 | 보통 |
| 일반인 | 무력 없음 | 하층 |

### 세력 구도
- **국가 무도부**: 관방 무자 조직
- **무도 세가**: 전승 유구한 무학 가문
- **무관/도장**: 무학 전수 기관
- **지하 세력**: 암시장, 킬러 조직
- **이족/요수**: 인류의 적

## 3. 무도 체계 설계

### 경계 구분 (표준판)
| 경계 | 특징 | 전투력 |
|------|------|------|
| 명경 | 힘 외방 | 1대10 |
| 암경 | 힘 내렴 | 1대100 |
| 화경 | 힘 화허 | 1대1000 |
| 종사 | 영역 초성 | 1대만 |
| 대종사 | 영역 대성 | 일성의 힘 |
| 무성 | 무도 극치 | 일국의 힘 |

### 무학 분류
| 유형 | 특징 | 대표 |
|------|------|------|
| 외공 | 육신 강화 | 금종조, 철포삼 |
| 내공 | 내력 수련 | 구양신공 |
| 권법 | 근접 격투 | 형의권, 팔극권 |
| 각법 | 다리 공격 | 담퇴, 척각 |
| 병기 | 무기 기법 | 검법, 도법 |
| 경공 | 신법 속도 | 능파미보 |

### 무도 자원
- **무학 비적**: 공법 전승
- **단약**: 체질 강화, 치유
- **천재지보**: 병목 돌파
- **무기**: 신병이기

## 4. 클래식 쾌감 루틴

### 무대 압도
- **장면**: 정식 비무, 모든 이의 주시
- **쾌감**: 일초로 제압, 전장 놀라게 함
- **핵심**: 충분한 복선과 적수 묘사 필요

### 무학 돌파
- **장면**: 생사의 기로/폐관 수련
- **쾌감**: 경계 돌파, 실력 급상승
- **핵심**: 돌파에 축적 필요, 갑자기 불가

### 무력으로 복종시키기
- **장면**: 깔보는 사람에게 실력으로 증명
- **쾌감**: 주먹이 곧 도리, 모든 사람을 때려서 복종시킴
- **핵심**: 무뇌 때리기 안 되고, 절제 필요

### 국전 영광
- **장면**: 국가 대표로 출전
- **쾌감**: 나라를 위해 영광, 민족 자부심
- **핵심**: 가국 정취 복선 필요

## 5. 대강 구조 (200만 자 표준)

### 1권: 입문 (1-80장)
- **핵심**: 주인공 무도 천부 각성
- **맵**: 도시/무관
- **클라이맥스**: 첫 천부 발휘, 동급 강적 격파

### 2권: 굴기 (81-180장)
- **핵심**: 무도 조직 합류, 대회 참가
- **맵**: 성급/전국
- **클라이맥스**: 중요 대회 챔피언 획득

### 3권: 성명 (181-350장)
- **핵심**: 유명 무자가 됨
- **맵**: 전국 범위
- **클라이맥스**: 종사 돌파, 무림 진동

### 4권: 쟁패 (351-550장)
- **핵심**: 국제 경쟁 참여
- **맵**: 국제 범위
- **클라이맥스**: 국전 승리, 국위 선양

### 5권: 정점 (551-700장)
- **핵심**: 무도 극치 추구
- **맵**: 전구/이계
- **클라이맥스**: 무도 정점 도달

## 6. 전투 설계

### 전투 리듬
```
시험 단계 (20%):
- 양측 시험, 기초 실력 시연
- 관중/해설이 양측 배경 소개

교봉 단계 (40%):
- 정식 교전, 초식 대결
- 무학 특징 시연

클라이맥스 단계 (30%):
- 절초 대결
- 뜻밖의 반전

종결 단계 (10%):
- 승부 분명
- 후속 영향
```

### 전투 묘사 요점
- **초식 명칭**: 무협감 필요
- **힘 비교**: 구체적 묘사 필요
- **환경 상호작용**: 전투가 환경에 미치는 영향
- **심리 묘사**: 양측의 심리 변화
