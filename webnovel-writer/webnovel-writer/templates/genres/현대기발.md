# 현대 로맨스 브레인홀 장르 템플릿 (Modern Romance Brainwave)

> **핵심 셀링포인트**: 현실 관계 + 규칙/이상현상 + 감정 반전. 초자연적 규칙이 현대 사랑에 침입할 때, 감정과 규칙은 어떻게 공존하는가?

## 1. 핵심 유파 세분화

### 규칙 연애류
- **특징**: 연애가 어떤 규칙의 제약을 받음
- **핵심 쾌감**: 규칙 이용, 규칙 돌파, 진심이 규칙을 이김
- **대표작**: 《결혼부터 시작하는 연애》《친애적소해》《아적전반생》

### 계약 인연류
- **특징**: 계약/거래로 시작하는 감정
- **핵심 쾌감**: 가짜가 진짜가 됨, 계약 반전, 진심 드러남
- **대표작**: 《하이생소묵》《삼삼래료》《미미일소흔경성》

### 환생 복수류
- **특징**: 환생 후 운명을 바꾸고, 진짜 사랑 획득
- **핵심 쾌감**: 함정 회피 기회 포착, 복수 성공, 진짜 사랑 함께
- **대표작**: 《환생지명류거성》《서녀공략》《환생지적녀화비》

### 이능 연애류
- **특징**: 특수 능력을 가진 현대 사랑
- **핵심 쾌감**: 능력 어시스트, 신분 비밀, 능력과 사랑
- **대표작**: 《독심》《타임》《전생슬라임》

## 2. 세계관: 현대 로맨스 브레인홀 사회학

### 규칙 유형
| 유형 | 특징 | 감정 영향 |
|------|------|-----------|
| 계약 규칙 | 명확한 약정 | 행동 제한 |
| 시스템 규칙 | 시스템 강제 | 임무 구동 |
| 초자연 규칙 | 신비한 힘 | 운명 견인 |
| 사회 규칙 | 현실 압력 | 외부 장애 |

### 능력 유형
| 능력 | 특징 | 감정에 대한 작용 |
|------|------|-----------|
| 독심 | 상대 생각을 앎 | 진심 파악 |
| 예지 | 미래를 앎 | 비극 회피 |
| 시간 | 시간 조종 | 유감 보상 |
| 환생 | 다시 한번 | 운명 변경 |

### 관계 단계
| 단계 | 특징 | 규칙 작용 |
|------|------|----------|
| 만남 | 운명 배치 | 규칙 발동 |
| 서로 알기 | 점차 이해 | 규칙 제한 |
| 시련 | 규칙 충돌 | 선택 결단 |
| 돌파 | 규칙 깨뜨리기 | 진심 승리 |

## 3. 규칙과 감정 설계

### 규칙 설계 원칙
```
감정과 관련:
- 규칙이 감정 발전에 영향
- 규칙이 감정 갈등을 조성
- 규칙이 진심을 시험

허점 이용 가능:
- 진심으로 돌파 가능
- 특정 조건으로 해제 가능
- 대가가 감당 가능

명확한 대가:
- 위반에 처벌
- 돌파에 대가
- 선택에 취사
```

### 감정과 규칙의 충돌
| 충돌 유형 | 표현 | 해결 방식 |
|----------|------|----------|
| 규칙 금지 | 함께할 수 없음 | 규칙 깨뜨리기 |
| 규칙 강제 | 반드시 헤어져야 함 | 허점 찾기 |
| 규칙 시험 | 선택 문제 | 진심 증명 |
| 규칙 대가 | 함께하면 대가 | 기꺼이 감수 |

### 대가 시스템
| 대가 유형 | 특징 | 감정적 의미 |
|----------|------|----------|
| 기억 대가 | 상대를 잊음 | 가슴 아픔 |
| 능력 대가 | 능력 상실 | 희생 |
| 신분 대가 | 신분 변경 | 선택 |
| 시간 대가 | 시간 상실 | 소중히 여기기 |

## 4. 클래식 쾌감 루틴

### 규칙 돌파
- **장면**: 진심으로 규칙 제한을 깨뜨림
- **쾌감**: 사랑이 모든 것을 이김
- **핵심**: 충분한 감정 복선 필요

### 신분 폭로
- **장면**: 숨겨진 신분/능력이 폭로
- **쾌감**: 반전 서프라이즈, 모두 때리기
- **핵심**: 복선이 있어야 함

### 운명 고쳐 쓰기
- **장면**: 원래의 비극적 운명을 바꿈
- **쾌감**: 비극 회피, 행복 획득
- **핵심**: 대비가 있어야 함

### 진심 증명
- **장면**: 시험을 통해 진심을 증명
- **쾌감**: 감동, 달콤, 원만
- **핵심**: 시험에 의미가 있어야 함

## 5. 대강 구조 (80만 자 표준)

### 1권: 만남 (1-50장)
- **핵심**: 규칙/능력으로 인해 만남
- **관계**: 낯선 사이→서로 앎
- **클라이맥스**: 규칙/능력 발견

### 2권: 서로 알기 (51-120장)
- **핵심**: 규칙 하에서 함께 지냄
- **관계**: 서로 앎→미묘
- **클라이맥스**: 마음 확인

### 3권: 시련 (121-200장)
- **핵심**: 규칙과 감정 충돌
- **관계**: 미묘→위기
- **클라이맥스**: 선택에 직면

### 4권: 돌파 (201-280장)
- **핵심**: 규칙을 깨고, 진심 선택
- **관계**: 위기→확정
- **클라이맥스**: 규칙 돌파

### 5권: 원만 (281-350장)
- **핵심**: 사랑하는 사람이 마침내 짝이 됨
- **관계**: 확정→영원
- **클라이맥스**: 원만한 결말

## 7. 현실과 브레인홀 균형

### 현실 기반
```
사실감 유지:
- 현대 도시 배경
- 사실적 인간관계
- 합리적 사회 규칙

브레인홀 요소:
- 초자연 규칙
- 특수 능력
- 운명 배치
```

### 감정 사실성
| 방면 | 요점 | 지뢰 |
|------|------|------|
| 감정 발전 | 점진적 | 너무 빠르고 갑작스러움 |
| 인물 반응 | 성격에 부합 | 스토리를 위해 봉사 |
| 갈등 해결 | 합리적이고 신뢰 가능 | 너무 우연 |
| 결말 | 복선 있음 | 억지 HE |

### 규칙과 일상의 융합
- 규칙이 일상 생활에 융합되어야 함
- 능력에 사용 제한이 있어야 함
- 초자연 요소에 설명이 있어야 함
