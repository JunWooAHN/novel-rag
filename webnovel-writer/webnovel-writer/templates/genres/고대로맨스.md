# 고대 로맨스 장르 템플릿 (Period Drama / Historical Romance)

> **핵심 셀링포인트**: 고풍 운치 + 권모 다툼 + 정 깊은 인연. 가공 또는 실제 역사 배경 아래, 사랑과 미움 그리고 권력 투쟁을 전개한다.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack F01 / Pack F18
- 범용 중첩: Pack U01

## 1. 핵심 유파 세분화

### 궁투류
- **특징**: 후궁 총애 다툼, 한 걸음씩 경영, 심기 게임
- **핵심 쾌감**: 비빈들과 지략 대결, 성총 획득, 단계적 승진
- **대표 패턴**: 궁녀/하위 비빈 → 총비/황후

### 택투류
- **특징**: 대가문 내부 다툼, 시모며느리, 살림 쟁권
- **핵심 쾌감**: 악독한 시어머니 제압, 살림 권한 장악, 부부 일심
- **대표 패턴**: 새색시 → 안살림 주인

### 권모류
- **특징**: 조정 게임, 가국천하, 지모 대결
- **핵심 쾌감**: 전략 수립, 풍운을 뒤집기, 청사에 이름을 남김
- **대표 패턴**: 정투에 휘말림 → 조정을 좌우함

### 달콤류
- **특징**: 달콤함 위주, 권모는 보조, 당분 폭발
- **핵심 쾌감**: 남주 독점 총애, 모두의 부러움, 달콤한 일상
- **대표 패턴**: 만남 → 알아감 → 사랑 → HE

## 2. 클래식 스토리 프레임워크

### 궁투 프레임워크
```
입궁 → 안착 → 총애 다툼 → 위기 → 정상/퇴출

상세 단계:
1. 입궁 (선수/사혼/가문 배치)
2. 후궁 초입 (괴롭힘/배경 찾기)
3. 성총 획득 (재예/성격/기연)
4. 적 만들기 (황후/총비의 억압)
5. 단계적 승진 (품계 상승/출산)
6. 중대 위기 (모함/실총)
7. 절지반격 (진상 폭로/역전)
8. 최종 결말 (황후 등극/이궁/제후 화합)
```

### 택투 프레임워크
```
시집감 → 발판 → 살림 장악 → 위기 → 안살림 주인

상세 단계:
1. 시집감 (높은 혼사/낮은 혼사/충희)
2. 시모와의 대결 (규칙 세우기/트집잡히기)
3. 형수동서 다툼 (자원/총애 다툼)
4. 남편 관계 (냉담/점차 열기/오해)
5. 살림권 쟁탈
6. 가문 위기 (가산몰수/몰락)
7. 위기극복
8. 안살림 주인이 됨
```

### 권모 프레임워크
```
휘말림 → 편 선택 → 게임 → 결전 → 새 국면

상세 단계:
1. 정치 소용돌이에 휘말림
2. 진영 선택/강제 편 가르기
3. 모략 참여
4. 다자 게임
5. 핵심 정보/전환점
6. 최종 결전
7. 새로운 국면
```

## 3. 대강 구조 (100만 자 표준)

### 1권: 궁/대저택 초입 (1-80장, 20%)
- **오프닝**: 입궁/출가의 계기
- **인물 등장**: 주요 세력, 핵심 조연
- **핵심 과제**: 발판 확보, 환경 파악
- **소클라이맥스**: 첫 번째 위기 해결

### 2권: 한 걸음씩 (81-180장, 25%)
- **세력 포석**: 동맹 포섭, 적 대응
- **감정 발전**: 남주와 관계 진전
- **핵심 갈등**: 주요 적수와 첫 교봉
- **클라이맥스**: 단계적 승리 획득

### 3권: 풍운변환 (181-300장, 30%)
- **스케일 확대**: 더 높은 차원의 게임
- **위기 심화**: 모함/실총/가문 연루
- **가장 어두운 순간**: 바닥까지 추락
- **전환점**: 핵심 조력 등장

### 4권: 절지반격 (301-380장, 20%)
- **반격 포석**: 증거 수집, 동맹 연합
- **진상 폭로**: 막후 흑수 드러남
- **최종 대결**: 정면 교봉
- **청산**: 원수 처벌

### 5권: 원만한 결말 (381-420장, 15%)
- **뒷수습**: 새 국면 수립
- **감정 원만**: 남주와 HE
- **외전/일상**: 행복한 생활

## 4. 고풍 대화 규범

### 호칭 체계
```
황실:
- 황제: 황상, 폐하, 성상
- 황후: 황후 마마, 모후
- 비빈: X비 마마, 마마
- 황자: X 전하, 왕야

관료:
- 관원: 대인, X공
- 관원 아내: 부인, X씨
- 아가씨: X 고낭, X 소저

평민:
- 남자: 공자, X랑
- 여자: 고낭, X낭
```

### 상용 고풍 어휘
```
칭호:
- 나: 신첩, 첩신, 본궁, 노비, 소녀자
- 너: 너/여, 각하, 족하
- 그: 저 사람, 이 사람

동작:
- 보다: 봐, 바라보다, 살피다
- 말하다: 이르다, 말씀하다, 가로되
- 걷다: 행하다, 가다, 향하다
- 오다: 이르다, 임하다, 도착하다

묘사:
- 아름다움: 경성, 절색, 국색천향
- 영리함: 총혜, 기민, 영롱한 마음
- 화남: 노하다, 화내다, 뇌정진노
```

### 대화 예시
```markdown
【문안 인사】
"신첩이 황상께 문안드립니다. 황상 만복금안하소서."
그녀는 우아하게 절하며, 자태가 공손하면서도 비굴하지 않았다.

【대립】
"언니 이 말씀이, 여동생은 감히 받을 수 없사옵니다."
그녀는 입을 가리고 가볍게 웃었지만, 눈 속에는 한기가 가득했다.

【사랑 고백】
"이 천하, 짐은 필요 없소. 그대만은, 짐에게 없어선 안 되오."
그는 그녀를 품에 안으며, 목소리는 낮고 단호했다.
```

## 5. 클래식 브릿지 라이브러리

### 만남 브릿지
```
1. 목숨을 구해준 은혜: 그녀가 그를 구함 (신분 모름)
2. 무례: 실수로 귀인과 부딪힘
3. 경홍일별: 어떤 자리에서 한눈에 잊지 못함
4. 소꿉친구: 어린 시절 놀이친구 재회
5. 대신/사칭: 다른 사람 대신 시집감
```

### 총애 다툼 브릿지
```
1. 재예 경탄: 한 곡/한 춤/한 시로 모두를 놀래킴
2. 지혜로 곤경 해결: 위기 순간 지혜를 발휘
3. 구가 유공: 핵심 순간에 귀인을 구함
4. 물러섬으로 전진: 약한 척 동정을 사다
5. 힘을 빌려 반격: 상대의 수법을 이용해 반격
```

### 모함과 반전
```
모함 수단:
- 누명: 방에 금지품 놓기
- 무고: 증거 조작/매수 인증
- 독살: 다른 사람에게 누명 씌움
- 이간: 동맹/남주와의 관계 이간질

반전 수단:
- 증거: 핵심 물증 인증
- 동맹: 핵심 순간 증언
- 계략: 뱀을 굴에서 끌어내어, 상대가 꼬리를 드러내게 함
- 귀인: 더 높은 지위의 자가 비호
```

## 7. 역사 배경 속참

### 상용 가공 왕조 템플릿
```
성세 템플릿:
- 국력 강성, 문화 번영
- 적합: 궁투, 달콤류
- 참고: 당 성세, 청 강건

난세 템플릿:
- 전쟁 빈번, 권력 교체
- 적합: 권모, 가국
- 참고: 오대십국, 남북조

말세 템플릿:
- 왕조 쇠락, 내우외환
- 적합: 비극, 환생
- 참고: 명말, 청말
```
