# 규칙 괴담 장르 템플릿 (Rules Mystery / Honkaku)

> **핵심 셀링포인트**: 논리 추리 + 공정한 단서 + 지력 게임. 독자와 탐정이 같은 출발선에 서며, 진상은 반드시 추론 가능해야 한다.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack M14 / Pack M06
- 범용 중첩: Pack U02

## 1. 핵심 유파 세분화

### 본격 추리류
- **특징**: 순수 논리 추리, 밀실/트릭/알리바이
- **핵심 쾌감**: 해독 쾌감, 진상 밝혀짐, 범인 처벌
- **대표 패턴**: 사건 발생 → 조사 증거 수집 → 추리 폭로

### 규칙 괴담류
- **특징**: 도시전설, 기이한 규칙, 생존 해독
- **핵심 쾌감**: 규칙 발견, 규칙 이용, 탈출
- **대표 패턴**: 괴담 조우 → 규칙 발견 → 규칙 이용 탈출

### 서스펜스 스릴러류
- **특징**: 분위기 조성, 심리 공포, 계속되는 반전
- **핵심 쾌감**: 긴장 자극, 진상 충격, 여운 무궁
- **대표 패턴**: 서스펜스 개시 → 단계적 벗기기 → 충격 반전

### 사회파 추리류
- **특징**: 범죄 동기 탐구, 사회 문제 비판
- **핵심 쾌감**: 인성 깊이, 사회 반성, 감정 공감
- **대표 패턴**: 사건 이면 → 인성 발굴 → 사회 비판

## 2. 본격 추리 십계 (웹소설 적용판)

```
계율1: 범인은 반드시 스토리 초기에 등장
계율2: 초자연적 힘은 진상 설명에 사용 금지 (오도에는 사용 가능)
계율3: 밀실에 비밀 통로는 최대 1개
계율4: 미지의 독약이나 장황한 과학적 설명이 필요한 장치 사용 금지
계율5: 전혀 등장하지 않은 신비인물이 범인일 수 없음
계율6: 탐정은 우연이나 육감에 의존해 수사할 수 없음
계율7: 탐정 본인이 범인일 수 없음 (더블 탐정 설정 제외)
계율8: 탐정은 독자에게 모든 단서 공개 필수
계율9: 조수 (왓슨 역할)의 사고는 독자에게 투명해야 함
계율10: 쌍둥이/분신은 전기에 명시 필수
```

## 3. 4대 핵심 지주

### 지주1: 공정성 (Fair Play)
```
✅ 올바른 예:
제10장: 탐정이 꽃병 파편 발견 (독자도 동시에 봄)
제20장: 탐정이 추리 "꽃병은 내부에서 깨졌다"
→ 독자가 돌아가서 검증 가능

❌ 잘못된 예:
제10장: 탐정이 단서 하나 발견 (내용 미묘사)
제20장: 탐정이 "난 이미 핵심 증거를 발견했었어!"
→ 독자 검증 불가, 불공정
```

### 지주2: 논리성 (Logic)
```
논리 사슬 예시:

알려진 단서:
1. 사망자는 잠긴 방 안에
2. 창문은 내부에서 잠김
3. 사망자 손에 열쇠

추리 과정:
1. 사망자 손에 열쇠 → 본인이 잠갔을 가능성
2. 창문 내부 잠금 → 범인이 창문으로 탈출하지 않음
3. 방이 잠김 → 범인이 사망자가 잠그기 전에 이미 떠났을 가능성
4. 추정: 사망자가 문을 잠근 후 미리 방 안에 숨어있던 범인에게 살해
5. 검증: 방 안에 숨을 수 있는 장소 찾기
```

### 지주3: 해결 가능성 (Solvability)
```
단서 분포 원칙:
- 핵심 단서는 최소 3회 출현 (다른 형태)
- 레드 헤링(오도)은 진짜 단서 수를 초과 불가
- 폭로 전 반드시 "최후 힌트" (challenge to reader)
```

### 지주4: 의외성 (Surprise)
```
반전 계층:
Level 1: 범인 정체 반전
Level 2: 동기 반전
Level 3: 사건 본질 반전
Level 4: 서술자/시점 반전
```

## 4. 규칙 괴담 프레임워크

### 규칙 설계 원칙
```
1. 규칙에 내적 논리 필수
2. 규칙의 예외에 복선 필요
3. 규칙 이용 탈출은 합리적이어야 함
4. 규칙의 출처에 설명 필요 (신비해도 암시 필요)
```

### 규칙 괴담 구조
```
조우 단계 (20%):
- 주인공이 이상 환경에 진입
- 첫 번째 피해자/이상현상 발견
- "규칙 설명서" 획득 또는 구두 힌트

탐색 단계 (40%):
- 규칙 경계 시험
- 규칙 위반자 처벌 (시연)
- 점차 규칙 체계 이해

이용 단계 (30%):
- 규칙 허점 발견
- 탈출 계획 수립
- 실행 과정 중 돌발상황

결말 단계 (10%):
- 성공 탈출 또는 실패
- 규칙의 최종 설명
- 여운 (열린 암시)
```

### 규칙 예시
```markdown
【엘리베이터 규칙】
1. 자기가 가려는 층만 누를 수 있음
2. 엘리베이터 안에 사람이 있을 때 말하면 안 됨
3. 거울에 여분의 인영이 보이면, 즉시 눈 감기
4. 엘리베이터가 4층에 멈추면, 내리지 말 것

【규칙 이용】
- "말하면 안 됨"을 이용해 동료에게 위험 암시
- "거울"을 이용해 위장자 발견
- "4층 금지 구역"을 이용해 적을 유인
```

## 5. 대강 구조 (40만 자 표준)

### 1권: 사건 발생 (1-30장, 15%)
- **오프닝 훅**: 시체/이상현상/실종
- **주요 인물 등장**: 탐정, 용의자, 피해자 관계인
- **환경 설정**: 밀폐 공간/시간 제한/특수 규칙
- **첫 조사**: 기초 단서 수집

### 2권: 조사 (31-100장, 35%)
- **용의자 정리**: 각자의 동기, 기회, 알리바이
- **단서 축적**: 물증, 인증, 정보
- **오도 전개**: 레드 헤링 등장
- **소클라이맥스**: 두 번째 사건/새 발견

### 3권: 추리 (101-150장, 25%)
- **단서 통합**: 연관 분석
- **가설 검증**: 배제법/증실법
- **진상 접근**: 핵심 단서 부상
- **독자 도전**: 최후 힌트

### 4권: 폭로 (151-180장, 15%)
- **탐정 추리**: 완전한 논리 사슬
- **범인 폭로**: 정체 확인
- **동기 밝히기**: 범죄 원인
- **트릭 해밀**: 수법 상세

### 5권: 마무리 (181-200장, 10%)
- **범인 처벌**: 법적/도덕적 심판
- **인물 결말**: 각자의 운명
- **여운**: 반성/새 사건 암시

## 6. 단서 설계 기법

### 3층 단서법
```
1층: 표면 단서 (모두 볼 수 있음)
- 사망 시간, 장소, 방식
- 명확한 물증

2층: 숨겨진 단서 (주의 깊게 봐야 발견)
- 무심코 지나친 디테일
- 대화 중 모순
- 타임라인의 틈

3층: 심층 단서 (연상/전문 지식 필요)
- 행동 심리 분석
- 전문 분야 지식
- 역사/배경 연관
```

### 레드 헤링 설계
```
유형1: 가짜 용의자
- 동기는 있지만 기회 없음
- 현장에 있었지만 알리바이 있음

유형2: 가짜 증거
- 조작된 물증
- 조종된 증인

유형3: 가짜 추리
- 조수의 잘못된 추론
- 탐정의 의도적 오도

유형4: 가짜 정체
- 위장자
- 사칭
```

## 7. 용의자 관리

### 용의자 설계 템플릿
```
성명: ___
관계: 피해자와의 관계
동기: 왜 살인하려 하는가
기회: 범행 시간이 있는가
수단: 범행 능력이 있는가
알리바이: 있음/없음/의심스러움
비밀: 숨겨진 정보 (사건과 관련 안 될 수도)
```

### 용의자 수량 제안
```
단편 (5만 자 이하): 3-5명
중편 (5-20만 자): 5-8명
장편 (20만 자 이상): 8-12명
```

## 9. 클래식 트릭 분류

### 밀실 트릭
```
1. 기계적 잠금 (타이머/원격/자동)
2. 사전 잠입 대기
3. 피해자 본인이 잠근 후 살해당함
4. 방이 밀실이 아님 (착각)
5. 사망 시간 위조
```

### 알리바이 트릭
```
1. 시간 위조 (시계/영상)
2. 대역 위장
3. 쌍둥이/유사자
4. 원격 살인
5. 공범 배합
```

### 정체 트릭
```
1. 사망자가 사망자가 아님 (사망 위장)
2. 범인이 범인이 아님 (누명)
3. 탐정이 곧 범인
4. 서술자 기만
```
