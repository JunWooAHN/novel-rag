# 현실 소재 장르 템플릿 (Realistic Fiction)

> **핵심 셀링포인트**: 사실감 + 사회 공감 + 인성의 깊이. 현실 생활에 뿌리내려, 독자의 강렬한 몰입감과 감정 공감을 불러일으킨다.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack M15
- 범용 중첩: Pack U02

## 1. 핵심 유파 세분화

### 직장 분투류
- **특징**: 직장에서 레벨업, 사업과 감정 병행
- **핵심 쾌감**: 역전 승진, 트집잡는 자 때리기, 사업 사랑 쌍수확
- **대표 패턴**: 말단 사원 → 업계 엘리트

### 결혼 생활류
- **특징**: 결혼 가정의 사실적 묘사, 감정 갈등
- **핵심 쾌감**: 나쁜 남/녀 응보, 진짜 사랑 도래, 행복 결말
- **대표 패턴**: 결혼 위기 → 자아 각성 → 새 삶

### 역전 성장류
- **특징**: 하층 인물 분투사, 운명 저항
- **핵심 쾌감**: 반전 역전, 자아 증명, 꿈 실현
- **대표 패턴**: 바닥 → 굴기 → 정점

### 가정 윤리류
- **특징**: 가정 갈등, 친정 유대, 인성 시험
- **핵심 쾌감**: 갈등 해소, 친정 회귀, 치유
- **대표 패턴**: 갈등 → 이해 → 화해

## 2. 사실감 고정 기법

### 디테일 사실성
```
장면 디테일:
- 지하철 출근길 혼잡
- 원룸의 좁고 어지러움
- 심야 야근의 피로
- 월말 카드값 초조

직업 디테일:
- 업계 은어/용어
- 업무 프로세스
- 직장 암묵적 규칙
- 야근 문화
```

### 감정 사실성
```
피해야 할 것:
❌ "그는 그녀의 아름다운 외모에 빠졌다"
❌ "그녀는 그의 재물에 끌렸다"

이렇게 해야 함:
✅ "새벽까지 야근할 때, 그가 조용히 책상 위에 놓은 따뜻한 커피"
✅ "싸움 후, 그가 몰래 이번 달 월세를 냈다는 걸 발견함"
```

### 대화 사실성
```
❌ 문어체:
"나는 이 방안에 실행 가능성 문제가 있다고 생각합니다."

✅ 구어체:
"이 방안… 좀 불안한 느낌인데."

❌ 너무 문예:
"내 마음이 심연에 빠진 것 같다."

✅ 사실적 표현:
"그 순간, 마음이 텅 비어서, 아무 말도 할 수 없었다."
```

## 3. 사회 의제 처리

### 흔한 의제
| 의제 | 진입 각도 | 주의사항 |
|------|----------|----------|
| 직장 성차별 | 여주 경험 → 저항 → 변화 | 설교 피하고, 이야기로 말하기 |
| 원가정 | 부모 PUA → 각성 → 경계 수립 | 부모를 악마화하지 않고, 복잡성 보여주기 |
| 결혼 곤경 | 편부모식 육아/시모 갈등 | 불안 팔지 않고, 출구 제시 |
| 직장 내권 | 996/감원/나이 차별 | 공감 있되 희망도 있음 |
| 외모 불안 | 외모 평가 → 자아 수용 | "역전 후 때리기" 단일 패턴 피하기 |

### 처리 원칙
```
1. 문제를 보여주되, 불안을 증폭하지 않음
2. 곤경을 보여주되, 출구도 제시
3. 현상을 비판하되, 집단을 공격하지 않음
4. 공감을 불러일으키되, 힘을 전달
```

## 4. 대강 구조 (60만 자 표준)

### 1권: 곤경 제시 (1-50장, 20%)
- **오프닝 훅**: 주인공의 현재 곤경 시연
- **인물 등장**: 주인공, 적수, 동맹, 연인
- **핵심 갈등**: 직장/결혼/가정 곤경
- **소클라이맥스**: 첫 돌파 시도 (실패)

### 2권: 발버둥과 각성 (51-130장, 30%)
- **갈등 격화**: 곤경 심화, 압력 배가
- **인지 전환**: 주인공 각성/변화 시작
- **능력 축적**: 학습, 성장, 준비
- **전환점**: 핵심 사건이 변화 추진

### 3권: 전력 돌파 (131-220장, 30%)
- **행동 전개**: 주동적 출격, 현상 변경
- **장애 조우**: 반대 세력의 방해
- **귀인 조력**: 핵심 조력 등장
- **클라이맥스**: 결정적 승리

### 4권: 새 생활 (221-280장, 20%)
- **성과 수확**: 사업/감정 원만
- **관계 화해**: 과거와 화해
- **새로운 도전**: 더 높은 차원의 추구
- **결말**: 열린 결말 또는 원만한 결말

## 5. 인물 깊이 조각

### 3차원 입체법
```
1차원: 외적 특징
- 외모, 직업, 사회적 신분
- 행동 습관, 말투

2차원: 내적 성격
- 장점과 단점
- 공포와 갈망
- 가치관과 원칙

3차원: 성장 아크
- 시작점 상태
- 변화 계기
- 종착점 상태
```

### 회색 인물 설계
```
반파는 순수 흑이 아님:
- 시어머니가 트집잡지만, 아들을 위해서
- 상사가 억압하지만, 자신도 착취당하고 있음
- 나쁜 남편이 외도하지만, 결혼 자체에 문제 있었음

주인공은 순수 백이 아님:
- 이기적인 면이 있음
- 실수를 할 수 있음
- 성장이 필요함
```

## 6. 클래식 브릿지 라이브러리

### 직장 브릿지
```
위기:
- 신입에게 공 빼앗김
- 상사에게 괴롭힘
- 직장 성희롱
- 35세에 구조조정

역전:
- 핵심 프로젝트 살림
- 이직 후 전 직장 압도
- 창업 성공
- 직장 암묵적 규칙 폭로
```

### 결혼 브릿지
```
위기:
- 외도 증거 발견
- 시모 대전
- 편부모식 육아
- 경제적 통제

각성:
- 이혼 결심
- 경제적 독립
- 자아 재정의
- 진짜 사랑을 만남
```

### 가정 브릿지
```
갈등:
- 결혼/출산 재촉
- 형제자매 편애
- 부모 PUA
- 경제 분쟁

화해:
- 부모의 한계 이해
- 건강한 경계 수립
- 선택적 용서
- 새로운 관계 패턴 창조
```

## 8. 대화 예시

### 직장 대화
```markdown
【괴롭힘】
"이 보고서 다시 해." 주임이 서류를 책상에 내던졌다.
"어디가 문제인가요?" 그녀는 분노를 참았다.
"내가 문제 있다면 문제 있는 거야, 신입은 그렇게 물어보지 마."

【역전】
"왕 경리님, 이 방안은 제가 만든 겁니다. 회의록에 기록이 있습니다."
그녀는 비굴하지도 거만하지도 않게 말했고, 아래에서는 술렁임이 일었다.
```

### 결혼 대화
```markdown
【다툼】
"일만 알지, 이 집 신경 쓴 적이나 있어?"
"내가 일 안 하면 돈이 어디서 나? 주택담보대출 자동차대출이 하늘에서 떨어지는 줄 알아?"
두 사람은 침묵했고, 공기가 얼음처럼 굳었다.

【화해】
"미안, 소리 지르면 안 되는 건데."
"나도 잘못했어, 우리… 잘 이야기해보자."
```
