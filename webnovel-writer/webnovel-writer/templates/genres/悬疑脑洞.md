# 서스펜스 브레인홀 장르 템플릿 (Mystery Brainwave)

> **핵심 셀링포인트**: 논리 추리 + 규칙 게임 + 고지능 반전. 규칙과 추리의 교차 속에서, 겹겹이 안개 뒤의 진상을 밝힌다.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack M06 / Pack M07
- 범용 중첩: Pack U02

## 1. 핵심 유파 세분화

### 규칙 추리류
- **특징**: 특정 규칙 하에서 추리 진행
- **핵심 쾌감**: 규칙 발견, 논리 연역, 규칙 반격
- **대표작**: 《궤비지주》《사망만화경》《전구고시》

### 밀실 탈출류
- **특징**: 특정 공간에 갇혀, 해독 탈출 필요
- **핵심 쾌감**: 단서 발견, 퍼즐 파해, 절경 탈출
- **대표작**: 《십종죄》《심리죄》《무증지죄》

### 정보 게임류
- **특징**: 정보 비대칭 하의 지력 대결
- **핵심 쾌감**: 정보차 이용, 심리 게임, 반전 폭로
- **대표작**: 《사기 게임》《도박묵시록》《늑대인간》류

### 시공 트릭류
- **특징**: 시간/공간의 트릭 이용
- **핵심 쾌감**: 트릭 폭로, 논리 자기모순 없음, 인지 전복
- **대표작**: 《용의자 X의 헌신》《백야행》《악의》

## 2. 세계관: 서스펜스 브레인홀 사회학

### 규칙 유형
| 유형 | 특징 | 예시 |
|------|------|------|
| 게임 규칙 | 명확한 게임 규칙 | 늑대인간/배틀로얄 |
| 초자연 규칙 | 초자연 현상의 규칙 | 저주/괴담 |
| 사회 규칙 | 숨겨진 사회 규칙 | 암묵적 규칙/음모 |
| 논리 규칙 | 순수 논리 추리 | 밀실/불가능 범죄 |

### 정보 계층
| 계층 | 인지 정도 | 역할 |
|------|----------|------|
| 전지 | 전부 파악 | 막후 흑수 |
| 다지 | 대부분 파악 | 핵심 참가자 |
| 소지 | 부분 파악 | 일반 참가자 |
| 무지 | 아무것도 모름 | 속은 자 |

### 추리 요소
| 요소 | 설명 | 작용 |
|------|------|------|
| 단서 | 발견 가능한 정보 | 추리 기반 |
| 복선 | 숨겨진 정보 | 반전 복선 |
| 오도 | 잘못된 방향 | 난이도 증가 |
| 진상 | 최종 답 | 폭로 목표 |

## 3. 추리 체계 설계

### 단서 설계
```
명단서 (30%):
- 직접 가시적
- 발견하기 쉬움
- 표면을 가리킴

암단서 (50%):
- 분석 필요
- 놓치기 쉬움
- 진상을 가리킴

오도 단서 (20%):
- 의도적 설치
- 오류를 가리킴
- 난이도 증가
```

### 추리 논리
| 유형 | 특징 | 예시 |
|------|------|------|
| 연역 추리 | 일반에서 특수로 | 규칙→결론 |
| 귀납 추리 | 특수에서 일반으로 | 현상→법칙 |
| 역추적 추리 | 결과에서 원인으로 | 결과→원인 |
| 유비 추리 | 유사성 추리 | A는 B와 유사 |

### 반전 설계
```
정체 반전:
- 범인이 뜻밖의 인물
- 피해자가 범인
- 탐정이 범인

동기 반전:
- 표면 동기가 가짜
- 진짜 동기가 뜻밖
- 무동기 범죄

진상 반전:
- 사건 자체가 가짜
- 다중 진상
- 진상이 상상보다 복잡
```

## 4. 클래식 쾌감 루틴

### 규칙 파훼
- **장면**: 규칙의 허점이나 진상 발견
- **쾌감**: 규칙을 이용해 반격/탈출
- **핵심**: 규칙이 일관적이고, 파훼가 합리적

### 추리 대결
- **장면**: 적수와 추리 대결
- **쾌감**: 지력 압도, 적수 패배
- **핵심**: 양측 모두 지능이 있어야 함

### 진상 폭로
- **장면**: 겹겹이 안개 후의 진상
- **쾌감**: 그제야 깨달음, 앞뒤 호응
- **핵심**: 복선이 있어야 하고, 논리 일관적

### 절경 역전
- **장면**: 필사의 국면이 역전
- **쾌감**: 긴장 자극, 위기 극복
- **핵심**: 역전에 복선이 있어야 함

## 5. 대강 구조 (100만 자 표준)

### 1권: 입국 (1-50장)
- **핵심**: 서스펜스 세계 진입, 규칙 파악
- **상태**: 혼란/학습
- **클라이맥스**: 첫 퍼즐 해결

### 2권: 성장 (51-120장)
- **핵심**: 추리 능력 향상
- **상태**: 성장/축적
- **클라이맥스**: 중대 사건 해결

### 3권: 심입 (121-200장)
- **핵심**: 핵심 미스터리 접촉
- **상태**: 심입/위험
- **클라이맥스**: 핵심 단서 발견

### 4권: 대결 (201-280장)
- **핵심**: 막후 흑수와 대결
- **상태**: 대항/게임
- **클라이맥스**: 막후 흑수 폭로

### 5권: 종국 (281-350장)
- **핵심**: 최종 진상, 궁극 대결
- **상태**: 결전/계시
- **클라이맥스**: 원만한 결말

- ✅ 추리 논리가 치밀
