# 도시 브레인홀 장르 템플릿 (Urban Brainwave)

> **핵심 셀링포인트**: 현실 도시 + 규칙/이상현상 침입 + 강반전. 초자연적 규칙이 일상생활에 침입할 때, 보통 사람이 틈새에서 어떻게 생존하는가.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack M04 / Pack M05
- 범용 중첩: Pack U02

## 1. 핵심 유파 세분화

### 규칙 침입류
- **특징**: 현실 세계가 초자연 규칙에 침입당함
- **핵심 쾌감**: 규칙 발견, 규칙 이용, 규칙 반격
- **대표작**: 《아재정신병원학참신》《심연귀도》《궤비지주》

### 도시 이상현상류
- **특징**: 도시에 각종 이상 현상 발생
- **핵심 쾌감**: 이상 탐색, 진상 폭로, 능력 각성
- **대표작**: 《아유일좌공포옥》《민조국이문록》《영이직파간》

### 시스템 강림류
- **특징**: 시스템/게임화가 현실 침입
- **핵심 쾌감**: 시스템 이용, 임무 완수, 등급 압도
- **대표작**: 《전구고무》《아적세포감옥》《전구재변》

### 평행세계류
- **특징**: 평행세계 발견/이동
- **핵심 쾌감**: 세계 탐색, 규칙 차이, 신분 전환
- **대표작**: 《윤회낙원》《무한공포》《전구진화》

## 3. 규칙 체계 설계

### 규칙 유형
| 유형 | 특징 | 예시 |
|------|------|------|
| 금지형 | 무언가를 할 수 없음 | 이름을 말할 수 없음 |
| 강제형 | 무언가를 해야 함 | 반드시 응답해야 함 |
| 조건형 | 조건 충족 시 발동 | 보면... |
| 시간형 | 특정 시간에 발효 | 새벽 3시 |
| 공간형 | 특정 장소에서 발효 | 엘리베이터 안 |

### 규칙 설계 원칙
```
자기모순 없음:
- 규칙 내부 모순 없음
- 규칙 간에 논리 있음

검증 가능:
- 위반 시 명확한 결과
- 준수 시 명확한 이익

이용 가능:
- 허점 이용 가능
- 역이용 가능

출처 있음:
- 규칙 형성에 원인
- 근원 추적 가능
```

### 대가 시스템
| 대가 유형 | 특징 | 회복 방식 |
|----------|------|----------|
| 생리 대가 | 신체 손상 | 시간/치료 |
| 정신 대가 | 심지 소모 | 휴식/특수 수단 |
| 자원 대가 | 물품 소모 | 획득/제작 |
| 존재 대가 | 존재감 하락 | 특수 방식 |

## 4. 클래식 쾌감 루틴

### 규칙 파훼
- **장면**: 규칙의 허점 발견
- **쾌감**: 허점 이용 탈출/반격
- **핵심**: 파훼가 합리적, 너무 우연이면 안 됨

### 능력 각성
- **장면**: 생사의 기로에서 특수 능력 각성
- **쾌감**: 적 반격, 국면 역전
- **핵심**: 능력에 제한 필요

### 진상 폭로
- **장면**: 이상 이면의 진상을 밝힘
- **쾌감**: 그제야 깨달음, 앞뒤 호응
- **핵심**: 복선 필요

### 등급 압도
- **장면**: 고등급 능력으로 저급 이상 압도
- **쾌감**: 쉽게 해결, 성장 시연
- **핵심**: 성장 과정 필요

## 5. 대강 구조 (150만 자 표준)

### 1권: 입문 (1-60장)
- **핵심**: 이상 세계 접촉
- **능력**: 초기 각성
- **클라이맥스**: 첫 이상 사건 해결

### 2권: 성장 (61-150장)
- **핵심**: 능력 향상, 더 많이 알아감
- **능력**: 꾸준한 향상
- **클라이맥스**: 중대 이상 사건 해결

### 3권: 심입 (151-280장)
- **핵심**: 이상 세계의 진상 탐색
- **능력**: 질적 변화
- **클라이맥스**: 부분적 진상 폭로

### 4권: 대항 (281-400장)
- **핵심**: 고급 이상/세력 대항
- **능력**: 정점 근접
- **클라이맥스**: 주요 적 격파

### 5권: 종국 (401-500장)
- **핵심**: 최종 진상, 궁극 대결
- **능력**: 정점
- **클라이맥스**: 원만한 결말

## 7. 분위기 조성

### 일상과 이상의 대비
```
일상 장면:
- 출근/등교
- 쇼핑/오락
- 사교/휴식

이상 침입:
- 익숙한 장면의 낯설어짐
- 일상 규칙의 실효
- 안전감의 붕괴
```

### 공포 분위기
| 유형 | 기법 | 효과 |
|------|------|------|
| 심리 공포 | 암시/여백 | 상상 공포 |
| 규칙 공포 | 위반 시 죽음 | 긴장 초조 |
| 미지 공포 | 정보 부족 | 불안감 |
| 반전 공포 | 인지 전복 | 충격 |

### 리듬 제어
```
복선 (20%):
- 일상 속 이상
- 불길한 징조

상승 (40%):
- 이상 사건 발생
- 위험 점차 상승

클라이맥스 (30%):
- 핵심 이상에 직면
- 생사 일선

마무리 (10%):
- 이상 해제/지속
- 여운/복선
```
