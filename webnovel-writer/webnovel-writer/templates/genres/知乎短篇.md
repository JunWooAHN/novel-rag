# 즈후 단편 장르 템플릿 (Zhihu Short Story)

> **핵심 셀링포인트**: 짧고 빠르게 + 강한 갈등 + 극적 반전. 3000-15000자 내에 기승전결을 완성하고, 처음 300자가 생사를 결정한다.

---

- 추천 제약 팩: Pack M17
- 범용 중첩: Pack U02

## 1. 핵심 특징

### 분량 포지셔닝
| 유형 | 글자 수 | 적용 장면 |
|------|------|----------|
| 극단편 | 3000-5000 | 단일 반전, 감정 폭발 |
| 표준 단편 | 5000-10000 | 이중 반전, 완전한 아크 |
| 장단편 | 10000-15000 | 다중 반전, 복잡한 감정 |

### 황금 300자 법칙
- **첫 50자**: 서스펜스 또는 갈등 조성
- **50-150자**: 인물 상황 수립
- **150-300자**: 핵심 갈등 제시

## 2. 10대 오프닝 훅 템플릿

### 1. 사망 오프닝
```
템플릿: 나는 죽었다, 그리고 [반전]
예시: 나는 죽었다, 결혼기념일에. 더 아이러니한 건, 나를 죽인 사람이 내 장례식에서 가장 크게 울고 있었다.
적용: 복수, 서스펜스, 시련문
```

### 2. 시간 역순
```
템플릿: [결과], 모든 것은 [시점]에서 시작해야 한다
예시: 그가 내 앞에 무릎 꿇고 재결합을 구할 때, 나는 그저 웃기기만 했다. 3년 전, 그는 이런 꼴이 아니었는데.
적용: 쫓아가는 남편 화장터, 거울 다시 붙이기
```

### 3. 신분 반전
```
템플릿: 모두가 내가 [A]라고 생각했지만, 사실 나는 [B]
예시: 모두가 내가 높은 집안에 매달린 가난한 친척이라고 생각했다, 나를 "친절하게 받아준" 사촌 언니를 포함해서.
적용: 얼굴 때리기, 쾌감문, 호문
```

### 4. 극한 상황
```
템플릿: [극한 상황], 나는 [비정상 반응]
예시: 영하 30도 냉동고에 갇혀, 나는 오히려 웃었다. 드디어, 당당하게 죽을 수 있게 되었다.
적용: 시련문, 구원, 서스펜스
```

### 5. 대화 오프닝
```
템플릿: "[충격적 대사]"
예시: "서명해, 아이는 내가 키울게, 너는 빈손으로 나가." 그는 이혼 합의서를 내 앞에 밀며, 눈에 혐오가 가득했다.
적용: 결혼, 시련문, 쾌감문
```

### 6. 환생/빙의
```
템플릿: 눈을 떠보니, 나는 [핵심 시점]으로 돌아와 있었다
예시: 눈을 떠보니, 나는 계단에서 밀려 떨어지기 하루 전으로 돌아와 있었다. 이번에는, 죽어야 할 사람은 내가 아니다.
적용: 환생 복수, 책 속 빙의
```

### 7. 비밀 폭로
```
템플릿: [누군가]가 모르는 것은, [비밀]
예시: 내 남편이 모르는 것은, 그의 백월광이 내가 돈 주고 고용한 배우라는 것이다.
적용: 반전, 복수, 쾌감문
```

### 8. 숫자 충격
```
템플릿: [숫자] + [비정상 사실]
예시: 결혼 7년, 그는 나를 32번 응급실에 보냈고, 나는 마침내 한 가지를 배웠다—죽은 척하기.
적용: 시련문, 각성, 복수
```

### 9. 대비 반차
```
템플릿: 예전에는 [A 상태], 지금은 [B 상태]
예시: 예전에는, 그는 내가 감히 범접할 수 없는 신이었다. 지금은, 그가 내 앞에 무릎 꿇고, 한 번만 봐달라고 구걸한다.
적용: 역전, 쫓아감
```

### 10. 서스펜스 질문
```
템플릿: 당신은 [질문]을 아는가?
예시: 한 사람이 얼마나 절망할 수 있는지 아는가? 아마 죽을 힘조차 없을 정도일 것이다.
적용: 시련문, 감정
```

## 3. 클래식 소재 템플릿

### 쫓아가는 남편 화장터 (8000자)
```
구조: 결과 → 회상 → 전환 → 쫓아감 → 결말

1막 (1000자): 남주 비천하게 재결합 구하고, 여주 냉담
2막 (3000자): 역순으로 결혼 중 학대/무시
3막 (1500자): 여주가 떠난 도화선
4막 (2000자): 남주 쫓아감 과정
5막 (500자): HE 또는 BE 결말
```

### 환생 복수 (6000자)
```
구조: 비참한 죽음 → 환생 → 포석 → 반격 → 결말

1막 (800자): 전생 비참한 죽음 장면
2막 (500자): 환생, 맹세 세움
3막 (2500자): 운명 변경, 한 걸음씩
4막 (1700자): 핵심 반격, 진상 폭로
5막 (500자): 원수 결말 + 새 삶
```

### 호문 얼굴 때리기 (5000자)
```
구조: 당함 → 참음 → 신분 공개 → 때리기 → 마무리

1막 (800자): 깔보임/괴롭힘
2막 (1200자): 참으며 감정 축적
3막 (1500자): 신분 공개 과정
4막 (1200자): 얼굴 때리기 클라이맥스
5막 (300자): 모두의 반응 + 결말
```

## 4. 결말 모드

### HE (Happy Ending)
```
적용: 달콤, 쫓아감 성공, 복수 원만
결미 루틴:
- 화해 포옹
- 결혼식/아이
- 수년 후 행복한 일상
```

### BE (Bad Ending)
```
적용: 시련문, 유감미, 칼질문
결미 루틴:
- 평생 엇갈림
- 한쪽 사망
- 사랑하지만 얻지 못함
- 열린 비극
```

### 열린 결말
```
적용: 여운 깊음, 토론 유발
결미 루틴:
- 서스펜스 남김
- 독자가 상상
- 여운이 무궁
```

## 5. 리듬 제어

### 글자 수 배분 황금 비율
```
오프닝 훅: 5% (독자 잡기)
배경 복선: 15% (빠르게 몰입)
갈등 상승: 40% (핵심 내용)
클라이맥스 반전: 25% (감정 폭발)
결말 마무리: 15% (여운)
```

### 리듬 가속 기법
- **짧은 문장**: 긴장감 조성
- **대화 추진**: 스토리 가속
- **과도 생략**: 핵심 장면으로 직행
- **감정 어휘**: 충격 강화

### 금기
- ❌ 장황한 배경 소개
- ❌ 과도한 심리 묘사
- ❌ 질질 끄는 과도 장면
- ❌ 복선만 깔고 폭발 안 함

## 6. 감정 곡선 설계

### 시련문 곡선
```
오프닝(낮음)→ 달콤한 회상(높음)→ 시련 전개(지속 낮음)→ 최시련(바닥)→ 결말(HE 상승/BE 더 낮음)
```

### 쾌감문 곡선
```
오프닝(억압)→ 참기(축적)→ 폭발(높음)→ 때리기(더 높음)→ 마무리(만족)
```

### 반전문 곡선
```
오프닝(가상 A)→ 복선(A 강화)→ 반전(B 폭로)→ 충격(임팩트)→ 새 이해(승화)
```

## 7. 빠른 캐릭터 구축

### 3초 캐릭터법
```
한 문장으로 캐릭터 정의:
- 직업/신분 + 핵심 특질 + 핵심 갈등

예시:
- "겉으로 참는 호문 며느리, 사실 전 가족 약점을 쥐고 있음"
- "나쁜 남자에게 버림받은 전처, 사실은 숨겨진 대인물"
- "비천하게 쫓아가는 재벌 사장, 3년 전 직접 그녀를 쫓아냄"
```

### 대비 조각법
```
전기 vs 후기:
- 전기 비천 → 후기 여왕
- 전기 냉담 → 후기 비천
- 전기 풍광 → 후기 몰락
```
