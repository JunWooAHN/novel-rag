# 다크 소재 초기화 템플릿

## 핵심 설정

### 다크 소재의 본질
```
질서 붕괴 + 새 질서 건설 + 극한 권력 + 도덕 회색
```

### 핵심 매력
- 권력 환상의 극한 만족
- 관습을 깨는 금기적 쾌감
- 약육강식의 생존 법칙
- 색다른 시점의 서사 경험

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack M16
- 범용 중첩: Pack U01

## 다크 주인공 설계

### 주인공 유형 선택
| 유형 | 특징 | 핵심 구동 |
|------|------|----------|
| 폭군형 | 절대 통치, 철혈 수완 | 질서와 통제 |
| 정복형 | 확장 야심, 끝없는 만족 | 점유와 정복 |
| 파멸형 | 모든 것 파괴, 세계 재건 | 파멸과 재생 |
| 기생형 | 은밀 침투, 암중 조종 | 생존과 진화 |

### 성격 특질 템플릿
```
이성적 냉혹 + 절대 장악 + 야심만만 + 고독 환자
```

### 주인공 기원 템플릿
```
세계에 버려짐 → 어둠의 힘 각성 → 복수/정복 → 새 질서 건설
```

### 주인공 복잡성
- 자기만의 행동 논리가 있음
- 순수한 악이 아님
- 이해 가능한 동기가 있음
- 간혹 인간성 보여줌

## 다크 시스템 설계

### 유전자 패권 시스템 (예시)
```
흡수 → 소화 → 진화 → 피드백
```

| 메커니즘 | 설명 | 쾌감 |
|------|------|------|
| 흡수 | 유전자/에너지 획득 | 약탈 쾌감 |
| 소화 | 힘으로 전환 | 성장 만족 |
| 진화 | 능력 업그레이드 | 강해지는 쾌감 |
| 피드백 | 전투 검증 | 압도 쾌감 |

## 다크 쾌감 설계

### 쾌감 유형
| 유형 | 발동 | 효과 |
|------|------|------|
| 지배 쾌감 | 절대적 타인 통제 | 권력 만족 |
| 정복 쾌감 | 성을 빼앗고 땅을 뺏음 | 확장 쾌감 |
| 흡수 쾌감 | 능력/자원 약탈 | 성장 만족 |
| 압도 쾌감 | 실력 격차 시연 | 강자 쾌감 |
| 공포 쾌감 | 적을 두렵게 함 | 위엄 만족 |

### 쾌감 구조
```
실력 격차 시연 → 적의 공포/절망 → 압도/정복 → 전리품 수확
```

### 다크 의식감
- 등극/관면 장면
- 적 굴복 장면
- 세력 확장 장면
- 진화 돌파 장면

## 공포 분위기 조성

### 공포 유형
| 유형 | 기법 | 효과 |
|------|------|------|
| 신체 공포 | 변이, 기형 | 생리적 불쾌 |
| 심리 공포 | 정신 제어, 세뇌 | 심리 압박 |
| 존재 공포 | 이해 불가한 존재 | 인지 붕괴 |
| 절망 공포 | 벗어날 수 없는 운명 | 질식감 |

### 분위기 묘사
```
환경 압박: 음침, 부패, 적막
감각 자극: 비린내, 끈적함, 귀를 찌르는 소리
심리 암시: 감시당하는 느낌, 도망갈 곳 없음
```

### 공포 점진
```
불안 → 긴장 → 공포 → 절망 → 붕괴
```

## 스토리 리듬

### 오프닝 (첫 10장)
- 어둠의 힘 각성
- 첫 흡수/정복
- 기초 세력 건설
- 행동 논리 확립

### 발전기 (10-100장)
- 세력 확장
- 능력 진화
- 더 강한 적 정복/흡수
- 새 질서 건설

### 클라이맥스기 (100장+)
- 최상위 포식자가 됨
- 대규모 영역 정복
- 궁극의 적에 직면
- 다크 제국 건설

## 도덕 경계

### 원칙 설정
- 주인공의 행동 논리 명확화
- 자기만의 원칙 있음 (비록 어둡더라도)
- 무뇌 살육이 아님
- 명확한 목표와 이유 있음

### 인간성 표현
- 간혹의 부드러운 순간
- 특정 사람/일에 대한 집착
- 내면의 고독과 갈등
- 인성이 완전히 사라진 것은 아님

## 주의사항

- **수위 조절**: 지나치게 잔혹하면 안 됨 (차단 방지)
- **논리 일관**: 다크하다고 멍청하면 안 됨, 주인공에 지능 필요
- **독자 공감**: 다크 주인공이라도 이해 가능한 동기 필요
- **리듬 조절**: 일방적 압박만 하면 안 되고, 쾌감 해방이 있어야 함
- **도덕 원칙**: 삼관이 너무 왜곡되지 않게, 기본 도덕 원칙 유지
- **인물 조각**: 다크 주인공에도 매력이 있어야 하고, 단순한 악이 아님
