# 다자다복 초기화 템플릿

## 핵심 설정

### 다자다복의 본질
```
시스템 업그레이드 + 후궁 수집 + 쾌감 밀집 + 감정 충족
```

### 핵심 매력
- 시스템의 시각화 성장
- 후궁의 감정적 충족
- 수집의 성취감
- 쾌감의 지속적 자극

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack F17
- 범용 중첩: Pack U03

## 시스템 설계

### 시스템 패널 템플릿
```
┌─────────────────────────────┐
│ 【다자다복 시스템】            │
├─────────────────────────────┤
│ 등급: Lv.5                  │
│ 경험치: 2350/5000             │
│ 자녀 수: 12                  │
│ 후궁 수: 5                   │
├─────────────────────────────┤
│ 속성 포인트: 15                  │
│ 스킬 포인트: 8                   │
│ 골드: 52000                 │
└─────────────────────────────┘
```

### 핵심 메커니즘
- **자녀 시스템**: 자녀 수량, 품질, 능력 계승
- **후궁 시스템**: 호감도, 친밀도, 전용 스킬
- **업그레이드 시스템**: 경험치 획득, 등급 상승, 속성 투자
- **임무 시스템**: 메인/서브/일일 임무
- **보상 시스템**: 뽑기, 업적, 마일스톤 보상

### 자녀 품질 설정
| 품질 | 확률 | 능력 계승 |
|------|------|----------|
| 보통 | 60% | 10% 속성 계승 |
| 우수 | 25% | 30% 속성 계승 |
| 엘리트 | 10% | 50% 속성 계승 |

## 후궁 관리

### 호감도 시스템
```
낯섬(0-20) → 아는 사이(21-40) → 호감(41-60) →
좋아함(61-80) → 연모(81-95) → 지애(96-100)
```

### 상호작용 방식
| 방식 | 호감도 | 쿨타임 |
|------|--------|------|
| 일상 대화 | +1-3 | 없음 |
| 선물 증정 | +5-20 | 1일 |
| 데이트 | +10-30 | 3일 |
| 공동 전투 | +5-15 | 없음 |
| 특수 이벤트 | +20-50 | 트리거형 |

### 후궁 밸런스 원칙
- 비중 균형: 모든 여주에게 등장 기회
- 감정 균형: 편애 불가
- 능력 균형: 각자의 강점
- 스토리 균형: 모두 전용 스토리 보유

---

## 쾌감 설계

### 시스템 쾌감
- **업그레이드 쾌감**: 등급 상승 → 속성 대폭 증가
- **뽑기 쾌감**: 희귀 당첨 → 강력한 아이템/스킬 획득
- **해금 쾌감**: 새 기능 해금 → 시스템 업그레이드
- **업적 쾌감**: 업적 달성 → 풍성한 보상

### 후궁 쾌감
- **공략 쾌감**: 호감도 만렙 → 후궁 편입
- **질투 쾌감**: 여주의 질투 → 감정적 충족
- **총애 다툼 쾌감**: 여주들의 총애 다툼 → 필요받는 느낌
- **일심 쾌감**: 후궁이 한마음 → 팀 느낌

### 자녀 쾌감
- **탄생 쾌감**: 고품질 자녀 → 서프라이즈
- **성장 쾌감**: 자녀가 인재로 → 성취감
- **계승 쾌감**: 능력 계승 → 전승감
- **역전 쾌감**: 자녀의 역전 → 자부심

## 감정선 설계

### 단일 여주 감정선
```
만남 → 오해 → 이해 → 설렘 → 고백 → 함께 → 깊어짐
```

### 다중 여주 감정선
```
메인 여주 우선 추진
서브 여주 교차 발전
동시에 너무 많이 추진하지 않기
```

### 감정 리듬
- 전반: 1-2명 주요 여주 집중 공략
- 중반: 3-4명 서브 여주 확장
- 후반: 모든 여주 스토리 수렴

---

## 스토리 리듬

### 오프닝 (첫 10장)
- 시스템 활성화
- 첫 번째 여주 편입
- 첫 번째 자녀 탄생
- 기본 설정 수립

### 발전기 (10-100장)
- 후궁 점차 확대 (3-5명)
- 자녀 수 증가 (10-50명)
- 시스템 기능 해금
- 세력 점차 확장

### 클라이맥스기 (100장+)
- 후궁 안정 (5-10명)
- 자녀 성장 (우수/전설 품질)
- 시스템 만렙
- 일방 제패/성신

---

## 세계관 설정

### 배경 선택
- 수선 세계
- 무협 강호
- 이세계 대륙
- 도시 이능
- 성간 시대

### 세력 설정
- 주인공 세력 (약에서 강으로)
- 적대 세력 (갈등 제조)
- 중립 세력 (자원 제공)
- 잠재 동맹 (후기 조력)

---

## 주의사항

- 후궁 여주는 너무 많으면 안 됨 (5-10명이 적절)
- 모든 여주에게 개성이 있어야 함 (천편일률 방지)
- 자녀가 단순 숫자이면 안 됨 (몇 명을 중점 육성)
- 시스템 보상은 절제가 필요 (실패 방지)
- 감정선이 허술하면 안 됨 (진짜 감정이 있어야 함)
- 쾌감 밀도 조절 필요 (장당 1-2개)
