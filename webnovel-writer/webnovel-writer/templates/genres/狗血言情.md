# 막장 로맨스 장르 템플릿 (Dog-Blood Romance)

> **핵심 셀링포인트**: 감정 갈등 + 시련 속 깊은 사랑 + 쫓아가는 남편 화장터. 막장은 폄하가 아니라, 독자의 감정 통점을 정확히 겨냥하는 무기다.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack F15
- 범용 중첩: Pack U01

## 1. 핵심 유파 세분화

### 재벌 달콤류
- **특징**: 남강녀약, 패도적 총애, 달콤함 많고 시련 적음
- **핵심 쾌감**: 무한 총애, 연적 얼굴 때리기, 호문 생활
- **대표 패턴**: 패도 재벌 × 신데렐라

### 쫓아가는 남편 화장터류
- **특징**: 전기에 여주 괴롭힘, 후기에 남주 무릎 꿇기
- **핵심 쾌감**: 여주 역전, 남주 후회, 비천한 복합 요청
- **핵심**: 충분히 시련을 주고, 충분히 비참하게 쫓아감

### 환생 복수류
- **특징**: 여주가 기억을 가지고 환생, 한 걸음씩
- **핵심 쾌감**: 나쁜 남녀 손으로 찢기, 운명 역전, 진짜 사랑 획득
- **핵심**: 전생이 충분히 비참하고, 금생이 충분히 통쾌

### 대역 문학류
- **특징**: 여주가 백월광 대역, 가슴 찢어짐
- **핵심 쾌감**: 대역 역전, 백월광 무너짐, 남주 후회
- **핵심**: 가슴 아픈 장면이 마음을 찌름

## 2. 클래식 공식

### 패도 재벌 공식
```
패도 재벌 + 신데렐라 = 권력 차 → 충돌 → 정복 → 달콤함
```

**필수 요소**:
- **남주**: 젊고 유능 (28-35), 재산 억 단위, 겉은 차갑고 속은 따뜻
- **여주**: 평범한 여자, 선량하고 강인, 자존심 있음
- **클래식 브릿지**: 계약 결혼, 벽치기 키스, 패도적 선언

### 대역 문학 공식
```
여주가 대역 → 학대당함 → 마음이 죽어 떠남 → 남주 쫓아감 화장터
```

**시련 포인트 설계**:
1. 남주가 여주를 이용해 백월광에 대한 그리움 해소
2. 여주에게 백월광 옷을 입힘
3. 백월광 귀환, 여주 버려짐
4. 진상을 알고 후회막급

### 쫓아가는 남편 화장터 공식
```
전기 여주 학대 → 오해로 이별 → 여주 역전 → 남주 비천하게 쫓아감 → HE
```

**쫓아감 5중주**:
1. 진상 발견, 충격과 후회
2. 필사적으로 찾고, 비천하게 만남 요청
3. 선물과 사과, 문전박대
4. 목숨 걸고 수호, 여주 감동
5. 긴 속죄, 마침내 용서받음

## 3. 대강 구조 (80만 자 표준)

### 1권: 달콤한 가상 (1-50장, 15%)
- **오프닝 훅**: 계약/협의 결합, 불평등 지위 시연
- **인물 등장**: 남녀주, 백월광, 연적
- **핵심 갈등**: 남주 냉담, 여주 참기
- **소클라이맥스**: 첫 설렘/오해

### 2권: 가슴 아픈 심연 (51-130장, 25%)
- **위기 상승**: 백월광 등장, 오해 심화
- **시련 포인트 집중**: 오해, 배신, 상처
- **전환**: 여주 마음이 죽고, 떠나기로 결심
- **클라이맥스**: 유산/중병/모함

### 3권: 결렬과 떠남 (131-180장, 15%)
- **부분적 진상 폭로**: 백월광의 진면목
- **여주 떠남**: 도주/깨끗이 떠남/가짜 사망
- **남주 충격**: 잃은 것의 소중함 발견

### 4권: 쫓아가는 길 (181-280장, 30%)
- **남주 후회**: 찾기, 기다림, 비천함
- **여주 성장**: 사업 성공, 자신감 독립
- **반복 밀당**: 옛정은 잊기 어렵고 용서하기도 어려움
- **클라이맥스**: 여주에 새 사람 생김, 남주 멘붕

### 5권: 거울 다시 붙이기 (281-350장, 15%)
- **진상 밝혀짐**: 모든 오해 해소
- **남주 속죄**: 목숨 걸고 수호/모든 것 포기
- **화해 과정**: 천천히 신뢰 재건
- **대결말**: HE, 결혼식/아이

## 4. 감정 장력 설계

### 가슴 아픈 4요소
```
1. 오해: 분명 서로 사랑하는데 서로 상처
2. 엇갈림: 계속 스쳐 지나감
3. 희생: 상대를 위해 묵묵히 헌신하지만 알려지지 않음
4. 유감: 발견했을 때는 이미 너무 늦음
```

### 달콤한 트리거
```
1. 소유욕: "넌 내 거야"
2. 질투: 다른 사람과 말하는 것만 봐도 미침
3. 총애: 온 세상에서 너에게만 온유
4. 보호: 그녀 앞을 가로막음
5. 고백: "사랑해, 아주 오래전부터"
```

## 5. 클래식 브릿지 속참

### 가슴 아픈 브릿지
```markdown
【대역 대사】
"내가 널 취한 게 사랑 때문인 줄 알아? 아냐, 넌 그녀의 그림자일 뿐이야."
그는 차갑게 말하며, 손에 백월광의 사진을 쥐고 있었다.

【마음이 죽어 떠남】
"미안해, 당신이 사랑하는 사람은 내가 아니야, 나도 더 이상 당신을 사랑하지 않아."
그녀는 빗속으로 돌아서 걸어갔고, 다시 돌아보지 않았다.

【무릎 꿇고 간청】
"내가 잘못했어, 돌아와줘…"
그는 빗속에 무릎 꿇었지만, 그녀는 고개도 돌리지 않았다.
```

### 달콤한 브릿지
```markdown
【패도적 선언】
"여자, 넌 성공적으로 내 주의를 끌었어."
루 사장님은 위험한 눈빛으로 그녀를 바라보았다.

【벽치기 고백】
그는 한 손으로 벽을 짚고, 그녀를 품에 가두었다.
"도망가려고? 늦었어. 이제부터 넌 내 사람이야."

【총애 일상】
"추워?" 그는 양복 재킷을 벗어 그녀 어깨에 걸쳤다.
"안 추운데…"
"그래도 입어, 내가 보기에 추워."
```

## 6. Strand Weave 설정

```json
{
  "strand_ratio": {
    "quest": 30,    // 사업선/외부 갈등
    "fire": 55,     // 감정선 (핵심)
    "constellation": 15  // 인간관계 네트워크
  },
  "fire_sub_strands": {
    "sweet": 40,    // 달콤한 비중
    "abuse": 35,    // 시련 비중
    "chase": 25     // 쫓아감 비중
  }
}
```

**리듬 힌트**:
- 로맨스류 Fire 선 비중은 ≥50%
- 달콤-시련 비율은 포지셔닝에 따라 조정 (순수 달콤 7:3, 시련연 4:6)
- 쫓아감 단계는 충분히 길고, 남주는 충분히 비참해야 함
