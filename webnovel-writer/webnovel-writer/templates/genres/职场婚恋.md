# 직장 결혼 연애 장르 템플릿 (Workplace Romance)

> **핵심 셀링포인트**: 직장 게임 + 성장 승진 + 감정 균형. 사업과 사랑의 저울 위에서, 자신만의 균형점을 찾는다.

## 1. 핵심 유파 세분화

### 사무실 연애류
- **특징**: 상하관계/동료 간의 감정
- **핵심 쾌감**: 짝사랑 성사, 신분 반전, 달콤한 일상
- **대표작**: 《삼삼래료》《하이생소묵》《너는나의영광》

### 직장 역전류
- **특징**: 직장 초보가 엘리트로 성장
- **핵심 쾌감**: 능력으로 때리기, 승진 역전, 사업 사랑 쌍수확
- **대표작**: 《환락송》《아적전반생》《도정호》

### 상전 게임류
- **특징**: 상업 경쟁 속의 사랑 미움
- **핵심 쾌감**: 상전 승리, 적수 굴복, 강강연합
- **대표작**: 《창업시대》《엽장》《정영변호사》

### 업계 엘리트류
- **특징**: 특정 업계의 전문 이야기
- **핵심 쾌감**: 전문성 압도, 업계 인정, 업계 전설
- **대표작**: 《외과풍운》《법의진명》《번역관》

## 2. 세계관: 직장 사회학

### 직장 등급
| 등급 | 특징 | 권력 |
|------|------|------|
| 고위층 | 의사결정권 | 전략 방향 |
| 중간층 | 집행권 | 부서 관리 |
| 기층 주관 | 감독권 | 팀 관리 |
| 일반 사원 | 실행자 | 구체 업무 |
| 인턴 | 학습자 | 잡무 |

### 업계 특색
| 업계 | 특징 | 핵심 갈등 |
|------|------|----------|
| 금융 | 고압 고급 | 실적 vs 도덕 |
| IT | 빠른 리듬 | 혁신 vs 안정 |
| 변호사 | 논리 치밀 | 정의 vs 이익 |
| 의료 | 생사가 달림 | 구명 vs 규칙 |
| 미디어 | 여론 영향 | 진실 vs 트래픽 |

### 직장 자원
| 자원 | 설명 | 획득 방식 |
|------|------|----------|
| 인맥 | 관계 네트워크 | 사교/프로젝트 |
| 실적 | 업무 성과 | 노력/기회 |
| 능력 | 전문 기술 | 학습/실전 |
| 평판 | 직장 명성 | 축적/유지 |
| 배경 | 상사 지원 | 실적/편 서기 |

## 3. 직장 체계 설계

### 승진 경로
```
전문 경로:
인턴 → 주니어 → 미들 → 시니어 → 전문가 → 수석

관리 경로:
사원 → 조장 → 주관 → 매니저 → 디렉터 → VP → CEO

창업 경로:
직장인 → 공동창업자 → 창업자 → 상장기업 대표
```

### 직장 게임
| 유형 | 수단 | 리스크 |
|------|------|------|
| 실적 경쟁 | 능력으로 승부 | 낮음 |
| 자원 쟁탈 | 프로젝트 빼앗기 | 중간 |
| 편 고르기 | 배경 선택 | 높음 |
| 사내 정치 | 파벌 형성 | 매우 높음 |

### 직장 규칙
```
명시적 규칙:
- 성과 평가
- 승진 제도
- 상벌 메커니즘

암묵적 규칙:
- 파벌 편 서기
- 인간관계
- 정보 차이
```

## 4. 클래식 쾌감 루틴

### 능력으로 때리기
- **장면**: 의심받은 후 실력으로 증명
- **쾌감**: 전문성 압도, 적수 입 다물게 함
- **핵심**: 전문적 디테일 지원 필요

### 승진 역전
- **장면**: 하층에서 고위직까지 승진
- **쾌감**: 예전에 깔보던 사람이 이제 우러러봐야 함
- **핵심**: 성장 과정이 있어야 함

### 상전 승리
- **장면**: 핵심 프로젝트/협상 승리
- **쾌감**: 적수 격파, 인정 획득
- **예시**: 창의적 방안으로 대형 고객 수주

### 신분 반전
- **장면**: 숨겨진 신분 폭로
- **쾌감**: 사실은 대표/금수저
- **핵심**: 복선 필요, 너무 갑작스러우면 안 됨

## 5. 대강 구조 (80만 자 표준)

### 1권: 입사 (1-50장)
- **핵심**: 직장 진입, 환경 적응
- **지위**: 신인/하층
- **클라이맥스**: 첫 프로젝트 성공

### 2권: 성장 (51-120장)
- **핵심**: 능력 향상, 감정 싹틈
- **지위**: 핵심 사원
- **클라이맥스**: 승진 기회 획득

### 3권: 시련 (121-200장)
- **핵심**: 사업 감정 이중 시련
- **지위**: 중간 관리
- **클라이맥스**: 위기 극복

### 4권: 돌파 (201-280장)
- **핵심**: 사업 돌파, 감정 확정
- **지위**: 고위/파트너
- **클라이맥스**: 사업 정점

### 5권: 원만 (281-350장)
- **핵심**: 사업 사랑 쌍수확
- **지위**: 업계 엘리트
- **클라이맥스**: 원만한 결말

## 7. 업계 묘사 기법

### 전문감 조성
- 업계 용어 사용하되 설명 필요
- 업무 프로세스 합리적
- 직장 규칙 사실적

### 상용 업계 설정
| 업계 | 핵심 장면 | 전문 요소 |
|------|----------|----------|
| 금융 | 거래/로드쇼 | 밸류에이션/실사 |
| 변호사 | 법정/협상 | 사례/조항 |
| 의료 | 수술/회진 | 증례/술식 |
| IT | 프로덕트/투자 유치 | 사용자/데이터 |
| 미디어 | 취재/발표 | 선제/트래픽 |

### 직장 분위기
```
일상 장면:
- 회의실 게임
- 탕비실 험담
- 야근 프로젝트 추진
- 팀빌딩 활동

핵심 장면:
- 업무 보고
- 프로젝트 발표
- 비즈니스 협상
- 위기 PR
```

## 8. 흔한 지뢰

### 반드시 피할 것
- ❌ 직장 묘사가 너무 가짜
- ❌ 연애만 하고 일 안 함
- ❌ 승진이 너무 빠르고 순탄
- ❌ 전문 지식 오류

### 권장 방법
- ✅ 직장 디테일 사실적
- ✅ 사업 감정 균형
- ✅ 승진에 과정이 있음
- ✅ 전문 지식 정확
