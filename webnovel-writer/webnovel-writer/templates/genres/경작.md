# 경영 장르 템플릿 (Farming & Kingdom Building)

> **핵심 셀링포인트**: 자원 축적 + 세력 건설 + 꾸준한 성장. "높은 성벽을 쌓고, 식량을 넉넉히 비축하고, 천천히 왕이 된다"—경영의 지혜로 세상을 정복한다.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack F12
- 범용 중첩: Pack U03

## 어원 설명

"경영문(경작문)"이라는 용어는 SLG 전략 게임에서 유래했으며, 플레이어가 "높은 성벽을 쌓고, 식량을 넉넉히 비축하고, 천천히 왕이 된다"는 취지로 세력을 발전시키는 것을 가리킨다. 경영문은 두 가지 큰 유파로 나뉜다:
- **초기 경영문**: 세력 경영, 내정 건설, 과학기술 발전, 경제/과학기술 우위로 적을 밀어붙이기
- **후기 경영문**: 집안 사소한 일, 생활 소소한 것, 소인물 분투

---

## 1. 핵심 유파 세분화

### 세력 경영류 (초기 경영)
- **특징**: 근거지 건설, 농업/경제/군사/정치 발전, 내정 우위로 적 압도
- **핵심 쾌감**: 세력 확장, 과학기술 압도, 천하 정복
- **대표작**: 《서서》《당전》《신송》《재집천하》《관거일품》

### 영지 건설류
- **특징**: 영지/봉지 획득, 영에서부터 건설
- **핵심 쾌감**: 영지 업그레이드, 인구 성장, 경제 번영
- **대표작**: 《영주시대》《제로부터》《아재이계유좌성》

### 기지 발전류
- **특징**: 말세/성간/이계에서 안전 기지 건설
- **핵심 쾌감**: 기지 확장, 자원 축적, 팀 강화
- **대표작**: 《말세지아유공간》《성간농장주》

### 집안 사소한 일류 (후기 경영)
- **특징**: 고대/근현대 배경, 소인물의 평범한 생활
- **핵심 쾌감**: 부자 되기, 생활 개선, 가정 화목
- **대표작**: 《농가소복녀》《금수농녀종전망》《청대빙의일상》

## 3. 세력 경영 시스템 (초기 경영 핵심)

### 기술 트리 설계
```
농업 기술:
원시 농경 → 철기 농구 → 수리 관개 → 윤작 제도 → 양종 배양

공업 기술:
수공 작업장 → 수력 기계 → 표준화 생산 → 유수선 → 산업혁명

군사 기술:
냉병기 → 궁노 개량 → 화약 무기 → 화총화포 → 열무기

상업 기술:
물물교환 → 화폐 유통 → 환어음 은행 → 주식 제도 → 금융 체계
```

### 인재 체계
| 유형 | 기능 | 획득 방식 |
|------|------|----------|
| 모사 | 전략 기획 | 모집/투신 |
| 무장 | 군사 지휘 | 모집/배양 |
| 내정 | 경제 관리 | 과거/추천 |
| 장인 | 기술 연구 | 모집/배양 |
| 상인 | 무역 경영 | 협력/모집 |

### 제도 건설
- **정치 제도**: 중앙집권/분봉제/의회제
- **경제 제도**: 계획경제/시장경제/혼합제
- **군사 제도**: 부병제/모병제/의무병역
- **선발 제도**: 과거/추천/고과

## 4. 클래식 쾌감 루틴

### 과학기술 압도 (세력 경영)
- **장면**: 앞선 과학기술로 뒤처진 세력에 맞섬
- **쾌감**: 차원 축소 공격, 과소승대
- **예시**: 화총으로 냉병기 군대에 맞섬

### 내정 우위 (세력 경영)
- **장면**: 적은 아직 내분 중이고, 주인공은 이미 발전 성장
- **쾌감**: 두텁게 쌓고 한 번에 터뜨려, 일전정건곤
- **핵심**: 발전 과정을 보여줘야 함

### 인재 귀심 (세력 경영)
- **장면**: 각방 인재가 주인공에게 투신
- **쾌감**: 인재 가득, 뭇별이 달을 받들듯
- **핵심**: 인재에 특색이 있어야 함

### 부자 되기 (집안 사소한 일)
- **장면**: 가난에서 부유로
- **쾌감**: 은전이 점점 많아지고, 생활이 점점 좋아짐
- **핵심**: 축적 과정을 보여줘야 함

### 극성 패대기 (집안 사소한 일)
- **장면**: 친척/이웃이 주인공을 깔봄
- **쾌감**: 주인공 성공 후, 상대가 후회막급
- **핵심**: 너무 작위적이면 안 됨

## 5. 대강 구조

### 세력 경영형 (200만 자 표준)

#### 1권: 입족 (1-80장)
- **핵심**: 근거지 획득, 발판 확보
- **세력**: 한 현/한 촌
- **클라이맥스**: 첫 위협 격퇴

#### 2권: 발전 (81-200장)
- **핵심**: 내정 건설, 실력 축적
- **세력**: 한 군/한 주
- **클라이맥스**: 과학기술/제도 초기 효과

#### 3권: 확장 (201-400장)
- **핵심**: 주변 흡수, 세력 확대
- **세력**: 수주/일방
- **클라이맥스**: 일방 패주가 됨

#### 4권: 쟁패 (401-600장)
- **핵심**: 천하 다투기
- **세력**: 반벽강산
- **클라이맥스**: 결정적 전투 승리

#### 5권: 통일 (601-700장)
- **핵심**: 천하 통일, 새 질서 건설
- **세력**: 천하
- **클라이맥스**: 등극/원만한 결말

### 집안 사소한 일형 (100만 자 표준)

#### 1권: 시작 (1-60장)
- **핵심**: 분가/빙의, 기초 자원 획득
- **자산**: 몇 무 박전/허름한 집
- **클라이맥스**: 첫 풍작, 생활 개선

#### 2권: 발전 (61-150장)
- **핵심**: 재배 확대, 가공 시작
- **자산**: 십여 무 땅, 작은 작업장
- **클라이맥스**: 판로 개척, 수입 배가

#### 3권: 성장 (151-250장)
- **핵심**: 산업 수립, 인력 고용
- **자산**: 큰 농장, 다수 작업장
- **클라이맥스**: 현지 부호가 됨

#### 4권: 정점 (251-350장)
- **핵심**: 상업 제국, 지위 상승
- **자산**: 체인 산업
- **클라이맥스**: 관방 인정 획득

#### 5권: 원만 (351-400장)
- **핵심**: 가문 번영
- **자산**: 세가대족
- **클라이맥스**: 원만한 결말

## 6. 경영 시스템 설계

### 농업 체계
| 유형 | 주기 | 이윤 | 리스크 |
|------|------|------|------|
| 식량 | 길음 | 낮음 | 낮음 |
| 채소 | 짧음 | 중간 | 중간 |
| 경제 작물 | 중간 | 높음 | 중간 |
| 약재 | 길음 | 높음 | 높음 |

### 가공 체계
- **초급 가공**: 건조, 절임, 제분
- **중급 가공**: 양조, 설탕 제조, 유 압착
- **고급 가공**: 약재 포제, 특색 식품

### 경제 순환
```
생산 → 가공 → 판매 → 자본 축적 → 확대 재생산
                ↓
           기술 업그레이드 → 효율 향상
```

## 8. 흔한 지뢰

### 반드시 피할 것
- ❌ 유수장, 갈등 없음
- ❌ 발전이 너무 순탄, 파란 없음
- ❌ 과학기술/제도가 시대 부적합
- ❌ 데이터 불합리

### 권장 방법
- ✅ 갈등과 파란 있음
- ✅ 발전에 장애와 대가 있음
- ✅ 과학기술/제도 점진적
- ✅ 데이터 합리적
