# 환상 로맨스 장르 템플릿 (Fantasy Romance)

> **핵심 셀링포인트**: 이세계 규칙 + 감정적 희생 + 숙명 반전. 기환의 세계에서, 종족과 운명을 초월한 사랑을 기록한다.

---

## 창작 제약 추천 (선택사항)
- 추천 제약 팩: Pack F11
- 범용 중첩: Pack U01

## 1. 핵심 유파 세분화

### 선협 로맨스류
- **특징**: 수선 세계의 사랑 미움
- **핵심 쾌감**: 선려쌍수, 도겁을 함께, 삼생삼세
- **대표작**: 《삼생삼세십리도화》《화천골》《향밀침침진여상》《유리》

### 현환 로맨스류
- **특징**: 가공 대륙의 기환적 사랑
- **핵심 쾌감**: 계약 인연, 종족 금기, 운명의 사람
- **대표작**: 《투라대륙》《투파창궁》《무동건곤》(로맨스 라인)

### 서양 판타지 로맨스류
- **특징**: 서양 판타지 배경의 사랑
- **핵심 쾌감**: 종족 금연, 마법 인연, 왕국 정략결혼
- **대표작**: 《트와일라잇》《뱀파이어 다이어리》《반지의 제왕》(로맨스 라인)

### 신화 로맨스류
- **특징**: 신선 요마의 사랑 이야기
- **핵심 쾌감**: 신선 부부, 인신 금련, 윤회 수호
- **대표작**: 《진석연》《동궁》《장상사》《여봉행》

## 2. 세계관: 환상 로맨스 사회학

### 종족 체계
| 종족 | 특징 | 인류와의 관계 |
|------|------|-----------|
| 신족 | 지고의 존재 | 모독 불가 |
| 선족 | 불로불사 | 고고재상 |
| 요족 | 수련 화형 | 차별받음 |
| 마족 | 천생 대립 | 적대 |
| 인족 | 수명 짧음 | 기본 |

### 금기 유형
| 금기 | 원인 | 대가 |
|------|------|------|
| 종족 금연 | 혈맥 불용 | 천벌 |
| 사도 금연 | 윤리 불용 | 사문 추방 |
| 원수 금연 | 입장 대립 | 족군 배신 |
| 인신 금연 | 수명 차이 | 윤회 추락 |

### 인연 유형
| 인연 | 특징 | 효과 |
|------|------|------|
| 계약 | 영혼 결합 | 생사상의 |
| 혈계 | 혈맥 연결 | 상대 감지 |
| 명정 | 천명으로 정해짐 | 피할 수 없음 |
| 윤회 | 생생세세 | 반드시 만남 |

## 3. 힘과 감정 체계

### 힘의 등급
```
범인 → 수사 → 진인 → 선인 → 신인 → 지고신
```

### 감정과 힘의 관계
| 감정 상태 | 힘에 대한 영향 | 스토리 작용 |
|----------|-----------|----------|
| 심마 | 돌파 방해 | 갈등 조성 |
| 쌍수 | 상호 증익 | 감정 승온 |
| 정겁 | 반드시 겪어야 함 | 감정 시험 |
| 순정 | 힘 폭발 | 클라이맥스 |

### 숙명 설계
```
전생의 인:
- 전생의 인연
- 미완성의 약속
- 진 빚

금생의 과:
- 운명적 만남
- 반복되는 선택
- 숙명 깨뜨리기
```

## 4. 클래식 쾌감 루틴

### 숙명적 만남
- **장면**: 운명이 정한 만남
- **쾌감**: 전생금생, 인연이 하늘의 뜻
- **핵심**: 전생 복선이 있어야 함

### 금기의 사랑
- **장면**: 종족/신분을 초월한 사랑
- **쾌감**: 사랑을 위해 모든 것에 맞섬
- **핵심**: 진짜 장애가 있어야 함

### 희생과 수호
- **장면**: 상대를 위해 모든 것을 희생
- **쾌감**: 감동, 가슴 아픔, 달콤함
- **핵심**: 희생에 가치가 있어야 함

### 고치에서 나비로
- **장면**: 시련을 겪은 후의 재회
- **쾌감**: 고생 끝에 낙, HE 결말
- **핵심**: 충분한 시련이 있어야 함

## 5. 대강 구조 (100만 자 표준)

### 1권: 만남 (1-60장)
- **핵심**: 운명적 만남, 감정 싹틈
- **관계**: 낯선 사이→서로 앎
- **클라이맥스**: 첫 번째 설렘

### 2권: 서로 알기 (61-150장)
- **핵심**: 깊이 알아감, 감정 상승
- **관계**: 서로 앎→미묘한 사이
- **클라이맥스**: 마음 확인

### 3권: 시련 (151-250장)
- **핵심**: 금기/장애 출현
- **관계**: 미묘→이별
- **클라이맥스**: 강제 이별

### 4권: 수호 (251-350장)
- **핵심**: 사랑을 위해 모든 것에 맞섬
- **관계**: 이별→재회
- **클라이맥스**: 금기 깨뜨리기

### 5권: 원만 (351-400장)
- **핵심**: 사랑하는 사람이 마침내 짝이 됨
- **관계**: 재회→영원
- **클라이맥스**: 원만한 결말

|------|------|-----------|
| 천진형 | 순수 선량 | 수호받음 |

| 숨겨진 신분 | 비밀 있음 | 신분 반전 |
| 전세환생 | 전생 기억 | 진상 찾기 |

### 남주 유형
| 유형 | 특징 | 여주에 대한 태도 |
|------|------|-----------|

| 복흑 마존 | 깊은 심기 | 몰래 수호 |
| 온화한 선군 | 옥처럼 온화 | 묵묵히 헌신 |
| 패도 제왕 | 강한 소유 | 독점적 총애 |

### 클래식 조연
| 역할 | 기능 | 결말 |
|------|------|------|

| 스승/어른 | 장애/지지 | 인정 |

## 7. 판타지 요소 설계

### 세계관 요소
| 요소 | 기능 | 예시 |
|------|------|------|
| 신기 | 감정 신물 | 정표 |
| 금지 | 핵심 장면 | 만남/이별 |
| 천겁 | 시련 | 함께 직면 |
| 윤회 | 숙명 | 삼생삼세 |

### 감정 도구
| 도구 | 기능 | 스토리 작용 |
|------|------|----------|
| 망정수 | 감정을 잊게 함 | 가슴 아픔 |
| 동심결 | 상대 감지 | 달콤함 |
| 혈계부 | 생사상의 | 인연 |
| 전세주 | 기억 보존 | 재회 |

### 장면 설계
```
달콤한 장면:
- 쌍수/치유
- 신식 교류
- 함께 천겁을 넘김

가슴 아픈 장면:
- 강제 이별
- 기억상실/오해
- 희생적 수호

클라이맥스 장면:
- 금기 깨뜨리기
- 운명에 맞서기
- 영원한 수호
```

## 8. 흔한 지뢰

### 반드시 피할 것
- ❌ 규칙이 불명확
- ❌ 감정 진행이 어색함
- ❌ 무의미한 시련
- ❌ 조연이 도구인간

### 권장 방법
- ✅ 규칙이 명확하고 일관적
- ✅ 감정에 복선이 있음
- ✅ 시련에 가치와 보상이 있음
- ✅ 조연에 인간미가 있음
