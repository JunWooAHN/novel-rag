# 과거 플랜 보관

이 디렉터리는 2026년 3~4월의 개발·재구축·설계 정리 플랜을 보존한다. 현재 구현의 실행 순서나 기술 선택 기준으로 사용하지 않는다. 기존 파일은 당시 결정과 설계 의도를 확인하는 참고 자료다.

- 현재 핵심 설계: [핵심 시스템 설계](../docs/systems/README.md)
- 현재 실행 계획 안내: [docs/plans](../docs/plans/README.md)
- 통합 실행 순서 제안: [2026-09-18 실행계획](../docs/plans/20260918-current-system-execution-plan-v0-1.md)

과거 플랜의 v1 전체 기능 이식, HelixDB, 인과 확률·등급, 고정 서버 구성은 현행 요구로 자동 승계하지 않는다. 재사용할 기능은 현재 작업의 완료 조건에 필요한지 확인한 뒤 가져온다.
