# 총강

## 이야기 한 줄 요약
HEMA 덕후 직장인 대붕이가 단종에 빙의, 빙의 자체를 신의 계시로 확신하고 잡탕 전투교리를 창시하여 철갑을 입고 "라이라이차차차!" 외치며 수양을 베고, 여진을 밟고, 대만·왜구를 넘어, 인도의 초석을 쥐고, 명나라의 천명을 교체하는 우당탕탕 대체역사.

## 창작 제약
- 반클리셰 규칙: UR-007(지식 전환에 시간/설비 필요) + AT-007(성장의 대가로 정신 상실)
- 하드 제약 (세계/능력/행동):
  1. 지식은 철강/HEMA/조선술에 극단 특화 — 정치/외교는 실전으로 깨져가며 배움
  2. 화약(초석) 절대 부족 — 인도 진출 전까지 화포는 사치품, 냉병기로 버텨야 함
  3. 빙의를 신의 계시로 확신 — 전투교리 창설, 전쟁할수록 광신 심화
- 주인공 결함: 전쟁광 + 소시오패스 + 광신 (빙의를 신의 계시로 확신, 전쟁할수록 심화)
- 반파 미러링: 홍치제도 이기기 위해 총력전 — 둘 다 신/천명을 명분으로 타인의 생명을 무자비하게 갈아버림. 대붕이는 진심으로 믿고, 홍치제는 정치적으로 이용

## 핵심 메인라인
- 메인라인 목표: 생존 → 수양 제거 → 여진 정벌 → 대만/왜구 해양전 → 인도 초석 확보 → 명나라 천명교체
- 주요 저항: 조선의 해양역량 부재, 초석/원자재 부족, MC의 급격한 광신 심화

## 핵심 암선
- 암선 주제: 평범한 HEMA 덕후가 광신도로 변해가는 과정 — "신의 전사인가 미치광이인가"
- 회수 노드: 수양 참수 장면에서 확신 굳어짐, 이후 전투마다 교리가 정교해지고 광기 심화

## 반파 계층 (개요)
- 소반파 (전기): 수양대군 (직접 참수로 제거 — 사이다 + 광신 점화)
- 중반파 (중기): 대만 원주민, 일본 왜구 (해양 진출 과정의 물리적 장벽)
- 대반파 (후기): 홍치제 시대 명나라 (기술 격차 + 천명 대 신앙의 최종 대결)

## 세계관/파워 시스템 소개
- 세계관 요점: 15세기 조선 → 기술 혁명 + 전투교리로 대체역사 분기 → 전 세계 확장
- 파워 시스템 요점: 기술 문명 (갑철→콘크리트/내화벽돌→제철소→조선→화포). 냉병기 강세기 → 인도 진출 후 화약 시대 개막.

## 복합 장르 융합 (선택)
- 주 장르 / 부 장르: 역사기발 / 밀리터리 코미디
- 융합 메커니즘 (한 문장): 광신도의 대진지한 전투교리 포교가 우당탕탕 코미디를 만들고, 그 위에 역사 대체역사의 기술 사이다가 얹힘
- 리듬 비율 (7:3 권장): 역사기발 7 : 밀리터리 코미디 3
- 핵심 갈등과 쾌감: 기술 사이다 + 전투 카타르시스 + "라이라이차차차!" 광신 코미디 + 정신 붕괴 서스펜스

## 주인공 성장선
- 시작점 상태: 평범한 직장인 (HEMA/리인액트먼트 덕후, 야금 지식 보유, 빙의에 혼란)
- 핵심 도약 노드: ①빙의를 신의 계시로 확신 ②갑철 대량생산 성공 ③수양 참수 + 광신 점화 ④제철소 완공 ⑤전투교리 체계화 ⑥대만 제압 + 해양 장악 ⑦인도 초석 확보 + 화포 완성 ⑧천명교체
- 종국 포지셔닝: "라이라이차차차!"를 외치는 미쳐버린 철갑 왕, 잡탕 전투교리로 세계를 뒤흔든 광신도 정복자

## 핵심 쾌감 마일스톤
- 제5장 부근: 첫 갑철 완성 — 조선에 없던 플레이트 아머의 등장
- 제10장 부근: 전투교리 첫 선포 — "내가 여기 온 것은 뜻이 있다" + 주변 경악
- 제25-30장: 수양대군 직접 참수 — 최대 사이다 + "이것은 성전이다!" 광신 점화
- 제50장 부근: 제철소 완공 + 여진 평정 — 기술 쾌감
- 제70장 부근: 첫 해양 전투 — 냉병기로 왜구 격파, 라이라이차차차 함성
- 제90장 부근: 인도 도달 — 초석 확보, 화포 시대 개막
- 제140-150장: 천명교체 — 명 대체, 최종 카타르시스
