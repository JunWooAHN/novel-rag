서비스 구조: 컨테이너 기반 환경

• 제공 환경은 VM이나 베어메탈이 아닌 Docker 컨테이너 기반입니다.
• 각각의 사용자 세션은 독립된 컨테이너 기반으로 제공됩니다.
• 컨테이너 환경 자체가 격리되어 있어 다른 사용자와 자원이 완전히 분리됩니다.
• Docker in Docker DinD 등 컨테이너 내부에서 추가 컨테이너 런타임을 구동하는 방식은
  지원하지 않습니다.
• Kubernetes 클러스터를 직접 구축하거나 운영하는 것은 지원하지 않습니다.
• pip, conda 등 패키지 설치 및 일반적인 Python 학습 워크플로우는 대부분 정상 동작합니다.

서비스 구조: 하위도메인 Proxy 접근 방식

• JupyterLab, VSCode 등 세션 내 앱은 하위도메인 subdomain
  Proxy를 통해 접근합니다.
  _ 예: https:// apps uuid .ainexus.ktcloud.com
• 사용자는 별도 포트 포워딩 없이 브라우저에서 바로 앱을 열 수 있습니다.
• 추가 포트가 필요한 경우 세션 시작 시 Preopen Ports 설정에서 지정합니다.
  _ 지정 가능한 포트 범위: 1025         65535
• SSH 접속 시에도 하위도메인 기반 주소와 별도 키/포트 정보가 앱 메뉴에서
  제공됩니다.
• 앱을 외부에 공개하면 외부 직접 접속 하위도메인 구조 이 가능하며, 해당
  세션으로 직접 접근이 아닌 반드시 Proxy를 통해 접근이 가능합니다.

서비스 구조: 사용자 공통 자원 정책

• GPU 종류/장수 및 CPU/memory 리소스는 사용자별로 상이함
• 세션당 최대 컨테이너: 2개

  균 값이 1 미만이면 유휴로 판단하고 자원을 회수
• 이미지 커밋: 최대 3장 보관 초과 시 기존 이미지 삭제 후 커밋

자원 관리: 자원 그룹

• 자원 그룹: 하드웨어 리소스를 관리하는 단위 그룹
   _ 프로젝트별로 자원 그룹이 할당됩니다.
   _ 사용자는 지정된 자원 그룹 내의 자원만을 이용해서 연산 세션을 생성할 수 있습니다.
   _ 사용자는 할당된 자원 그룹 내 자원을 자유롭게 사용할 수 있습니다.

    예시 NIPA H200 프로젝트에 H200 자원 그
    룹을 할당하고, NIPA A100 프로젝트
    에 A100 자원 그룹을 할당합니다.



    A 프로젝트에 소속된 사용자는 H200 GPU를
    사용하게 되고, B 프로젝트에 소속된 사용자
    는 A100 GPU를 사용하게 됩니다.

데이터 폴더




  데이터 폴더 페이지에서는, 사용자의 파일을 보존할 수 있는 다수의 개인, 프로젝트 폴더를 관리합니다.
  연산 세션의 기본 폴더는 세션이 삭제되면 같이 삭제되므로, 학습 데이터, 모델 체크포인트, 결과물 등은 반드시
  데이터 폴더에 저장해야 합니다.
  데이터 폴더는 세션과 독립적으로 존재하므로 세션이 삭제되어도 데이터가 유지됩니다.
  같은 폴더를 여러 세션에 마운트해 데이터를 공유할 수 있습니다.

Q. 제공되는 환경이 일반 VM 이나 Baremetal 환경이 아닌 컨테이너 기반의 서비스라고 설명 들었는데
차이점이 뭔가요?

A. 저희가 제공하는 GPU 학습 환경은 도커 컨테이너 Docker container 기반의 서비스 입니다.
도커 컨테이너는 애플리케이션과 그 종속성을 하나의 패키지로 묶어주는 기술입니다. 컨테이너는 호스트
운영 체제 위에서 실행되며, 별도의 운영 체제를 필요로 하지 않습니다. 학습 환경에서 도커 컨테이너를
사용할 경우 VM 환경보다 쉽고 빠르게 자원 확장, 축소가 가능하므로 효율적인 관리가 가능합니다. 특히
딥러닝 및 고성능 컴퓨팅 연산 자원관리에 최적화 되어 있습니다. 가령 장애 발생 시 중단된 시점부터
재시작하거나 동일 인스턴스를 시작하는 등, 다양한 장애 대응 옵션을 제공합니다. 따라서 성능 확보가
중요한 딥러닝 학습, 서비스 환경에서는 도커 컨테이너를 활용해 빠르게 할당/회수하는 시스템을 추천합니다.

Q. 제공받은 서비스에 도커 Docker 가 설치된 것으로 확인되는데 도커 데몬 docker daemon 이
돌아가지 않습니다. 제공 받은 환경에서 여러 개의 컨테이너를 띄워서 학습하려고 하는데 도움 부탁드립니다.

A. 저희가 제공하는 환경은 도커 컨테이너 Docker container 기반의 환경입니다. 사용하고 계시는 환경은
