# ad4f 코드 및 진행 중 스캔 경로의 범위 한정 독립 수락

**판정: 고정 코드판 `ad4f94668b380e4344c391deaaecc8b2ec104291100b0b4544879063a8534932`로 진행하는 가역 draft scan은 수락. 실제 전량 결과와 불변 릴리스는 대기.** 이 판단은 [ff89 합성 관통 검토](smoke-code-review-ff89ce4a.md) 이후의 Meta Bloom 재개 검증과 발행 게이트 반례에 한정한다. 엔지니어 보고상 실제 원격 코드 `/home/work/novel-toy-tune/reality-yago46-through-1899-20260929/build.py`도 같은 SHA이며 PID 39714가 facts 단계에 진입했다. 이 검토자는 원격 프로세스나 PG를 직접 재조회하지 않았다. 로컬 `tests/yago_history_sot`는 8/8 재실행 통과했다.

- 첫 실행판 e460의 Meta 원본 receipt SHA-256 `c8036e0a751584da8a4ecebe746397b135acbaf351ed867f700267a680a6fa2a`, 원본 Meta SHA `d6ddcf0803a13fcf69f3b32df2c6f817fc6a807c27bd9cae429287dbc460c020`, 6,221,779행 중 Meta 6,221,745행·header 34행이다. [Bloom 재개 검증](../run-evidence/first-attempt/meta-bloom-verification.json) SHA-256 `238073a1d56f52c0c160fe40095cf8eccb7b9f946ad4b6c7c447dd92a5d362aa`는 SQLite Meta의 distinct parent key 4,800,887개로 Bloom을 다시 만들어 SHA `1150aa65c46a14f2c4e037b58bfd91d52557deb7d0ed1becc4555bd988edd833`을 기록한다. ad4f 코드의 `completed_receipt('meta')`는 이 재구성 SHA와 실제 `meta-bloom.bin` SHA를 비교하고 불일치면 중단한다. 원본 720MB를 재스캔할 필요 없는 안전한 완료 단계 재사용 계약이다.
- 최종 합성 격리 시험 보관물 [`smoke-review-final.tgz`](../run-evidence/smoke/smoke-review-final.tgz) SHA-256 `de2f9bb55dcce8b34e220471b1074447a238484f9f79a1176a15465d6b327e97`, 안의 [`smoke-result.json`](../run-evidence/smoke/smoke-result.json) SHA-256 `eaae60102b15a49c4a788ef7c32038babc98954c58d4c10204727b99295f5884`. driver SHA `6ba5d4508202b6b2688f9a47d3516709d36e49f4fe60c45a7da01384b416c9d3`. 합성 DB는 claim 7/Meta 4/auxiliary 10/context anchor 1 및 동일 readback SHA `160a0f7a49719478ae8d50d7169ce8e7eb2e9a78cf2738e8a8359a6fcc4c22dc`를 보고한다. 잘못된 reviewer readback hash의 발행 거부 `true`, 발행 뒤 claim UPDATE 거부 `true`가 driver의 예외 경로 assertion과 결과에 대응한다. `synthetic-acceptance.json`은 시험용이며 실제 릴리스 독립 수락이 아니다.
- ad4f는 stage receipt에 실행 코드 SHA를 남긴다. 합성 `publish()`는 코드/manifest SHA 및 수락한 `readback_sha256`·receipt bundle SHA·행 수가 현재 PG 값과 다르면 발행을 거부한다. 이 작업의 실제 acceptance JSON은 **아직 존재하지 않아야 하며**, 전량 산출물 독립 대조 전에는 만들지 않는다.

남은 수락 조건: 선택 원본 각 파일의 full-scan SHA·물리행 및 mapped/excluded/unknown/failed 분모, H/K/taxonomy 컷오프·BCE/Meta 표본의 원 파일 행 재조회, staging PG의 claim/Meta/aux/context 고아·수량·readback 해시, Luna 기계 검증과 기존 r3·Wikidata 실행 보존을 확인한다. 그 다음 정확한 결과 hash에 묶은 별도 독립 수락판을 만들고 불변 발행 뒤 새 연결 readback을 검토한다. 현재 facts receipt가 미완료라는 엔지니어 보고를 결과 완료로 바꾸지 않는다.
