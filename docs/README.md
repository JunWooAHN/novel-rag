# 문서 안내

프로젝트의 주제별 시작점은 [글공장 문서 위키](wiki/index.md)다. 규범은 [핵심 시스템 설계](systems/README.md), 진행 순서는 [현행 실행계획](plans/README.md), 확인된 원문 적재 상태는 [코퍼스 검토](research/chapter-ingestion/review.md)에서 직접 확인한다. 위키는 원자료와 승인·캐논 원장을 대신하지 않는다.

Codex 작업의 역할 배정·재개는 [Astra 오케스트레이션 하네스](harness/README.md)에서 시작한다. 대화에서 확정한 작업 범위는 [세션 결정](harness/session-decisions.md), 중단점은 [현재 체크포인트](harness/current-checkpoint.md)에 기록한다.
