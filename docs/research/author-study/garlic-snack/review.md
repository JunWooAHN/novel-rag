# 마늘맛스낵 작품별 Sol 검토

검토일: 2026-09-24. **두 작품 모두 표본 기반 분석으로 수락**한다. 수락은 지정한 표본과 코드로 확인한 표제 구조에 한정되며 전편 정독이나 흥행 원인 검증을 뜻하지 않는다.

## 《고려, 신대륙에 떨어지다》 — 수락

- [보고서](works/goryeo.md)와 [표본 좌표](works/goryeo-samples.json)의 원문 사본 SHA-256은 `b1f719ca45c171fd28b20d074e3a508946a923b4c8ff64ebd4c0076834d19b82`다. G01~G06의 시작·끝과 식별 인용 시작·끝을 로컬 원문에서 독립 계산했다. code point, UTF-16, UTF-8 byte, 물리 행이 모두 일치했다.
- 장면 의미를 직접 대조했다. G01은 남미 고려 건국 약속과 상민의 고립·경제적 부담, G02는 해강의 인연 권유와 상민의 짧은 수용, G03은 재난에 따른 대외 지원·수출·파병 축소, G04는 아랍 연방의 선전포고와 베네치아 방위군의 카이로 후퇴, G05는 소비에트 내부 숙청·선포·고려 적대, G06은 태양풍 영향 감소에 대한 축하와 상민의 부재·계승 결의를 보여 준다.
- 첫 검토에서 앞부분 표제 누락을 발견해 같은 Luna에게 수정 요청했다. 수정본의 원문 줄 시작 `◈` 표제 500개를 다시 세었고, 제목이 모두 비어 있지 않으며 서로 다른 문자열임을 확인했다. 첫 표제는 8행 `◈ Universal Kingdoms`, 마지막은 164,028행 `◈ 소비에트 연방`이다. 명시적 `501화 소비에트 연방(2)`는 164,204행에 있다. 수정 보고서는 500개 `◈` **표제 순번**과 501~653화 **명시적 회차 번호**를 구분하며, 앞의 500개를 공식 1~500화로 확정하지 않는다. 300·400화 숫자행은 작가 공지의 문장이다.
- G04의 “카이로 함락”은 원문의 “카이로에서 도망쳤다”로 고쳤다. G06에서 태양풍 영향 감소와 상민의 출발 사이 직접 인과는 발췌만으로 미확인이라고 제한했다. 수정 사항을 원문과 재대조했다.

남은 한계: G01은 도입 일부, G05는 501화 일부다. G02의 수용 뒤 관계 변화, G05의 회차 말미 훅, `◈` 표제와 공식 1~500화의 일대일 대응, 표본 사이 사건은 확인하지 않았다. 결말 판단은 실제 653화 말미와 작가의 완결 후기에만 근거한다.

## 《폴란드 여왕 키우기》 — 수락

- [보고서](works/poland.md)와 [표본 좌표](works/poland-samples.json)의 6묶음(1, 4, 10~11, 251~252, 495~496, 524화)에서 code point 시작·끝, 물리 행, 식별 인용 위치를 로컬 원문으로 독립 대조해 모두 일치했다. 모든 묶음은 첫 해당 표제에서 시작해 마지막 해당 화의 다음 표제 또는 파일 끝에서 끝난다.
- 전체 표제 점검에서 일반 `N화 제목` 1~520화 520개와 작품명으로 시작하는 내부 표제 521~524화 4개를 따로 확인했다. 번호는 중복 없이 1~524가 이어진다. 이는 **보유 본문 표제**의 상태이고, 플랫폼 각 회차와 개별 대응은 확인하지 않았다.
- 장면 의미는 1화의 식당 만남·반지·보호 약속 뒤 폭발, 4화의 엘라가 얀 3세에게 미래 지식을 제안해 관심을 얻는 대화, 10~11화의 전술적 위험과 다음 화의 승리·영토/지위 결과, 251~252화의 여러 전선과 마제파의 복수 뒤 모힐라가 그를 살해하는 정치적 결말, 495~496화의 북해 해전·상륙·런던 함락을 원문에서 대조했다. 실제 마지막 524화는 화성 로켓 발사와 세진·아가타의 만남, 첫 화 보호 질문의 변주, 완결 표기와 작가의 말로 끝난다. 작가의 말이 495화를 이전 완결편으로 지목하는 것도 확인했다.

남은 한계: 표본 사이의 본문, 520~523화의 사건, 첫 결말 뒤의 개정·판매 이력과 독자 반응은 확인하지 않았다. 이 보고서의 연속 화 연결은 직접 읽은 10~11화, 251~252화, 495~496화에만 근거한다.

## 취합 기준

두 보고서 모두 관찰과 해석을 구분하고, 표본 밖의 전개·회차 말미·선택의 장기 결과를 메우지 않도록 제한했다. [작가 프로필](author-profile.md)은 수락한 표본에서 두 작품에 걸쳐 관찰되는 작법 후보와 작품별 차이를 나눠 기록한다. 원격 MD5가 없어 보관 사본과 Drive 원본의 바이트 동일성은 독립 검증되지 않았다는 [사전 점검](preflight.md)의 한계가 유지된다.
