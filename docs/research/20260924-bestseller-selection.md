# 보유 소설 중 베스트셀러·흥행작 분석 후보

확인일: 2026-09-24

**후속 사용자 결정:** 작품별 흥행 순서 대신 리첼렌·간다왼쪽·명원·마늘맛스낵 작가의 보유작을 우선한다. 아래 선정과 첫 두 작품 제안은 이전 참고안으로 보존한다. 현재 실행 기준과 담당자는 [작가별 분석 배정표](author-study/README.md)를 따른다.

## 결론

공유 드라이브의 보유 목록에서 흥행 근거가 확인되는 20편을 1차 후보로 선정했다. 이 중 A군 10편을 우선 분석하고, B군 10편은 비교 범위를 넓힐 때 추가한다. 이는 전체 보유작의 판매량 1~20위라는 뜻이 아니며, 공개 판매 순위·독자 규모와 분석 목적을 함께 고려한 선정이다.

분석 기준을 맞출 첫 두 작품은 《1588 샤인머스캣으로 귀농 왔더니 신대륙》과 《경제왕 연산군》을 제안한다. 사용자가 예로 든 1453~1600년 구간과 연관된 배경을 가지며, 농업과 경제라는 다른 출발점에서 역사 변화를 어떻게 서사로 만드는지 비교할 수 있기 때문이다. 이 제안은 공식 작품소개를 바탕으로 한 분석 설계이며, 아직 원문 분석으로 기법이나 품질을 확정한 것은 아니다.

## 확인 범위와 기준

- [98_소설 폴더](https://drive.google.com/drive/folders/18FL7KY4IfeQrqA8UlZQe5jyMUWny5OuD)의 소설 관련 하위 폴더 13개를 Drive `list_folder`로 확인했다. 로컬 동기화 경로는 macOS에서 읽기가 거부되어 커넥터를 사용했다.
- 해당 13개 폴더에서 파일 120개: TXT 106개, EPUB 1개, 7z 10개, ZIP 2개, 기타 1개. 원문으로 보이는 119개 파일을 파일명 기준으로 묶으면 103개 작품이다. 내용 해시로 동일성을 확인한 수치는 아니다.
- 루트의 뷰어·앱 폴더와 뷰어 설치 ZIP은 소설 목록에서 제외했다. 기타 파일명 `2`도 작품 수에서 제외했다.
- 파일명, 파일 크기, 보유 회차 표기, 공식 플랫폼 작품소개·흥행 지표를 확인했다. 소설 원문을 내려받거나 정독하지 않았으며, 본문의 누락·중복·인코딩은 아직 검증하지 않았다.
- 문피아 누적 조회수·선호작 수는 독자 반응 지표다. 판매 부수·고유 구매자·매출로 해석하지 않는다. 노벨피아는 플랫폼과 과금 방식이 달라 문피아 조회수와 단순 합산·서열화하지 않는다.
- 수치는 2026-09-24에 열람한 공식 페이지의 표시값이다. 웹 캐시와 실제 집계 시점은 서로 다를 수 있다. 반올림한 수치로 규모를 비교하고, 원값은 별도 JSON에 보존했다.
- 아래 ‘분석할 질문’은 공식 소개·태그를 바탕으로 정한 연구 질문이다. 작품을 읽고 해당 기법이 성공했다고 판정한 결과가 아니다.
