# 집필 기준 초안 v0.1 — 사용자 선택용

기준일: 2026-09-24. **현재 상태: 비교 결과에서 제안한 초안. 채택·승인 전.** [네 작가 비교표](author-comparison.md)의 기능 후보를 실제 집필 입력으로 옮기기 위한 결정지다. 특정 작가의 문장·줄거리·표현을 혼합해 복제하는 명세가 아니다.

## 먼저 읽을 1쪽: 결정할 것

**이미 승인된 시스템 순서**는 `작가가 정한 결말 앵커 → 필요한 선행 조건과 중간 사건 역설계 → 부족한 연결의 역사 창조(Backfilling) → 정방향 영향 검토 → 사용자 승인·역사표 잠금 → 장면 명세 → 집필·검수`다. 실제 집필에는 작품 사용 기간의 원역사 검토가 먼저 완료되어야 하고, 잠긴 중간 사건도 집필 제약이다. 학습은 **선택한 기존 원문을 정답**으로 두고 이전 문맥·가상 역사표·인물 인지 범위·이번 장면 명세를 역구성한 다음 작은 실험을 한다. 이후 결과나 정답 표현을 입력에 미리 넣지 않는다. 근거: [핵심 시스템 §1–5](../../systems/README.md), [실행 계획 R·A·B](../../plans/20260918-current-system-execution-plan-v0-1.md).

**아직 결정되지 않은 취향**은 아래 네 가지다. 오른쪽은 비교 표본을 바탕으로 한 **추천 기본값**이며 사용자 승인으로 기록하지 않는다. 한 항목에서 다른 선택지를 고를 수 있고, 장면 종류에 따라 조합을 달리할 수도 있다.

| 결정 | 짧은 선택지 | 추천 기본값(제안) | 판단 근거·상충점 |
|---|---|---|---|
| A. 설명과 장면 밀도 | **A1** 선택·반문·행동 속에서 설명 / **A2** 필요한 구간은 해설로 압축 / **A3** 장면과 짧은 해설 교대 | A3. 핵심 결정은 장면, 긴 시간·제도 경과는 압축 | [고종](../author-study/richerlen/works/gogjong.md)의 난징 논의와 후일담, [고려](../author-study/garlic-snack/works/goryeo.md) G03·G05가 서로 다른 형식을 쓴다. 전부 장면화하면 진도가 늦고, 전부 요약하면 선택의 감각이 약해질 수 있다. |
| B. 성취와 비용 | **B1** 성취의 통쾌함 우선 / **B2** 성취와 사람·제도의 비용 병치 / **B3** 비용·상실 중심 | B2. 중요한 성취에서만 누가 얻고 잃는지 확인 | [폴란드](../author-study/garlic-snack/works/poland.md) 10–11화의 보상과 251–252화의 죽음, [공정무역](../author-study/myeongwon/works/fair-trade.md) S06·S08이 보상 층위를 달리한다. 모든 승리에 희생을 붙일 필요는 없다. |
| C. 시점의 거리 | **C1** 주인공 밀착 / **C2** 주인공 중심에 필요한 주변 시점 / **C3** 다중 인물·역사가 시야 | C2. 주인공의 감정 축을 유지하되 정책의 외부 결과만 제한적으로 이동 | [콧수염](../author-study/richerlen/works/mustache.md)의 1인칭 밀착과 [순종](../author-study/richerlen/works/sunjong.md)의 해외 정치 시점, [공정무역](../author-study/myeongwon/works/fair-trade.md) S08의 귀환병은 서로 다른 장점을 보인다. 이동할수록 인지 누설 검사도 중요해진다. |
| D. 회차의 끝과 결말의 회수 | **D1** 사건 결과를 즉시 닫기 / **D2** 결과 뒤 새 질문 남기기 / **D3** 위험을 다음 화에서 곧 회수하기 | D2를 평상시 후보로, 실제 연속 화의 긴박한 사건에만 D3 | [1588](../author-study/ganda-left/works/1588.md) 521→522·600→601, [폴란드](../author-study/garlic-snack/works/poland.md) 10→11·495→496은 다음 화 회수 사례다. [1588](../author-study/ganda-left/works/1588.md) 661화와 [폴란드](../author-study/garlic-snack/works/poland.md) 524화는 도입 요소의 변주로 닫는다. 매 화마다 인위적 위험·훅을 넣는 기준은 제안하지 않는다. |

이 표에서 **선택이 필요한 것은 A–D의 선호와 적용 범위**다. 결말 앵커·사용할 기존 원문·학습 구간도 후속 단계에서 사용자가 고른다. 지금의 추천 기본값을 선택 결과나 확정된 학습 데이터로 간주하지 않는다.

## 제안하는 집필 입력과 검수 질문

아래의 **‘반드시 검토’·‘선택’·‘회피’ 모두 작법 제안**이다. 시스템이 이미 승인한 잠금·인지·역사 검토 규칙과 구별한다. 한 장면에 모든 필드를 억지로 채우는 양식이 아니며, 장면의 기능에 맞춰 비적용을 표시할 수 있다.

| 제안 등급 | 집필 전 입력·검수 질문 | 근거와 예외 |
|---|---|---|
| 반드시 검토 **제안** | 이번 장면이 다루는 승인 역사표 사건, 시점·장소, 직전 문맥, 현재 인물별로 아는 사실을 확인한다. 누가 무엇을 바라거나 피하는지, 이번 장면이 그 상태를 바꾸는지도 확인한다. | [시스템 §3–5](../../systems/README.md)의 동결 패킷·인지 구분에 맞추기 위한 작법 표현이다. 순수 이행·휴식 장면에 새로운 대형 갈등을 만들 필요는 없다. |
| 반드시 검토 **제안** | 정책·기술·역사 설명이 있을 때 독자가 바로 이해해야 할 판단, 정보의 출처, 상대의 반론 또는 현장 결과를 확인한다. 설명문 자체가 가장 명확하다면 사용한다. | [리첼렌 프로필](../author-study/richerlen/author-profile.md), [마늘맛스낵 프로필](../author-study/garlic-snack/author-profile.md)의 장면형·요약형 사례를 모두 인정한다. |
| 반드시 검토 **제안** | 중요한 선택의 결과가 실제로 확인되었는지, 위험만 제시된 것인지, 보상과 비용의 부담자가 누구인지 구별한다. | 고종의 난징 계획은 실행 전이고, 고려 G06의 직접 인과는 표본에서 확인되지 않았다. 위험을 이미 발생한 대가로 쓰지 않는다. |
| 선택 **제안** | 갈등을 상대의 반문, 대안 비교, 외부 시점, 수치, 감각, 반복 이미지 중 장면에 맞는 하나 이상으로 구현한다. | [명원 S03–S08](../author-study/myeongwon/works/fair-trade.md)과 [간다왼쪽 200·351·661화](../author-study/ganda-left/works/1588.md)의 기능은 서로 대체 가능하거나 병행 가능하다. |

## 선택 뒤 첫 학습 예시를 만드는 순서

1. 사용자가 A–D의 선호, 선택할 기존 작품·원문 구간, 문체 참고 범위를 고른다. 원문 구간은 학습 정답으로 유지한다. [작가 비교표](author-comparison.md)의 기능 후보와 실제 취향을 구별해 기록한다. 지금의 1588 파일럿은 학습 전 설계·검수 자료일 뿐 사용자의 이 선택을 대신하지 않는다.
2. **학습용 역구성 예시와 문체 reference를 만들기 전에** 개발 풀 내부 split과 겹치는 target·이전 문맥·파생물의 묶음 정책을 고정한다. 이미 분석한 7편의 원문·이전 문맥·발췌·파생 분석과 파일럿은 개발 자료이며 미관측 최종 test로 옮기지 않는다. 문체 reference는 train에서만 만든다. 이는 자료 지위와 분할의 결정이며 실제 학습 승인과 다르다.
3. 정답 구간의 **시작 이전**까지의 문맥을 자른다. 이전 문맥·현재 사실·인물의 지식은 장면 시점까지로 제한한다. 이번 장면이 실현해야 할 계획 사건은 결과 수준으로 별도 제공할 수 있다. 정답 장면 뒤 원문, 정답의 문장·대사·표현을 입력에 누설하지 않는다.
4. SOTA가 정답 구간에 맞는 가상 역사표·장면 목표·허용 사실·금지 조건을 역구성한다. 사건의 발생 시점, 독자 공개, 인물 인지를 나눠 적고 사람 검수로 원문과 모순·과잉 지정·표현 누설을 확인한다. 가상 역사표는 이 **학습 예시의 조건**이며 실제 작품의 승인 정사가 아니다.
5. 원문 정답과 검수한 입력을 묶는다. 소수 예시로 같은 입력의 기준선→짧은 학습→저장·재로드 결과를 비교한다. 문체·명세 준수·복제·비용을 따로 판정하며 좋은 결과를 이유로 사용자 취향을 소급 승인하지 않는다.

이 순서는 새 원고의 선행 생성이 아니라 [시스템 §5](../../systems/README.md)가 정한 기존 원문 정답의 입력 역구성이다. 실제 새 작품의 역사표 설계와 집필은 별도의 사용자 결말 앵커·승인·잠금이 갖춰진 뒤 진행한다.
