# 역설계 학습 후보 선정 정책 v0.1

이 정책은 [역설계 입력 계약](reverse-input-contract.md)에 넣을 **작은 개발 후보**를 고르는 절차다. 사용자의 작가 간 비교와 취향·집필 기준 선택 전에는 후보가 프로토타입일 뿐이며 학습 투입 대상이 아니다. [분석 현황](../author-study/README.md)의 7편과 그 이전 문맥·발췌·파생 분석은 이미 개발 자료다. 1588 파일럿도 후보 생성 전에 개발 풀로 고정하며 미관측 최종 test로 재분류하지 않는다.

## 절차

1. 검토된 작가 프로필·작품 분석의 초·중·후반 표본에서 목적이 뚜렷한 장면을 소수만 제안한다. 동일한 유형만 고르지 않고 정보 공개, 선택과 대가, 설명의 장면화 등 **대표성과 반례**를 함께 적는다. 다른 작가의 기법을 한 평균으로 합치지 않는다.
2. 후보의 시작과 끝을 **완결된 장면 행위** 기준으로 정한다. 정해진 글자 수 발췌나 회차 첫머리를 장면으로 간주하지 않는다. 선택·갈등·결과 또는 의도한 열린 끝이 범위 안에서 확인되는지 점검한다. 다음 회차 연결을 학습하려면 해당 말미와 필요한 다음 도입의 경계를 각각 표시한다.
3. 직전 문맥을 목표 시작 이전의 확인 가능한 범위로 묶는다. 장면 이해에 필요한 인물·장소·선행 사건이 충분한지 확인하고 중간에 읽지 않은 구간을 이어 붙인 줄거리로 채우지 않는다. 방대한 문맥이 필요하거나 필수 선행 사건을 확인할 수 없으면 보류한다.
4. 사건 시점, 독자 공개, 인물별 인지 시점을 분리해 검증한다. 원문을 본 후에야 안 결과는 `reconstructed_assumption`으로 표시하고 Writer의 인물 지식에 넣지 않는다. 실제 설정상 미래 지식이 있다면 획득 경로와 근거를 남긴다.
5. 로컬 원문 파일 hash와 대상·문맥의 좌표 단위 및 `[start,end)`를 기록하고 exact slice를 대조한다. 관련 분석 보고서 좌표도 연결한다. 분석 보고서의 식별 인용만으로 정답 구간을 대신하지 않는다.
6. [입력 계약](reverse-input-contract.md)의 검토 레코드와 Writer 입력을 만들고 **따로** 검수한다. 결과 수준의 계획 사건은 허용하지만 원문 문장·대사·표현 힌트, 장면 뒤 문맥, 무단 미래 지식을 제거한다. 정답은 별도 참조로 보존한다.

사용자가 나중에 고를 취향·집필 기준은 **어떤 원문 후보를 최종 채택하거나 보류할지** 판단하는 데 쓴다. 이미 존재하는 장면의 사건·문체가 그 기준과 다르면 후보를 보류하거나 반례로 남긴다. 원문을 선택 기준에 맞추려고 역사표·인물 동기·장면 목적에 없는 사실을 덧붙이지 않는다. 취향 미승인 상태에서도 원문 충실도와 계약 경계를 점검하는 개발 예제는 만들 수 있지만, 그 수락은 최종 학습 후보 채택이 아니다.

## 판정

| 판정 | 조건 |
|---|---|
| `accept_for_prototype` | 장면 경계가 완결되고, 이전 문맥이 충분하며, 인물 지식 경계를 설명할 수 있고, 원문 hash·좌표·정답이 대조되며, 문체/구조상 선정 이유와 반례 또는 적용 한계가 기록됨. 입력 누수 검수도 완료됨. |
| `hold` | 경계가 잘렸거나 이전 문맥의 공백이 있거나, 지식 시점·화자 범위·근거 좌표·입력 누수 중 하나라도 미확인. 필요한 확인 범위를 기록하고 재검수함. |
| `reject` | 원문과 좌표가 불일치하거나, 목표 장면을 이해시키려면 이후 원문의 결과·표현을 이전 문맥에 넣어야 하거나, 복구할 수 없는 지식 경계 충돌이 있음. 짧은 사유를 기록함. |

`accept_for_prototype`도 사용자 취향 선택, 사용 허락, 실제 학습 승인과 다르다. 이 단계의 후보와 계약 JSON은 설계·검수 자료이며 학습용 예시 또는 문체 reference가 아니다. 후속 **학습 예시·reference 생성 전에** 개발 풀 내부의 split과 겹침 정책을 고정한다. 동일 장면의 겹치는 target/window·이전 문맥·파생 질문·변형본은 split 사이 누수가 없게 묶고, reference는 train에서만 만든다. 분석된 원문을 미관측 최종 test라고 표시하지 않는다. 일반화 확인은 분석 밖의 허용된 자료 또는 독립적인 새 집필 과제로 별도 설계한다.

첫 파일럿은 간다왼쪽 《1588 샤인머스캣으로 귀농 왔더니 신대륙》 담당자가 준비하는 `pilot-1588/source-audit.md`와 `source-slices.json`의 후보 1개를 받는다. 해당 파일이 오면 위 조건으로 장면 경계·선행 문맥·인물 인지·좌표를 다시 판정한다. 그 전에는 기존 1화 관찰 구간을 수락된 후보로 취급하지 않는다.
