# 작가 비교에서 집필 기준·입력 역설계로

진행일: 2026-09-24. 사용자가 작가 비교와 집필 기준 정리를 승인했으며, 이후 단계는 **기존 원문을 정답으로 두고 입력을 역구성**하는 순서로 진행한다. 루트는 배정·진행 관리·결과 취합을 맡고 실무는 Sol·Luna가 수행한다.

**실행 결과:** 작가 비교표·집필 기준 초안·입력 계약의 교차 검토를 마쳤고, 원문 한 장면에서 만든 입력 예제는 Sol이 `accept_for_prototype`으로 수락했다. 사용자 취향 선택과 실제 학습 투입은 미확정이다.

## 이번 실행 범위

1. 검토된 네 작가의 분석을 공통 항목으로 비교한다.
2. 근거·반례가 연결된 집필 기준 초안과 사용자 선택지를 만든다. 미선택 취향을 승인된 규칙으로 표시하지 않는다.
3. 학습용 입력 역구성 계약과 후보 선정 기준을 마련한다.
4. 동일 작품 담당 Luna가 원문 후보 한 장면의 이전 문맥·경계를 확인하고, 계약에 따라 개발용 예제를 역구성한다. Sol이 독립 대조한다.

예제는 입력 계약을 검토하기 위한 자료다. 채택된 취향 명세나 학습 데이터셋으로 자동 승격하지 않는다. 새 원고 생성·실제 학습·공개 캐논 반영은 이 실행의 산출물에 포함하지 않는다.

사용자에게 제시한 선택: 설명 방식, 성취와 비용의 정서, 시점 거리. 응답 전에는 추천 기본값을 채택된 취향으로 표시하지 않는다.

파일럿은 《1588 샤인머스캣으로 귀농 왔더니 신대륙》 1화 게임 선택 장면이다. 이전 문맥은 Python 코드포인트 `[0,3022)`, 대상 원문은 `[3022,3925)`이며 CRLF를 보존한 사본을 참조한다. 이 예제는 입력 역구성·지식 경계 검토를 위한 작은 사례이고, 실제 역사·정치 사건의 역설계·Backfilling·정방향 영향 검토·역사표 잠금을 검증한 것은 아니다.

검토 과정에서 이전 문맥에 섞인 대상 장면의 정보와, split 선행 순서·계획 결과 입력의 모호성을 수정했다. 수정 및 대조 근거는 위 두 검토 기록에 남겼다. 7편과 이번 파일럿·사용 문맥·파생물은 개발 자료로 유지하며 미관측 최종 test로 사용할 수 없다. 실제 학습용 예시·reference 생성에는 별도의 split 정책 고정과 채택 절차가 필요하다.

원문은 [보관 목록](../../references/README.md), 선행 분석은 [작가별 분석](../author-study/README.md)을 참조한다. 실제 사용자의 채택 결정과 검토자의 근거 수락은 구별한다.
