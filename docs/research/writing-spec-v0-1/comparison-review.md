# 작가 비교·집필 기준 초안 독립 검토

검토일: 2026-09-24. 대상은 [작가 비교표](author-comparison.md)와 [집필 기준 초안](writing-criteria-draft.md)이다. [수락된 7편 분석과 작가별 Sol 검토](../author-study/README.md)의 프로필·보고서·표본 ID를 대조했다. 원문 7편을 다시 분석하지 않았다.

## 판정

**비교표는 선택 전 자료로 사용 가능하다.** 각 작가 칸이 작품·회차 또는 표본 ID와 연결되고, 한 작품만 보유한 간다왼쪽·명원의 작가 일반화를 유보한다. 리첼렌 3편과 마늘맛스낵 2편도 확인 표본 안의 반복으로 제한한다. 고려 G01의 부분 발췌, 고려 G05의 회차 끝 미확인, 폴란드 495화와 보유본 마지막 524화의 차이, 1588의 인접 회차 연결 등 중요한 반례와 관찰 범위가 각 [고려 보고서](../author-study/garlic-snack/works/goryeo.md), [폴란드 보고서](../author-study/garlic-snack/works/poland.md), [1588 보고서](../author-study/ganda-left/works/1588.md)에 맞게 표시되어 있다. 표본으로 판매 원인·작품 전체 빈도·독자 효과를 확정하지 않는다.

**집필 기준은 사용자 선택용 초안으로 사용 가능하다.** A–D 추천을 미승인 제안으로 표시했고, [핵심 시스템](../../systems/README.md)의 결말 앵커 역설계→Backfilling→정방향 검토→승인·잠금→장면 집필과 실제 집필 전 원역사 검토를 취향 선택과 구별했다. 가상 역사표를 학습 fixture로 한정하고 실제 승인 정사로 높이지 않은 점도 맞다. 아래 두 수정 요청은 editor의 수정본에서 반영된 것을 재확인했다.

| 중요도 | 근거·발견 | editor에게 요청할 변경 |
|---|---|---|
| **수정 완료** | 처음에는 「선택 뒤 첫 학습 예시를 만드는 순서」의 split 고정이 역구성 예시 뒤에 있었다. [현행 실행계획 R §3.1](../../plans/20260918-current-system-execution-plan-v0-1.md)은 **학습 예시·문체 reference 생성 전** split 고정을 요구한다. | 수정본 2번에서 split·겹침 정책을 예시·reference 생성 전에 놓았고, 분석된 7편·이전 문맥·파생물·파일럿의 개발 자료 지위와 실제 학습 승인과의 차이를 명시했다. |
| **수정 완료** | 처음의 “이미 확정된 사건만” 표현은 이번 장면이 **실현해야 할 계획 결과**까지 배제하는 뜻으로 읽힐 수 있었다. [핵심 시스템 §3·§5](../../systems/README.md)는 계획 결과를 Writer 명세에 허용한다. | 수정본 3번에서 이전 문맥·현재 사실·인물 지식의 시점 제한과 이번 장면의 결과 수준 계획 사건을 별도 입력으로 구별했다. 정답 문장·대사·이후 원문은 제외했다. |
| **유지** | 비교표는 설명의 장면화만 강제하지 않고 고종 후일담·고려 G03/G05·폴란드 495화 등의 요약·해설 반례를 제시한다. 집필 기준의 A3 추천도 승인된 취향이라고 주장하지 않는다. | 현재 상태 표기를 유지한다. |

추가 일반화 오류나 근거 ID 불일치는 확인한 검토 자료에서 발견하지 못했다. 추천 A3/B2/C2/D2는 사용자의 미승인 선택지이며 이 검토가 채택을 뜻하지 않는다.
