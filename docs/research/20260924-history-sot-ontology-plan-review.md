# 역사 SoT·온톨로지 조사 계획 독립 검토

검토일: 2026-09-24. **판정: 조사 계획 수락.** 다른 Sol이 [계획](../plans/20260924-history-sot-ontology-research-plan.md)을 [핵심 시스템 설계](../systems/README.md), [기존 영어 위키백과·Granite 계획](../plans/20260914-enwiki-granite-knowledge-ingestion-plan-v0-1.md), [공식 출처·로컬 관찰 지도](20260924-history-sot-ontology-source-map.md)와 대조했다. 검토자는 이 기록만 작성하고 계획 본문과 다른 소유 파일은 수정하지 않았다.

작성 담당은 초안의 로컬 XML 수량을 사용자 확인과 파일명·크기 재집계의 **19개, 46,445,603,916 bytes**로 고쳤다. 다운로드 완료와 공식 배포 목록 대조, 파일별 checksum, 압축·파싱 검증은 별도 상태로 남겼다. 네 검색 비교군에는 동일한 기간·상태·인지·릴리스 필터를 적용하도록 명시했다. 원역사 assertion 릴리스의 검토가 모든 원문 주장에 대한 새 사람 전수 승인 게이트로 읽히지 않도록 검토 방법과 예외 상향을 조사 대상으로 두었다.

계획은 불변 XML 출처, 출처·검토 상태가 연결된 원역사 assertion 릴리스, 최소 개념·관계·시간 계약, 재생성 가능한 키워드·벡터 인덱스를 구별한다. 온톨로지 전체 완성을 벡터 후보 검색의 선행조건으로 확정하지 않고, PostgreSQL + pgvector 목표와 기존 작품 역사표·정사의 승인 경계를 유지한다. R0–R5는 질문, 담당, 산출물, 종료 조건과 후속 파일럿의 공정 평가 방법을 정의하며 `1453–1600`은 예시 범위로 표시한다.

공식 배포 manifest·checksum 대조, 덤프 본문 파싱, gold 근거 구축, 임베딩, DB 구축, 검색 벤치마크, 실제 역사 자료 검토는 **미실행**이다. 따라서 이 판정은 역사 SoT의 최종 스키마, 온톨로지 채택, 검색 성능 또는 원역사 범위 검토 완료를 뜻하지 않는다.
