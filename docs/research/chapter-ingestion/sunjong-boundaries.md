## 경계 보류와 길이 이상치

`155화 부국강병`의 시작점은 확인되지만 다음 numbered marker는 `313화 런던 관광`이다. 두 시작점 사이는 1,755,946 code point이며 그 안에는 독립 꺾쇠 제목이 있지만 156–312 번호 표제는 하나도 없다. 이 때문에 155화 marker는 `numbered` + `hold`로 남겼고, 무번호 구간 전체를 155화 한 편으로 확정하지 않았다. `< 대장정 > 끝` 표식 역시 미확정 구간의 실제 회차 경계를 알려주지 않는다.

155를 제외한 연속 numbered 시작점 간격의 중앙값은 9,559.0 code point, 최댓값은 12,705 code point다. 155→313의 1,755,946 code point 간격은 길이 이상치로 식별되며 분할 추정은 하지 않았다. 모든 marker의 `label`은 `text[start_cp:start_cp+len(label)]`와 대조했고, 시작점 중복 없이 정렬되었음을 검증했다.

## 첫 50개 번호 표제

첫 1–50화는 정확한 번호 표제와 다음 번호 경계가 확인되어 **확정 50, 보류 0**이다. 이 count는 표제 경계 확인을 뜻할 뿐 본문 의미나 DB 적재 상태를 뜻하지 않는다.

기계 판독용 결과: [sunjong-boundaries.json](sunjong-boundaries.json). 전체 marker에는 작품명 앞머리, 번호 표제, 독립 제목 섹션, 322화 후기, 미확정 대장정 종료 표식을 원문 순서로 담았다.
