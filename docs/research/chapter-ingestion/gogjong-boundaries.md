# 폭군 고종대왕 일대기 원문 경계 메모

- 원문: `docs/references/richerlen/폭군 고종대왕 일대기 1-530 (완) 리첼렌 누락수정.txt`
- SHA-256: `9f3688428abd072b291a753246201cf621d11cd95621c2f755da401840ecc94c` (manifest 기록과 일치)
- 좌표: BOM과 CRLF를 유지한 `read_bytes().decode('utf-8')` 전체 문자열의 Python 코드포인트 0-based 오프셋.
- 경계 파일: `gogjong-boundaries.json`; 표제 라벨은 각 위치에서 원문 슬라이스와 대조함.

스캔 결과 `【…】` 표제 513개를 찾았다. 그중 명시적 번호가 표제에 붙은 것은 0개다. 따라서 첫 1–50회 매핑은 불가능하며 모든 표제의 `number_claimed`는 null이다. 제목 인덱스 순번을 공식 회차로 보지 않았다. 원문 앞머리의 복구 메모에 나열된 404, 405, 407, 408, 409는 본문 경계별 매핑이 아니다.

표제 이외에 숫자만 단독 표기된 소구획 28개(주로 1–5)가 있다. 이들은 제목 표제 아래 내부 구획으로 보이며 공식 회차 번호로 확정할 근거가 없어 JSON marker로 회차화하지 않았다. 중복 번호는 0개, 명시 회차 번호 불명 수는 표제 전체 513개다.

`【프롤로그】`는 명시 표제라 prologue로 표기했다. 본편 끝의 `［完］` 뒤에 나오는 `▣ 후일담`은 명시 구획 표식이라 note로 추가했다. 그 뒤의 제목들은 제목 경계로 기록했지만 별도 공식 회차임을 뜻하지 않는다. 마지막 `【역경과 승리의 역사】`는 끝부분 후일담 구간의 일부라 unresolved/hold로 두었다. 특히 마지막 공식 회차로 확정하지 않았다. `【예상치 못한 승전】` 다음 표제까지 26,891 코드포인트인 비정상 긴 구간도 unresolved/hold로 표시했다.

원문 경계 표식의 문자열 위치는 코드로 재검증했다. 이 결과는 표제 구조 기록이며, 본문 의미 분석이나 공식 연재 목차 대조는 포함하지 않는다.
