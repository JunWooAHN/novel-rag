# 프로젝트 자원 현황

기준일: 2026-09-25. 이 문서는 [제품 요구](../PRD.md)를 수행할 때 사용할 수 있거나 사용할 계획인 자원을 **확인 수준별로** 보여준다. 과거 문서의 사양을 현재 가용 자원으로 승격하지 않는다. 접속 주소·계정·키·토큰은 여기에 적지 않는다. 역할 목표와 구현 상태는 [핵심 시스템 설계](README.md)를 따른다.

| 자원 | 확인 수준과 근거 | 프로젝트에서의 역할 | 남은 확인 |
|---|---|---|---|
| 현재 로컬 MacBook Pro18,4, Apple M1 Max, 통합 메모리 64GB, CPU 10코어, Darwin 25.6.0 arm64 | 2026-09-25 현재 호스트에서 직접 관측한 사양. [64GB 맥북 운영 원칙](README.md#64gb-맥북-운영-원칙)은 목표 설계 | 로컬 집필·소량 임베딩·문서/코퍼스 작업의 후보 노드 | Gemma 변환본의 실제 지원·속도·메모리와 동시 실행은 미검증 |
| KT cloud H200 | 사용자가 2026-09-25 **사용 가능, 2026년 12월 말까지**라고 확인. [핵심 설계](README.md#6-교체-가능한-기술-변하지-않는-계약)의 첫 학습 목표와 [운영 시작 절차](../../toy-tune/ops/backendai/README.md) 기록 | 첫 Gemma 학습 실행 목표 | 실제 세션의 GPU·스토리지·이미지·접속 상태와 학습 성공은 미검증 |
| A40 GPU | 사용자가 2026-09-25 사용 가능하다고 확인. [과거 인덱스](../alt_history_factory_index_v3.md#13-하드웨어)의 구체 사양은 현행 증거가 아님 | 대체 GPU 실행 후보 | 연결 호스트·대수·메모리·실행 환경은 미확인 |
| HP ProLiant 2대 | [2026-04 서버 메모](system-setup.md)의 과거 기재. 현재 가용 여부는 사용자나 현물로 확인하지 않음 | 별도 서버/보조 자원 후보 | 현재 보유·가용 여부와 실제 사양 확인 필요 |
| 중앙 PostgreSQL + pgvector | [핵심 설계](README.md#6-교체-가능한-기술-변하지-않는-계약)의 목표 구조. 운영 연결·설치 확인 기록 없음 | 공용 원역사와 작품별 변경·검색의 장래 운영 DB | 실제 호스트·저장 위치·백업 및 복구 구현 미정 |
| Supabase의 독립 테이블 | 사용자가 2026-09-25 백업용으로 사용할 수 있다고 확인 | 원격 백업 저장 대상 후보 | 백업 쓰기·복원 검증은 미실행. Storage 버킷 제공 여부는 확인되지 않음 |

## 보유 데이터

| 자료 | 확인된 범위와 근거 | 사용·검증 경계 |
|---|---|---|
| 영어 위키백과 덤프 | 로컬 읽기 전용 관측: XML 19개와 체크섬·`_SUCCESS`를 포함한 21개 파일, 총 46,445,606,013 bytes | 원문 파싱과 체크섬 검증은 아직 하지 않았다. 정본 역사 assertion이나 검색 인덱스 완성을 뜻하지 않는다. |
| 보유 소설 원문 | [원문 manifest](../references/manifest.json)와 [독립 적재 검토](../research/chapter-ingestion/review.md): 7편 원문 61,533,769 bytes | 소설 분석의 개발 자료다. 회차별 1–50화 의미 분석이나 학습 투입 완료와 구분한다. |
| 분석용 SQLite | [원문 코퍼스](../../data/analysis/novel-corpus.sqlite3) 읽기 전용 관측: 158,130,176 bytes, 7작품·7원문판·17분할판·과거판 포함 5,233구간 | 현재 분할판 수·확정 경계와 구별한다. 원문 재사용을 위한 코퍼스이며 운영 정사가 아니다. [검토 기록](../research/chapter-ingestion/review.md) |
| 문서 검색용 SQLite | [문서 DB](../../data/document_harness/documents.sqlite3): 2026-09-25 적재·검증 시점 156판, `canon=true` 6판 | 문서 탐색용 별도 DB다. 이후 문서 채택에 따라 숫자가 바뀌며 작품 캐논을 뜻하지 않는다. [사용법](../../tools/document_harness/README.md) |

문서 검색용 SQLite와 원문 분석용 SQLite가 있다는 사실이 중앙 운영 DB·Gemma 학습·역사 설계 흐름의 완성을 뜻하지 않는다. [현재 실행 상태](../harness/session-decisions.md#확인된-실행과-미완료-작업)와 각 검토 기록에서 범위를 확인한다.
