|  |  |  |
| SSH 접속 포트 | 10022 | 설정 완료 및 외부 접속 확인 |
| 사용자 계정 | supr | 비밀번호 설정 완료 |
| 현재 OS | Ubuntu 24.04 LTS | 업그레이드 완료 |

🛠️ 주요 설정 메모

네트워크: 한 랜카드에 IP 2개 할당(Aliasing) 유지 중.

클린업: Pacemaker, Corosync 등 구형 클러스터 서비스 완전 제거 완료.

OS 상태: 20.04에서 24.04로 순차 업그레이드 완료.

🛠️ 주요 설정 메모

🔐 공통 보안 수칙

SSH 포트 관리: 모든 서버는 반드시 커스텀 포트(10022)만 사용하며, 22번 포트는 닫음.

방화벽 정책: ufw 활성화를 유지하며, 향후 Docker 서비스용 포트만 선별적으로 개방.

업데이트 관리: apt update && apt upgrade를 정기적으로 수행하여 보안 패치 유지.
