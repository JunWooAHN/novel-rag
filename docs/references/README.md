합계: 61,533,769바이트. 원래 파일명을 유지했고 Drive 원본은 변경하지 않았다.

[보관 목록과 해시](manifest.json)에 Drive ID·출처 URL·로컬 상대경로·크기·MD5·SHA-256·BOM·줄바꿈 정보를 기록했다. 커넥터가 반환한 텍스트를 UTF-8로 보존했으며, 담당자가 줄바꿈과 BOM·끝 개행을 응답과 대조했다. 7편 모두 로컬 크기가 Drive 메타데이터와 일치한다. 원격 checksum이 응답에 없어 원격 원본과의 바이트 동일성을 독립적으로 증명한 것은 아니다. 로컬 해시는 이후 파일 변경 확인에 사용한다.

원문은 이 폴더의 `.gitignore`로 Git 추적에서 제외했다. [분석 결과와 검토 상태](../research/author-study/README.md)는 별도로 관리한다. 파일명 회차와 공식 연재 회차가 다른 작품, 회차 표제가 없는 구간은 각 작가의 사전 점검 및 작품 분석에 한계를 기록한다.
