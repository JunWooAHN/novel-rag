# 문서 위키 작업 지침

이 폴더에서 문서를 정리할 때 [index.md](index.md)로 범위를 파악하고 [rules.md](rules.md)의 ingest·query·lint 순서를 따른다. 원자료는 기존 경로에서 보존하고, [sources.md](sources.md)에 출처·종류·상태·대체 관계를 등록한다. 주제별 종합에는 중요한 주장마다 원문서의 상대링크를 붙이며 `목표/계획/실행 확인/검토 수락/사용자 승인/미결정`을 섞지 않는다.

권위는 최신 사용자 결정, [시스템 기준](../systems/README.md), 확인 실행 결과, 현행 계획, 조사, 과거 문서 순이다. 구현과 설계, 회차 번호와 무번호 구간, 학습 fixture와 운영 캐논을 구별한다. 링크 존재·수치·시점·상태를 확인하고 [log.md](log.md)에 변경 행을 추가한다. 기존 로그 행은 고치지 않는다.

이 지침은 `docs/wiki/`의 문서 갱신에만 적용한다. 새 승인 게이트나 운영 코드·DB 작업 절차를 만들지 않는다. 위키 편집으로 승인 역사표·캐논·학습 투입 상태를 변경하지 않는다.
