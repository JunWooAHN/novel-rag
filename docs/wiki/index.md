# 글공장 문서 위키

기준일: 2026-09-24. 이 위키는 프로젝트 문서의 **주제별 읽기 지도**다. 설계 이유, 확인된 실행 결과, 미결정을 출처와 함께 연결한다. 원자료와 검토 기록을 보존하며, 위키 자체는 승인 역사표·공개 정사·원문·실험 원장이 아니다. 작품별 설정과 캐논을 축적하는 LLM Wiki는 별도 대상이다. [핵심 설계 §7](../systems/README.md#7-글공장-위키와-작품별-위키)

현재판은 핵심 기준·현행 계획·확인된 코퍼스 검토·선행 작가 연구를 연결한 **1차 종합**이다. [출처 색인](sources.md)의 모든 원자료를 전문 독해하거나 소설 원문 전체를 새로 분석했다는 뜻이 아니다.

| 읽으려는 것 | 페이지 |
|---|---|
| 시스템이 무엇을 만들고 어디서 사람이 결정하는가 | [역사 설계와 집필](system.md) |
| 재미 우선의 정본·개변 역사와 작은 앵커 이음새 | [문답 설계 정리](../systems/20260924-history-ontology-and-anchor-bridges.md), [역사 설계와 집필](system.md) |
| 원역사·작품 정사·코퍼스·검색의 경계 | [자료와 검색](data.md) |
| 작가 분석에서 입력 역구성과 학습까지 | [분석과 학습](writing.md) |
| 확인된 실행 상태와 다음 일 | [현재 상태와 미결정](status.md) |
| 다음 LLM의 수집·질의·검증·갱신 절차 | [위키 운영 규칙](rules.md), [폴더 지침](AGENTS.md) |
| Codex 역할 배정과 중단 후 재개 | [프로젝트 하네스](../harness/README.md), [세션 결정](../harness/session-decisions.md), [현재 체크포인트](../harness/current-checkpoint.md) |
| 위키 자체의 변경 이력 | [추가형 변경 로그](log.md) |
| 대상 문서 목록과 분류 | [문서 출처 색인](sources.md) |

판단 순서는 **최신 사용자 결정 → [핵심 시스템 설계](../systems/README.md) → 확인된 [실행 결과](../research/chapter-ingestion/review.md) → [현재 계획](../plans/README.md) → 조사 → 과거 문서**다. 이 순서는 새 사실을 승인으로 바꾸는 규칙이 아니다. 특히 [상세 아키텍처 v5](../20260914-novel-factory-architecture-v5.md)의 남은 SQLite 운영 전제는 현행 PostgreSQL 목표와 다르다. [시스템 설계 머리말](../systems/README.md), [실행계획 §2](../plans/20260918-current-system-execution-plan-v0-1.md#2-과거-플랜에서-현재-작업으로-바꾸는-기준)

이 위키의 **현재**는 문서와 검증 기록이 밝힌 시점의 상태다. 이후 코드를 재검증하지 않은 주장은 `목표`, `계획`, `확인 결과`, `미결정` 중 하나로 읽어야 한다. 작업 시작점은 [현재 상태](status.md), 규범의 원문은 항상 [핵심 설계](../systems/README.md)다.
