# 역사 설계와 집필

**목표 설계.** 작가가 결말·목표일·금지 전개를 앵커로 정한다. SOTA가 필요한 선행 조건과 중간 사건을 역산하고, 빈 간극을 창작 사건으로 채운다(Backfilling). 각 사건의 성립 조건·동기·자원·효과를 정방향으로 다시 검토하고 다른 앵커와 공개 사실의 충돌을 드러낸다. 확률·점수로 인과를 증명하거나 미해결 간극을 숨기지 않는다. [핵심 설계 §1–2](../systems/README.md#2-역사-설계의-규칙), [상세 설계 §8](../20260914-novel-factory-architecture-v5.md#8-핵심-역방향-인과-추론역사표-창조구속력-있는-집필)

```text
작가 앵커 → 역설계 → Backfilling → 정방향 검토 ↺
                                ↓
                    작가 승인 → 역사표 잠금
                                ↓
                 장면 명세 → Gemma 집필 → 검수
                                ↓
                 본문·실현 전표 승인 → 공개 정사
```

승인 범위의 **중간 사건까지** 잠긴 집필 제약이다. Gemma는 대사·묘사·장면 구성에서 자유롭지만 계획 사건을 바꾸지 않는다. 계획 변경에는 영향 검토와 재승인이 필요하고, 공개된 역사는 새 계획으로 덮어쓰지 않는다. 잠금은 권한, 프로그램 검사, SOTA 검수, 사람 승인으로 집행한다. [핵심 설계 §3](../systems/README.md#3-역사표가-먼저-본문은-그-실현)

원역사 검토와 작품 개변 검토는 별개다. 실제 집필 전에 작품의 사용 기간과 필요한 이전 배경의 원역사를 검토 완료해야 한다. 장면에는 계획·정사·인지 범위를 묶은 동결 패킷을 건네며, 인물이 모르는 미래를 주입하지 않는다. 본문에서 실현한 전표를 추출해 계획과 대조한 뒤 승인된 정확한 묶음만 공개 정사에 한 번 반영한다. [핵심 설계 §4](../systems/README.md#4-원역사와-작품-역사의-경계), [§5](../systems/README.md#5-모델과-데이터의-역할), [§6](../systems/README.md#6-교체-가능한-기술-변하지-않는-계약)

기간·인지 검색과 실제 저장 층의 경계는 [자료와 검색](data.md)에, 동결 입력을 학습 예시로 역구성하는 방법은 [분석과 학습](writing.md)에 정리했다.

**구현 상태.** 이 흐름은 현재 목표 설계이며 역사 역설계·잠금·검수·공개 게이트의 새 운영 구현 완료 기록이 아니다. 현재 `toy-tune`에는 준비·검증 CLI만 확인되었다. [실행계획 §1](../plans/20260918-current-system-execution-plan-v0-1.md#1-출발점), [§3](../plans/20260918-current-system-execution-plan-v0-1.md#3-실행-순서와-완료-조건)

**최근 문답의 초점:** 전 세계 정본 역사 온톨로지와 작품 개변 역사를 상호 분석하고, 작가가 놓은 여러 작은 앵커 사이의 자연스러운 사건·조건·상태 변화 이음새를 만든다. 실제 역사 사건을 앵커로 놓아 중간 전개의 복원 결과를 대조하는 평가도 목표다. 구간 입력/출력과 가림·평가 지표는 아직 제안이며, 역사 계산기나 DB가 구현됐다는 뜻은 아니다. [정본·개변 역사와 앵커 이음새 정리](../systems/20260924-history-ontology-and-anchor-bridges.md)

**확정한 품질 기준:** 재미가 먼저이며 역사 전문가도 납득할 만한 개연성이면 충분하다. SOTA가 앵커 사이의 필요조건을 역산하고 부족한 핵심 조건을 중간 사건·갈등·선택·대가로 메운 뒤 필요한 만큼 정방향 검토한다. 작가는 납득 가능한 후보 중 재미있는 경로를 선택·잠그고 Gemma가 본문으로 실현한다. 시간·앵커·승인 정사의 핵심 모순을 허용하거나 전문가 전수 승인 절차를 추가한 것은 아니다. [핵심 설계 §1–3](../systems/README.md#1-만드는-것), [이음새 통합 문서](../systems/20260924-history-ontology-and-anchor-bridges.md)
