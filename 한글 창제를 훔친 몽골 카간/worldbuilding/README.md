# 세계관 설정 파일

`worldbuilding` 디렉토리는 대체 역사 소설의 배경 이야기, 역사, 설정, 등장인물과 관련된 모든 문서를 중앙에서 관리하는 저장소입니다. 이 디렉토리는 소설 속 허구 세계의 복잡한 설정들을 포괄적이고 체계적으로 이해할 수 있도록 돕기 위해 만들어졌습니다.

## 파일 및 폴더 구조

- `setting.mdc`: 세계의 전반적인 설정과 배경을 설명합니다.
- `history.mdc`: 역사적 사건과 연표를 포함합니다.
- `characters/`
  - `main_character.mdc`: 주인공에 대한 상세 정보입니다.
  - `supporting_character_1.mdc`: 주요 조력자 1에 대한 상세 정보입니다.
  - `antagonist.mdc`: 주요 악당에 대한 상세 정보입니다.
  - `README.md`: 캐릭터 폴더에 대한 설명을 담고 있습니다.

## 파일 상세 설명

- **`setting.mdc`**: [setting.mdc 상세 설명 - 예: 주요 지리적 위치, 정치 상황, 사회적 규범, 기술 발전 수준]
- **`history.mdc`**: [history.mdc 상세 설명 - 예: 주요 역사적 분기점, 주요 갈등, 중요한 문화적 변화, 주요 사건 연표]
- **`characters/main_character.mdc`**: [주인공 상세 설명 - 예: 배경, 성격, 목표, 주요 관계 등]
- **`characters/supporting_character_1.mdc`**: [조력자 1 상세 설명 - 예: 배경, 성격, 주인공과의 관계, 역할 등]
- **`characters/antagonist.mdc`**: [악당 상세 설명 - 예: 배경, 동기, 능력, 주인공과의 대립 관계 등]
- **`characters/README.md`**: `characters` 폴더 내의 파일 구성 및 각 파일의 역할에 대한 간략한 안내를 포함합니다.
