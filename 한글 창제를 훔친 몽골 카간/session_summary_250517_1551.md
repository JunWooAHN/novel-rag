# 칸글 프로젝트 세션 요약 (2025-05-17 15:51)

## 1. 프로젝트 개요

- **프로젝트 명칭:** "칸글 창제를 가로챈 몽골 제국의 막내아들"
- **핵심 설정:** 현대 한국인이 1204년 칭기즈칸의 아들인 툴루이에게 빙의하여 한글(작중 '칸글')을 창제하고 역사를 바꾸는 대체 역사 소설입니다.
- **주요 장르:** 대체 역사, 착각계 개그물 (일부 캐릭터에게 미스터리/스릴러 요소 포함)

## 2. 프로젝트 구조 및 규칙

### 2.1. 폴더 구조

- `kangul/`
  - `worldbuilding/`: 세계관 설정 (자산, 캐릭터, 역사 기록, 세부 설정 등)
    - `history/`: 연도별 역사 기록 (`1204.mdc` 등)
    - `characters/`: 주요, 보조, 공통 캐릭터 설정 (`mains/`, `subs/`, `commons/`)
    - `settings/`: 문화, 정치, 기술 등 세부 설정
  - `series/`: 실제 소설 내용 (권 > 장 > 화 구성)

### 2.2. 주요 규칙 (`000-rule`)

- 파일 수정 전 사용자에게 변경 내용과 이유를 명확히 설명하고 명시적인 허가를 받아야 합니다.
- 사용자 허가 후 파일 수정을 실행합니다.
- 임의적인 파일 생성, 수정, 삭제는 엄금합니다.
- 변경 사항 제안 시 사용자가 이해하기 쉽도록 명확하게 설명합니다 (필요시 diff 형식 또는 비교 설명 활용).
- 답변은 번호 매기기 형식을 사용합니다.
- AI는 소설 작성 전문가 역할을 수행하며, 한국어를 사용하고 특정 소통 지침을 따릅니다.

## 3. 세계관 설정 (`1204.mdc`) 주요 내용

- 툴루이는 천연두 예방을 위해 우두법(종두법)을 도입합니다.
- 툴루이는 한글을 '칸글'이라는 이름으로 "창제"하며, 이를 신의 계시 또는 소르칵타니 베키와의 공동 작업 결과로 제시합니다.
- 툴루이와 소르칵타니 베키는 칸글이라는 존경에서 로맨스로 발전하는 관계를 구축합니다.

## 4. 주요 등장인물 설정 요약

### 4.1. 툴루이 (주인공)

- 현대 한국인 빙의자. 칸글 및 현대 지식을 신의 계시처럼 제시. "될 대로 되라"는 성격. 오해를 인지하지만 종종 순응.

### 4.2. 소르칵타니 베키 (제2사도, 히로인, '칸글교' 공동 설계자)

- 역사적으로 툴루이의 네스토리우스파 기독교인 아내. 지적이고 정치적 감각이 뛰어남. 툴루이를 예언자로 믿음. 칸글교에 기독교적 요소를 융합하며, 제1사도 기록의 보증인 역할.

### 4.3. 아륵 (제1사도, 불멸의 기록자, 수수께끼의 존재)

- 20대 후반/30대 초반 외모지만 나이를 먹지 않음. 완전기억능력자. 툴루이의 언행을 신의 계시로 믿고 기록하여 '칸글교' 원시 경전 형성. 툴루이의 정체를 어렴풋이 이해할 가능성. 트레이드마크: "그건 비밀입니다."

### 4.4. 사이드 무함마드 이븐 야흐야 알하사니 알바그다디 (제4사도, 칸글교 교리 설계자, 최초의 통합 칼리프)

- 무타질라 합리주의 성향의 수니파 학자. 툴루이 제국의 최고 종교 권위자. 툴루이의 '계시'를 무타질라 관점에서 해석하여 칸글교 교리 구축.

### 4.5. 윤기령 (제5사도, 칸글의 문학적 완성자, 제국의 목소리)

- 고려 출신의 언어 천재. 칸글의 문학적 형식(운율, 시가 등)을 완성하고 알타이어족 문법 통합 실험. 툴루이를 남몰래 연모. "보추" 캐릭터 속성 보유.

### 4.6. 수부타이 (제3사도, 칸글 전파의 강철 철퇴)

- 칭기즈칸의 사준사구 중 한 명. 칸글의 군사적 위력을 목격하고 툴루이의 절대적 지지자가 됨. 군 내부 칸글 전파 및 군사 작전을 통한 확산 선봉. 툴루이의 '건강 관리 프로젝트'로 건강 증진.
